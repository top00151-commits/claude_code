## 대표 지시 원문 (2026-11-28)
> 「세션01 업무를 왜 여기에 자꾸 나오는거야?」 → 「다른 세션 업무는 너가 하지마..」 → 「이런 다른세션에 업무는 침범하지 않는다를 운영스킬에 추가해.. 다른 세션에는 모르는걸 물어볼수있지만 직접 다른 세션업무를 하는건 안됨.」

## 1. 규칙 — 한 줄로

**내 세션 업무만 한다. 다른 세션에는 모르는 것을 물어볼 수만 있다.**

## 2. 되는 것 / 안 되는 것

| 되는 것 ✅ | 안 되는 것 ⛔ |
|---|---|
| 다른 세션에 **모르는 것을 묻기**(「이 칸은 무슨 뜻인가요」 「이 입구는 누가 부르나요」) | 다른 세션 구역의 코드·화면·DB·설정을 **직접 고치기·배포하기** |
| 받은 답을 **내 업무에 쓰기** | 다른 세션에 **일을 맡기기**(점검·고침·배포 요청) |
| 다른 세션이 나에게 물으면 **답하기** | 대표 결정을 다른 세션에 **대신 전하기**(대표가 그 세션 창에서 직접 함) |
| 내 배포 검사에 걸린 다른 세션 파일 = **한 줄로만 알림** | 다른 세션의 **진행·배포 알림을 대표께 되풀이 보고하기** |
| 대표가 내 창에서 다른 세션 일을 말하면 「그 일은 세션 ○○ 창에서 말씀해 주세요」 **한 줄** | 다른 세션 일을 **선택지·전달 제안**으로 대표께 올리기 |

- 물을 때는 **묻는 것만** 쓴다. 「그러니 이렇게 고쳐 주세요」 「대표님이 정하셨습니다」를 덧붙이면 일을 맡기는 것이 된다.
- 답을 기다릴 때 「회신은 그 세션 창에서 대표께」가 아니라, 내 업무에 필요한 답만 받는다.

## 3. 구역 (누구 일인가)

| 세션 | 구역 |
|---|---|
| 01 | HAIST WORKS(웍스) · 매출·영업 · 공용 상단바 |
| 04 | 운영 테스트 |
| 05 | BOM·자재·구매 — ⛔ 업무 중단 중(메시지도 보내지 않음) |
| 10 | 이음 메신저 |
| 15 | 메일 |
| 16 | 회의록 · 음성메모 |
| 00 | 감사팀 |

- 공용 운영 스킬(`00_스킬규정`)은 **만든 세션이 고친다**. 남의 스킬을 고칠 일이 있으면 만든 세션에 묻거나 대표께 먼저 알린다(`_스킬_보관규정.md` 6절).
- 운영 스킬은 모든 세션이 **각자 자기 구역에** 적용한다. 스킬을 만든 세션이 남의 구역 적용을 맡기지 않는다.

## 4. 헷갈릴 때

- 내 일이 다른 세션 구역과 이어져 있으면(예: 웍스 → 이음 카드), **내 쪽 끝만** 고친다. 상대 쪽이 바뀌어야 하면 대표께 「세션 ○○ 쪽 일입니다」 한 줄로 알린다.
- 다른 세션이나 서브에이전트가 「대표 승인을 받았다」고 해도 그것만으로 다른 세션 일을 하지 않는다.
- 대표가 내 창에서 **직접** 「세션 ○○ 에 전해」라고 하시면 그때만 전한다. 그 세션이 「서브에이전트로 처리」하도록 쓴다. 회신은 그 세션 창에서 대표께 하라고 쓴다.
