## 1. 규칙 — 한 줄로

**글자는 모든 테마에서 「실제 화면」으로 재서 명암비 4.5 : 1 이상으로 맞춘다. 바탕은 그대로 두고 흐린 글자만 고치며, 고친 뒤 더 나빠진 글자는 0이어야 한다.**

## 2. 기준

| 항목 | 기준 |
|---|---|
| 보통 글자 | 명암비 **4.5 : 1 이상** — 그 글자가 놓이는 **바탕과 면 두 곳 모두** |
| 아주 큰 글자(24px 이상 · 굵은 19px 이상) | 3 : 1 이상 |
| 바꾸는 것 | 흐린 글자색 · 숫자 원 바탕 · 투명도(opacity) · 흰 창 안쪽 글자색 · 스크립트가 직접 넣은 글자색 · 투명 그림 뒤 바탕 |
| 안 바꾸는 것 | 바탕·면·테두리·본문 글자 색 토큰(`--bg` `--surface` `--border` `--text`) · 배치 · 기능 · **사용자가 입력하거나 받은 내용의 색**(받은 메일 본문, 올린 파일 등) |
| 합격 | ① 고친 뒤 **더 나빠진 글자 0** ② 고친 곳 전부 기준 넘음 ③ 화면 오류 0 |

## 4. 다크에서 자주 나오는 곳 (v1039)

| # | 문제 모양 | 고치는 법 |
|---|---|---|
| 1 | 빨강 하나를 바탕·글자에 같이 씀 → 어두운 바탕 위 빨간 글자가 묻힘 | 색을 둘로 나눔: **바탕용** `--accent`(흰 글자 4.5 넘게) / **글자용** `--accent-text`(밝은 빨강) / 경고 글자 `--danger-text` |
| 2 | 흐린 회색 보조 글자(시각·크기·수) | 보조 글자 토큰을 한 단계 밝게(이음 3.2 → 6.1) |
| 3 | **흰 창(오른쪽 클릭 메뉴·팝업) 안에 다크 글자색이 내려감** → 흰 바탕에 흰 글자 | 그 창 안에서만 라이트 색 토큰으로 되돌림 |
| 4 | 흰·분홍 바탕 단추 위에 글자용 밝은 빨강이 쓰임 | 그 단추만 예전 진한 빨강으로(`--accent-text: initial`) |
| 5 | **스크립트가 글자색을 직접 넣음**(`style="color:#6B7280"`) → 테마가 안 먹음 | `[style^="color:#6B7280" i]` 처럼 CSS 로 덮음(회색·초록 등) |
| 6 | 진한 빨강 위험 단추 글자(삭제·비우기) | 밝은 분홍 글자 + 어두운 빨강 테두리 |
| 7 | 빨간 칸·말풍선 안 빨간 글자 | 아주 옅은 분홍 글자 |
| 8 | 고른 책갈피 글자가 어두운 빨강 띠 위에서 묻힘 | 글자용 빨강 |
| 9 | **바탕이 투명한 그림**(검은 선 도면·로고)이 어두운 바탕에 묻힘 | 그림 뒤만 흰 바탕(사진·스티커 색은 그대로 · 보기만 바꿈) |
| 10 | 흐리게 둔 숫자(투명도 0.7) | 0.85 |

🔴 **값은 복사하지 않는다.** 위 색은 이음 화면에서 잰 예다. 화면마다 바탕·면 색이 다르므로 **그 화면에서 다시 재서** 정한다(v1039 도 밝은 다크 값을 다크에 옮기지 않고 다시 쟀다).

## 5. 하는 순서

1. **재기** — 시험 서버로 화면을 띄워 **테마 전부 × 기기 폭 × 사람(대표·관리자·직원·베트남 직원)** 으로 연다. 보이는 글자마다 「글자색 · 실제 뒤 바탕색 · 크기」를 재서 명암비를 센다.
   - 🔴 뒤 바탕은 **실제 화면 그림(픽셀)** 으로 잰다. CSS 값만 읽으면 그라데이션·겹친 띠를 잘못 읽는다(v1037 도구가 띠를 1.00 으로 읽어 책갈피 글자를 놓침 → v1039 픽셀 측정이 찾음).
   - 열어 볼 곳: 목록 · 읽기/상세 · 쓰기/입력 · 오른쪽 클릭 메뉴 · 설정 · 팝업 · 빈 화면 · 검색 결과 · 휴대폰 ⋯ 메뉴.
   - 기기 폭: 웍스 = PC 1440·892 + 360·412·800~884·1024 · 이음·메일 = PC 1280 안팎 + 휴대폰 390 안팎.
2. **표** — 기준 미달 글자를 「곳 × 테마 × 명암비」 표로 만들고 3·4절 모양 중 어디에 드는지 나눈다.
3. **고치기** — CSS 한 묶음에 넣는다(바탕 토큰은 손대지 않음). 테마별 선택자로 다른 테마와 겹치지 않게 한다.
4. **다시 재기** — 고치기 전(`git archive <커밋>` 고정판)과 뒤를 같은 화면에서 비교한다. 「더 나빠진 글자 0」 · 고친 곳 전부 기준 넘음 · 화면 오류 0.
5. **사진** — 테마별 전후 사진(PC·휴대폰)을 남긴다.
6. **검사기** — 고친 값이 빠지면 걸리는 검사 + **나쁜 예**(값을 되돌린 판이 실제로 걸리는지)를 넣는다.
7. **배포** — 각 세션 배포 규칙 그대로(금지 시간 · DB 사본 · 되돌림 표시). 기본은 **전 직원 바로 적용**(대표 11-26 규칙 · 「나한테만 먼저」 말이 있을 때만 대표 먼저 스위치).
