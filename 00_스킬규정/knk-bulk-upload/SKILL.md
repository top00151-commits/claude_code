## 1. 규칙 — 한 줄로

**사람이 컴퓨터에 정리해 둔 폴더 그대로 한 번에 올라가야 한다. 빠짐·잘림·중간 상태가 없어야 하고, 끝나면 몇 장이 올라갔는지 숫자로 보여 준다.**

## 2. 폴더 읽기

| 할 일 | 방법 · 함정 |
|---|---|
| 끌어다 놓은 폴더 | `item.webkitGetAsEntry()` 로 안까지 다시 들어가며 읽는다. `dataTransfer.files` 만 보면 폴더가 파일 한 장으로 보인다 |
| 큰 폴더 | `readEntries` 는 **한 번에 100개 안팎만** 준다 → 빈 답이 올 때까지 다시 부른다 |
| 고르기 단추 | 「📁 폴더 고르기」(`<input type=file webkitdirectory multiple>`) 를 「파일 고르기」 옆에 따로 둔다 |
| 저절로 생기는 파일 | `Thumbs.db` · `desktop.ini` · `.DS_Store` · `~$` 로 시작하는 것은 조용히 건너뛴다(「올릴 수 없음」에 넣지 않음) |
| 휴대폰 | 폴더 고르기는 브라우저마다 다르다 → 화면에 「폴더째 올리기는 PC 에서」 안내 |

## 3. 폴더 = 묶음

- 폴더 안에 폴더가 여럿이면 **폴더마다 묶음 하나**로 보여 준다(이름 · 장수 · 종류). 사람이 이름·종류를 고치거나 폴더를 통째로 뺄 수 있게.
- 폴더 이름에서 정할 수 있는 것은 정해서 **보여 주고**, 사람이 「적용」을 눌러야 저장한다(`knk-no-silent-change`). 예: 「베트남어」 폴더 → 베트남어 방.
- 묶음은 **번호(ID)로** 잇는다. 이름으로 묶으면 같은 이름의 다른 묶음이 합쳐진다(v1054 책갈피 사고 직전에 찾음).

## 4. 파일 이름 → 보이는 이름

- 규칙은 **서버와 화면이 똑같아야** 한다. 한쪽만 고치면 미리보기와 저장 이름이 달라진다.
- 확인은 **실제 올릴 파일 이름 전부** + 예시로 서버 결과 = 화면 결과를 센다(v1054: 330 + 8 모두 같음).
- 앞 번호(`01_`)만 빼고 나머지 `_` 는 띄어쓰기로. 「마지막 `_` 뒤만」 같은 규칙은 이름을 자른다.
- 길이 한도는 실제 파일 이름에서 가장 긴 것을 재고 정한다. 한도를 넘으면 자르지 말고 그 줄에 표시해 사람이 고치게.
