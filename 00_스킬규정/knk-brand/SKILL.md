## 2. 구성

### 심볼마크 「KNK」 (높이 H = 1 로 잰 값 · 원본 선 실측)
- 폭 **3.07** · 두꺼운 세로 획 **0.254**
- **K · N · K** — K 는 두꺼운 획 + 약 45° 꺾인 팔, N 은 두꺼운 획 + 사선 + **오른쪽 획을 가는 줄 세 개로 나눔**(각 0.0875, 중심 간격 0.157)
- 세 줄을 합친 굵기(0.26) ≈ 두꺼운 획(0.254) → 멀리선 하나의 N, 가까이선 세 줄
- 둘레 여백: 안내서 최소공간규정 「사방 3.5」 · 가장 작게: 인쇄 심볼 세로 20mm, 시그니처 세로 8mm (화면 제안 16px)

- 심볼 N 의 **세 줄을 한 띠**로, **가로 · 약 +52° · 약 -52°** 세 방향의 띠가 엇갈려 삼각형을 이루고, 모든 띠가 끊기지 않고 이웃으로 이어진다.

## 3. 의미 (안내서 원문 요약)

- **HAIST Innovation** = **H**uman(인간) + **AI** + Be**st**(최고) — 「인간과 AI의 협업을 통한 혁신」. 철학: **인간 중심의 연결과 새로운 지식 창출**.
- **K와 K 사이의 N = 연결과 조화** — 인간의 지식과 과학적 지식을 연결해 새로운 가치를 만들고 끊임없이 발전한다.
- **N의 세 줄** —
  1. **점진적인 변화와 발전 (Transformation)** — 어제보다 나은 내일
  2. **혁신적인 기술 (Innovation)** — AI와 최첨단 기술로 시대를 선도
  3. **미래를 향한 비전 (Future Vision)** — 다가올 변화를 예측하고 미래 기술을 개척
- **패턴** — KNK의 3선을 사선으로 바꿔 **발전과 미래**를, 모든 선이 유기적으로 이어진 모양으로 **KNK의 자동화 시스템**을 뜻한다.
