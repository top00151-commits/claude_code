| 항목 | 기준 |
|---|---|

## 3. 휴일 목록 — 공용 엔진에서만

- 휴일은 **휴일 목록 라이브러리(holidays)로 해마다 저절로** 만든다 — 웍스 `HOLIDAYS_KR` / `HOLIDAYS_VN`. 음력 휴일·대체 휴일 포함.
- ⛔ **화면이나 코드에 휴일 날짜를 직접 적지 않는다**(기준 문서 §7-3).
- 휴일 이름 언어는 코드로 못박는다 — `language="ko"` / `language="vi"` 항상 명시(서버 환경에 맡기면 영어 이름이 나와 제헌절이 휴일로 잘못 뜬 일이 있다 · z1041).
- 대체 휴일인지는 **공용 판정 하나로만**(`_hol_is_alt` / `isAltHol`) — 화면마다 「대체」「nghỉ bù」 글자를 직접 검사하지 않는다(대소문자가 달라 베트남 대체 휴일이 한 번도 안 맞은 일이 있다).
- 회사 예외(제헌절 빼기 · 근로자의 날 더하기)는 엔진 한 곳에서만.

## 4. 어디에 쓰나

| 모양 | 쓰는 것 |
|---|---|
| 날짜 입력 칸(납기·마감일·기간 등) — 웍스 | `KnkCal` — `input[type=date]` 면 저절로 붙는다. 나중에 생긴 칸은 `KnkCal.attach(el)` |
| 날짜 입력 칸 — 이음 | 이음 공용 날짜 고르기(`class="knk-date"`) |
| 월 달력(수주 납기 · 일일 업무 · 회의 일정) | 웍스 `_build_month` 모양 / 이음 `_knkCalGrid` — 2절 모양 그대로 |
| 일정표 날짜 머리글(1일~말일 가로 한 줄 · 작업일정표·전사일정표) | **이것도 달력이다.** `_calendar_day_marks()` 로 요일 색 + 9px 「K」「V」 + 이름은 마우스 올리면 |
| 메일 날짜 고르기 | 웍스와 같은 `KnkCal` |

- 납기처럼 「남은 날 수」 색이 필요한 달력은 기준 문서 §4-4 색(지연 연빨강 · 지남 회색 · 3일 안 주황 · 7일 안 노랑 · 여유 녹색)을 그대로 쓴다.
- 날짜의 하루 경계는 **입력하는 사람의 소속** 기준(본사 = 한국 시간 · 베트남 = 베트남 시간). 「오늘」 표시도 같은 기준.

## 5. 만들 때

- 새 달력을 짜지 말고 위 공용 것을 불러 쓴다. 꼭 새로 그려야 하면(좁은 칸 등) 휴일은 엔진에서 받고 2절 색·표시를 그대로 따른다.
- ⚠ 이음은 휴일을 두 곳에서 받는다 — 서버 `/api/holidays`(회의 달력)와 미리 만든 파일 `static/holidays_kr_vn.json`(날짜 고르기 · 2026-11-28 확인 = 2032년까지 들어 있음). 미리 만든 파일은 저절로 늘지 않으므로 **새 화면은 서버 쪽(`/api/holidays`)을 쓴다.** 파일을 쓰는 곳을 고칠 때는 해마다 다시 만드는지 확인한다.
- 휴일 자료가 비면(서버 재시작 뒤 등) 표시만 빠지고 달력은 그대로 떠야 한다 — 오류로 달력이 안 뜨면 안 된다.
- 테마(다크 등)에서도 빨강·파랑·K·V 가 또렷한지 `knk-text-contrast` 로 잰다.
