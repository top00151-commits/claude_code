## 1. 규칙 — 한 줄로

**직원을 보여 주거나 고르는 곳은 「🇰🇷 본사 N」「🇻🇳 베트남법인 N」 책갈피로 나누고, 부서 순서대로, 「사진 + 이름 + 직책 · 부서」 한 줄로 보여 준다. 한 목록에 두 법인을 섞어 늘어놓지 않는다.**

## 2. 책갈피

| 항목 | 기준 |
|---|---|
| 책갈피 | 맨 위에 가로로 두 개 — **「🇰🇷 본사 N」「🇻🇳 베트남법인 N」**(N = 그 책갈피의 사람 수, 동그란 작은 숫자) |
| 고른 책갈피 | 진한 회사 색 바탕 + 흰 글씨 · 고르지 않은 쪽 = 연한 회색 바탕 |
| 처음 열 때 | 본사 책갈피 · 본사에 사람이 없으면 베트남법인 |
| 셋째 책갈피 | 외부 손님이 끼는 곳(손님 방 등)에서만 **「🤝 외부」** 를 셋째로 둔다(이음 v1019) |
| 비어 있을 때 | 그 책갈피 안에 「해당 인원이 없습니다.」 — 책갈피 자체는 지우지 않는다(수 0 으로) |
| 화면 언어 | 베트남어·영어 화면이면 책갈피 이름도 그 언어로(이음 `users.corp.vn` 등 번역 열쇠) |

**본사·법인 나누는 기준 = 부서.** 부서 정렬 열쇠가 `02_VN/` 으로 시작하면 베트남법인, 나머지(`01_KOR/` · 분류 안 된 부서)는 본사. 이름·언어·사번 모양으로 짐작해 나누지 않는다.

## 3. 순서

1. **부서 순서** — 부서 번호 순. **「00_총괄」이 항상 맨 앞**(회사 부서 나열 규칙과 같음). 그다음 01, 02 …
2. 같은 부서 안 — 지금 이음 화면의 순서(서버가 준 순서)를 그대로 쓴다. 화면마다 새 정렬을 만들지 않는다.
3. 봇·잠긴(퇴사) 계정은 명단에 넣지 않는다(사람 수 세기 규칙과 같음).

## 4. 한 줄 모양

```
[☐]  (사진)  이름(굵게)  직책 · 부서                    상태
```

| 칸 | 기준 |
|---|---|
| 고르기 칸 | 여러 사람을 고르는 곳만 맨 왼쪽 네모 · 보기만 하는 명단은 없음 |
| 사진 | 동그란 얼굴 그림 · 없으면 이름 첫 글자 + 사람별 색 |
| **이름** | 굵게. 베트남 직원 = **「베트남 원래 이름 (한글 부르는 이름)」** 예) `Nguyễn Văn Khải (카이)` — 한국어 화면 기준. 베트남어 화면이면 베트남 이름만, 본사 직원은 영어 이름(이음 `_dispName`) |
| 직책 · 부서 | 이름 옆에 작은 흐린 글씨로 「직책 · 부서」 예) `프로 · 01_기술영업팀` · `과장(팀장) · 02_설계팀` |
| 상태 | 맨 오른쪽 끝(접속·오프라인·회의 중 등) — 상태가 필요 없는 명단이면 생략 |

- 이름 표기를 화면마다 따로 짜지 않는다 — 이음은 `_dispName`·`userPickerHtml`, 웍스는 이름 표시 공용(`vname_full`)을 쓴다.

## 5. 검색과 고르기

- 검색 칸은 책갈피 위. **검색은 지금 보고 있는 책갈피 안에서만** 걸러 준다. 이름·직책·부서·영어 이름·아이디 모두로, 한글 초성으로도 찾는다.
- **책갈피를 바꿔도 이미 고른 사람은 그대로 남는다.** 「N명 선택」 수는 두 책갈피를 합친 수.
- 고른 사람을 저장할 때는 **이름이 아니라 번호(사용자 번호·사번)** 로 저장한다(연결은 항상 번호).

## 6. 만들 때

- **이음**: 새 사람 고르기 창은 `_groupedPickerHtml` + `_wireUserPickerSearch` 를 그대로 다시 쓴다(방 만들기 창과 같은 배선).
- **웍스·메일**: 같은 모양으로 맞춘다 — 책갈피 두 개 · 부서 순 · 「이름 직책 · 부서」 한 줄. 웍스에 공용 조각이 없으면 **한 곳에 공용 조각을 만들고** 화면마다 그것을 쓴다(화면마다 복사 금지).

- 글자 또렷함은 `knk-text-contrast`, 칸 높이·여백은 `knk-even-layout` 을 함께 따른다.
