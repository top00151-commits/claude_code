## 1. 진척률 모델 — 사업부별 차별화

### 01 검사기 (일정 중심)
- **사이클**: 2주 내외 (빠름), 월 ~200건
- **세부항목 % 폐기** → 부서별 시작일/완료일로 추적
- `DEPT_SUB_ITEMS` 모두 빈 리스트
- 부서진척률(K11): 시작일 입력=50%, 완료일 입력=100%
- PMS 전체 진척률 = 완료 부서 수 / 참여 부서 수

### 02 자동화 (% 진척률)
- **사이클**: 4-8주 (길음), 월 10-20건
- 세부항목 % 유지 + 항목별 예정일 짝
- 부서진척률(K11): 본인 부서 세부항목 평균 (자동 계산)
- PMS 전체 진척률 = 참여 부서 평균 (제외 부서 분모 제외)

### 🐛 수정된 버그 (02 자동화)
1. **`_collect_dept_progress`**: `_has_pic`(bool=True)이 평균에 1.0으로 오염 → bool 제외, sub_vals만 평균
2. **`_write_progress`**: `avg/100` 이중 축소 (90%가 0.92%로 표시) → `/100` 제거
3. **중복 관리코드**: 빈 행이 데이터 행 덮어쓰기 → 빈 데이터 덮어쓰기 방지

## 2. 빈 칸 = 해당없음 (02 자동화)

| 입력 | 의미 | 진척률 평균 |
|------|------|-------------|
| 빈 칸 | 해당없음 | **분모 제외** |
| 0 | 미착수 | 분모 포함 (0%) |
| 0.5 | 50% 진행 | 분모 포함 |
| 1.0 | 100% 완료 | 분모 포함 |
| 전 항목 빈 칸 | 부서 해당없음 | K11 = "해당없음" 표시 |

- 입력값 0~100 정수도 자동 0~1 정규화
- '제외' 부서는 PMS에서 분모 제외

## 4. 항목별 [%·예정일] 짝 배치 (02 자동화)

### 구조
```
C12: 상세컨셉(%)   C13: 예정일   ← 짝 1 (청)
C14: 3D/2D설계(%)  C15: 예정일   ← 짝 2 (주황)
C16: BOM작성(%)    C17: 예정일   ← 짝 3 (청)
...
```
- 한 항목 = 진척률 컬럼 + 예정일 컬럼
- 항목별 청(#0277BD)·주황(#EF6C00) 교대 (옵션 B 시각 그룹)
- 각 "예정일" 컬럼에 항목별 메모 (어느 항목 예정일인지 명시)
- `_collect_dept_progress` 컬럼 인덱스 `i*2` 적용

## 5. 메모 (코멘트) 개선

### 박스 크기 + 폰트
- 박스: 500×220 → **720×420 px**
- 폰트: 9pt → **11pt 맑은 고딕**
- `fix_comment_font_size()` 신규 — comments xml의 `<text><t>`를 `<r><rPr><sz>` 형태로 재작성

### sync 후 보존 (중요 버그 수정)
- **문제**: openpyxl `wb.save()` 시 VML 박스가 144×79로 되돌아감
- **해결**: sync.py 모든 `wb.save()` 후 `_fix_after_save()` 호출 (VML + 폰트 재적용)
- 01·02 sync.py 모두 적용

### 메모 내용
- 빈 칸 = 해당없음 안내
- 0/0.5/1.0 입력 의미
- 날짜 컬럼 "★ 날짜 입력 (% 아님 ⚠️)" 경고

## 6. 헤더 가독성

### 부서명 (PMS) — 4글자 룰
- 4글자 초과 시 `4글자\n나머지`
- 예: `개발혁신팀` → `개발혁신`+`팀`, `제조기술1팀` → `제조기술`+`1팀`
- 부서 컬럼 너비 7 통일

### 세부항목 (부서 파일) — 2줄 wrap
- `wrap_label_2lines()` — 영문↔한글 경계 우선 + 균형 분리
- 예: `BOM작성`→`BOM`+`작성`, `3D/2D설계`→`3D/2D`+`설계`, `IO맵/리스트`→`IO맵/`+`리스트`
- 최대 2줄 보장 (3줄 방지)
- 입력칸 너비 7 통일

### R2 업데이트 일시
- 우측 3컬럼 병합 → "업데이트: 2026-05-03 12:57" 풀 표시 (잘림 방지)

```
M-260330       (첫 번째)
M-260330-2     (둘째) ← 잘못
```

### 변경 후 (정정)
```
M-260330       (첫 번째)
M-260330-1     (둘째)
M-260330-2     (셋째)
```
- sync.py `n = 2` → `n = 1`
- V2·V3 01·02 모두 코드 수정
- 기존 데이터 정정: `-N` → `-(N-1)` 시프트
  - V2 검사기·자동화 ✅
  - V3 검사기 ✅
  - V3 자동화 ⏸ (PMS 파일 잠금으로 미완 — 파일 닫고 재실행 필요)

- **우려**: 무거운 시스템 = 안 쓰는 시스템
- **검토된 옵션**:
  1. 현행 유지 (7팀 추적)
  2. 외주 팀만 추적 (설계·구매·베트남)
  3. PMS 단일 시트 (부서 파일 전부 폐기)
  4. 단순 완료 체크
  5. 자동 추적 (HAIST WORKS 연동)
  6. 진행단계 칸반 1열
  7. 색상 신호등 (자동)
- **빅터 최종 권고**: 검사기 부서 파일 7개 폐기 → PMS 단일 운영
  - 부서담당자 컬럼만 유지 (책임 명시)
  - 진행상태 + 비고로 외주 표시
  - 자동화 사업부는 별도 (현행 유지)
- **결정 대기 중**
