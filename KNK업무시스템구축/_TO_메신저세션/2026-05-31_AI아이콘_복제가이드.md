## 0. 무엇을 만드나

**사용자 아바타처럼 생긴 원형 배지 안에 "AI" 텍스트.** 색으로 AI 동작 상태를 표시:

- 🔵 **파란 원** = AI **동작/사용 가능**
- 🔴 **빨간 원** = AI **미동작 또는 그 사용자가 사용 불가**
- 글씨는 **흰색**(파랑·빨강 양쪽 배경에서 모두 잘 보임)
- 원 둘레에 **흰색 테두리**(배경과 분리)

크기: 기본 **50px**(큰 표식), 작은 변형 **22px**(헤더 등).

---

## 1. 핵심 원리

```
서버에서 ai_on(bool) 계산  →  템플릿에 전달  →  class="ai-avatar on/off"
   (AI 켜졌나·이 사용자 쓸 수 있나)              파랑/빨강 자동
```

- **색은 CSS가 `.on`/`.off` 클래스로 결정** — 템플릿은 `{{ 'on' if ai_on else 'off' }}` 한 줄
- "AI" 글씨는 고정, 배경색만 상태에 따라 바뀜

## 2. [복붙] CSS — 원형 AI 아바타 배지

```css
/* AI 표식 = 아바타형 원형 배지. 동작=파란 원 / 미동작=빨간 원, 글씨 흰색 */
.ai-avatar { display:inline-flex; align-items:center; justify-content:center;
             width:50px; height:50px; border-radius:50%; color:#fff; font-weight:800;
             font-size:17px; letter-spacing:.03em; line-height:1; flex-shrink:0;
             border:2px solid #fff; box-sizing:border-box;
             text-decoration:none; cursor:pointer; box-shadow:0 1px 4px rgba(0,0,0,.20);
             transition:transform .12s ease, box-shadow .15s ease; }
.ai-avatar.on  { background:#2563eb; }   /* 파랑 = AI 동작/사용 가능 */
.ai-avatar.off { background:#dc2626; }   /* 빨강 = AI 미동작/사용 불가 */
.ai-avatar:hover { transform:translateY(-1px); box-shadow:0 3px 9px rgba(0,0,0,.24); }

/* 작은 변형(22px) — 헤더·목록 등 */
.ai-avatar.sm { width:22px; height:22px; font-size:9px; border-width:1px;
                box-shadow:0 1px 2px rgba(0,0,0,.16); }

/* (보조) 문장 속 'AI' 글자만 색칠하는 인라인형 */
.ai-mark { font-weight:800; letter-spacing:.02em; }
.ai-mark.on  { color:#2563eb; }
.ai-mark.off { color:#dc2626; }
```

> **픽셀 동일을 원하면 색·크기·테두리 값을 바꾸지 말 것.** 크기만 조정하려면 `width/height/font-size` 3개만.

## 3. [복붙] HTML 사용법

### (A) 큰 배지 — 버튼/진입점
```html
<a href="javascript:void(0)" onclick="openAiPanel()"
   class="ai-avatar {{ 'on' if ai_on else 'off' }}"
   title="AI {% if ai_on %}· 사용 가능{% else %}· 현재 사용 불가{% endif %}">AI</a>
```

### (B) 작은 배지 — 헤더 옆
```html
<div style="display:flex;align-items:center;gap:7px;">
  <span class="ai-avatar sm {{ 'on' if ai_on else 'off' }}">AI</span> 빅터
</div>
```

### (C) 문장 속 인라인
```html
<span class="ai-mark {{ 'on' if ai_on else 'off' }}">AI</span> 켜짐 — 무엇이든 물어보세요
```

> 메신저 i18n 쓰면 "AI" 글자는 그대로(약어), 툴팁만 다국어 키로.

## 4. [복붙] 서버에서 ai_on 계산 (Flask)

"이 사용자가 지금 AI를 쓸 수 있나"를 bool 로 만들어 템플릿에 넘긴다.

```python
def ai_enabled_for(user) -> bool:
    """True → 파란 배지(동작) / False → 빨간 배지(미동작·사용불가).
    판정: ① AI 서비스 가용(키 설정) ② 로그인 ③ (선택)사용자별 AI 허용 플래그."""
    # ① 메신저 AI 가용 여부 — 메신저는 번역 등에 이미 AI 사용 중.
    #    환경변수/키로 판단 (예: ANTHROPIC_API_KEY 또는 메신저의 ai_available()).
    import os
    ai_service_ok = bool(os.environ.get("ANTHROPIC_API_KEY") or os.environ.get("OPENAI_API_KEY"))
    if not ai_service_ok:
        return False
    # ② 로그인 사용자
    if not user:
        return False
    # ③ (선택) 사용자별 차단 — users.can_use_ai 같은 플래그. 없으면 기본 허용.
    try:
        flag = user.get("can_use_ai")
        if flag is not None:
            return bool(flag)
    except Exception:
        pass
    return True
```

**템플릿에 전달** — 두 방법 중 택1:

```python
# (1) 매 렌더마다 전달
return render_template("page.html", ai_on=ai_enabled_for(current_user), ...)

# (2) 전역 컨텍스트 프로세서(모든 템플릿에 자동 주입) — 권장
@app.context_processor
def inject_ai_on():
    return {"ai_on": ai_enabled_for(get_current_user())}
```

> 메신저는 이미 AI(번역 등)를 쓰므로 보통 `ai_on = True`(파랑). AI 키가 빠지거나 특정 사용자를 막으면 빨강.

## 5. 색·규칙 표준 (반드시 동일)

| 상태 | 배경 | 글씨 | 테두리 |
|---|---|---|---|
| AI 동작/사용가능 | 파랑 `#2563eb` | 흰색 `#fff` | 흰색 2px |
| AI 미동작/사용불가 | 빨강 `#dc2626` | 흰색 `#fff` | 흰색 2px |

- 크기: 큰 배지 **50px**(글씨 17px) / 작은 배지 **22px**(글씨 9px, 테두리 1px)
- 흰 글씨는 두 배경 모두 대비 양호 — **색 바꾸지 말 것**

## 7. 메신저 특화 메모

- 메신저 AI 진입점(번역·요약·챗봇 등) 어디에 붙여도 동일 규칙으로 색 표시.
- "동작 여부"의 정의는 메신저가 정함: AI 키 설정됨 / 번역 서비스 살아있음 등.
- 다크 테마면 흰 테두리가 더 또렷. 라이트 테마도 흰 테두리로 분리되어 무방.
- 클릭 동작(`onclick`)은 메신저 기능에 맞게 (AI 패널 열기 등).
