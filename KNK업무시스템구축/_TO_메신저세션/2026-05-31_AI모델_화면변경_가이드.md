- WORKS와 메신저는 **AI 설정이 완전 별개**. WORKS에서 모델 바꿔도 메신저는 안 바뀜.

## 1. ⭐ 신형 OpenAI 모델 파라미터 자동 대응 (가장 중요 · 먼저)

신형 모델(GPT-5 / o 계열)은 `max_tokens` 대신 **`max_completion_tokens`**, 그리고 `temperature` 미지원일 수 있습니다. 구·신형 양쪽을 자동 처리하는 헬퍼로 OpenAI 호출을 감싸세요.

```python
def openai_create(client, model, messages, max_tokens, temperature):
    """구·신형 OpenAI 모델 파라미터 차이 자동 대응.
    파라미터 오류일 때만 변형 재시도, 그 외(키·모델없음)는 즉시 전달."""
    variants = [
        {"max_tokens": max_tokens, "temperature": temperature},             # 구형 표준
        {"max_completion_tokens": max_tokens, "temperature": temperature},  # 신형
        {"max_completion_tokens": max_tokens},                              # 신형 + temperature 미지원
        {"max_tokens": max_tokens},                                         # 구형 + temperature 미지원
    ]
    last = None
    for v in variants:
        try:
            return client.chat.completions.create(model=model, messages=messages, **v)
        except Exception as e:
            last = e
            m = str(e).lower()
            is_param = ("unsupported_parameter" in m or "not supported" in m
                        or "max_completion_tokens" in m or "max_tokens" in m
                        or "temperature" in m)
            if not is_param:
                raise   # 파라미터 문제 아님 → 그대로
    raise last
```

**적용**: 메신저의 OpenAI 호출부(번역·요약 등 `client.chat.completions.create(...)`)를
`openai_create(client, model, messages, max_tokens, temperature)` 로 교체.

> ※ 메신저 번역이 **Anthropic(claude)** 만 쓰면 이 부분은 OpenAI 사용할 때만 필요. 단, 추후 OpenAI 모델 선택 가능하게 하려면 넣어두는 게 안전.

## 2. 모델·공급사를 '설정값'으로 읽기 (우선순위: 환경변수 > 설정 > 기본)

하드코딩 대신 설정에서 읽게 만들면 화면에서 바꿀 수 있습니다.

```python
import os

DEFAULT_MODEL = {"openai": "gpt-4o-mini", "claude": "claude-sonnet-4-5"}

def _setting(key, default=""):
    # 메신저의 설정 저장소에서 읽기 (app_settings 테이블 등). 없으면 default.
    row = db.execute("SELECT value FROM app_settings WHERE key=?", (key,)).fetchone()
    return (row["value"] if row else default) or default

def get_ai_provider():
    p = (os.environ.get("KNK_AI_PROVIDER") or _setting("ai_provider") or "").strip().lower()
    if p in ("claude", "anthropic"): return "claude"
    if p in ("openai", "gpt"):       return "openai"
    # 자동: 키로 결정
    if os.environ.get("ANTHROPIC_API_KEY"): return "claude"
    if os.environ.get("OPENAI_API_KEY"):    return "openai"
    return ""

def get_ai_model(provider=None):
    m = (os.environ.get("KNK_AI_MODEL") or _setting("ai_model") or "").strip()
    if m: return m
    provider = provider or get_ai_provider()
    return DEFAULT_MODEL.get(provider, DEFAULT_MODEL["openai"])
```

> 메신저에 `app_settings`(key/value) 테이블이 없으면, 메신저가 이미 쓰는 설정 저장 방식으로 대체하세요.

## 3. 관리자 화면 — 모델 변경 + 연결 테스트 (Flask)

### 라우트
```python
from flask import request, render_template, redirect, jsonify

@app.route("/admin/ai-settings", methods=["GET", "POST"])
def admin_ai_settings():
    if not current_user_is_admin():        # 메신저의 관리자 판정으로
        return redirect("/")
    if request.method == "POST":
        for k in ("ai_provider", "ai_model"):
            v = (request.form.get(k) or "").strip()
            db.execute("INSERT INTO app_settings(key,value) VALUES(?,?) "
                       "ON CONFLICT(key) DO UPDATE SET value=excluded.value", (k, v))
        db.commit()
        return redirect("/admin/ai-settings?saved=1")
    info = {
        "provider": get_ai_provider() or "(비활성)",
        "model": get_ai_model(),
        "set_provider": _setting("ai_provider"),
        "set_model": _setting("ai_model"),
        "env_model": os.environ.get("KNK_AI_MODEL", ""),
    }
    return render_template("admin_ai_settings.html", info=info, saved=request.args.get("saved"))

@app.route("/admin/ai-settings/test", methods=["POST"])
def admin_ai_settings_test():
    if not current_user_is_admin():
        return jsonify(ok=False, error="forbidden"), 403
    try:
        provider = get_ai_provider()
        model = get_ai_model(provider)
        # 메신저의 AI 클라이언트로 짧게 1회 호출 (openai면 openai_create 사용)
        ok, ans = ai_chat_short("한 단어로 'OK' 라고만 답하세요.")  # 메신저 함수에 맞게
        return jsonify(ok=ok, provider=provider, model=model,
                       answer=(ans or "")[:200] if ok else "", error="" if ok else (ans or ""))
    except Exception as e:
        return jsonify(ok=False, error=str(e))
```

### 화면 (요지)
- 현재 공급사·모델 표시
- 공급사 select(자동/openai/claude) + 모델명 input → 저장
- **연결 테스트 버튼** → `/admin/ai-settings/test` 호출 → ✅/❌ 표시
  - 잘못된 모델명·파라미터 문제를 **즉시 감지**(조용히 죽는 것 방지)

```html
<input name="ai_model" value="{{ info.set_model }}" placeholder="예: gpt-5.4-mini / gpt-4o-mini">
<button type="button" onclick="aiTest()">🔌 연결 테스트</button>
<div id="r"></div>
<script>
async function aiTest(){
  const r = await (await fetch('/admin/ai-settings/test',{method:'POST'})).json();
  document.getElementById('r').textContent = r.ok
    ? '✅ 정상 · 모델 '+r.model+' · '+r.answer
    : '❌ 실패 · '+r.error;
}
</script>
```
