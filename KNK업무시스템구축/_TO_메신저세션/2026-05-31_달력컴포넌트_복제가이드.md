## 0. 무엇을 만드나 (스크린샷 기준)

월(月) 1개 그리드 달력. 일요일 시작 7열. 각 날짜칸에:
- 날짜 숫자 (일요일·공휴일=빨강 / 토요일=파랑 / 평일=회색)
- **한국 공휴일 → 빨간 K 배지**, **베트남 공휴일 → 주황 V 배지** (대체공휴일은 점선)
- 그날 항목 건수(있으면 하단 알약)
- 오늘=금색 ring, 선택한 날=노랑+빨강 ring, 다른 달 날짜=흐리게
- 칸 배경은 D-day 상태색(지남/임박3/주간7/여유)
- 헤더: `← 오늘 → [월 선택]` 네비

> 메신저는 **Flask + Jinja**라 템플릿·CSS·파이썬 빌더 모두 그대로 포팅 가능. (HAIST WORKS는 FastAPI지만 빌더는 표준 라이브러리만 써서 호환)

## 2. [복붙] 공휴일 생성기 (한국/베트남 자동)

**의존성**: `pip install holidays` (메신저 컨테이너에 추가)

```python
# app.py 모듈 최상단 1회 실행 — HOLIDAYS_KR / HOLIDAYS_VN 전역 dict 생성
def _build_holidays_auto():
    """holidays 라이브러리로 한국·베트남 공휴일 자동 생성 (7년: 작년~5년후).
    음력·대체공휴일·nghỉ bù 자동 처리. 매년 수동 갱신 불필요."""
    try:
        import holidays as _hol_lib
    except ImportError:
        return {}, {}            # 미설치 시 빈 dict — 달력은 그대로 동작(배지만 안 뜸)
    from datetime import date as _d
    cy = _d.today().year
    years = list(range(cy - 1, cy + 6))
    kr, vn = {}, {}
    try:
        for d, name in _hol_lib.KR(years=years).items():
            if "제헌절" in name:          # 2008년부터 공휴일 아님 → 제외
                continue
            kr[d.isoformat()] = name
        for y in years:                   # 근로자의 날(라이브러리에 없음) 추가
            kr.setdefault(f"{y}-05-01", "근로자의 날")
    except Exception as e:
        print(f"[holidays] KR 실패: {e}")
    try:
        for d, name in _hol_lib.VN(years=years).items():
            vn[d.isoformat()] = name
    except Exception as e:
        print(f"[holidays] VN 실패: {e}")
    return kr, vn

HOLIDAYS_KR, HOLIDAYS_VN = _build_holidays_auto()   # { "2026-05-05": "어린이날", ... }
```

## 3. [복붙] 달력 빌더 (월 1개 → 데이터 모델)

```python
import calendar as _cal
from datetime import date as _date

def build_calendar_month(year, month, *, day_data=None,
                         today=None, selected_iso=""):
    """달력 1개월 데이터 생성 (일요일 시작).
    day_data: { "YYYY-MM-DD": {"count": int, "amount": float, "overdue": int} }
              ← 메신저가 자기 DB로 만들어 넘기는 '일별 데이터'. 없으면 빈 달력.
    today:    오늘 date (없으면 date.today())
    selected_iso: 선택된 날짜 "YYYY-MM-DD" (없으면 "")
    """
    day_data = day_data or {}
    today = today or _date.today()
    today_iso = today.isoformat()
    weeks = []
    for week in _cal.Calendar(firstweekday=6).monthdatescalendar(year, month):  # 6=일요일 시작
        row = []
        for dt in week:
            iso = dt.isoformat()
            b = day_data.get(iso) or {"count": 0, "amount": 0.0, "overdue": 0}
            d_left = (dt - today).days
            if   b["count"] == 0:   cls = "empty"
            elif b["overdue"] > 0:  cls = "overdue"
            elif d_left < 0:        cls = "past"
            elif d_left <= 3:       cls = "d3"
            elif d_left <= 7:       cls = "d7"
            else:                   cls = "future"
            row.append({
                "date": iso, "day": dt.day, "in_month": (dt.month == month),
                "count": b["count"], "amount": b["amount"], "cls": cls,
                "is_today": (iso == today_iso),
                "is_selected": (iso == selected_iso),
                "hol_kr": HOLIDAYS_KR.get(iso),
                "hol_vn": HOLIDAYS_VN.get(iso),
                "is_sun": (dt.weekday() == 6),
                "is_sat": (dt.weekday() == 5),
            })
        weeks.append(row)
    return {"year": year, "month": month, "weeks": weeks}
```

> `calendar.Calendar(firstweekday=6)` = **일요일 시작**. 월요일 시작 원하면 `0`.
> `weekday()`: 월=0 … 토=5, 일=6.

## 4. [복붙] 네비게이션 + 일별 데이터 만들기 (Flask 라우트 예시)

```python
from datetime import date, timedelta
from flask import request, render_template

@app.route("/calendar")           # 메신저 원하는 경로로
def messenger_calendar():
    today = date.today()

    # (1) 표시할 월 결정 — ?cal_ym=YYYY-MM (없으면 이번 달)
    y, m = today.year, today.month
    cal_ym = request.args.get("cal_ym", "")
    if cal_ym:
        try:
            y, m = int(cal_ym[:4]), int(cal_ym[5:7])
            if not (1 <= m <= 12): y, m = today.year, today.month
        except Exception:
            y, m = today.year, today.month

    # (2) 일별 데이터(건수) — 메신저 자기 DB로 채움. 예: 그날 일정/메모/할일 수
    day_data = {}
    rows = db.execute("SELECT due_date, status FROM <메신저테이블> WHERE ...").fetchall()
    for r in rows:
        dd = (r["due_date"] or "")[:10]
        if not dd: continue
        b = day_data.setdefault(dd, {"count": 0, "amount": 0.0, "overdue": 0})
        b["count"] += 1
        # (선택) 지남+미완료면 overdue
        if dd < today.isoformat() and r["status"] not in ("DONE",):
            b["overdue"] += 1

    # (3) 달력 데이터 생성
    selected = request.args.get("date", "")     # 클릭한 날(옵션)
    m_obj = build_calendar_month(y, m, day_data=day_data,
                                 today=today, selected_iso=selected)

    # (4) 네비 (이전/다음/오늘/현재)
    prev_y, prev_m = (y-1, 12) if m == 1 else (y, m-1)
    next_y, next_m = (y+1, 1)  if m == 12 else (y, m+1)
    nav = {
        "prev":    f"{prev_y:04d}-{prev_m:02d}",
        "next":    f"{next_y:04d}-{next_m:02d}",
        "current": f"{y:04d}-{m:02d}",
        "is_today_view": (y == today.year and m == today.month),
    }
    return render_template("messenger_calendar.html", m=m_obj, nav=nav, selected=selected)
```

## 7. 데이터 모델 계약 (날짜칸 1개의 필드 — 빠지면 표시 누락)

| 필드 | 타입 | 의미 |
|---|---|---|
| `date` | `"2026-05-31"` | ISO 날짜 |
| `day` | `31` | 일(숫자) |

| `hol_vn` | str/None | 베트남 공휴일명 → V 배지 |

## 10. 메신저 특화 메모

- 메신저의 "그날 데이터(count)"는 무엇이든 가능: 일정 수 / 미확인 메시지 / 할일 마감 등. `day_data` 만드는 §4 (2) 부분만 메신저 도메인으로.
- 날짜 클릭(`href`)은 메신저가 원하는 동작으로 (그날 일정 필터 등). 지금은 `?date=` 로 선택만.
- `<input type="month">` 빠른 이동은 그대로 동작.
- 픽셀 동일을 원하면 **CSS(§6)는 값 변경 없이** 복사할 것(색·크기 그대로).
