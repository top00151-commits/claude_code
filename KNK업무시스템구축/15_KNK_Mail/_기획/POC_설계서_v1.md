## 1. POC가 증명하려는 것 (1주)

| # | 검증 항목 | 합격 기준 |
|---|---|---|
| 1 | 받기: 외부에서 보낸 메일이 우리 시스템에 도착 | 분실 0건 |
| 2 | 보내기: 우리 시스템에서 보낸 메일이 상대 받은편지함(스팸 아님)에 도착 | 스팸함 0건 |
| 3 | 저장: 메일 본문·첨부가 NAS(우선 로컬)에 안전 보관 | 유실 0건 |
| 4 | AI: 도착 메일 자동 분류·번역·요약 동작 | 베트남어 메일 한국어 요약 확인 |
| 5 | UI: WORKS 안에서 받은편지함·보낸편지함·쓰기 사용 가능 | 베트남법인 5명이 설명 없이 사용 |

## 2. 구조 (A안 기준)

```
[외부 발신자]
    ↓ 테스트도메인 (예: test1@knk-mailtest.com)
[Cloudflare 받기 (Email Routing + Email Worker)]
    ↓ Worker가 메일 원문을 HTTPS POST
[WORKS 앱 신규 메일 수신구멍 (/api/mail/inbound, 비밀토큰 검증)]
    ↓
[저장: mail_messages 테이블(SQLite) + 첨부파일 uploads/mail/]
    ↓
[AI 처리: ai_client.py 그대로 — 분류·번역·요약]
    ↓
[메일함 UI: mail_inbox.html 등 (WORKS 컴포넌트 표준 재사용)]

[보내기] WORKS 쓰기 화면 → AWS SES SMTP (기존 mail_send.py 구조에 접속처만 SES 추가)
```

- 회사 도메인·외부 그룹웨어는 **일절 건드리지 않음**. POC 참여자는 테스트 주소를 추가로 받는 것.
- POC 동안 실거래처 메일은 기존 그룹웨어 그대로 (제약 3·4 준수).

## 3. 만들 것 (코드 단위)

| 파일 | 내용 | 신규/수정 |
|---|---|---|
| `app/mail_store.py` | 메일 저장·조회 (테이블 2개: mail_messages, mail_attachments) | 신규 |
| `app/main.py` | 라우트: 받은편지함/보기/쓰기/발송 + `/api/mail/inbound` 수신구멍 | 수정 |
| `app/mail_send.py` | SES SMTP 프로필 추가 (기존 그룹웨어 발송 경로는 그대로 유지) | 수정 |
| `app/templates/mail_inbox.html` 외 2~3종 | 메일함 UI (쉬운이름 표기 규칙 적용) | 신규 |
| Cloudflare Email Worker (JS 약 40줄) | 수신 메일 → WORKS로 전달 (Cloudflare 화면에 등록) | 신규 |
| AI 연동 | 도착 시 자동: 분류(견적·발주·세금계산서·일반)·언어감지·요약 | ai_client 재사용 |

## 4. 계정·비용 (대표 결제 필요 항목)

| 항목 | 비용 | 비고 |
|---|---|---|
| 테스트 도메인 1개 | 연 1~2만원 | §5 추천안 |
| Cloudflare 계정 | 무료 플랜 | 받기·Worker 모두 무료 한도 내 |
| AWS 계정 (SES) | POC 기간 수백 원 미만 | 카드 등록 필요, 발송 $0.001/통 |

## 5. 테스트 도메인 추천안

- **이름 후보**: `knk-mailtest.com` (1순위) / `knkmail-poc.com` / `haist-mail.com`
- **구매처 1순위 — Cloudflare에서 직접 구매**: 어차피 Cloudflare 계정이 필요하고, 거기서 사면 도메인·받기 설정이 한곳에서 끝남 (연 약 $11, 해외카드 결제)
- 2순위 — 가비아 등 국내 구매 후 네임서버만 Cloudflare로 지정 (국내 카드 결제 선호 시)

## 6. 일정 (대표 준비물 도착 기준)

| Day | 작업 |

## 7. 안전 장치

- 수신구멍은 비밀토큰 없는 요청 전부 거부 (외부 노출 차단)
- 실패는 표면화 — 수신 실패 시 관리자 화면에 오류 목록 (except:pass 금지, 데이터 연결성 원칙)
- POC 데이터는 운영 DB와 분리 테이블 — 실패해도 WORKS 본체 무영향
- 절대 제약 체크: 회사 도메인·주소·MX 접촉 0 (mail_address_immutable)
