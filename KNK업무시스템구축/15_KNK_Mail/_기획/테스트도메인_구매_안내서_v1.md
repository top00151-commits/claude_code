## 추천 방법 — Cloudflare에서 직접 구매 (한 곳에서 끝)

어차피 메일 "받기"에 Cloudflare 계정이 필요하므로, 도메인도 거기서 사면
네임서버(주소 안내소) 연결 작업이 아예 필요 없습니다.

### 준비물
- 이메일 주소 (대표님 메일)
- **해외 결제 가능한 카드** (VISA / MasterCard — 법인카드 가능) 또는 PayPal

### 1단계 — 계정 만들기 (5분)
1. 브라우저 주소창: `dash.cloudflare.com/sign-up`
2. 이메일 + 새 비밀번호 입력 → **Sign Up(가입)** 클릭
3. 가입에 쓴 메일함을 열어 Cloudflare가 보낸 메일의 **Verify email(이메일 확인)** 버튼 클릭
   → 화면이 관리 대시보드로 이동하면 계정 완성

### 2단계 — 도메인 구매 (10분)
1. 로그인 화면 **왼쪽 메뉴**에서 **Domain Registration(도메인 등록)** 클릭
2. 그 아래 **Register Domains(도메인 등록하기)** 클릭
3. 검색창에 `knk-mailtest` 입력 → 검색
4. 목록에서 `knk-mailtest.com` 옆 가격(연 $10~11) 확인 → **Purchase(구매)** 클릭
5. 등록자 정보 입력 — **영문으로** 입력:
   - 이름 / 회사명(선택) / 주소 / 전화 / 이메일
   - 개인정보 노출 걱정 불필요: Cloudflare가 소유자 조회(WHOIS)에서 자동으로 가려줍니다
6. 기간 **1 Year(1년)** 확인 → 카드 정보 입력 → 결제 완료
7. 왼쪽 메뉴 **Domains** 목록에 `knk-mailtest.com`이 보이면 끝.
   (Cloudflare 안에서 샀으므로 네임서버 설정은 자동 — 추가 작업 0)

### 주의사항
- **자동 갱신(Auto-Renew)** 이 기본으로 켜져 있음 — 1년 뒤 약 $11 자동 결제.
  POC 후 계속 쓸 예정이므로 그대로 두셔도 됩니다 (끄는 곳: Domains > 해당 도메인 > Auto-Renew)
- 화면이 영어입니다 — 위 버튼 이름 그대로 따라가시면 되고, 막히면 화면을 찍어 채팅으로 주세요
- `knk-mailtest.com`이 그새 선점됐다고 나오면 2순위 `knkmail-poc.com`으로 동일 진행

1. `gabia.com` 접속 → 검색창에 `knk-mailtest.com` 검색
2. 장바구니 → 1년 → 결제 (국내카드/계좌이체, 세금계산서 발행 가능, 연 1.5~2만원대)
3. **추가 단계 필요**: 이후 Cloudflare 계정을 만들고(위 1단계), Cloudflare에 도메인을
   연결하면서 안내받는 네임서버 주소 2개를
   가비아 [My가비아 > 도메인 통합 관리 > 네임서버 설정]에 입력해야 합니다
   → 이 단계는 구매 후 알려주시면 빅터가 화면 순서대로 안내
