## 2. 절대 준수 5대 제약 (위반 시 작업 중단)

### 제약 1. 메일주소 변경 금지
- `@knknara.co.kr` 모든 직원 주소 영구 유지
- 명함·계약서·세무서류 등록 주소 그대로
- 거래처 안내 공지 불필요

### 제약 2. knknara.co.kr 도메인 유지
- KNK 소유 도메인, 영구 보유
- MX 레코드만 신중하게 전환 (Phase 4 시점)
- DNS 변경 시 사전 백업·테스트 필수

### 제약 3. 거래처는 변화 인지조차 안 되어야 함
- 보낸사람 = 본인 그대로
- 답장 받는 주소 = 동일
- 도메인 워밍업 위험 회피 (검증된 발송망 활용)

### 제약 4. 단계적 전환 — 한 번에 끊지 않음
- Phase 0~5 점진적 (1년)
- 베트남법인 5명 → 본사 leader 10명 → 전 직원 90명
- 양수신 병행 운영 기간 필수

### 제약 5. 외부 그룹웨어 결재는 별도
- 메일만 자체 전환, 전자결재는 1년 후 별도 검토
- 한 번에 다 바꾸면 위험 폭증
- 메모리 정책 정합: 외부 그룹웨어 결재 유지

## 4. 기술 스택 후보 (Phase 0 POC에서 결정)

### A. 발송 (보내기)
| 옵션 | 비용 | 평판 | 권고 |
|---|---|---|---|
| **AWS SES** | $0.001/통 (90명 ≈ 월 3~4만원) | 매우 높음 | ⭐ 1순위 |
| SendGrid | 월 5천통 무료, 추가 $0.001 | 높음 | 2순위 |
| Mailgun | $0.80/1000통 | 높음 | 3순위 |
| 자체 SMTP (Postfix) | 0원 | 워밍업 1년 필요 | ❌ 비추 |

### B. 받기 (수신)
| 옵션 | 비용 | 안정성 | 권고 |
|---|---|---|---|
| **Cloudflare Email Routing** | 무료 | 매우 높음 | ⭐ 1순위 |
| 자체 IMAP 서버 (Dovecot) | 0원 | 자체 운영 부담 | 2순위 (Phase 4 이후) |
| AWS SES Inbound | $0.10/1000통 | 높음 | 3순위 |

### C. 저장
| 옵션 | 권고 |
|---|---|
| **자체 NAS (DSM RAID)** — 이미 보유 | ⭐ 1순위 |
| AWS S3 (외부 이중 백업) | 추가 |
| PostgreSQL / SQLite (메타데이터·검색) | 1순위 |

### D. UI
| 기술 | 권고 |
|---|---|
| 01 HAIST WORKS 기존 FastAPI + Jinja2 | ⭐ 1순위 (재사용) |
| 10 KNK_Messenger 통합 | 메신저 안에서 호출 |

### E. AI
| 기능 | 빅터 통합 |
|---|---|
| 자동 분류 (견적·발주·세금계산서·일반) | ai_chat() 활용 |
| 한↔베 자동 번역 | ai_translate() 활용 |
| 긴 메일 요약 | ai_summarize() 활용 |
| 답장 초안 작성 | ai_chat() 활용 |

## 5. 단계적 로드맵 (Phase 0~5)

### Phase 0 — POC (1주)
- 보조 도메인(예: `knk-mail.com` 또는 서브도메인) 임시 활용
- AWS SES 발송 + Cloudflare 받기 prototype
- 베트남법인 5명 1주 테스트
- **산출물**: POC 보고서 + 기술 스택 확정

### Phase 1 — 베트남법인 본 가동 (1개월)
- 베트남 5명 실 메일 사용 시작
- 외부 그룹웨어 병행 (양수신)
- AI 번역·분류·요약 통합
- **검증 지표**: 분실 메일 0건 / 평균 응답시간 / 직원 만족도

### Phase 2 — 본사 leader 확대 (3개월 누적)
- 본사 leader 5~10명 추가
- 양수신 병행 유지
- 거래처 메일 처리 검증
- **검증 지표**: 거래처 클레임 0건

### Phase 3 — 전 직원 양수신 (6개월 누적)
- 본사 84명 + 베트남 5명 모두 가동
- 외부 그룹웨어 + 우리 시스템 둘 다 살림
- **검증 지표**: 전체 메일 양수신 정합 100%

### Phase 4 — MX 전환 (9개월 누적)
- MX 레코드를 우리 서버로 전환
- 외부 그룹웨어 메일은 백업·읽기 전용 모드
- 사전 24시간 백업·테스트 필수
- **검증 지표**: 전환 후 24시간 메일 분실 0건

### Phase 5 — 외부 그룹웨어 메일 해지 (1년)
- 비용 절감 실현
- 외부 그룹웨어 결재는 별도 유지 (메모리 정책)
- **검증 지표**: 월 비용 90%+ 절감 달성
