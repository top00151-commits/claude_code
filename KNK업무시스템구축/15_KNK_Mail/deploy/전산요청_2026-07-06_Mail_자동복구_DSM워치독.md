# [전산 요청] KNK Mail 자동복구 — 외부 DSM 워치독 등록 (2026-07-06)

## 배경 (왜 필요한가)
KNK Mail(자체 메일·`kmail.knknara.co.kr`)은 앱(uvicorn `run.py`·5053)이 죽거나 멈추면 컨테이너 안에서 자동으로 되살릴 안전망이 필요합니다. (2026-06-21 kmail 502 — 앱이 죽은 채 방치되어 502였던 실제 사고)

2중으로 자동화합니다:
- **1단계(이미 적용·LIVE, 2026-06-22)**: 컨테이너 **내부** 워치독 `mail_watchdog.sh` — healthz(앱 .venv python urllib)를 감시해 `run.py`가 죽거나 멈추면 **사람 개입 없이 자동 재기동**. 부팅훅(`/root/.bash_profile` `KNK-MAIL-WATCHDOG-START`)에 등록되어 재부팅 후에도 자동.
- **2단계(이 요청)**: 컨테이너 **밖** DSM 워치독 — 1단계가 못 살리는 경우(**컨테이너 통째 멈춤 / NAS 재부팅 후 컨테이너 자체가 안 뜸 / 내부 워치독까지 죽음**)를 위한 최종 안전망.

## 요청 사항 (전산, 1회 등록 — 약 5분)

### 1) 컨테이너 이름 확인
NAS 에 SSH 접속 후:
```
docker ps --format '{{.Names}}'
```
→ **Mail 컨테이너 이름 확인**(예상: `KNKHAIST.MAIL`). 다르면 아래 스크립트의 `CONTAINER=` 값을 그 이름으로 수정.

### 2) 워치독 스크립트 복사
첨부 파일 **`nas_watchdog_mail.sh`** 를 NAS 호스트의
```
/volume1/docker/knk_mail/nas_watchdog_mail.sh
```
로 복사하고 실행권한 부여:
```
chmod +x /volume1/docker/knk_mail/nas_watchdog_mail.sh
```
(경로의 `knk_mail` 폴더명이 다르면 실제 경로로. 스크립트 내용은 경로와 무관.)

### 3) DSM 작업 스케줄러에 등록 (1분 간격)
**DSM > 제어판 > 작업 스케줄러 > 생성 > 예약된 작업 > 사용자 정의 스크립트**
- 사용자: **root**
- 일정: 매일 / 반복: **1분 간격**
- 실행 명령:
  ```
  sh /volume1/docker/knk_mail/nas_watchdog_mail.sh
  ```
- 저장 후 **[실행]** 으로 1회 수동 테스트 → 로그 확인:
  ```
  cat /var/log/knk_watchdog_mail.log
  ```

### 4) (강력 권장) 컨테이너 자동 재시작 켜기
**DSM > Container Manager > 컨테이너 > (Mail 컨테이너) > 설정** 에서
**자동 재시작(restart=always)** 활성화 → **NAS 재부팅 시 컨테이너가 자동으로 다시 뜸**.

## 동작 요약 (등록 후)
- 1분마다 컨테이너 healthz(python urllib·컨테이너에 curl 없음) 점검 → 정상이면 아무것도 안 함.
- 컨테이너가 멈춰 있으면 → `docker start`.
- 연속 2회(약 2분) 실패 → ① 컨테이너 안 `run.py` 재기동 → 그래도 안 되면 ② `docker restart`.
- 복구/실패 시 **DSM 관리자 알림**(synodsmnotify) 발송.

## 검증 기준
- 등록 후 [실행] → `/var/log/knk_watchdog_mail.log` 에 점검 기록이 남으면 정상.
- (선택) 업무 외 시간에 `docker stop <Mail 컨테이너>` → 2~3분 내 워치독이 자동으로 다시 띄우는지 로그로 확인.
- **메신저·WORKS 컨테이너 무영향**(Mail 만 대상).

## 비고
- 1단계 내부 워치독(`mail_watchdog.sh`)은 이미 적용되어 있어, **이 2단계 등록 전에도** 앱 단위 장애는 자동복구됩니다. 2단계는 '컨테이너 통째 장애·재부팅'까지 막는 최종 안전망입니다.
- 비밀값(.env)·메일 코드는 건드리지 않습니다. DSM 호스트 측 스케줄러 등록 + 컨테이너 자동재시작 설정뿐입니다.
- ⚠ 참고: Mail 컨테이너 `.env`(`KNK_MAIL_PUBLIC_BASE` 등)의 영구화도 별도 필요(재부팅 시 SSO 설정 유실 방지) — 자동복구와 별개 항목.
