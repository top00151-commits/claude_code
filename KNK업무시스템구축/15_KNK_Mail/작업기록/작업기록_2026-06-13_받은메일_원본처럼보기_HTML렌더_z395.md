대표 선택: **"원본처럼 보이게"** (HTML 서식 + 서명 이미지, 단 안전하게).

## 구현
1. **첨부 추출**(`mail_store.parse_raw_email`): 첨부를 파일명뿐 아니라 **바이트·content_id·인라인여부**까지 추출. 인라인 서명 이미지(Content-ID 보유) vs 일반 첨부 구분. 텍스트 본문 끝 `[첨부 N개]`는 인라인 제외 '진짜 첨부'만 표기.
2. **저장**(`store_inbound(attachments=)` → `mail_attachments`): `data`(BLOB)·`content_id`·`is_inline` 컬럼에 저장. 건당 12MB 상한(초과 시 메타만).
3. **안전 HTML 정리**(`sanitize_html_for_view`): `script/style/iframe/object/embed/form` 등 제거 · `on*` 이벤트·`javascript:` 스킴 제거 · **`src="cid:..."` → `/mail/{id}/att/{att_id}`** 치환(서명 로고 표시).
4. **격리 렌더**(`mail_view.html`): 정리된 HTML 을 **`<iframe sandbox="allow-same-origin allow-popups">`**(스크립트 실행 불가)에 srcdoc 으로 렌더. **이중·삼중 안전**: 서버 정리 → Jinja escape → sandbox. **원본(서식)/텍스트만 토글** + 첨부 칩(다운로드). 인라인 스크립트는 IIFE+window 노출(SPA `.main` 교체 안전).
5. **첨부 서빙**(`GET /mail/{id}/att/{att_id}`): 바이트 서빙, **소유권 강제**(메일 소유자만), 이미지=inline·그 외=download, `X-Content-Type-Options: nosniff`.
6. **DB**: `mail_attachments` 신규 컬럼 + 기존 DB **마이그레이션**(PRAGMA 확인 후 `ALTER ADD COLUMN`).
