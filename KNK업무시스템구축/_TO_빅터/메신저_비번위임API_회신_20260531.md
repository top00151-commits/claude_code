## 2. API 계약 (구현된 그대로)

> 공통: `POST/GET` · 헤더 **`X-SSO-Service-Key: <공유키>`** 필수(없거나 불일치 시 **403** `{"error":"forbidden"}`) · 응답 JSON · 내부망 호출.

### 2.1 비번 검증 — `POST /msg/api/sso/verify-password`
요청: `{ "employee_no": "5", "password": "<평문>" }`
- 성공(200):
```json
{
  "valid": true,
  "pwv": 3,
  "must_change_password": false,
  "user": {
    "employee_no": "5", "name_kr": "김정락", "name_en": "Kim Jeongrak",
    "name_vi": null, "dept": "경영", "position": "대표이사",
    "entity": "KOR", "email": "kjr@knk.co.kr", "is_admin": true
  }
}
```
- 실패(비번틀림/사용자없음/퇴사·비활성/게스트): `{ "valid": false }` (항상 200, 사유 미세분)
- 무차별 대입: 사번당 **분당 5회 실패** 초과 시 `429 {"valid":false,"error":"rate_limited"}` (성공 시 카운터 리셋)
- 참고: 응답에 `must_change_password` 추가 제공(WORKS 가 최초변경 유도에 활용 가능, 불필요하면 무시).

### 2.2 관리자 초기화 — `POST /msg/api/sso/admin-reset-password`
요청: `{ "employee_no": "43", "reset_by": "5" }`
- 동작: 본사=휴대폰 숫자 / VN='9999' 로 리셋 + `must_change_password=1` + `pwv += 1`
- 성공(200): `{ "ok": true, "new_pwv": 4, "temp_pw_hint": "휴대폰 번호 (숫자만)" }` (VN 은 hint="9999 (베트남 법인 공통 초기비번)")
- 실패(200): `{ "ok": false, "reason": "no_phone" }` (본사인데 휴대폰 없음) / `"not_found"` / `"owner_protected"`(최고관리자 비번은 원격 초기화 금지) / `"invalid_request"`

### 2.3 pwv 조회 — `GET /msg/api/sso/pwv?employee_no=5`
- 성공(200): `{ "employee_no": "5", "pwv": 3 }`
- 없는 사번: `{ "employee_no": "5", "pwv": null }`
