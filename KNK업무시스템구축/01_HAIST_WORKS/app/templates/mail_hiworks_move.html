왜 하나요? 이음 메일은 하이웍스의 「받은 메일함」만 받아 옵니다. 그래서 하이웍스 「메일 자동분류」 규칙이 개인 메일함으로 바로 넣는 새 메일과, 하이웍스 개인 메일함에 든 옛 메일은 이음 메일에 오지 않습니다.
· 위 순서대로 1 → 2 → 3 을 하면 끝납니다(대략 10~30분). 화면의 설명만 따라 하시면 됩니다 — 누구에게 묻지 않아도 됩니다.
· PC 에서 하세요(복사·붙여넣기·파일 올리기 때문 · 휴대폰으로는 진행 상황만 보셔도 됩니다).
· 내 메일함에만 들어갑니다 · 하이웍스 메일은 지우지 않습니다 · 같은 메일은 두 번 들어가지 않습니다 · 새 메일 알림·자동 응답은 나가지 않습니다.

① 규칙 옮기기 — 하이웍스 「메일 자동분류」 표를 복사해 붙여 넣기
{{ mi('triangle-alert') }} 이걸 안 하면, 하이웍스 규칙에 걸린 새 메일이 이음 메일에 안 옵니다.
  1. PC 에서 하이웍스 메일을 엽니다(다른 창이나 탭에).
  2. 왼쪽 아래 {{ mi('settings') }} 「메일 환경설정」을 누릅니다.
  3. 위쪽 탭 중 「메일 자동분류」를 누릅니다 — 「분류 대상 · 분류 조건 · 조건 내용 · 이동할 메일함」 표가 보입니다.
  4. 표가 있는 화면 아무 빈 곳을 한 번 누르고 Ctrl + A(전체 선택) → Ctrl + C(복사).
    화면 전체가 파랗게 골라져도 괜찮습니다 — 메뉴 글자 같은 것은 빼고 규칙 줄만 골라 읽습니다. 표만 마우스로 끌어 골라도 됩니다.
  5. 이 화면 아래 점선 칸을 누르고 Ctrl + V(붙여넣기) — 바로 읽어서 아래에 미리 보기가 나옵니다.
  6. 표 아래에 쪽 번호(1 2 3 …)가 있으면, 하이웍스에서 다음 쪽을 눌러 4~5번을 쪽마다 반복합니다. 붙여 넣을 때마다 쌓입니다(같은 줄을 두 번 붙여도 한 번만).
  7. 미리 보기에서 맞는 줄만 체크(처음엔 새 규칙이 모두 체크되어 있음)하고 「{{ mi('check') }} 확인한 규칙 저장」을 누릅니다. 잘못했으면 ↺ 되돌리기.
아래는 아직 저장 전입니다. 체크한 줄만 저장됩니다. 폴더가 이음 메일에 없으면 저장할 때 새로 만듭니다(같은 이름 폴더가 있으면 그 폴더).
옮길 수 없는 규칙은 하이웍스에 그대로 두셔도 됩니다 — 다만 그 규칙에 걸린 메일은 이음 메일에 오지 않으니, 필요 없으면 ②에서 함께 지우세요.

② 하이웍스 규칙 지우기 — ①을 저장한 뒤에
{{ mi('triangle-alert') }} 하이웍스에 규칙이 남아 있으면 그 규칙에 걸린 새 메일이 하이웍스 개인 메일함으로 바로 들어가 이음 메일에 안 옵니다.
👉 ①을 먼저 저장하세요. 먼저 지우면 그사이 온 메일은 이음 메일 「받은편지함」에 그냥 쌓입니다(없어지지는 않습니다 — 나중에 폴더로 옮기면 됩니다).
  1. 하이웍스 메일 → 왼쪽 아래 {{ mi('settings') }} 「메일 환경설정」 → 위쪽 「메일 자동분류」 탭.
  2. 줄마다 오른쪽 「관리」 칸의 「삭제」를 누릅니다. 표 맨 위에 전체를 고르는 네모 칸이 있으면 그것을 누르고 한 번에 지워도 됩니다.
  3. 쪽이 여러 개면(표 아래 1 2 3 …) 모든 쪽에서 지웁니다. 표가 비면 끝입니다.
  4. ①에서 「옮길 수 없음」으로 나온 규칙도 필요 없으면 지웁니다(남겨 두면 그 메일은 계속 하이웍스에만 있습니다).
  5. 다 지웠으면 아래 「✓ 하이웍스 규칙을 다 지웠어요」에 체크합니다.
· 규칙을 지워도 메일은 없어지지 않습니다 — 규칙(나누는 약속)만 지워집니다.
· 이 체크는 이 PC 화면에만 기억됩니다(다른 PC 에서는 다시 체크).

③ 옛 메일 올리기 — 하이웍스 「메일 백업」 파일
{{ mi('triangle-alert') }} 하이웍스 개인 메일함에 든 옛 메일은 이음 메일에 없습니다 — 백업 파일을 올리면 같은 이름 폴더로 들어옵니다.
  1. 하이웍스 메일 → 왼쪽 아래 {{ mi('settings') }} 「메일 환경설정」 → 위쪽 「메일함 관리」 탭 → 「메일 백업」.
  2. 옮길 개인 메일함(내가 만든 폴더 · 예: 주간업무)을 고르고 백업(내려받기) 단추를 누릅니다. 메일이 많은 메일함은 하나씩 받으세요.
  3. PC 에 받아진 파일(보통 「다운로드」 폴더)을 아래 「{{ mi('folder-open') }} 파일 고르기」로 고르거나 점선 칸에 끌어다 놓습니다. 여러 개를 한 번에 골라도 됩니다. 압축(zip)은 풀지 말고 그대로 올리세요.
  4. 다 올라가면 「하이웍스 메일함 → 이음 메일 폴더」 이름이 보입니다. 이름이 맞는지 보고(고쳐 써도 됨) 「{{ mi('inbox') }} 넣기 시작」.
  5. 다음 메일함도 같은 방법으로 받아서 올립니다. 다 했으면 아래 「옛 메일 올리기 끝」을 누릅니다.
· 올릴 수 있는 파일: .zip(안에 .eml 이나 .mbox · zip 안의 zip 도 한 단계까지) · .eml · .mbox(.txt 로 된 mbox 도) — 한 파일 최대 {{ max_gb }}GB.
· 올리는 동안에는 이 화면을 닫지 마세요(끊기면 같은 파일을 다시 고르면 이어서 올립니다). 넣기가 시작되면 화면을 닫아도 서버에서 계속합니다.
· 이미 이음 메일에 있는 메일은 두 번 들어가지 않고 같은 이름 폴더로 옮기기만 합니다 — 내가 이미 다른 폴더에 둔 메일·지운 메일은 그대로 둡니다.
· 받은 날짜는 원래 날짜 그대로 · 내가 보낸 메일은 「보낸 메일함」으로 · 다 넣지 못한 파일은 {{ keep_days }}일 동안 서버에 두었다가 지웁니다(이어 넣기용).
