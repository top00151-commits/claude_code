Cloudflare 보내기 연결 순서

1
Cloudflare → Workers 요금제를 유료(Workers Paid, 약 $5/월)로 업그레이드 (보내기는 유료에서 제공)
2
Cloudflare → 컴퓨트 → 이메일 서비스 → 이메일 보내기(Email Sending) → 도메인 온보드로 knk-mailtest.com 추가 → DKIM 레코드 자동 추가(승인)
3
발송용 SMTP 자격(사용자명·비밀번호) 발급 — 호스트 smtp.mx.cloudflare.net, 포트 465
4
위 ①~④ 칸에 호스트·계정·비밀번호·보내는 주소 입력 → 저장
5
메일 쓰기에서 본인 다른 메일로 시험 발송 → 도착 확인

막히는 화면이 나오면 캡처해서 빅터에게 보내주세요. 단계별로 안내합니다. (대량 발송이 필요해지면 AWS SES로 호스트만 바꿔도 됩니다)
