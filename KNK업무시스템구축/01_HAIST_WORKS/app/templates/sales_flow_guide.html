매출영업센터 · 등록부터 입금까지

ⓘ 등록부터 입금까지 — 이 순서로 누르세요

왼쪽 메뉴와 화면 단추 이름 그대로 적었습니다 · 각 단계의 [바로 가기]를 누르면 그 화면이 열립니다

관리번호 부여 → 제작요청 발행 → 등록은 건을 맡은 영업 담당자가 직접 합니다. 발행하면 고른 부서에 바로 통보됩니다. 외근 중이면 다른 사람이 대신 발행해도 되고, 발행한 사람과 영업담당자는 따로 남습니다.

  1. 1
    등록 — 관리번호 · 수주번호 · 제작요청
    누가: 영업 담당자 · 언제: 고객 발주(PO)를 받으면
    • 왼쪽 메뉴 🆕 등록 → 사업부 카드(🔬 검사기 · 🤖 자동화 · 💄 라이프밸류 · 🌐 기타 · 📦 소모품)를 고릅니다.
    • 고객사1 · 프로젝트명 · 모델명 · 장비명 · 수량 · 단가 · 발주일 · 고객 PO 번호 · 납품일 · 영업담당자를 적습니다.
    • 관리번호는 자동 발급됩니다.{% if can_manual %} 엑셀에서 이미 매긴 번호가 있으면 🔧 수동발행에 체크 → 번호 → [검증] 뒤 등록합니다.{% endif %}
    • 아래 📋 제작요청서에서 지금 발행을 고르고, 통보할 부서·사람을 고릅니다(한 번 고른 뒤 지금 고른 것을 기본으로 저장을 누르면 다음부터 자동으로 골라집니다).
    • ＋ 등록을 누르면 관리번호·수주번호가 나오고, 고른 부서에 제작요청이 통보되고, 작업 일정표에 「제작요청」이 적힙니다.
    바로 가기 ▶
  2. 2
    고칠 때 — 제작요청 수정 · 취소
    누가: 영업 담당자 · 언제: 수량·자료 경로·사양이 바뀌면(메일 RE 대신)
    • 왼쪽 메뉴 📋 프로젝트 → 그 건을 눌러 엽니다(위쪽 👤 내 건만을 누르면 내 건만 보입니다).
    • 제작요청서 화면에서 고친 뒤 🔁 수정발행 · 부서 다시 통보 · 없던 일이 되면 🚫 취소 발행.
    바로 가기 ▶
  3. 3
    제작 중 — 일정 · 납기 확인
    누가: 영업 담당자 · 관리 실무 · 팀장
    • 왼쪽 메뉴 📅 작업 일정표 → 위쪽 👤 내 건만(내 이름이 영업담당자인 건) → 납품일 · 단계 · 메모를 봅니다.
    • 한 번 누른 👤 내 건만은 내 계정에 기억되어 달을 바꿔도 그대로입니다. 다시 누르면 전체가 보입니다.
    바로 가기 ▶
  4. 4
    출하 · 납품
    누가: 영업 담당자 · 관리 실무
    • 📅 작업 일정표에서 그 줄의 달력 날짜를 눌러 「출하」로 바꿉니다.
    • 여러 줄을 한 번에: 줄 앞 ☑ 를 고르고 🚚 일괄출하(오늘 날짜로 출하).
    바로 가기 ▶
  5. 5
    마감 — 거래명세서 · 세금계산서
    누가: 관리 실무(안지연 · 이새롬 프로) · 세금계산서 실제 발행은 지금처럼 회계 시스템에서
    • 📅 작업 일정표의 거래명세서 · 세금계산서 칸에 발행일과 금액을 적습니다(나눠 발행하면 2차·3차… 추가).
    • 같은 고객사 여러 건을 한 장으로: ☑ 고르고 ⚙ 도구 ▾ → 📄 묶어 발행.
    바로 가기 ▶
  6. 6
    입금 확인 — 준비 중
    누가: 관리 실무(안지연 프로) → 관리팀
    • 지금은 입금 예정일이 된 고객사를 관리 실무가 관리팀에 확인하고 정리합니다(이음웍스 밖).
    • 이음웍스 「💰 입금 확인」(입금일 된 고객사 목록 → 관리팀에 확인 요청 → 답이 오면 입금 기록)은 다음 단계로 준비 중입니다.
      • {% if ar_pending %}
    • 💰 미수금 · 🚚 납품·수금 화면의 미수 숫자는 아직 실제와 다릅니다(입금 기록 정리 전 — 이미 받은 돈도 미수로 셈).
      • {% endif %}

  7. 7
    매출 보기 · 보고
    누가: 팀장 · 대표
    • 왼쪽 메뉴 🏢 매출 홈 → 📊 매출 보고서(팀장 보고 양식 엑셀).
    바로 가기 ▶
