인벤터 BOM 양식 바꾸기

설계 파일 → 회사 간이 양식 (기존 ①-a)
인벤터에서 내린 유닛별 BOM 엑셀들을 올리면 구매품만 골라 회사 간이 양식으로 만들어 드립니다.
만들어지는 것 — 구매품 PART LIST 간이판 (.xlsx)
자세히 — 사람이 확인할 것
품명이 빈 줄과 서보모터 줄(케이블은 전장팀과 협의)은 지어내지 않고 보고로 알려 드립니다. 가공품·용접 등 구매품이 아닌 줄은 왜 뺐는지 전부 보고합니다. 중복 형번은 유닛별 포장 때문에 합치지 않고 줄대로 둡니다.

BOM 한 파일로 합치기

기구·전장 취합 → 통일판 (기존 ①-b)
간이 양식(기구)과 전장 BOM을 함께 올리면 한 시트로 합치고 합계 수식까지 넣어 드립니다.
만들어지는 것 — 통일판 마스터 뼈대 (.xlsx) · 단가·납기는 비워 둡니다(구매팀 몫)
자세히 — 만들어지는 칸
통일판 26칸(B~AA)으로 맞추고 수량·발주수량·금액 합계 수식을 넣습니다. 단가·협력사·납기 칸은 구매팀이 채우는 자리라 비워 둡니다.

변경된 설계 반영하기

기존 마스터 개정 · 손 기입 보존 (기존 ①-c)
제작 중 부품이 추가·변경·삭제되면, 지금 쓰던 마스터와 바뀐 유닛의 인벤터 BOM만 올리십시오. 단가·협력사 같은 손 기입과 다른 유닛은 건드리지 않습니다.
만들어지는 것 — 개정본 마스터 (.xlsx) · 무엇이 바뀌었는지 보고로 알려 드립니다
자세히 — 어떻게 표시되나
추가된 부품은 「추가」, 빠진 부품은 줄을 남기고 「삭제」 + 확정단가 0(실물 관행), 형번이 바뀌면 「옛->새」로 적습니다. 어느 부품에 대응하는지 애매하면 고치지 않고 후보로만 알려 드립니다. 올리지 않은 유닛은 한 칸도 건드리지 않습니다.

과거 구매단가 찾아 넣기

수불부 대조 · 참고단가 (기존 ③)
마스터와 수불부를 올리면 과거에 실제로 구매했던 단가를 찾아 채워 드립니다. 형번+협력사·최근 발주일 기준이며, 이미 적혀 있는 단가는 덮지 않습니다.
만들어지는 것 — 기존단가가 채워진 마스터 (.xlsx)
여기서 채워지는 값은 과거 구매단가(참고용)입니다. 이번 협력사의 확정단가가 아닙니다. 다른 협력사에서 산 이력으로 채운 줄은 어느 업체 가격인지 보고에 표시되니 확인해 주십시오.

견적요청서 만들기

협력사별 (기존 ②)
마스터에서 협력사 한 곳의 견적요청서를 만듭니다. 변경단가·소요일·입고가능일은 매입처가 채울 자리라 비워 둡니다.
만들어지는 것 — 협력사 견적요청서 (.xlsx)
자세히 — 「단가가 비어 있는 품목만」의 뜻
기존단가 칸이 빈 줄만 골라 담습니다. 앞 단계에서 다른 협력사 실적으로 채워진 줄은 값이 차 있어 여기서 빠집니다 — 그 품목의 견적이 필요하다면 이 체크를 풀고 만드십시오. 「옛->새」 형번 표기는 그대로 둡니다.

발주서 파일 만들기

파일 생성 · 실제 발주 아님 (기존 ②)
마스터에서 발주서 파일을 만듭니다. 협력사를 비우면 전체 협력사 묶음(zip)으로 만들어 드립니다.
만들어지는 것 — 협력사 발주서 (.xlsx 또는 .zip)
파일을 만드는 것이지 발주가 나가는 것이 아닙니다. 협력사에 보내는 것은 지금처럼 사람이 합니다.
⚠ 발주수량에서 베트남 재고를 빼는 규칙이 확인 중입니다(구매팀 확인 대기). 보내기 전에 수량을 꼭 확인해 주십시오. 수량을 계산하지 못한 줄은 보고에 「수량 확인 필요」로 표시됩니다.
