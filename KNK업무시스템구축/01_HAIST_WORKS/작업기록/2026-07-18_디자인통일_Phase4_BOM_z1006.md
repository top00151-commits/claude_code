## 1. 전환 원칙 — 셸만 knk, BOM 로직·표는 유지+브리지

| 전환(knk) | 유지(업무 특화·색만 Sage 브리지) |
|---|---|
| 머리글 → knk-page-head + Tabler(자재마스터 `ti-packages`·보드로 `ti-arrow-left`) | **BOM 자동비교 로직**(변경어휘 3종·추가/변경/삭제 판정) |
| 주요 버튼 → knk-btn(primary/ghost) | 비교 표(tblx)·**요약 스트립**(sum-strip·adds/changes/deletes/🔴발주후변경 의미색) |
| :root → **pq→knk 풀 Sage 브리지** | 업로드 JS(KNKBusy 오버레이·replace 모드 confirm)·bomUpForm/bomApplyForm |
| | 리포트 카드(itm/ent)·변경 태그(tag add/chg/del)·취소선 old→new |

## 2. ⭐이 파일 특유의 브리지 처리

- **base 토큰을 로컬 미정의**: 이 두 화면은 `--pq-surface/line/ink`를 로컬 `:root`에 안 정의하고 **전역(v5_tokens/styles.html) 상속**,
  로컬엔 시맨틱(`--pq-ok/info/warn/danger`)만 정의했었음. → **풀 브리지로 base까지 명시 Sage** 부여(다른 폼과 동일 규격 보장).
- **토큰명 차이 주의**: 이 파일들은 `--pq-err`가 아니라 **`--pq-danger`**, 그리고 **`--pq-line-3`**(파일 드롭 점선)도 씀
  → 브리지가 `--pq-danger→--knk-danger`·`--pq-line-3→--knk-border-strong`(#B9C2BB·실존 토큰 확인)까지 매핑.
- JS는 폼 ID(bomUpForm/bomApplyForm)·버튼 ID(upBtn/applyBtn)만 참조 → 버튼 class를 knk-btn으로 바꿔도 **무영향**(ID 보존).

## 3. 세부

- **제목 이모지 제거**(`📋`/`📄`) — 형제 화면·po_form과 통일된 깔끔한 knk-page-title. 아이콘은 Tabler 버튼.
- **죽은 CSS 정리**: `.pl-head`/`.pl-title`/`.pl-actions`/`.btn-main`/`.btn-ghost` 군 + **미디어쿼리 잔재 `.pl-head{padding}`**까지 제거
  → `.main > .knk-page-head` 배경 보정 1줄만 남김.
- 리포트 `.pl-meta`(별도 div) → knk-page-head 안 `knk-page-meta`(제목 아래)로 이식.
