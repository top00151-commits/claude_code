## 0. 신고

> "프로젝트 정보 수정에 들어가서 **완제품 장비수량** 수정했는데, 이게 **부품쪽에 같이 포함**되어 있어서
>  **별도로 나와있으면** 좋을 것 같네요."
> "여기에 같이 포함되어있으니까 이게 헷갈릴 수 있을 것 같아요. **그렇다면 부품의 수량은 어디에 입력?**"

대표가 *"상품을 선택해야만 부품항목에 나오니깐 / 저건 상품에만 해당하는거야"* 라고 답했으나
신고자는 **"제 의도를 제대로 파악하지 못한 것 같으니 패스"** 하고 대화를 접었다.

**엇갈린 지점**: 대표는 *"그 상자가 **왜 뜨는가**"*(형태=상품일 때만)에 답했고,
신고자는 *"그 상자 **안에** 완제품 수량이 섞여 있다"*를 말했다. 서로 다른 얘기였다.

---

## 1. 원인 ① — 성격이 다른 값이 한 상자에 나란히

```
[고치기 전]
┌─ 부품 (주황 상자) ──────────────────────────────────┐
│  부품 품명      │  부품 모델명   │  🏭 완제품 수량      │   ← 3칸 나란히
│  (대표 1식)     │              │  (몇 대분)          │
└───────────────────────────────────────────────────┘
```

**부품 품명 · 부품 모델명 바로 옆**에 완제품 수량이 붙어 있으니 **부품 수량으로 읽힌다.**
게다가 그 상자에는 **부품 수량 칸이 없다** → *"그렇다면 부품의 수량은 어디에?"* 는 **당연한 질문**이었다.

> 간편폼(`project_quick_form`)은 **이미 분리돼 있었다**(별도 주황 띠 + 설명 한 문장).
> 정식 폼만 3칸으로 눌러 담아 두 화면이 서로 달랐다.

## 2. 원인 ② — 안내문이 **없는 곳**을 가리켰다

상자 아래 안내문:
> "실제 상세 명세는 **① 아래 '추가 품목'에서 줄 추가** 또는 ② 등록 후 프로젝트 상세의 엑셀로"

그런데 **'추가 품목' 섹션은 `{% if not project %}` — 신규 등록에서만 나온다.**
신고자는 **[프로젝트 정보 수정]** 이었으므로 그 섹션이 **화면에 아예 없었다.**

**화면이 답을 못 줘서 나온 질문이었다.**

## 3. 고친 것

```
[고친 뒤]
┌─ 부품 (주황 상자) ────────────────────────────────────────────┐
│  부품 품명 (대표 1식)        │  부품 모델명                     │
│  ┌────────────────────────────────────────────────────────┐  │
│  │ 🏭 완제품 장비 수량  [ 12 ]                                │  │
│  │ 대분 — **부품 수량이 아닙니다.** 이 상품(부품 묶음)으로       │  │
│  │ 만드는 완제품 장비가 몇 대인지 …                            │  │
│  └────────────────────────────────────────────────────────┘  │
│  ⓘ 부품 하나하나의 수량은 이 화면이 아니라 **프로젝트 상세**에서   │
│     — 수주 카드의 [＋ 항목 추가] 또는 [📤 상품 양식 올리기]       │
│  [🔧 부품 수량 넣으러 가기 (프로젝트 상세)]                       │
└──────────────────────────────────────────────────────────────┘
```

| | |
|---|---|
| 배치 | 부품 칸(품명·모델명)과 **완제품 수량 분리** — 간편폼과 같은 모양으로 통일 |
| 문구 | 칸 옆에 **"부품 수량이 아닙니다"** 명시 |
| 안내 | **화면별로 갈라 씀** — 신규=`아래 '추가 품목'` / 수정=`프로젝트 상세` |
| 경로 | 수정 화면에 **[🔧 부품 수량 넣으러 가기]** 버튼(그 프로젝트 상세로 직행) |
| ⚠JS | 상자가 `grid` → `block` 이 되었으므로 **토글 JS 의 display 값도 함께** 수정 |

### ⚠ 하마터면 또 놓칠 뻔한 층
토글 JS 가 `partW.style.display='grid'` 를 넣고 있었다. **HTML만 바꿨으면 상자 안이 무너진다.**
추적기 ④층(화면 JS)을 확인해서 잡았다. cf `feedback_trace_all_layers`

### 참고 — 정식 폼은 사실상 '수정 전용'
`/projects/new` 는 NEW_EQUIP·OTHER 를 **간편폼으로 넘긴다**(`main.py` 26781~). 정식 폼의 신규 모드는 거의 안 쓰인다.
→ 신고자가 본 화면이 **정식 폼의 주 사용처**가 맞다.
