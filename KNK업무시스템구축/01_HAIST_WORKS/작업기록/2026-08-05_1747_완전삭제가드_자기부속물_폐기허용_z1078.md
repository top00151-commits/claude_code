## 1. 배경 — 전환기 교착 실사례 2건

전환기(엑셀 관리번호 수동입력 기간·대표 확정 08-05)에는 **수주 삭제 → 관리번호 회수**가 일상 흐름인데, 회수된 껍데기 프로젝트가 **자기 부속물** 때문에 영영 못 지워졌다:

| 사례 | 남은 참조 | 결과 |
|---|---|---|
| SOCKET (구 006T2607) | 제작요청서 1 · 자기 이력 23 · 자기 항목 1 | 폐기 차단 |
| SM-S952 (구 007T2607) | 자기 이력 23 · 자기 항목 1 | 폐기 차단 · **상태 '취소'로도 불가** |

관리번호가 **있으면**(실거래 0) 지울 수 있는데(z1060b), 번호까지 반납한 더 이른 단계가 **더 엄격**한 비대칭.

## 2. 새 규칙 (게이트 v3 F-02 이력: 07-24 원안 → 07-27 z1060b → **08-05 z1078**)

**관리번호 없는 건**:
- **타 업무 연결**(수주·변경서·품질이슈·BOM·소모품연결·자식 프로젝트·자재이동 등) 있으면 → **종전대로 차단**
- **자기 부속물만** 남았으면 → **폐기(위험구역·본인 비밀번호 2단계)에 한해 완전삭제 허용**
  - 자기 부속물 = `project_history`(자기 변경이력) · `project_items`(자기 장비항목) · `prod_requests`+`prod_request_images`(자기 제작요청서·첨부)
- **일반·일괄 삭제(force=False)** = 종전대로 전부 차단. 자기 기록뿐이면 안내 문구가 "위험 구역 → 폐기(완전삭제)로 삭제할 수 있습니다"로 바뀜

## 3. 검증 — WP-01 PASS 101 / FAIL 0 (기존 99 + 신규 2)

- **신규 ①**: 자기 기록만 껍데기 일반 삭제 → 차단 + '위험 구역' 안내 문구 확인
- **신규 ②**: 같은 껍데기 폐기(force) → 삭제 성공 + **부속물 4표(이력·항목·제작요청서·첨부) 연쇄 소거 0건 확인**
- 기존 차단 전부 유지: 타 업무 연결(변경·이슈·소모품연결·부모자식·혼합 열거)·비관리자·환경 스위치 잠금·999/A 판별·z1060b 실거래 기준
