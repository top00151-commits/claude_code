## 2. 전환 (머리글·표·빈상태·필터 버튼만 knk)

- 머리글 → `knk-page-head` + Tabler 버튼(엑셀 `ti-download`·이동이력 `ti-history`·안전재고 `ti-target`·
  재주문 `ti-refresh`·재고현황 `ti-packages`·발주목록 `ti-clipboard-list`)
- 표 → `knk-table knk-table--dense`(공통 고정 머리글·줄무늬·hover). 특화(코드 모노·mute·행클릭·
  잔고0 흐림·바닥 합계줄 sticky)만 페이지 보정
- 빈상태 → `knk-empty`(잔고 `ti-packages`·이동 `ti-history`·입고 `ti-package-import`)
- 이동 필터바 '적용' 버튼 → `knk-btn--sm`
- :root → **pq→knk(Sage) 브리지**(이동은 `--pq-purple`=이동 칩용 원값 보존)

## 3. 유지 (업무 특화·색만 브리지) — po_receive 원칙

- **KPI 스트립**: 의미색 대시보드(잔고0·안전재고 미달·검수대기·QC·확정 등)라 knk-kpi 변형과 무대응 →
  페이지 유지(브리지로 Sage 색 자동). JS innerHTML 없음이라 안전.
- 이동유형 칩(chip-mv: IN 녹·OUT 빨·ADJUST 주황·TRANSFER 보라)·증감 색·입고상태 칩(chip-rs 5종) 전부 보존.
- 저장/필터 파라미터·라우트·행클릭 로직 불변.
