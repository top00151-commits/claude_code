# 세션 05 조율 — 환율 관리를 매출영업센터로 통합(단일 기준) 제안

- **작성**: 2026-07-29 (수) 18:49 KST · **작성**: 세션 01(매출/영업)
- **전달**: 대표 → 세션 05(자재구매)
- **목적**: 환율(FX)을 **정하는 곳을 한 곳(매출영업센터 월 기준환율)으로** 통일하기 위한 조율. 자재구매센터의 별도 '환율 등록'을 어떻게 정리할지 **세션 05와 합의**하려는 제안서(대표 확정 전, 코드 변경 없음).
- **근거 규정**: 현황판 §4 **규칙 48**(2026-07-29 대표 확정) — "WORKS 월 기준환율은 `/admin/fx-rates`(exchange_rates)이 단일 기준".

---

## 0. 한 줄 요약

**환율을 '정하는(입력)' 곳은 매출영업센터 월 기준환율 한 곳으로.** 자재구매센터는 그 값을 **읽어서** 자재 단가 원가 환산·알림에 쓴다(따로 정하지 않음). 자재구매의 별도 '환율 등록'은 제거(또는 조회 전용화) — **어떻게·언제는 세션 05와 합의**.

---

## 1. 사실 확인 (세션 01이 코드로 검증)

- **두 화면이 '같은 테이블'에 쓴다** — 데이터는 이미 하나(`exchange_rates`):
  - 매출영업센터: `POST /admin/fx-rates/save`(`admin_fx_rates_save`) → `INSERT INTO exchange_rates …`
  - 자재구매센터: `POST /rates/new`(`rates_create_submit`) → `exchange_rate_create(...)` → **같은 `exchange_rates`**
- 그래서 자재구매 '환율 이력'의 **출처가 전부 "월기준"**이고 값(USD 1,527.30·EUR 1,758.45·VND 0.058 …)이 **매출 월 기준환율과 동일**하다. = 자재구매 화면은 **이미 같은 소스를 읽고 있음**.
- 즉 문제는 '데이터가 둘'이 아니라 **'입력·관리 UI가 두 센터에 나뉘어 있다'**(정하는 곳이 둘 → 혼선 소지 = 규칙 48이 막으려는 것).

## 2. 제안 (대표 방향: "환율 관리는 매출영업센터로")

- **FX '정하기/입력' = 매출영업센터 한 곳**(월 기준환율·규칙 48). → 자재구매의 별도 '환율 등록(`/rates/new`)'은 **제거하거나 조회 전용화**해 두 번째 입력점을 없앤다.
- **FX '읽기(조회)·원가 시뮬·알림'** = 자재구매가 **shared `exchange_rates`를 읽어** 계속 쓸 수 있다(자재 단가 원가 환산은 매입 성격이라 자재구매에 남는 게 자연스러울 수도). → **어디에 둘지는 세션 05·대표 결정**(§4).
- ⛔ **두 번째 환율 테이블을 만들지 말 것** — 단일 소스 `exchange_rates` 유지(규칙 48).
- **한국은행 API 자동연동**(예정)은 이 **단일 소스에만** 붙인다(양쪽 각각 붙이면 소스가 갈라짐).

## 4. 역할 분담 제안 + 세션 05가 결정할 것

**제안 분담**
- **세션 01(매출)**: 매출영업센터의 환율 '정하기' 진입점 정비(월 기준환율은 이미 존재). 조회/대시보드를 매출 소속으로 착지시키기로 하면 그 landing 담당.
- **세션 05(자재구매)**: 자재구매의 **'환율 등록(`/rates/new`)' 제거 또는 조회 전용화**·사이드바 '환율' 메뉴를 조회/링크로·원가 시뮬/알림은 **shared FX 읽기**로 유지(정하지 않음).
- **공유**: `exchange_rates` 단일 테이블 유지.

**세션 05가 답해줄 결정 항목**
1. 자재구매의 **'환율 등록(`/rates/new`)'을 제거해도 되는가?**(매출 월 기준환율이 유일 입력이 됨) — 제거 vs 조회 전용.
2. **원가 시뮬(`/rates/cost_sim`)·알림(`/rates/alerts`)·한국은행 API 자동연동**을 어디에 둘지: 자재구매 유지(shared FX 읽기) vs 매출영업센터 이동. (API는 단일 소스에만.)
3. 자재구매센터 사이드바 **'환율' 메뉴** = 조회/링크로 남길지, 완전 제거할지.
4. 이행 시점·순서(세션 05 진행 중인 WP-04/BOM과 충돌 없게).
