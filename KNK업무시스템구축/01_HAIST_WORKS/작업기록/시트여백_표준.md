# 시트여백 — 입력/등록 시트 좌우 여백 표준 (⚠ 절대준수)

> 대표 지시(2026-06-14, **여러 번 반복 지적**). 앞으로 **모든 입력/등록 "시트"** 제작·수정 시 이 문서를 먼저 보고 그대로 적용한다.
> 한 줄: **시트는 모니터 폭을 꽉 채워라. 가운데에 1080px 같은 캡 두고 좌우를 비우지 마라. 필드는 모니터 비율 따라 자동 조정되게.**

---

## 1. 규칙 (필수)
1. **시트 래퍼에 `max-width` 캡 금지** + **`margin: 0 auto`(가운데 정렬) 금지.**
   - ❌ `.xx-wrap { max-width: 1080px; margin: 0 auto var(--space-6); padding: 0 var(--content-pad); }`
   - ✅ `.xx-wrap { margin: 0 0 var(--space-6); padding: 0 var(--content-pad); }`  ← **풀폭**, 좌우 여백은 `var(--content-pad)`(데스크톱 32px·모바일 16px)만.
2. **좌측 정렬은 `page-head` 와 동일하게** — `page-head` 도 `padding: … var(--content-pad) …` 라 둘 다 같은 32px 에서 시작 → 제목과 폼이 한 줄로 정렬됨. (시트 padding 을 `--content-pad` 로 맞출 것.)
3. **필드 레이아웃은 반응형(모니터 비율 자동 조정):** 둘 중 하나 사용.
   - 12열 그리드: `display:grid; grid-template-columns: repeat(12, 1fr);` + 칸은 `span N` + 좁은 화면 media query(예: `@media(max-width:820px){ … repeat(2,1fr) }`). (등록폼 `.qf-grid` 방식)
   - 자동 채움: `grid-template-columns: repeat(auto-fit, minmax(280px, 1fr));` (영업기회폼 `.op-grid` 방식, z420)
4. 폭이 매우 넓어도 개별 input 이 보기 싫게 길어지면, **그 input 칸만** `max-width` 로 제한(래퍼가 아니라 필드 단위). 래퍼는 항상 풀폭.

## 2. 예외 (캡 유지가 맞는 것)
- **인쇄/문서 양식(A4 종이 모사):** `export_*_print.html`(BL/CI/PL 등)의 `max-width: 820px; margin:0 auto` 는 **종이 비율 재현이라 유지.** 화면 편집 시트가 아님.
- **모달 본문**(`position:fixed` 오버레이 안의 카드)은 가독성 위해 캡 가능.
- 좁은 단일 설정 패널은 캡 허용하되, **데이터 입력/등록 시트는 무조건 풀폭.**

## 5. 새 시트 제작 체크리스트
- [ ] 래퍼에 `max-width` 캡 없음 / `margin:0 auto` 없음
- [ ] `padding: 0 var(--content-pad)` (page-head 와 좌측 정렬 일치)
- [ ] 필드 그리드 반응형(12열 또는 auto-fit) + 좁은 화면 media query
- [ ] 1280·1920·2560 폭에서 좌우 빈 여백 없이 꽉 차는지 확인
