안녕하세요, 안지연 프로님. 대표님을 통해 **"웍스에 입력된 내용으로 월간보고서(PPT)를 만들고 싶다"**는 요청을 전달받고, 7월 월간보고 PPT(7장)와 참고 원장 엑셀을 전부 읽은 뒤 **웍스에 실제로 들어있는 데이터와 월별로 대조**해 봤습니다. 그 결과와, 진행하려면 무엇이 필요한지를 정리해 드립니다.

## 1. 결론 먼저

- **매출 숫자의 골격은 이미 웍스 안에 있습니다.** 웍스의 세금계산서 발행 기록(발행일·금액)으로 월별 매출을 집계하면, **1~6월은 원장 국내 매출의 94~103%가 그대로 나옵니다.**
- 다만 보고서 7장을 **전부 자동으로 만들 수는 없고**, 아래처럼 "자동으로 되는 부분 + 직접 쓰시는 부분"으로 나뉩니다.

| 보고서 장 | 내용 | 웍스로 자동화 |
|---|---|---|
| 1·7장 | 표지 · 마감 | ✅ 자동 |
| 2장 | 매출현황 (분야별 당월+누계+비율) | 🔶 **금액은 자동 가능** — 단, 분야 구분(아래 3번)이 웍스에 없어 새로 만들어야 함 |
| 3·4장 | ISSUE 현황 (검사기 / 자동화) | 🔶 골격(고객사·모델·수주·진행상태)은 자동 초안 → **이슈 내용 서술은 직접 작성** |
| 5장 | 결제현황 및 매출계획 | ❌ 수금·미수 데이터가 웍스에 없음 (지금처럼 수기) |
| 6장 | KNK VINA 매출 | ❌ 베트남 법인 원장 — 웍스 관리 범위 밖 (지금처럼 수기) |

## 2. 대조 실측 결과 — 원장 국내 매출 vs 웍스 세금계산서 발행 기록

| 월 | 원장(국내) | 웍스 집계 | 일치율 |
|---|---|---|---|
| 1월 | 413,609,129 | 424,985,000 | 102.7% |
| 2월 | 819,701,050 | 784,054,050 | 95.7% |
| 3월 | 6,634,574,000 | 6,568,684,000 | 99.0% |
| 4월 | 3,078,781,600 | 2,967,481,400 | 96.4% |
| 5월 | 3,645,830,010 | 3,631,080,010 | **99.6%** |
| 6월 | 2,145,921,000 | 2,017,581,000 | 94.0% |
| **7월** | **4,196,808,000** | **3,130,047,000** | **74.6%** ⚠ |

- ⚠ **7월만 약 10.7억 원이 웍스에 아직 없습니다.** 확인해 보니 **자동화장비(삼성전기 계열) 건의 세금계산서 발행 기록이 웍스에 미입력**된 것이 거의 전부입니다.
- 즉, 자동 보고서가 정확하려면 **세금계산서를 발행할 때마다 웍스에도 발행일·금액을 입력**해 주시는 것이 전제가 됩니다.
  - 입력 위치: **작업일정표에서 해당 건(호기)의 세금계산서 칸**(1·2·3차 발행일·금액) / 소모품은 소모품 화면의 세금계산서 칸.
- 해외 매출(수출)은 7월 기준 절반 정도만 웍스에 있어, 해외 쪽은 입력 범위를 함께 정해야 합니다.

## 3. 진행하려면 필요한 것 — 프로님 도움이 필요한 부분

1. **분야 구분 기준** — 보고서 2장은 매출을 **PBA / MAIN FPCB / TSP / SENSOR / 자동화 / 기타**로 나누는데, 웍스에는 지금 이 구분 칸이 없습니다(검사기/자동화 2단계뿐).
   → 각 건을 **무엇을 보고 분야를 나누시는지**(고객사인지, 모델명인지, 품목인지) 알려주시면, 자동 분류 규칙을 만들 수 있는지 검토하겠습니다. 칸을 새로 만들면 **기존 건(약 490건)의 분야 지정**도 한 번 필요합니다 — 최대한 자동 제안 + 프로님 확인 방식으로 줄이겠습니다.
2. **해외 매출 환산 환율** — 보고서는 "월 평균 매매기준율"(7월 1,497.43)을 쓰시는데, 웍스의 표준 환율(매월 1일 기준 월 기준환율)과 다른 개념입니다. 어느 쪽으로 맞출지 정해야 합니다.
3. **7월 미입력분 입력** — 위 2번 표의 7월 차이(자동화장비 발행 기록)를 웍스에 입력해 주시면, 자동 집계가 원장과 맞는지 바로 검증할 수 있습니다.

## 4. 앞으로 진행 단계 (대표님 승인 후 착수)

1. **1단계** — 웍스에 「월간 매출현황」 화면 + 엑셀 내려받기: 발행일 기준 월별·누계, 국내/해외, 검사기·자동화·소모품 구분 (바로 개발 가능)
2. **2단계** — '매출 분야' 칸 신설 + 기존 건 분류 → 보고서 2장의 분야별 표를 그대로 재현
3. **3단계** — 지금 쓰시는 PPT 서식 그대로 **파일 자동 생성** + ISSUE 현황(3·4장) 자동 초안 (이슈 서술만 다듬으시면 되는 형태)
- 5장(결제)·6장(VINA)은 웍스에 데이터가 없어 자동화 대상에서 빼고 지금처럼 수기 유지를 권합니다.
