## 전환 (z1005~1008 레시피: 셸만 knk, 업무 위젯 유지+브리지)

| 전환(knk) | 유지(업무·색만 Sage 브리지) |
|---|---|
| 머리글 `.pi-head` → `<header class="knk-page-head">`(breadcrumb·title·meta) | **단계바**(step-bar 1·2·3)·**qsec 섹션** |
| 네비 버튼 → knk-btn(목록 ghost·빈 템플릿 primary) | **KPI 스트립**(전체/정상/중복/오류 의미색)·**tbl-erp 미리보기·결과 표** |
| `:root` pq→knk **Sage 풀 브리지**(surface·line·ink·ok/info/warn/err+soft) | **상태 칩**(chip-st ok/error/dup/inserted)·**업로드존**(드래그앤드롭)·**작성 가이드**·**submit-bar** |
| 파일 입력 포커스 → Sage focus(#3E6F89) | 진행 오버레이·에러/성공 배너(인라인 pq 변수 → 브리지) |

- **JS 무변경**: 드래그앤드롭 시각효과·등록 확정 오버레이 그대로. `data-knk-no-dropzone`(자체 .drop UI, 전역 드롭존 우회) 유지.
- **POST 동작 보존**: `/suppliers/import`(업로드·검증)·`/suppliers/import/apply`(등록 확정)·`/suppliers/import/template.xlsx`(템플릿).
- **레이아웃**: `.pi-page`(고정 뷰포트 flex)·`.pi-body`(flex:1 스크롤) 구조 유지 — 머리글만 knk-page-head(`.pi-page > .knk-page-head{배경·경계·flex:none}`).
- **죽은 CSS 정리**: `.pi-head`/`.pi-title`/`.pi-meta`/`.pi-actions`/`.crumb` 군 제거.
- **발주 QR 인쇄(po_qr_print)**: `@media print`·`@page`·A4 인쇄 문서 = 디자인 통일 예외([[knk_sheet_margin_standard]] 인쇄 A4는 캡 유지) → **전환 대상 아님·현행 유지**.
