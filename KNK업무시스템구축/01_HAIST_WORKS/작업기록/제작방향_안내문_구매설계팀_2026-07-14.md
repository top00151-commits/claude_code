# 자재·구매 시스템 제작 진행 방향 안내

- 받는 분: 구매팀 · BOM 작성 부서(설계팀·전장설계팀·소프트웨어팀)
- 작성: 2026-07-14 · 김정락 대표 (개발 담당: 빅터)
- 목적: 제작 진행 방향을 공유드립니다. 읽어보시고 **보완할 점·추가할 점을 회신**해 주세요. 주신 의견은 개발에 바로 반영합니다.

---

## 1. 왜 만드는가

BOM이 여러 번 바뀌는 과정에서 생기는 아래 문제를 없애는 것이 목표입니다.

- 바뀐 BOM을 눈으로 이전 버전과 비교해 다른 부분만 골라내는 수작업
- 이미 발주한 품목이 변경됐는데 늦게 알아 생기는 오구매·취소·재발주
- 색칠과 비고로 변경을 관리하다 "최종본이 맞는지" 헛갈리는 상황
- 같은 부품이 이름·모델명 표기만 달라 여러 개 등록되는 문제

**원칙: 여러분의 일이 늘어나면 실패입니다.**
지금 쓰는 엑셀은 그대로 씁니다. 비교·기록·경고를 시스템이 대신합니다.
만들었는데 도움이 안 되면 그 기능은 없앱니다.

---

## 2. 업무가 이렇게 바뀝니다

1) **설계·전장·SW팀**: 완성한 BOM 엑셀을 프로젝트 화면에 올립니다 (메일·메신저 전달 대신)
   → 구매팀에 자동 알림이 갑니다.
2) 시스템이 직전 버전과 **자동 비교**합니다
   → 추가/변경/삭제된 품목을 자동으로 표시 (예: 수량 2→4 처럼 전후 나란히)
3) **이미 발주된 품목이 변경되면 빨간 경고 + 담당자 알림**
   → 취소·재발주 놓침을 방지합니다.
4) **구매팀**: 품목을 클릭해 대체품(이원화)·변경 내용을 등록합니다
   (품명·규격·Maker·수량·단위·단가 입력, 금액은 자동 계산)
   → 언제 누가 뭘 바꿨는지 **이력이 자동 기록**됩니다 (색칠·비고 불필요)
5) BOM 화면에 **현재 실재고**가 함께 표시됩니다
   → 재고를 사용할 품목 / 추가 발주할 품목을 한 화면에서 바로 구분
6) 발주가 필요한 품목만 **체크 → 견적요청서/발주서 자동 생성**
   → **국문/영문 선택** 출력 (VINA 발주·견적요청 대응)
7) 납기가 지연되면 담당자에게 **자동 알림**
8) 제작팀 **출고요청 → 구매팀 '출고 완료' 클릭 → 재고 자동 차감**

## 3. 지금 쓰시는 BOM 엑셀, 양식 그대로 올리면 됩니다

설계팀이 구매팀에 전달하는 **실제 BOM 양식 기준으로** 만듭니다
(영업관리코드 · CATEGORY · PRODUCT NAME · PRODUCT CODE · 제조사 · 대당/총 수량 · 단위 · 구매처(KOR/VINA)).
**양식을 바꾸실 필요 없습니다.**

- **영업관리코드**(예: 001M2607)로 해당 프로젝트에 자동 연결됩니다.
- 빨간 **`기존->변경` 표기**(예: `GPA 0803->KQ2Z08-03NS`, 제조사 `SANG-A->SMC`)는
  시스템이 **자동으로 읽어 변경 이력으로 기록**합니다.
  코드와 제조사가 함께 바뀌는 이원화(대체품)도 그대로 잡힙니다.
- 앞으로는 화살표·빨간색을 손으로 안 쓰셔도 됩니다 — 새 값으로만 고쳐 올리면
  시스템이 직전 버전과 자동 비교해 바뀐 부분을 찾아냅니다.
  (쓰시던 습관대로 `->` 표기를 하셔도 똑같이 인식합니다)
- **대당 수량 / 총 수량** 두 칸 모두 그대로 유지·표시됩니다.
- **구매처(KOR/VINA) 빈칸**은 구매팀이 BOM 화면에서 품목별로 지정합니다
  (여러 품목 한 번에 지정 가능). VINA 지정 품목은 영문 견적요청서·발주서로 이어집니다.
- 한 부품이 여러 부품으로 바뀌는 경우(예: 밸브 어셈블리 1개 → 부품 3개)도 처리합니다.
- CATEGORY(Bottom Frame 등 구분)별 묶어 보기·필터를 지원합니다.

## 4. 회의 때 주신 의견, 이렇게 반영했습니다

- **정성진 팀장** — 현업 부서(설계·전장·SW)가 직접 BOM 업로드 → 반영 (2번-1)
- **정성진 팀장** — 부서별 코드 등록·발주 권한 부여 (설계팀=외주가공품, 가공팀=외주가공·원부자재) → 반영. 단, **중복 방지 장치를 먼저 설치한 뒤** 권한을 엽니다 (아래 0단계)
- **오용균 프로** — 품목 클릭 → 대체품·변경품 등록 창 + 이력 누적 → 반영 (2번-4)
- **오용균 프로** — 실재고 표시로 재고사용/추가발주 구분 → 반영 (2번-5)
- **오용균 프로** — 체크 후 발주서 생성·발송 → 반영 (2번-6)
- **허동준 매니저** — BOM 체크박스 → 견적요청서/발주서 즉시 생성, 국문/영문 → 반영 (2번-6)
- **김선미 프로** — 업체 등록 선행 → 공급사 일괄등록 기능이 **이미 준비되어 있어 지금 바로 시작 가능** (아래 6번)
- **김선미 프로** — 발주서·견적요청서 영문 출력 → 반영 (2번-6)
- **이홍규 프로** — 납기 지연 자동 알림 → 반영 (2번-7)
- **이홍규 프로** — 출고요청서 → 출고완료 → 재고 자동 반영 → 반영 (2번-8)

## 5. 일정 (3개월 · 4단계)

- **0단계 (1주차) — 자재 목록 정리**
  같은 부품이 여러 개 등록된 것을 찾아 하나로 합치고,
  앞으로 등록할 때 "이미 등록된 것 같아요"를 자동으로 알려줍니다.
  (대소문자·공백·하이픈 등 표기가 달라도 같은 모델명을 알아봅니다)
  ※ 부서별 직접 등록 권한을 열기 전에 이 장치부터 깔아야 중복이 늘지 않습니다.
- **1단계 (2~4주차) — BOM 화면**
  업로드 · 자동 비교 · 변경 이력 · 실재고 표시 · 발주 후 변경 경고
- **2단계 (5~8주차) — 견적·발주 연결**
  체크 → 견적요청서/발주서 생성 · 국문/영문 · 부서별 등록·발주 권한
- **3단계 (9~12주차) — 납기·출고**
  납기 지연 자동 알림 · 출고요청 → 출고완료 → 재고 자동 반영

각 단계를 배포할 때마다 실제로 써보시고 **"도움 된다 / 안 된다"** 를 말씀해 주세요.
그 답에 따라 다음 단계를 조정합니다.

참고로 견적요청서·발주서 "전송"은 1차에서는 **파일 자동 생성**(다운로드 후 메일 첨부)으로 시작하고,
시스템에서 바로 발송하는 것은 다음 단계에서 검토합니다.

## 6. 부탁드립니다 (3가지)

1) **실제 BOM 엑셀 파일 2개 (가장 중요!)**
   양식은 확인했습니다 — 이제 **실제 파일**로, 같은 프로젝트의 **"변경 전 / 변경 후"** 한 쌍을 주세요.
   빨간 `->` 표기 자동 인식과 버전 자동 비교를 실제 사례로 검증하는 데 씁니다.
2) **업체(공급사) 등록 시작**
   WORKS → 공급사 → 일괄등록에서 엑셀 템플릿을 받아 채워 올리시면 됩니다.
3) **이 문서에 대한 의견 회신**

### 특히 알려주시면 좋은 것

- 전장·SW팀도 설계팀과 같은 BOM 양식을 쓰시나요? 다르면 어떤 항목(컬럼)이 다른가요?
- 견적요청서·발주서에 반드시 들어가야 하는 항목은? (기존 양식 파일을 주시면 가장 좋습니다)
- 출고요청서에는 어떤 항목이 필요한가요?
- 납기 지연 알림은 **누구에게, 납기 며칠 전**부터 가면 좋을까요?
- 이 방향에서 빠진 것, 걱정되는 것이 있나요?

회신은 대표 또는 메신저(Eum)로 편하게 주세요. **주신 의견이 곧 개발 명세가 됩니다.**
