## 2. parts.html 전환 (업무 로직·저장·권한 게이트 불변)
- **교체**: 헤더→`.knk-page-head`(빵부스러기/제목/메타/액션) · 버튼 5개→`.knk-btn`(ghost 4+primary 1, Tabler 아이콘)
  · 배너 3종(공통 과다·오류·일괄등록 결과: 인라인 스타일)→`.knk-alert`(warning/danger/success) · KPI→`.knk-kpi-strip`
  · 표→`.knk-table--dense`(36px·sticky·zebra·hover) · 상태 pill→`.knk-badge` · 빈 상태→`.knk-empty`(ti-search-off/ti-package)
  · 조회 버튼 문구 '검색'→'조회'(가이드 §9.4 전 화면 통일).
- **유지(업무 특화·가이드 전환표)**: chip-biz(레거시 b-e/b-c 포함)·chip-acc·stk-mini·pgbar·공통 filterbar·
  tbl-zone 독립 스크롤·행 클릭 이동·모든 Jinja 로직/권한(can_supplier·can_purchase_price 🔒).
- **페이지 :root 토큰 유지 근거**: --pq-ok/--biz-* 등은 공통 파일에 정의가 없어 이 페이지가 유일한 정의처
  (재선언 아님 — grep으로 확인).
- **사업부 재구성(대표 확정)**: 등록 폼 선택지=T/M/공통뿐(part_form 실측) → KPI·필터 = 전체/T 검사기/M 자동화/
  **공통**/미지정/활성비율. E(전기)·C(화학)는 **실데이터 있을 때만** 자동 표시(`{% if e_cnt %}` — 숨은 데이터 유실 0),
  라벨은 'E (레거시) · 과거 분류 — 정리 대상'으로 정직 표기.
- **🔎 발견·수정 — '미지정' 숫자 부풀림**: `parts_stats().x_cnt = total-T-M-E-C`라 **공통이 미지정에 포함**돼 있었음.
  공통을 별도 KPI로 분리하며 템플릿에서 `x_cnt - common_cnt` 보정(DB 함수 불변 — 영향 0).
- `/parts?biz_div=공통` 필터 = 기존 `AND biz_div = ?` 문자열 매칭이라 코드 변경 없이 동작(라우트/DB 무수정).
