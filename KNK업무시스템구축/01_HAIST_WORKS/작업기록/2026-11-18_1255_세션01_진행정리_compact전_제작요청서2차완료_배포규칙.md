## 5. 오늘 데인 것(다시 안 하려고)
1. **예전 대표 결정과 부딪치는 계획은 먼저 여쭌다** — 2-4 「소모품 줄 모델 칸」이 z730(6/30 「부품 줄에 모델 입력 금지」)과 부딪침 → 만들기 전에 여쭘 → 대표 「정확하게」 → 실제 자료로 설명하니 더 나은 길(연결 장비 자동)로 결정
2. **설정 파일은 필요한 줄만** — supervisor 설정을 grep 하다가 OpenAI 키 값을 화면에 찍음(외부 유출 없음 · 대표께 알림) → `grep -n "command\|environment"` 같은 넓은 grep 금지 · 키 이름으로만
3. **셸 heredoc 안 파이썬 문자열의 `\\n` 은 `\n` 이 되어 깨진다** — 패치 스크립트는 Write 도구로 쓰거나 raw 문자열(`r'''…'''`)
4. **새 물음(confirm)을 넣으면 옛 사용자 입장 드라이버가 멈춘다** — 브라우저가 자동으로 「취소」 → 드라이버에 dialog 처리 · 칩에 「×」 단추를 넣으면 글자 비교도 바뀜
5. **고정 띠는 `left:50% + translateX` 면 폭이 반으로 줄어 두 줄로 접힌다** → `left:0;right:0;margin:0 auto;width:max-content`
6. **인쇄는 `visibility:hidden` 만으로는 자리가 남아 빈 쪽** → `display:none`(`:has()` 로 종이 양식 조상만 남김)
7. **운영 사본이 오래되면 최근 입력(연결 장비 등)이 없다** — 실제 화면 확인 전 그 자료가 사본에 있는지 먼저(읽기 전용으로 필요한 칸만 다시 떠서 넣음)
8. **윈도우 grep 의 `$'\r'` 개수는 믿지 말 것** — 줄 끝은 파이썬으로 바이트 세기
9. 다른 세션의 표준 검사 위반은 **바탕 그대로에서 다시 돌려** 내 것이 아님을 확인 → 알리기만(세션 15 가 고침)
