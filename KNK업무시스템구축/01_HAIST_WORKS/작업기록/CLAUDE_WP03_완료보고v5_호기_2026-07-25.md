## 3. DB 법인 기본값 제거 증빙 (§8-3)
- DDL에서 `DEFAULT 'KOR'` 제거(`NOT NULL CHECK(KOR/VN)` 유지)
- **DB 직접 INSERT에서 법인 생략 → 실패**: `NOT NULL constraint failed: project_units.entity` ✅
- PostgreSQL 전환 DDL도 동일 정책(WP-02 타입 매핑은 원본 스키마를 그대로 읽으므로 자동 반영)

## 4. 기존 적용 DB 보정 마이그레이션 증빙 (§8-4)
- `DEFAULT 'KOR'`가 있는 구버전 표를 만들어 마이그레이션 실행 → **`fixed: ["project_units.entity DEFAULT 'KOR' 제거"]`**
- **기존 데이터 보존 확인**(`('기존호기','VN')` 그대로) · 보정 후에도 법인 생략 INSERT 실패 ✅
- ⚠ 보정 중 발견·수정한 함정: SQLite `ALTER TABLE RENAME`은 **다른 표의 FK 참조까지 새 이름으로 바꿔** 이력 표가 깨집니다 → `PRAGMA legacy_alter_table=ON`으로 해결(신규 DB에선 안 보이고 보정 경로에서만 터지는 결함이었습니다).
