## 1. 원인(재현함)
- 웍스는 메뉴를 누르면 본문(.main)만 갈아 끼운다(`spa_nav`). 새 화면의 전용 스타일은 붙이고(`data-knk-page-style`) 다음에 지우지만, **처음 열린 화면 <head> 의 전용 스타일은 지우는 표시가 없어 계속 남았다.**
- 전사 일정표 <head> = `@media (min-width:1024px){ .main{ overflow:hidden !important } }`(본문 스크롤 끄기 · 시트만 스크롤).
- 전사 일정표를 처음 열고(새로고침·첫 화면) 메뉴로 다른 화면에 가면 → 그 화면 본문도 스크롤이 꺼진 채 → 제목 띠 고정(`knk_sticky_head` z106)이 「본문이 아니라 화면 전체가 스크롤」(좁은 창 방식)으로 보고 **상단바 높이(80px)만큼 내려 붙임** → 제목 띠 위 80px 빈칸 · 아래 단추 줄 가림 · 본문 휠도 잘 안 굴러감.
- 시험 서버 재현(1616px · 어두운 테마): 전사 일정표 → 메뉴 → 프로젝트 = 본문 `overflow hidden` · 제목 띠 `top:80px` · 본문 121px / 제목 201px(틈 80). 「가끔」 = 전사 일정표를 거쳐 메뉴로 옮겼을 때만 · 새로고침하면 사라짐.

## 2. 고침
1. **근본**(`_v5_partials/spa_nav.html`): 처음 열 때 <head> 의 style·link 에 `data-knk-orig` 표시 → 화면을 바꿀 때 **새 화면에 같은 것이 없으면 지움**(공용 스타일은 두 화면에 다 있어 그대로 · 스크립트가 나중에 만든 스타일은 표시가 없어 건드리지 않음) · 같은지 비교는 표시를 뺀 모양으로(공용 스타일 두 번 넣지 않음). 다른 화면의 <head> 전용 스타일 새는 것도 함께 막힘.
2. **안전장치**(`_v5_partials/knk_sticky_head.html`): 본문 `overflow:hidden` 도 본문이 스크롤 칸으로 봄(내려 붙이지 않음).
