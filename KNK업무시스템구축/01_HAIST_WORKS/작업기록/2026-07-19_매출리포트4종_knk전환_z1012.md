# z1012 — 매출 분석 리포트 4종 knk Sage 전환 · Phase 5②

- **일자**: 2026-07-19
- **지시**: 대표 "복구하고 다음거 진행해" → 매출영업 다음 배치.
- **대상(4)**: `sales_forecast`(매출 예측)·`sales_aging`(연체 분석)·`sales_production`(생산 진행)·`sales_outstanding`(미수금).
- **공통 패턴**: 모두 `--qv-*` 흰/슬레이트 로컬 재정의 + `class="page-head"` + 일반 스크롤(고정 flex 아님). z1011과 동일 브리지·머리글 레시피.

## 전환 (화면당)
| 전환(knk Sage) | 유지 |
|---|---|
| `body{}` `--qv` 6토큰 → knk Sage 브리지(surface·inset·경계·글자) | **데이터 시각화 색**: aging heat-map(heat-0~4)·pill 상태·bar-fill(예측 amber)·`--biz-*` 사업부색 |
| 머리글 `.page-head` div → `<header class="knk-page-head">`(breadcrumb·title·meta) | **공통 컴포넌트**(kpi-card·bento·tbl·section·card) — 브리지로 자동 Sage |
| 머리글 액션 → knk-btn: forecast `↻ 재계산`(primary)·outstanding `📊 연체 분석`(ghost) | **표 안 전역 버튼**(production `▶ 생산 시작`·`📦 납품`=전역 `.btn`) — 현행 유지(회귀 방지·후속 일괄) |
| `.main > .knk-page-head` Sage 배경밴드+경계+content-pad 정렬 | mgmt-pill 잉크 알약·POST 폼(forecast/refresh·production/start)·모든 데이터 |
| 반응형 `@media .page-title` → `.knk-page-title` | |

- **머리글 액션 판단**: 머리글 액션 버튼만 knk-btn 전환(다른 전환화면 머리글과 통일). 표 안 행 버튼(전역 `.btn`=amber)은 유지 — 렌더 실측 불가 상황에서 리스크 최소화, 필요시 전역 `.btn` 1곳 일괄 처리로 후속.
- **죽은 CSS 제거 불필요**: 이 4개는 `.page-head/.page-title` 등을 **전역**에서 상속(로컬 정의 없음) — 머리글 마크업만 교체.
