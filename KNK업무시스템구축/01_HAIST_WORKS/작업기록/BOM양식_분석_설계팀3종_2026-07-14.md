## 1. ⭐ 변경 표기 어휘 — 완전 해독 (파일 안에 범례가 있었음)

002M2603 파일 상단 r3~r4에 설계팀 자체 범례 발견:

> **"변경시 녹색 배경 붉은색 텍스트"**
> **"신규추가 노랑색 배경"**

실측으로 확인된 3가지 어휘:

| 표기 | 의미 | 실측 근거 | 파서 판정 방법 |
|---|---|---|---|
| 셀 안 `기존->변경` | **변경** (코드·제조사·품명) | 3파일 합계 156건. PRODUCT CODE 118 · MANUFACTURER 36 · PRODUCT NAME 2 | 셀 텍스트 `->` / `→` 패턴 |
| **노란 배경** (FFFFFF00) | **신규 추가** 품목 | 003M2506에 195셀 · 002M2603에 76셀 | 채움색 |
| **취소선** (+빨강) | **삭제** 품목 | 002M2505 r122 (CYLINDER MXQ8-30AS-M9B) · 003M2506 r67 (POWER MOLLER CONTROLER) 행 전체 취소선 | font.strike |

### ⚠ 기술 핵심: 빨간색으로는 변경을 못 잡는다
화살표 셀 다수의 폰트색이 `None`으로 나옴 — 빨간색이 **셀 일부(변경된 뒷부분)에만 리치텍스트로** 칠해져 있어 openpyxl 셀 단위 색으로는 안 잡힘.
→ **파서는 색이 아니라 ①`->` 텍스트 ②노랑 채움 ③취소선 3가지로 판정** (전부 실측 검증됨).

## 2. 공통 골격 (3파일 컬럼 코어)

헤더 행 = **r7** (3파일 동일). 셀 안 줄바꿈으로 3개국어 병기 (`CATEGORY⏎구분 / Danh mục`).

| 컬럼 | 비고 |
|---|---|
| NO. | 행번호 |
| CATEGORY (구분) | 어셈블리 유닛 (GANTRY UNIT·전장·AIR…) — 12~13종/파일 |
| CODE | 유닛 코드 (AA·AC… ← '정리' 시트의 AA00=BOTTOM FRAME UNIT 체계). 002M2505는 빈 경우 많음 |

| MANUFACTURER | 제조사 |

| UNIT | 단위 (EA·SET·M·PACK) |

| DELIVERY (납기) | 자유 텍스트 ("4~5 DAY"·"발주 후 2~3주 소요" — 빨강 강조 있음) |

## 3. 중요한 발견

1. **'개정이력' 시트 존재** (002M2505): No./Content/Date/Author 수동 이력 기록 — "구매품 중복으로 삭제"·"AIR UNIT 추가" 등 6건. **설계팀이 손으로 하고 있는 이 작업이 곧 우리가 자동화하는 것.** 업로드 시 이 시트를 읽어 초기 이력으로 가져올 수 있음.
2. **BOM이 발주 추적표를 겸하고 있음**: 발주일·입고예정일(1~5차)·납기 컬럼에 실데이터 — 설계팀 BOM 파일 하나로 구매 진행까지 관리 중. 시스템에선 이 부분이 PO 연결로 대체됨 (엑셀 컬럼은 읽어서 초기 상태로 반영).
3. **'정리' 시트**: 유닛(어셈블리)별 구매품/가공품 금액 집계 — BOM 보드의 CATEGORY별 소계 화면으로 대체 가능.
4. **VN 작성자(THUAN)** 실존 — 3개국어 헤더가 실사용. 영문/베트남어 대응은 장식이 아님.
5. 단가 158~192종 실입력 — 설계팀이 단가까지 채움 (구매팀이 검증·갱신하는 구조).

## 4. 파서 구현 스펙 (1단계 개발용)

1. **헤더 탐지**: r1~15 스캔, 키워드 매칭 (기존 parts_bulk_import의 SCAN_MAX 방식 재사용). 셀 내 줄바꿈 제거 후 별칭 매칭: `PRODUCT CODE|코드명|Mã sản phẩm`, `AMOINT|AMOUNT|합계`, `TOTAL|UNIT TOTAL`, `구분|CATEGORY|Danh mục` 등. 2행 병합 헤더 대응.
2. **시트 선택**: 구매품/가공품/공용부 시트별 파싱 (가공품은 재질·후처리 컬럼 매핑). 복사본 시트("(2)") 존재 시 업로드 미리보기에서 시트 선택.
3. **프로젝트 연결**: ①영업관리코드 열 → ②제목 셀(r2) 정규식 `\d{3}[A-Z]\d{4}` → ③파일명 → ④수동 선택 폴백.
4. **변경 판정 3어휘**: `->`/`→` 분해(OLD/NEW, `+` 다분해=1→N), 노랑 채움=신규, font.strike=삭제. 색은 판정에 사용 금지(리치텍스트 함정).
5. **값 읽기**: data_only=True (수식 합계·TOTAL은 캐시값). 날짜 셀 datetime 처리. 수량 정수/실수, 단가 콤마 제거.
6. **버전 비교(엑셀 표기와 독립)**: 직전 버전과 모델명 정규화 키(대소문자·공백·하이픈 무시) + 품명 보조로 라인 매칭 → 추가/변경/삭제 자동 산출. 엑셀 표기(1~3)는 **보조 신호 + 이력 주석**으로 병기.
7. **미등록 자재**: 자재 마스터에 없는 모델명 → "확인 필요" 버킷 (자동 생성 금지 — 0단계 가드 통과 후 등록).
