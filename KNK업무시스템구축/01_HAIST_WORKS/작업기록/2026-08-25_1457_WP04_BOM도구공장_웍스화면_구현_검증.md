## 무엇을 만들었나

**`/bom/tools` — BOM 도구 공장 화면.** 파일을 올리면 결과물을 만들어 주고, **입력 파일·산출물·실행 보고가 전부 웍스에 남아 언제든 다운로드**된다 (대표 지시 그대로).

| 구성 | 내용 |
|---|---|
| 도구 패키지 | `_검증/`의 도구 5종을 **`app/bom_tools/`** 로 이동(git mv) + 양식 4종 동봉(간이판은 BUDS 실물에서 자료 비워 도출) — 명령줄 실행도 그대로 됨 |
| DB | `bom_tool_runs` 표 신설 (관리번호·단계·입력 JSON·산출물·보고 전문·실행자·시각) — init_db 마이그레이션, 기존 표 무변경 |
| 저장 | `bom_tools_store/`(.gitignore) — ⛔ `/uploads` 정적 마운트(공개) **밖** 비공개 폴더, 다운로드는 권한 라우트로만 + **보관함 밖 경로 방어** |
| 라우트 | GET `/bom/tools`(화면·기록) · POST `/bom/tools/run/{step}`(draft/master/price/rfq/po) · GET `/bom/tools/download/{id}?f=out|inN` |
| 권한 | 조회 = 기존 `can_view_logistics`(대표 결재 정책 그대로) · 실행 = 기존 `_bom_can_upload`(자재 담당+설계·SW·전장팀) |
| 화면 | 단계 카드 5개(설명+양식) + 실행 기록 표(산출물⬇·입력 파일들⬇·보고 펼치기·실행자). 사용자 JS 없음(순수 폼) |
| 진입 | BOM 보드 머리에 「BOM 도구」 단추 (+ 부스러기 경로) |

발주서 전체 생성은 **zip 묶음**으로 저장(협력사 13곳 → 파일 1개). ③에서 관리번호는 마스터 제목칸에서 자동 인식.
