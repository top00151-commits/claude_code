# 메일 스팸·피싱 방어 설계 (대표 지시 2026-06-19)

> 목적: `@knknara.co.kr` 위험 스팸/피싱을 ①자동 필터 ②수동 차단 ③사용자 보호로 막아 **직원 실수(피싱 클릭·악성첨부) 사고 예방**.
> 전제: 100% 자동차단 불가(구글·하이웍스도) → **3층 방어 + "실수해도 안전하게"**가 핵심.
> 적용처: **WORKS 메일(`01_HAIST_WORKS` `/mail`)** 먼저(대표 실사용) → 독립앱(`15_KNK_Mail`) 미러. 배포=모노레포 push→미러.

## 3층 방어 (대표 승인 순서)
1. 🥇 **차단목록(수동) + 위험 경고배너 + 실행파일 첨부차단** ← 지금 구현
2. 🥈 발신 위조검증(SPF/DKIM/DMARC 헤더) 격리 + AI 피싱 분류
3. 🥉 신고 버튼 + 화이트리스트

## 1번 상세 설계

### 핵심 위치
- `mail_store.store_inbound()` = 모든 수신(인바운드 라우트 + 하이웍스 가져오기)이 거치는 단일 적재점 → **여기에 차단·위험판별 훅**(중복정리 dedup과 같은 자리).
- `mail_view_body.html` = 읽기 화면 → 위험 경고배너.
- 첨부 서빙 `/mail/{id}/att/{aid}` + 표시 → 실행파일 차단/경고.

### 1a. 차단목록(수동) — mail_store
- 테이블 `mail_blocklist(id, pattern, kind[email|domain], note, created_by, created_at, UNIQUE(pattern))` — **전사 공용**(관리자=대표 관리).
- `mail_messages` +컬럼: `is_blocked INTEGER DEFAULT 0`, `risk_level INTEGER DEFAULT 0`(0안전~3위험), `risk_note TEXT`. (lazy ALTER `_ensure_security_cols`)
- 함수: `is_sender_blocked(c, from_email)`(이메일 정확 or 도메인/서브도메인), `add_block/remove_block/list_blocks`.
- **store_inbound 훅**: owner 해석 후 `is_sender_blocked`→ `is_blocked=1`로 저장(삭제 아님=오차단 복구 가능). 받은편지함에선 숨기고 **🚫 차단함** 폴더에 표시.
- 관리: `/mail/blocklist`(GET 목록+추가/삭제) + 받은편지함·읽기화면 **🚫 차단 버튼**(발신 1클릭 차단). 권한=로그인(전사목록이라 관리자 권장 — 우선 can_view? 일단 admin/ceo 추가, 직원은 신고(3번)).

### 1b. 위험 경고배너 — assess_risk + mail_view
- `assess_risk(from, to, subject, body, html, attachments)` → `(level 0~3, notes[])` **규칙 기반(AI 아님·무료·빠름)**:
  - level3: **실행파일 첨부**(DANGEROUS_EXTS) — 가장 위험
  - level2: 외부발신 + 의심링크 + 피싱문구(비밀번호/계정/송장/invoice/verify/긴급…)
  - level1: 외부발신(우리 도메인 아님)
- store_inbound가 `risk_level/risk_note` 저장.
- `mail_view_body.html` 상단 **빨간/주황 경고배너**(level≥2 빨강 "⚠ 위험 — 링크·첨부 절대 주의", level1 회색 "외부 발신") + `[외부]` 표시.

### 1c. 실행파일 첨부 차단 — DANGEROUS_EXTS
- `DANGEROUS_EXTS={.exe .scr .com .pif .bat .cmd .vbs .js .jar .lnk .msi .ps1 .hta .iso …}`.
- 첨부 표시(mail_view): 위험 확장자 → ⚠ 빨강 + "위험: 실행파일 — 다운로드 주의".
- 첨부 서빙 `/mail/{id}/att/{aid}`: 위험 확장자면 **기본 차단**(경고 페이지 경유 or `?confirm=1` 강제다운만). 직원 무심코 클릭→실행 방지.

### 위험 확장자(초안)
`.exe .scr .com .pif .bat .cmd .vbs .vbe .js .jse .jar .lnk .msi .reg .ps1 .wsf .hta .cpl .scf .inf .chm .iso .img .vhd`
(+ `.zip/.7z/.rar`는 '압축'이라 일단 경고만, 내부검사는 2번 단계)
