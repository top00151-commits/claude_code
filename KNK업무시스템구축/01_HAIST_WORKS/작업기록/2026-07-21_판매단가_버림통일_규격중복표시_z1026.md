## 1. 확인 결과 — 2건 중 1건이 실제와 달랐다

|---|---|---|
| ① 판매단가 = 소수점 이하 **버림** | **반올림** (`round(cost×(1+margin/100))`) | ❌ **다름** |
| ② 인보이스 = 소수점 2자리(셋째 반올림) | `round(sell_krw / fx, 2)` | ✅ 맞음 |

## 2. 수정 — ① 판매단가 버림

**계산 지점이 4곳**이라 서버는 공용 함수로 통일했다.

```python
def _sell_from_cost(cost, margin):
    """판매단가 = 매입 × (1+마진%) — 소수점 이하 버림.
    ⚠부동소수 방어: 6자리에서 한 번 정리한 뒤 버린다."""
    return int(math.floor(round(float(cost) * (1 + float(margin) / 100.0), 6)))
```

| 위치 | 파일 | 내용 |
|---|---|---|
| 서버 ① | `app/main.py` 상품 양식 파서 | `_sell_from_cost(cost_krw, margin)` |
| 서버 ② | `app/main.py` PACKING LIST confirm | `_sell_from_cost(_cost, _margin)` |
| 화면 ① | `project_detail.html` 상세 실시간 | `Math.floor(Math.round(c*(1+m/100)*1e6)/1e6)` |
| 화면 ② | `project_quick_form.html` 간편폼 실시간 | 동일 |
| 안내 | `app/main.py` 양식 '작성안내' 2줄 | "소수점 이하 버림" 명시 |

### ⚠ 부동소수 함정 — 그냥 `floor` 하면 1원이 깎인다
`5,800 × 1.12` 가 컴퓨터에서 `6,495.999…` 로 떨어지면 소박한 `floor` 는 **6,495**를 만든다(1원 손실). 실제 사례로 `2,519,000 × 1.12 = 2,821,280.0000000005` 를 확인했다. 그래서 **6자리에서 정리한 뒤 버린다.**

검증: 139행 전수 — *소박한 floor 였다면 1원 깎였을 행* **0행**(헬퍼가 방어).

## 3. 수정 — ③ 규격 중복 표시

같은 수주 안에서 **규격(spec)이 2줄 이상**이면 그 줄을 표시한다.

- `<tr class="dup-spec">` + 규격 칸에 **`중복 N`** 표식 + 줄 왼쪽 3px 띠
- **오류로 취급하지 않는다** — 납기가 달라 일부러 나눈 경우가 많다(대표 파일 3건 모두 7/30·8/6 분리). 그래서 빨간 경고가 아니라 연한 amber
- 마우스 올리면: *"같은 규격이 이 수주에 N줄 있습니다 — 납기가 달라 나눠 적은 것이면 정상입니다"*

### CSS 설계 판단
```css
table.so-units.parts-excel tr.dup-spec > td { box-shadow: inset 0 0 0 9999px rgba(251,191,36,.13); }
```
`background !important` 로 덮으면 **매입·마진 칸의 기존 배경(#fff7ed)이 지워져 원가 열 구분이 사라진다.** `inset box-shadow` 로 **덧칠**해서 기존 색을 살린 채 톤만 얹었다. (LIVE 확인: 중복 줄에서도 원가 칸 배경 `rgb(255,247,237)` 유지)

## 5. 안지연 프로께 회신할 내용

1. **판매단가 = 소수점 이하 버림** — 말씀이 맞습니다. 다만 **기존에는 반올림**이었어서 오늘 버림으로 바꿨습니다. 앞으로 올리는 건부터 적용되며, 이미 등록된 건은 그대로 둡니다(임의 재계산하면 인보이스가 소급 변경되므로).
2. **인보이스 = 소수점 2자리(셋째 반올림)** — 맞습니다. 변경 없습니다.
3. **규격 중복 표시** — 적용했습니다. 규격 칸에 `중복 N`, 해당 줄은 연한 색 + 왼쪽 띠. 001M2607 기준 3종 6줄이 표시됩니다(전부 납기 분리 건으로 보입니다).

## 6. 남은 후속
- 이미 등록된 수출 상품 수주의 판매단가는 **반올림 기준 그대로**다. 일괄 재계산은 인보이스 금액을 소급 변경하므로 하지 않았다 — 필요하면 대표 지시로 별건 처리.
- 규격 중복 표시는 **부품(PARTS) 수주 상세**에만 적용. 소모품·완제품 표는 미적용.
- 판매단가 직접 수정 시 **마진% 역산**은 기존대로 반올림(`Math.round((price/cost-1)*1000)/10`) — 표시용 값이라 손대지 않음.
