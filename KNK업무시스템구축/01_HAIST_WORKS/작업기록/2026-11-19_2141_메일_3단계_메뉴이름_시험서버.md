## 쓰는 사람 입장에서 바꾼 것
### 1. 삭제는 어디서 해도 같게
- 지금까지: 목록 한 통 삭제 = 묻지 않고 휴지통 + 「↺ 되돌리기」 / 여러 통 고른 띠·읽기 칸 🗑 = 「삭제할까요?」 묻고 되돌리기 없음 → 같은 일이 곳마다 달랐음
- 이제: **어디서든 묻지 않고 휴지통 + 「↺ 되돌리기」**(휴지통이라 실수해도 잃지 않음)

### 2. 같은 일은 같은 이름
| 전 | 이제 |
|---|---|
| 「🚫 스팸함으로 · 다시 안 받기」 / 「이 사람 다시 안 받기」(곳마다 다름) | **「🔕 다시 안 받기(나만 · 스팸함으로)」** — 경고 상자·⋯ 메뉴·오른쪽 클릭 같게 |
| 「🚫 이 발신 차단」(관리자) | **「⛔ 회사 전체 차단(관리자)」** — 나만 막기와 헷갈리지 않게 |
| 보낸 곳별 정리 「별표」 | **「⭐ 중요」**(메일 화면 다른 곳과 같은 말) |
| 「← 메일함」 | **「← 받은편지함」**(폴더·규칙·정리 화면) |
| 「📮 내 계정」 | **「📮 내 회사 주소 연결」**(쓰기 화면·계정 화면 같은 이름) |
| 「메일 자동분류 규칙」 | **「🏷 메일 종류 규칙」**(설정 줄과 같은 이름) |
| 「📦 수주 등록」 | **「🛒 수주 등록」**(📦 보관과 그림이 겹쳐 헷갈렸음) |

### 3. 낡은 안내·어려운 말 정리
- 폴더 화면 「📁 이 폴더로」 → 실제 단추 이름 **「📁 다른 폴더로…」**
- 보낸편지함 빈 안내 「왼쪽 ✏️ 메일 쓰기」 → 실제 자리 **「위 ✏️ 새 메일」**
- 쓰기 화면의 NAS · 발송망(Cloudflare/AWS SMTP) · 「AI 키」 같은 속사정 말 없앰
- 번역 언어 이름 en/vi → **영어 · 베트남어**
- 관리자 차단 확인창의 앞뒤 안 맞던 문구(「이미 받은 것도 이동·삭제 아님」) → **「이미 받은 메일도 스팸함으로 옮깁니다」**(실제 동작대로)

### 4. 더 편하게
- **대화 묶기 = 제목 + 상대 회사**: 「견적 요청」처럼 흔한 제목이 다른 회사 메일끼리 한 대화로 섞이던 것 막음(우리 회사끼리 주고받은 것·바깥 회사 하나뿐인 대화는 그대로 한 묶음)
- **🖨 인쇄 = 메일만**: 읽기 칸에서 누르면 메일만 있는 창이 열려 저절로 인쇄 · 단추·메뉴·🚩 상자는 인쇄에서 뺌(전에는 목록·도구 줄까지 찍힘)
- **단축키 S = ⭐ 중요**(노트북엔 Insert 키가 없는 경우가 많음 · Insert 도 그대로)
- 명령 줄 「읽음·안 읽음」 그림 ✉ → **◐**(새 메일 ✉ 과 겹치지 않게)
- **스팸함 숫자 = 실제 통수**(전에는 목록 한도 300 이 숫자로 보일 수 있었음)
- ⭐ 회신 필요 메일을 📦 보관하면 **「↩ 『회신 필요』에서도 빠졌어요」** 알림(조용히 사라져 놓치지 않게 · 11-18 설계 「보관=끝난 일」은 유지)
- 휴지통 화면 찾기 칸 = **「받은편지함에서 찾기」**라고 알려 줌(휴지통 안을 찾는 줄 알기 쉬웠음)
- ❔ 도움말에 **📱 휴대폰에서 쓰는 법** · 도구 줄이 화면보다 길면 오른쪽 끝을 흐리게(「옆으로 밀면 더 있음」 표시)
