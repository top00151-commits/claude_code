# z887 — 소모품 사진 확대·축소(줌) 뷰어 + 화질 보정

- 날짜: 2026-07-09
- 버전: v5H226z887
- 지시(대표): "소모품 사진 볼 때 확대·축소(줌) 기능을 넣어줘. 사진이 작을 때는 크게 확대해서 봐야 해. 그리고 사진 화질도 가능하면 좋게 보정해줘."
- 첨부: WORKS 사진 뷰어 창 "KNK Eum WORKS - line6_photo_full.jpg (258×155)" — 258×155 작은 JPG가 큰 화면 가운데 원본(100%)으로 아주 작게 표시됨.

## 배경 / 원인
- 소모품 상세(`app/templates/consumable_detail.html`)의 라인 표 사진 셀은
  `<a href="{원본}" target="_blank"><img src="{썸네일}"></a>` 구조.
- 즉 클릭하면 **원본 이미지 파일을 새 창(설치형 PWA 창)에 그대로** 연다 → 별도 HTML 뷰어가 없어
  브라우저 기본 이미지 표시(원본 크기 100%)라서 작은 사진은 아주 작게 보였다.
- WORKS 전체에 공유 사진 뷰어(라이트박스/줌)가 **존재하지 않음**(grep 확인). PC/모바일 2종 뷰어도 없음.

## 변경 내용
### 1) 전역 사진 뷰어 파티셜 신설 — `app/templates/_v5_partials/photo_viewer.html` (신규)
- `chrome.html`(모든 페이지 포함·전역 UI IIFE 표준 위치·`.main` 바깥이라 SPA 교체에 영향 없음) 말미에서 **1회 include**.
- 문서(document) 위임 클릭 리스너(캡처 단계)라서 SPA로 `.main`이 갈려도 유지되고, 동적으로 추가된 사진 링크도 처리.
- 확대/축소 UX:
  - `+`/`−` 버튼, 마우스 휠 줌(**커서 위치 기준**), 드래그 팬(이동), **더블클릭 토글**(맞춤↔확대).
  - `맞춤(fit)` / `100%` / `↺ 초기화` 컨트롤. 배율 % 실시간 표시(버튼).
  - **작은 사진도 화면을 채움**: 열면 기본 '맞춤'이라 258×155도 화면폭까지 확대되어 크게 보임.
    최대 배율 = max(맞춤×4, 8) → 최소 **800%**, 작은 이미지는 훨씬 더(캡 3200%).
  - 모바일: **두 손가락 핀치 줌 + 드래그 팬**. Pointer Events로 마우스/터치 통합(별도 `(pointer:coarse)` 게이팅 없음
    → 안드로이드 S펜 통째 꺼짐 함정 회피), stage에 `touch-action:none`.
  - 키보드: Esc 닫기(캡처+stopPropagation로 페이지 Esc 핸들러와 충돌 방지), `+/-` 줌, `0` 맞춤.
  - **기존 기능 보존**: `⤓ 저장`(원본 다운로드), `↗ 원본`(원본 새 창), `✕`/Esc 닫기.
- 화질 보정(클라이언트 표시만):
  - 확대 시 뭉개짐 완화 = `image-rendering:auto`(부드럽게, 픽셀 계단 아님).
  - 선택 토글 `✨ 선명` = **자체 인라인 SVG 언샤프 마스크**(feConvolveMatrix 3×3, 커널 합 1.0으로 밝기 보존)
    + 미세 대비/채도(`contrast(1.05) saturate(1.03)`). 외부 라이브러리/CDN 없음(엄격 CSP 준수).
  - **원본 파일·다운로드 품질은 그대로**(필터는 화면 표시 전용). 진짜 해상도 복원은 불가 — "부드럽게 크게 보기 + 선택적 선명도" 수준(한계 정직히).
- XSS: 파일명은 `textContent`로만 삽입(안전). 중복 초기화 방지 `window.__knkPvInit` 가드.

### 2) `app/templates/_v5_partials/chrome.html`
- 말미에 `{% include "_v5_partials/photo_viewer.html" %}` 1줄 추가(전 페이지 전역 로드).

### 3) `app/templates/consumable_detail.html`
- 라인 사진 링크 2곳(사진위치 LOCATION·사진 PICTURE)에 `data-knk-zoom data-knk-name="..."` opt-in 추가.
  `target="_blank"`는 폴백으로 유지(JS 미동작 시 원본 새 창).
- 사진 업로드 후 셀을 다시 그리는 JS(`cell.innerHTML=...`)의 앵커에도 `data-knk-zoom` 추가
  → 새로 첨부한 사진도 뷰어로 열림.
