## 1. ① AI 행 원산지 공란 — **원인이 하나가 아니었다**

내가 앞서 *"AI 저장문에 `origin` 컬럼이 없다"* 고만 보고했는데, 코드를 다시 보니 **원인이 둘**이었다.

| | |
|---|---|
| ㉠ | `INSERT ... export_hs_dict(part_key,model,name_en,vn_name,hs_code,status,…)` — **`origin` 컬럼 자체가 없음** |
| ㉡ | 🔴**애초에 저장할 원산지를 안 들고 왔다** — `_hs_items_for_project` 가 `order_items.origin` 을 읽어 오는데 `targets.append(...)` 에서 **그 값을 버렸다** |

㉠만 고쳤으면 여전히 공란이었을 것이다. **둘 다** 고쳤다.

```python
targets.append({..., "origin": str(it.get("origin") or "").strip()})
```
```python
"INSERT OR IGNORE INTO export_hs_dict(part_key,…,hs_code,origin,status,…)"
…  t["_hs"], t.get("origin") or "", "AI", 0, "AI",
   "AI 추정 — 검토 필요" + ("" if t.get("origin") else " (원산지 미기재)"), …
```

⛔**AI 에게 원산지를 추정시키지 않는다.** AI 프롬프트는 지금도 HS 8자리와 베트남어 품명만 물어본다.
원산지는 **세관 신고 항목**이라 지어내면 안 된다(z1041b 규칙: *틀린 값보다 빈 값*).
없으면 사유에 **'(원산지 미기재)'** 라고 남겨 사람이 채우게 한다.

### ⚠ 실효는 여기까지다 (정직히)
- 이 수정은 **앞으로 만들어질** AI 행에 적용된다. 통관 입력표에 **원산지가 적혀 있을 때만** 따라간다.
- **이미 있는 AI 행 165건은 안 바뀐다.** 그건 **검토표(z1044)로 채우는 것이 맞다.**
- 로컬 검증 DB 는 통관 품목 174건 중 **원산지 기재가 0건**이라, 실제로 값이 넘어가는 것은
  `INSERT` 문을 직접 실행해 확인했다(칸/값 대조 후 되돌림). **LIVE 에서 몇 건이 채워질지는 모른다.**

## 2. ② 원산지를 말없이 덮던 것

`같은 HS 재출현` 갈래가 이랬다.

```sql
origin = CASE WHEN ?<>'' THEN ? ELSE origin END   -- 새 값이 있으면 무조건 덮음
```

**HS 는 다르면 `PENDING`(확인 대기) 으로 세우면서 원산지만 조용히 바꾸고 있었다.**
`GERMANY×4 → CZECHIA` 처럼 아무도 모르게 바뀐다. [[feedback_data_connectivity]](자동연결=명확한 단일후보만)에 어긋난다.

### 고친 규칙

| 상황 | 처리 |
|---|---|
| 새 값이 비었음 | 그대로 (변화 없음) |
| 기존이 비었음 | **채운다** (채움은 안전) |
| 같은 값 | 그대로 |
| **다름** | ⛔**덮지 않는다** + 사유에 기록 · `or_clash` 로 셈 |

```
⚠원산지 이견: 기존 KOREA ↔ 신규 JAPAN (Invoice&packinglist_VN(260420).xlsx)
```

⚠**상태는 건드리지 않는다.** HS 는 맞으므로 자동 채움은 계속 쓸 수 있어야 한다.
103종을 `확인 대기`로 쏟아내면 **HS 자동 채움까지 막혀** 과잉이 된다.
대표가 z1044 에서 승인한 원칙 — *"다르면 값은 그대로 두고 사람이 고른다"* — 을 원산지에 적용한 것이다.

화면 결과 표시도 **충돌과 따로** 센다.
`✅ 파일명 — 60행 (추가 0 · 갱신 57 · ⚠원산지 이견 4)`

## 4. 안 한 것

- **기존 102종을 자동 정리하지 않았다** — 어느 쪽이 맞는지는 시스템이 모른다. 검토표로 사람이 고른다.
- **원산지 표기 표준화(SWISS→SWITZERLAND 같은 사전)** — 만들면 편하지만 **잘못 묶으면 세관 신고가 틀어진다.**
  대표·통관 담당 확인 후 별건으로.
- **이미 있는 AI 행 165건 원산지 채우기** — 검토표 경로가 이미 있다.

### ⚠ 아직 못 본 갈래 (정직히)
`확인 대기` 상태인 줄에 원산지 이견이 겹치면 **HS 충돌 사유가 원산지 사유로 덮인다**(사유 칸이 하나뿐).
실제 19개 파일에서는 **0건**이라 재현되지 않았다. 발생하면 사유 칸을 두 줄로 나눠야 한다.
(누가 확정했는지는 `review_file` 칸에 따로 남아 있어 출처는 안 잃는다.)
