## 1. 「쓰는 곳」 전수 (코드 grep: `mail_att` · `_att_dir` · `_content_att_path` · `mail_attachments` · `path` · `sha256` · `get_attachment`)
첨부 파일을 **경로로 들고 있는 곳은 `mail_attachments` 표 하나뿐**이다. 나머지는 모두 그때 바이트를 읽어 복사한다.

| 곳 | 파일을 어떻게 쓰나 | 정리에서 |
|---|---|---|
| `mail_attachments.sha256` · `.path` (받은·보낸·임시보관·예약(`direction='sched'`)·휴지통(1)·완전 삭제 대기(2)·차단·스팸·본문 그림(cid, `is_inline=1`)) | 경로·지문을 줄에 적어 둠 | **모든 줄 = 쓰는 곳**(메일 상태로 거르지 않음 · 주인 메일 줄이 없는 떨어진 줄도) |
| 옛 방식 경로 `data/mail_att/<메일 번호>/<첨부 번호>_이름` (z525 첫 판) | `path` 에 적힘 · `sha256` 없음 | 그 메일 번호·첨부 번호 줄의 `path` 꼬리와 맞춰 봄 |
| 보기·내려받기 `GET /mail/{id}/att/{aid}` · 락아 읽기 `/api/mail/ro/.../attachment/...` · 본문 대신 보기(`view_body_fallback`) | 줄의 `path` 로 그때 읽음 | 줄이 있으니 남음 |
| 전달(`fwd_src`) · ⏱ 예약 보내기 · 👉 맡기기(이음으로 파일 넘김, `mail_delegate`) | `get_attachment` 로 바이트를 읽어 **복사**해 보냄 | 파일 경로를 따로 안 들고 있음 |
| 웍스 수주·견적·프로젝트 | 메일 첨부를 경로로 잇는 곳 **없음**(전수 grep · `att_id`·`mail_att` 참조는 메일 코드뿐) | 영향 없음 |
| 큰 파일 링크 `data/mail_large/<토큰>/` | 다른 폴더 · 자기 기한 정리(`purge_expired_large`) | 건드리지 않음 |
| 하이웍스 옮기기 중간 파일 `data/mail_hwm_tmp` | 다른 폴더 | 건드리지 않음 |
| 아웃룩 가져오기 · 하이웍스 옮기기 저장 | `_save_attachments` → 같은 내용 파일 재사용 | 재사용 때 **수정 시각을 지금으로**(아래 3) |
| 옛 KNK 메일(15_KNK_Mail · 다른 컨테이너 `/opt/knk_mail`) | 첨부를 DB BLOB 로만 읽음 · 웍스 디스크와 다른 곳 | 영향 없음 |
| `deploy/migrate_mail_blobs_to_files.py`(BLOB → 파일 옮기기 · 한 번 쓰는 도구) | 같은 내용 파일 재사용 | 재사용 때 수정 시각 새로(같은 보호) |
| DB 백업 사본(`knk.db.bak_*`) | 되살리면 옛 줄이 돌아옴 | 「아무도 안 씀」을 처음 본 날부터 7일 여유 → 최근 7일 안의 백업을 되살려도 첨부가 깨지지 않음 |

## 2. 동작 — `app/mail_store.py`
- `purge_orphan_att_files(session, now=None, max_files=3000, max_secs=300)` — 밤 23:30 틀에서 `purge_expired_pending` **바로 뒤**, 큰 파일 정리·줄이기(VACUUM) 앞.
  1. 금지 시간(평일·주말 08:50~09:30 · 월 02:00~07:30) = 기존 `mail_vacuum.quiet_reason` 을 함수 안에서 먼저 보고, 지우는 동안 50개마다 다시 봄.
  2. **디스크 목록 먼저**(DB 안 엶 · 바로가기 안 셈) → **쓰는 곳은 읽기 한 번**(`mail_attachments` 의 지문·경로 꼬리 · 쓰기 잠금 없음).
  3. 지우는 조건(모두): 쓰는 곳 0 · 파일 수정 시각 7일 지남 · 「아무도 안 씀」을 처음 본 날(새 표 `mail_att_orphan_seen`)부터 7일 지남.
  4. 지우기 직전 그 파일 하나만 다시 셈(지문 색인) → 이름을 바꿔 떼어 냄(`.orphan_del`) → 수정 시각·쓰는 곳을 **한 번 더** → 그래도 0 이면 지움. 중간에 쓰는 곳이 생기면 제자리로. 멈춰서 떼어 낸 채 남은 것은 다음 밤 제자리로.
  5. 모르는 모양 파일은 안 지움(세기만) · 옛 방식 메일 번호 폴더가 비면 치움 · 7일 넘은 저장 중 임시 파일(`.tmp_`)은 지움.
  6. 안전 멈춤: 첨부 줄이 0 인데 파일만 있음(다른 DB) · 줄은 있는데 디스크 파일과 하나도 안 맞음(다른 폴더) → 아무것도 안 지우고 `night_att_stop` 이력.
  7. 결과 = 기존 이력 표 `mail_purge_log` 한 줄(`night_att_files` · 주인·누른 사람 NULL = 시스템 · 지운 수 · 크기 · 기다림 · 남긴 수와 까닭 · 상한 걸림).
- `_write_content_file` — 같은 내용 파일을 다시 쓸 때 `os.utime` 으로 수정 시각을 지금으로(그 사이 밤 정리가 떼어 냈으면 새로 씀).
- `count_orphan_att_files` — 미리 세기(지우지 않음 · 아무것도 안 씀) · `last_orphan_result` — 마지막 결과 한 줄.
