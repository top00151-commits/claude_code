## 1. 무엇이 문제였나

충돌 사유(`충돌: 기존 76169990 ↔ 신규 94054990 (Invoice&packinglist_VN(260311).xlsx)`)를
템플릿이 **34글자에서 잘라** 화면엔 이렇게만 나왔다.

```
충돌: 기존 76169990 ↔ 신규 94054990 (Inv…
```

**하필 잘린 자리가 파일명 앞**이다. 사용자가 알아야 할 것은 *"어느 파일과 충돌했나"* 인데
바로 그것이 `…` 뒤로 사라졌다. 칸은 `width:96px` 고정이라 넓힐 수도 없었다.

> 대표가 "너비 조정"이라고 표현했지만, **넓혀도 안 보인다** — 서버가 이미 잘라서 보냈기 때문.

## 3. ⚠ 배포하고 나서 한 번 더 — z1043b

LIVE 화면을 보니 **HS코드가 숫자 중간에서 끊겨** 있었다.

```
충돌: 기존 76169990 ↔ 신규 9
4054990 (260311)
```

`word-break:break-all` 때문. **통관은 법적 신고라 코드 오독은 위험**하다.

```css
.hsd-note { font-size:10.5px; color:#b45309; line-height:1.5; margin-top:3px;
  white-space:pre-line; word-break:keep-all; overflow-wrap:break-word; }
```

`keep-all` + `overflow-wrap:break-word` = **띄어쓰기에서만** 넘어간다.
`↔` 를 줄바꿈으로 바꿔(`white-space:pre-line`) 기존/신규가 각 줄에 오게 했다.

```
충돌: 기존 76169990
신규 94054990 (260311)
```
