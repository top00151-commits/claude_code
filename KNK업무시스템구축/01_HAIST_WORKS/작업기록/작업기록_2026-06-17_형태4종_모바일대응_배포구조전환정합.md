## K. 앞으로의 규칙 (이 세션에서 확정/갱신)
1. **WORKS 배포 = 모노레포(`claude_code`)에만 push** → 미러 자동 → 배포repo → NAS. **배포repo 직접 push 금지.** main.py도 모노레포 포함.
2. 형태 = **완제품/제품/상품/기타**, 호기는 **완제품만**. (`knk_form_types_finished_goods.md`)
3. 새 페이지 모바일: styles.html include만 하면 viewport·셸 자동. 다단 그리드 768px 1열·넓은표 overflow-x. (`knk_mobile_responsive_standard.md`)
4. `hidden` 안 먹으면 author display CSS 함정 의심 → `#id[hidden]{display:none!important}`. (`knk_hidden_attr_css_trap.md`)
5. `/api/version` 은 이제 **미러 커밋 SHA**를 보여줌(내 모노레포 커밋 SHA 아님).
