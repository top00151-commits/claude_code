## 1. 원인 (재 봄)
- **단위**: 엑셀에서 수량 단위(EA·SET·PCS)는 글자가 아니라 **수량 칸(F)의 표시 형식** 안에 있다(`###,###\ "SET"`). 바꾸기(z1191u)는 값만 옮기고 **칸 서식은 최종 양식 줄의 것**을 썼다.
  - 그래서 원본 SET 이 EA 로 바뀌었고, 거꾸로 최종 양식 8번째 품목 줄(41행 · 대표 260921 에서 온 SET)이 원본 EA 줄을 SET 으로 바꿀 수도 있었다.
- **패킹**: 원본 패킹 시트의 품목만 옮겼다. 261110 은 원본 패킹 시트에 품목이 **0줄**이라 새 파일 패킹도 비었다.
- 옛 인보이스 실물(57개 · 읽기만): 단위 EA 5,835줄 · **SET 44줄 · PCS 8줄** · 단위 없음 103줄. **SET/PCS 가 섞인 파일 25개.** 패킹 빈 파일은 261110 하나.

## 2. 무엇이 바뀌나 (`app/hs_form_convert.py` 중심)
- **수량 단위 = 올린 파일 줄마다 그대로**
  - 원본 수량 칸 형식에서 단위 글자를 읽어(없으면 G 칸의 단위 글자) 새 파일의 같은 품목 줄에 **같은 단위의 표시 형식**을 입힌다. 글꼴·테두리·정렬은 최종 양식 그대로, 단위만 원본.
  - 원본에 단위가 없는 줄은 최종 양식 첫 줄 서식(EA).
  - 인보이스·패킹 둘 다.
- **패킹 = 원본이 비면 인보이스 품목으로 채움**
  - 원본 패킹에 품목이 하나도 없을 때만: 인보이스 품목 중 품명(D) 또는 수량(F)이 있는 줄을 패킹 양식에 맞춰 넣는다(번호·품명·수량·단위 · 수책은 관리코드 B 포함).
  - **중량·부피·박스는 빈칸**(인보이스에 없는 값 — 지어내지 않음).
  - 원본 패킹에 품목이 있으면 전처럼 원본 패킹 그대로.
- **검사(바꾼 뒤 대조)에 단위 추가**: 줄마다 원본 단위 ↔ 새 파일 단위가 다르면 「단위: 원본 X · 새 파일 Y」로 경고.
- **화면 안내**(`export_hs_fill.html`): 바꾸기 결과 줄에 「수량 단위는 올린 파일 그대로(SET 1줄)」·「패킹 19줄은 인보이스 품목으로 채움(중량·부피는 비어 있음)」(해당할 때만).
- **`main.py` 두 줄**: 바꾸기 결과에 `units`·`pl_from_inv` 를 화면으로 넘김.
- **안 바꾼 것**: 품목 값·HS 채우기·머리(보내는 곳·받는 곳)·DB·권한
