## 2. z373b — 프로젝트 상세 단가·금액 전면 비공개 (보안)

### 왜
z373으로 **모든 제작요청 통보가 전부서에 `/project/{id}` 링크**를 보낸다. 그 링크로 들어온 **비영업 부서원**(생산·품질·제조 등, `can_view_sales` 없음)이 도착하는 프로젝트 상세에 단가·금액이 그대로 보이면 "금액 비공개"가 깨진다. (프로젝트 상세는 로그인만 하면 전직원 열람 가능.)

### 권한 관계(핵심)
- `can_money = can_view_sales(u)` 는 `can_use_sales(u)`(편집권한 `_editable`)를 **포함**.
- 따라서 `{% if _editable %}` 편집 입력칸은 이미 안전 → **표시값(display)만** 가리면 됨.

### 방식
표시값을 `{% if can_money %}{{값}}{% else %}🔒{% endif %}` 로 마스킹(표의 **열 수·구조 유지**, 레이아웃 안 깨짐). CSS 숨김은 view-source 로 새므로 서버 마스킹.

### 가린 지점(전수)
통화별 합계 · 전체 수주 합계(그랜드토탈+KRW환산) · 통관표 7곳(금액KRW/인보이스단가·금액USD/관세KRW·USD/최종USD/단가) · SO 합계·합계차액 · 자식 프로젝트 수주액·누적 · 소모품 사용 이력(단가·금액·합계) · 소모품 수주 이력(단가·합계·합계) · 우측 패널 수주액(단가×수량·호기별 분해 포함)·최종 고객 매출 · 마진 분석 버튼. (KPI 매출 카드는 z372에서 이미 게이트.)
*HS코드·관세율(%)·VAT율(%)·통화코드·환율(fx_rate)은 금전 수치가 아니므로 제외.*

### 변경 파일
- `app/templates/project_detail.html` (가격 게이트)
- `KNK_시작.bat` (z373 라인에 후속 기록 추가)
