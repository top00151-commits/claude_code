## 4. 고치실 때 쓰실 공용 한 벌 (이미 배포돼 있습니다)

같은 규칙을 화면마다 따로 쓰다가 생긴 일이라, **계산과 표기를 각각 한 곳에만** 뒀습니다.

### 서버 — `app/main.py`

```python
_ccy_breakdown(rows, amount_key, ccy_key="currency", date_keys=(), rates=None)
# → {"by_ccy":[{currency,total,cnt}], "mixed":bool, "krw":float|None,
#    "missing":[(통화,'YYYY-MM')], "naive":float}
```

- `rates` 는 `_fx_load_rates(c)` 또는 커서가 없으면 `_fx_rates_now()`
- `date_keys` = 환산 기준월을 뽑을 날짜 칸 후보. **대표규정 §4 규칙48 — 기준은 납품월**
- 환율이 없는 통화가 섞이면 **`krw` 를 `None` 으로 돌려줍니다**(반쪽 숫자 금지)
- ⚠ `naive` 는 통화 무시 단순합입니다. **화면에 쓰지 마십시오** — 시험 대조 전용입니다

발주 목록이라면 이런 모양이 됩니다:

```python
po_total_bd = _ccy_breakdown(
    orders, "total_amount", "currency",
    date_keys=("order_date", "due_date"), rates=_fx_load_rates(c))
```

### 화면 — `app/templates/_v5_partials/knk_ccy_total.html`

```jinja
{% import "_v5_partials/knk_ccy_total.html" as _ccy %}
...
{{ _ccy.ccy_total(po_total_bd) }}          {# 통화 하나면 예전 그대로 보입니다 #}
{{ _ccy.ccy_total(po_total_bd, compact=true) }}   {# KPI 카드처럼 좁은 칸 #}
```

- **통화가 하나면 예전과 똑같이** 한 줄로 보입니다(「잘 되는건 안 건드린다」)
- 섞이면 통화별로 나눠 적고 그 아래 `≈ ₩…(월 기준환율로 바꾼 합계)` 를 붙입니다
