# 작업기록 — 프로젝트 변경 이력 금액 마스킹 (z896)

- 일자: 2026-07-09
- 담당: 빅터(01 세션)
- 지시: 김정락 대표 — "프로젝트 상세의 프로젝트 변경이력에 금액이 다 나온다. 일반 직원이 보면 안 된다."
- 관련 이전 작업: [[z894]] 전사일정표 관리번호 클릭 → 제작요청서 보기로 우회(진입 링크 차단). 이번 z896은 **변경 이력 자체의 금액 마스킹**(별개 사안).

## 배경 / 문제
- 프로젝트/수주 상세의 **📜 프로젝트 변경 이력**이 `field / old_value / new_value / note`를 아무 게이트 없이 그대로 렌더.
- 실제로 이력에 **금액 원문**이 텍스트로 저장됨:
  - 헤더 인라인 편집이 `amount_krw`(매출/수주액) 허용 → old/new 에 금액 원문.
  - `수주액(자가치유)` old/new = 금액.
  - `수주발행(자동)` note = `(10,000,000)`, `단가 … × N = …`.
  - `호기 추가` new = 단가, `호기 수정` new = `단가 X → Y 통화`(납기·라벨 등과 혼재).
- 같은 페이지의 다른 금액(KPI·단가·자식 프로젝트 합계)은 모두 `can_sales_amt`로 🔒 처리되는데 **변경 이력만 빠져 있었음** → `feedback_price_gating_can_money`·`knk_field_access_policy` 위반.
- 추가로 수주 상세 라우트(`GET /sales/orders/{id}`)는 로그인만 확인(영업 권한 가드 없음)이라 일반 직원도 접근 가능 → 이력 금액 노출 경로가 둘.

## 방침 (대표 확인)
- 금액 = 기술영업팀 권한자(대표·임원 등)만 열람. **권한 없는 등록자가 우회 접근해도 마스킹으로 비노출**.
- 게이트 = 페이지의 다른 금액과 동일한 `can_view_field(u,'sales_amount')`(= `can_sales_amt`, 팀별 매출금액 정책).
- 이력 줄 자체는 유지하되 **가격 부분만 🔒**(납기·상태·라벨·건수 등 비가격 변경은 그대로 보이게). 서버 소스에서 마스킹 → 브라우저로 금액이 아예 안 나감(두 화면 동시 커버).
- 환율(`fx_rate`)은 금액이 아니라 이번 범위 제외(노출 유지).

## 변경 파일
1. `app/database.py`
   - `get_project_history(project_id, limit, mask_money=False)` — `mask_money=True`면 `redact_history_money()`로 가격 항목 🔒 치환 (단일 소스).
   - 신규 헬퍼: `_HIST_MONEY_FIELDS`(amount_krw 등)·`_HIST_MONEY_KW`(단가·금액·수주액·매출·매입·원가·공급가·판매가)·`_HIST_AMOUNT_RE`(천단위 콤마) + `_hist_seg_is_money` / `_hist_mask_value`(‘ / ’ 세그먼트 단위, 가격 세그먼트만) / `_hist_mask_note`(금액 신호 있으면 “금액 비공개 🔒”) / `redact_history_money`.
2. `app/main.py`
   - `project_detail`(라인 ~6621): `mask_money = not can_view_field(u,'sales_amount')` 전달.
   - `sales_order_detail`(라인 ~18014): 동일.
3. `app/templates/project_detail.html` — 이력 카드 아래, 비권한자(`not can_sales_amt`)에 “🔒 단가·매출·수주액 등 금액 항목은 열람 권한자만 표시됩니다.” 안내.
4. `app/templates/sales_order_detail.html` — 이력 표 아래 동일 안내.
