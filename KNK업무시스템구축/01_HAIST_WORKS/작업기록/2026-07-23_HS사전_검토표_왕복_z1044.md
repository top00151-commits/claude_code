## 0. 착수 전에 짚은 것

- 사전은 **928건**인데 화면은 **400건까지만** 보인다 — 내보내기는 화면 제한을 따르면 안 된다.
- 기존 [업로드]는 **인보이스 파서**(`_hs_parse_invoice_xlsx`)뿐이라 **검토표를 올리면 못 읽는다** — 되받는 경로가 없다.
- 928행짜리 엑셀이 왕복하면 **아무도 안 건드린 칸까지 통째 덮어쓰는 사고**가 가장 위험하다.
- 한국·베트남이 각각 고친 파일 **2개**가 돌아오는데, 규칙이 없으면 **나중에 올린 쪽이 조용히 이긴다**.

## 2. 만든 것

### 2-1. 내보내기 — `GET /export/hs-dict/review.xlsx`

시트 `HS검토표` 한 장, 14열. **충돌·AI 추정이 맨 위**, 줄 색으로 구분(⛔연빨강 / 🟡연노랑).

```
[1행] 제목
[2행] 검토자 [        ] ← 이름 (비우면 파일 이름으로 구분)
[3행] ①고칠 것만 파란 칸에 ②지금 값이 맞으면 같은 값을 그대로 → '확정'으로
      ③HS는 숫자 8자리 ④다 적었으면 그대로 [파일 올리기]에
[4행] # │ 규격(모델) │ 영문 품명 │ 상태 │ 확인 사유 │ 현재 HS │ 확정 HS │
      현재 원산지 │ 확정 원산지 │ 현재 베트남어 품명 │ 확정 베트남어 품명 │
      검토 의견 │ 횟수 │ 최근 출현
```

| | |
|---|---|
| 잠금 | **시트 보호** — 회색(현재 값) 칸은 못 고침. 파란 칸 4개 + 검토자 칸만 열림 |
| 그래도 되는 것 | **필터·정렬·열너비** (막으면 928행을 못 쓴다) |
| HS 칸 | **텍스트 서식(`@`)** — ⚠엑셀이 앞자리 0 을 먹는다(`04059990`) |
| 고정 | 머리글 + 번호·규격 열 (`freeze C5`) · 자동필터 `A4:N932` |

### 2-2. 되받기 — 같은 `POST /export/hs-dict/upload`

**머리글 엄격 대조**로 판별한다 — `규격(모델)` + `확정 HS코드` 두 머리글이 다 있으면 검토표.
없으면 기존 인보이스 파서로 넘어가고, **둘 다 아니면 사람 말로** 알린다
(⛔위치 폴백 없음 — z978 규정).

반영 규칙 (`_hs_apply_review`)

| 담당자가 한 것 | 결과 |
|---|---|
| 값을 **다르게** 적음 | 그 칸만 반영 + **확정**으로 |
| 값을 **같게** 적음 | 값 그대로 + **확정**으로 승격 (= "지금 값이 맞다"는 확인) |
| **의견만** 적음 | 상태는 **그대로**, 의견만 기록 |
| **아무것도 안 적음** | **손도 대지 않음** |
| HS 가 8자리가 아님 | 그 줄만 걸러 `⛔HS 형식오류 n` 로 보고 |
| 사전에 없는 규격 | 건너뜀 (사전 성장은 인보이스로만) |

⭐**충돌 판정** — `export_hs_dict.review_file` / `review_at` 칸 신설.
'누가 확정했나'를 저장해야 충돌이 보인다.

> **충돌 = 다른 검토자가 이미 채워 놓은 값을 다르게 적은 것.**
> **빈 칸을 채운 것은 충돌이 아니다**(서로 나눠 적은 것).
> 인보이스에서 온 값을 검토자가 고치는 것도 충돌이 아니다(그게 검토다).

충돌하면 **값은 아무 것도 바꾸지 않고** `PENDING` 으로 두고 사유를 남긴다 — 통관은 법적 신고.

```
검토 충돌: HS코드 84123100 ↔ 85444294 (안지연 프로 ↔ 베트남 통관담당)
```

⚠줄 매칭은 **번호(`#`) + 규격 이중 확인** — 번호만 믿으면 담당자가 정렬한 순간 줄이 밀린다.
어긋나면 번호를 버리고 규격으로 찾는다.
