## 1. 찾은 것 (운영 `uvicorn.log` 최근 20만 줄 · 약 9/8~10/11 · 읽기만)

| | |
| --- | --- |
| 9/14(추정) | `/sso/land` → `upsert_user_from_payload` → `sqlite3.OperationalError: database is locked` → **500** — 이음에서 WORKS 를 연 사람이 오류 화면을 봤다 |
| 10/2(추정) | 같은 자리에서 같은 잠김(이때는 500 으로 끝난 기록은 없음) |

| 매출·영업 화면 | 9/1 이후 서버 오류(5xx) 0번 |

- WORKS 의 DB 연결은 다른 쓰기를 **5초**(`timeout=5.0` · `busy_timeout 5000`) 기다린다. 그보다 오래 잡혀 있으면 「database is locked」. 5초 값은 모든 화면에 걸려 있어 **바꾸지 않았다**(세션 16 도 같은 의견).
- 코드를 따라가 보니 두 갈래였다.
  - **있는 직원** — 정보 갱신 `UPDATE users` 가 잠김을 그대로 올려 **500**(9/14 와 같음).
  - **처음 들어오는 사람** — `sso_client` 의 새 직원 `INSERT` 는 **모든 예외를 삼키고 None** → 화면은 「사용자 동기화 실패(사번 컬럼 마이그레이션 필요 가능)」 → 잠김인데 **엉뚱한 안내**.
