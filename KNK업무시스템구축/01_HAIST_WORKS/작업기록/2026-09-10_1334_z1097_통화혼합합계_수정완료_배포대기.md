## 1. 무엇이 잘못돼 있었나

프로젝트 **005M2511 · BIM LINE**(프로젝트 통화 USD) 아래쪽 「수주번호 합계」:

| 수주번호 | 통화 | 금액 |
|---|---|---|
| M-251127-1 | **USD** | 83,882.73 |
| M-260819-2 | **KRW** | 1,720,000 |

`83,882.73 + 1,720,000 = 1,803,882.73` — **원화를 달러로 취급해 그대로 더했다.**
대표 사진의 적색 숫자와 한 자리도 다르지 않다.

원인 코드(수정 전 `project_detail.html:1190`):

```jinja
{% set _gtotal.t = _gtotal.t + (_so.total_amount or 0) %}   ← 통화를 안 봄
{% set _gt_ccy = p.currency or 'KRW' %}                     ← 표시는 프로젝트 통화 하나
```

⭐ **같은 화면 위쪽 「확정 매출」 KPI 는 이미 통화별로 나눠 그리고 있었다**(`v5H226z696`).
서버도 통화별 정확한 합계(`currency_mix`)를 이미 계산해 화면에 넘기고 있었다.
**아래쪽만 그 규칙에서 빠진 것** — 대표규정 「⛔한 곳만 고치고 완료 금지」의 교과서 사례.
