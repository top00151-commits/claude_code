## 1. 적용 내용 (z992/z999 레시피 그대로)

### suppliers.html (목록)
- 머리글 → `knk-page-head`(+Tabler): 엑셀 내보내기 `ti-download`·양식 받기 `ti-file-spreadsheet`·
  일괄 등록 `ti-upload`(ghost) · **협력사 등록 `ti-plus`(브랜드 primary — 이전 '잉크 검정' 폐지)**
- 일괄등록 결과 배너(인라인 스타일) → `knk-alert--success`+닫기 knk-btn--sm
- KPI 4칸(전체/활성/국내/해외) → `knk-kpi-strip`(페이지 `.kpi-cell` CSS 삭제)
- 검색 버튼 → **'조회'**(§25 용어 통일)+`knk-btn--sm` · 빈상태 → `knk-empty`(`ti-building`)
- **협력사 카드 그리드(sp-grid/sp-card·부서띠·연락처·상태 알약) = 업무 특화 유지** — 색만 브리지로 Sage
- :root 부분 선언(ok/info/warn만) → **전체 pq→knk 브리지**(+`--pq-line-3`→border-strong 포함)

### supplier_form.html (폼)
- :root 전체 브리지(z999 표준) · 머리글 → knk-page-head(제목 🏢 제거·코드 knk-num·활성 알약 유지·
  목록 `ti-arrow-left` ghost·발주 `ti-plus` secondary)
- 섹션 4개(기본 정보/연락처/결제·거래 조건/주소·비고) → `knk-form-section`(__head/__title/__body,
  h3 잉크바 ::before 폐지) · 필드 16곳 → `knk-field`(맨 input 공통 규격 36px·**포커스 `#3E6F89`** —
  이전 '잉크 테두리+그림자' 폐지) · `.field-row` 2/3열 그리드·`.field-hint`·`.mono`는 페이지 유지
- 하단 액션바 → `knk-submit-bar is-sticky`(하단 고정 유지) · 저장=**브랜드 primary**·취소=ghost
- 사이드 위험 버튼 → `knk-btn--sm knk-btn--danger` · **chip-pick(활성/비활성 라디오칩)·
  요약/리드타임 통계/입력 가이드 사이드 카드 = 업무 특화 유지**(브리지로 Sage)
- 로직·Form name(name/code/contact/…)·삭제 confirm 전부 불변(§18)
