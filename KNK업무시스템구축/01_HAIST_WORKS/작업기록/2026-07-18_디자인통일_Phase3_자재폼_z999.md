## 1. 공통 컴포넌트 확장 (knk-components.css — 폼 전환의 선행 작업)

- **`.knk-field` 직계 맨 요소도 같은 규격**: `.knk-input/.knk-select/.knk-textarea` 계열 8개 규칙
  (base·textarea·hover·focus·focus-visible·placeholder·readonly·disabled)에
  `.knk-field > input/select/textarea` 를 그룹 셀렉터로 병기.
  → 폼의 input 42곳에 클래스를 일일이 붙이지 않고 **한 소스**로 동일 규격. 깊이 중첩된
  업무 특화 입력(`.pp-vendor` 구매사 카드 등)은 직계가 아니라 **제외되어 기존 모습 보존**.
  hidden input 도 직계지만 UA `display:none` 이 유지되어 무영향.
- 라벨도 동일: `.knk-field__label` 에 `.knk-field > label`, `.required` 에 `.req` 별칭 병기.
- **`.knk-col-3`**(3칸 폭) 신설 + 반응형 2단(≤1023px→span2·≤767px→span1)에 포함.
- 스코프 검사기: foundation 2블록·components **100블록 전부 `.knk-`**·`!important` 0 ✅

## 3. 🔧 숨은 결함 수복 — '추가 규격' 고아 섹션

- **실측**: 변환 전 div 여닫 = **137/138(닫힘 1개 과잉)**. '추가 규격 · 문서 출력명' 섹션이
  여는 `<div class="qsec">` 없이 `qsec-h`+`f-body`만 있고, 끝의 잉여 `</div>`가 우연히 균형을
  맞추던 **고아 구조**(브라우저가 관용 파싱으로 버텨온 것).
- **수복**: 섹션 머리에 `<div class="knk-form-section" data-dn="pf:extra">` wrapper 부여 →
  잉여 닫힘이 정확히 이 wrapper 의 닫힘이 됨. 변환 후 **136/136 균형 0** ✅
  (이제 카드 테두리·배경도 다른 섹션과 동일하게 정식으로 나옴)
