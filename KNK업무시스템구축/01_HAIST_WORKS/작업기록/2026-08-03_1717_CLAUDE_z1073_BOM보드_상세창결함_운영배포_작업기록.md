## 2. 무엇이 잘못돼 있었나

품목 정보를 화면의 각 줄에 실어두는 `data-item` 속성을 **큰따옴표**로 감쌌다.

```jinja
data-item="{{ it | tojson | e }}"      ← 잘못
```

Jinja 의 `tojson` 은 `<` `>` `&` `'` 는 escape 하지만 **`"` 는 그대로 둔다**
(스크립트 태그 안이나 **홑따옴표** 속성에 넣으라고 만들어진 함수이기 때문).

그래서 JSON 의 **첫 `"` 에서 속성이 끊겨**, 브라우저가 읽은 `data-item` 은 **`{` 한 글자**였다.
나머지는 전부 가짜 속성으로 흩어졌다(한 줄에 **69개** 속성이 생김 — 실측).

- 값이 평범해도 **항상** 깨진다. JSON 은 키마다 `"` 를 쓰기 때문이다 → **그 화면의 모든 줄**
- 창을 여는 코드가 `try { ... } catch(e) {}` 라 **아무 표시 없이 조용히 실패** → 오래 발견되지 않음
- `| e` 는 `tojson` 결과(Markup)에 **아무 일도 하지 않는다**. 안전해 보이게 만들던 장식이었다

## 4. 고친 것

```jinja
data-item='{{ it | tojson }}'          ← 홑따옴표. tojson 이 ' 를 ' 로 바꿔주므로 안전
```

`| e` 는 제거했다(하는 일이 없으면서 안전해 보이게 만들던 것). 재발 방지 주석을 같은 자리에 남겼다.
