## 검증 — 직접 실행 2중

**1) 시험 14건 / 실패 0** + 전체 회귀 5종 그린(19/21/23/17/14 = **총 94건 / 0**):
- ⭐ **결정적 골든: 001M의 기존단가 117줄을 지우고 자동 복원 → 허동준 매니저 손 기입값과 100% 일치(117/117)** — 규칙(형번+협력사·최근 발주일)이 본인 작업을 완벽 재현. (단순 형번 대조는 98%였는데 협력사 열쇠를 넣자 100% — "매입처 이원화" 답이 정확했음의 증명)
- 채움 127줄 = 원기입 117 + **마스터 저장(8/20) 뒤 발주된 신규 10줄**(수불부가 8/25까지라) — 도구가 사람 기록보다 최신
- 매입처 이원화·최근일 우선·변동 감지·무결성(다른 칸 무변경)·뼈대 참고 41건(전장 51줄의 80%) 전부 시험으로 고정

**2) 실무 직접 실행** (산출물 대표 전달): 001M 기존단가 138줄 지운 사본 → **127줄 자동 복원 + 견적 대상 12줄 목록**. 전장 뼈대(협력사 미정 51줄) → 채움 0 + **과거 실적 참고 41건**.

🔴 자체 발견·수정: ①시험 truth에 합계줄(P175 SUBTOTAL 수식)이 섞임 — 품목줄만으로 한정 ②변동 감지 시험이 수불부에 없는 형번을 골라 헛침 — 실적 있는 줄로 선택 ③전장 뼈대 직접 실행에서 "협력사 미정이면 아무것도 못 함" 구멍 발견 → 참고 목록 기능 추가 (직접 실행 검증이 잡아준 설계 구멍).

## 도구 사슬 완성 (①→②→③)

```
인벤터 유닛 BOM ─①a→ 간이판 초안 ─①b(+전장 BOM)→ 통일판 뼈대
    ─③→ 기존단가 자동(실적 91%·일치 100%) + 협력사 미정 참고 + 견적 대상 목록
    ─②→ 협력사별 견적요청서(신규만도 가능) · 발주서(--all 13곳 일괄)
```

남은 사람 몫 = 품명 빈칸 보충 · 서보 케이블 전장 협의 · 협력사 확정(비교견적) · 단가 확정 — 인터뷰에서 "사람 판단"으로 분류된 그 네 가지뿐.
