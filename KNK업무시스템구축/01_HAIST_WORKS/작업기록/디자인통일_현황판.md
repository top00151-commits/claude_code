## 4. 재발 방지 핵심 규칙 (작업자 필독)

1. **색 변수**: 셸/공통 CSS의 실팔레트 = v5_main 종이색(`--paper/--paper-2/--paper-3/--line/--ink/--mute/--knk-red`).
   design_v2 계열(`--surface`·`--ink-2`·`--line-2` 등)은 **미정의=선언 무효**. 반드시 폴백 병기. 신규 코드는 `--knk-*`만.
2. **검증**: 색·배치 변경은 배포 전 **LIVE에 후보 CSS 임시 주입→실측→원복**(프로브는 body 끝에 append).
   함정 발견 시 같은 파일 기존 코드까지 **소급 grep**.
   배포 감시는 '버전 변화'가 아니라 **`git ls-remote <배포리포> HEAD` 목표 해시 도달**로 판정(직전 문서
   커밋 미러에 오탐된 z1000 사례). 셸 색 작업 = **design_quiet_v3.html이 실승자**(v5_main은 base).
   ⚠**미러 실행 누락 시(z1005)**: 미러 HEAD가 20분+ 정지하면 '토큰 사망' 단정 말고 **경로(`01_HAIST_WORKS/**`) 안 파일을
   커밋해 재트리거**(빈 커밋은 경로필터 미매칭으로 무효). 미러는 전체 WORKS 서브트리 export라 밀린 변경까지 함께 배포됨.
3. **신규 화면**: 가이드 §26 체크리스트 12항목 + `/admin/design-kit`에서 복사. `<title>`="화면이름 · KNK …" 형식.
4. **금지**: 신규 CSS `!important`·페이지 `:root` 공통색 재선언·영문 enum 노출·hover로 폭 바뀌는 아이콘.
5. **§자동높이(z1009)**: 데이터 표·스크롤 영역 높이에 `max-height:calc(100vh - Npx)` **매직넘버 금지** → 공용 `data-knk-fill`(기본=max-height 측정)/`data-knk-fill="grow"`(flex 눌림 화면·지정높이). 헬퍼=`_v5_partials/knk_autofill.html`(styles.html include). 실제 시작위치 재서 화면 아래까지 채움=모니터 크기 자동 적응. opt-in 전용(잘 되는 표는 그대로)·예외=카드 안/사용자 높이조절/드롭다운/모달/인쇄. 세로=자동채움 ⊕ 가로=풀폭(시트여백) 한 세트. 최초=통관 입력(grow·`ccb446b`). 상세=`2026-07-19_통관표_높이자동채움_표준화_z1009.md`.
6. **§가로스크롤·머리글(z1023)**: 넓은 표(부품 28컬럼 등)는 좌우 스크롤바가 표 **맨 아래**에 있어 세로로 끝까지 내려야만 보였다 → 가로 래퍼에 **`data-knk-hscroll`** 한 줄(헬퍼 `_v5_partials/knk_hscroll.html`). 화면 하단 `position:fixed` 공용 바가 래퍼 폭·위치에 맞춰 뜨고 **양방향 동기화**. ⛔바 위치·폭 매직넘버 금지(래퍼 실측에서 계산)·opt-in 전용. 함께: 데이터가 스크롤되며 **제목 배경 위로 비쳐 올라오면** 그 화면의 `page-head`가 `sticky`인지 확인(부모 `overflow:hidden`이면 `sticky`가 무력화되므로 `static`이 정답인 경우가 많다).
7. **§금액 계산(z1026 · 안지연 프로 요청·대표 확정)**: **판매단가 = 매입 × (1+마진%) — 소수점 이하 버림**(2026-07-21 이전은 반올림이었음). 인보이스(외화) = **소수점 2자리·셋째에서 반올림**. 원화 = 정수.
   - ⛔**계산식을 화면·서버에 각자 적지 말 것** — 서버는 공용 `_sell_from_cost(cost, margin)` 하나로, 화면은 같은 규칙(`Math.floor(Math.round(x*1e6)/1e6)`). z1026 당시 계산 지점이 **4곳**(서버 2·화면 2)에 흩어져 있었다.
   - ⚠️**부동소수 함정**: 그냥 `floor` 하면 `5,800×1.12`가 `6,495.999…`로 떨어져 **1원이 깎인다**(실사례 `2,519,000×1.12 = 2,821,280.0000000005`). **6자리에서 정리한 뒤 버릴 것**.
   - ⛔파이썬 `round()`=**은행식 반올림**(`55,372.5→55,372`). 학교식이 필요하면 직접 구현.
   - 상세=`2026-07-21_판매단가_버림통일_규격중복표시_z1026.md`
8. **§줄·셀 강조(z1026)**: 표의 특정 줄을 강조할 땐 **`background: … !important` 금지** — 매입·마진 칸의 인라인 배경(`#fff7ed`)까지 덮어 **원가 열 구분이 사라진다**. → **덧칠 방식**: `box-shadow: inset 0 0 0 9999px rgba(...)` (공용 클래스 **`knk-row-flag`**, `styles.html` 전역). 기존 색을 지우지 않고 톤만 얹는다.
   - **"중복은 오류가 아니다"** — 같은 규격이 여러 줄인 건 납기가 달라 일부러 나눈 경우가 대부분. **빨강 경고 금지**, 연한 amber + "확인해 보세요" 톤 + 왜 그런지 알려주는 툴팁.
9. **§자동계산은 사용자 입력을 지우지 않는다(z1028 · 안지연 프로 신고)**: 자동계산 함수는 **자기가 관할하는 상태일 때만** 사용자 입력칸을 덮는다.
   - 실제 사고: `qUnitSum()`이 '수량≥2'만 보고 **추가발주 여부를 안 봐서**, 호기줄을 지운 직후 호출되자 빈 배열을 보고 **단가를 지웠다**. 사용자에겐 *"칸 클릭은 되는데 숫자가 안 써진다"*(=**써도 지워짐**)로 보였다.
   - 규칙 ①**관할 조건을 전부 검사**(모드·대상 DOM 존재 여부까지) ②모드가 풀리면 **안내문(placeholder)도 원복**(안 그러면 '못 쓰는 칸'으로 오해) ③**같은 칸을 두 함수가 건드리면 역할을 명확히 가른다**(예: 호기줄 있으면 A, 없으면 B).
   - 상세=`2026-07-22_간편등록폼_단가지워짐_복원갇힘_z1028.md`
10. **§임시저장 복원(z1028)**: **값을 되돌렸으면 그 값에 딸린 화면 상태 함수도 반드시 같이 호출한다.**
