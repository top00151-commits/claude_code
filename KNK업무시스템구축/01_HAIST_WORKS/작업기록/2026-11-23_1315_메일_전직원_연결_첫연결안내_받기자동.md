## 바꾼 것
- **첫 연결 화면** `app/templates/mail_account.html`(받기를 아직 안 켠 사람에게만)
  - ① 하이웍스에서 먼저 설정하기 — 메일 › 환경설정 › 기본 설정 › POP3/SMTP · 「사용 함」 · **수신 대상(최근 6개월 메일 = 권함 / 전체 메일 = 오래된 것까지 · 일주일 뒤 저절로 6개월로)** · 허용 국가 그대로 · 읽음 표시 두 가지 뜻 · 메일 전용 비밀번호 만들기 · 저장
  - ② 지난 메일을 어떻게 할까요? — 「📥 지난 메일도 가져오기」 / 「🆕 지금부터 오는 새 메일만」(둘 다 하이웍스 메일함은 그대로)
  - ③ 계정(주소·메일 전용 비밀번호) + **「위 ①의 하이웍스 설정을 마쳤고, ②에서 … 확인했습니다」에 표시해야 「🔗 연결하고 받기 시작」이 눌림**(서버도 같은 조건을 다시 확인)
  - 연결된 뒤에는 「받기가 켜져 있습니다 · 마지막으로 받은 때 · 지난 메일 가져오는 중」
- **받기 자동** `app/main.py` `POST /mail/account`
  - 첫 연결이면 → DB 를 쥐지 않은 채 하이웍스 POP3 에 접속해 봄 → 안 되면 받기를 켜지 않고 까닭을 알림(잘못된 비밀번호로 계속 두드리지 않게)
  - 되면 → 「새 메일만」 = 지금 하이웍스에 있는 메일을 받아 본 것으로 표시 · 「지난 메일」 = 가져오기 표시 → **받기 켬** → 첫 받기를 바로 한 번(뒤에서)
  - 예전 「보내기 전용 — 새로 연결한 사람은 가져오지 않음」은 없앰
- **지난 메일 가져오기** `app/mail_fetch.py` + `_mailfetch_run_owner_locked`
  - 새 칸 `old_import`·`setup_choice`·`setup_at`(표에 칸만 더함 — 업무 자료를 바꾸지 않음)
  - 가져오는 동안: 한 번에 200통씩(최근 것부터) · **대량 막기(300통 넘으면 하루 치만) 안 함** · **AI 요약 안 함**(느림·비용) · **부재중 자동 응답 안 보냄**
  - 남은 지난 메일이 없으면 저절로 보통 받기로
- **연결 안 한 사람 안내 띠** `mail_app_head.html` — 메일 화면 위 주황 띠 「📮 하이웍스 메일을 아직 연결하지 않았습니다 … 연결하기 →」 · 가져오는 중이면 파란 띠 · 숫자 묻는 입구(`/api/mail/counts`)가 `linked`·`importing` 을 같이 돌려줌
- **본인 주소로 보내기 전원** — 관리자 「메일 보내기 설정」 → 「모든 직원」(설정값 `mail_send_via_fetch=all`) · 코드에 이미 있는 선택 → 올릴 때 바꿈
