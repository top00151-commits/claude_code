| ② 본문 전체가 `<form>` 안(단추 있는 영수증) | 08·11 | 정리 단계가 `<form>…</form>` 를 내용째 지움 |

## 바꾼 것
- `app/mail_store.py`
  - `parse_raw_email`: 글/HTML 부분은 `attachment` 가 아니면 (아직 그 종류 본문이 없을 때) 본문으로 — 이름·inline 표시가 붙어 있어도
  - 첨부의 「인라인(숨김)」은 **그림만** — 그림이 아닌 파일(PDF·엑셀·txt)은 inline 표시가 있어도 첨부 목록에 보임
  - `_decode_part` + 새 `decode_guess`: 모르는 글자 방식이면 HTML 속 `<meta charset>` → UTF-8 → 한국어(cp949) 순으로 짐작해 풂
  - `sanitize_html_for_view`: `<form>`·`<noscript>` 는 태그만 떼고 내용은 남김(스크립트·단추·입력칸은 그대로 지움 · 격리 칸 안이라 안전) · 스스로 닫는 `<svg/>`·`<math/>` 먼저 지움 · `<embed>`(닫는 태그 없음)는 태그만
  - 새 `html_has_content`: 정리한 HTML 에 보일 것(글자·그림)이 없으면 HTML 칸 대신 글 본문을 보여 줌
  - 새 `view_body_fallback`·`inline_is_file`: **예전에 이미 잘못 저장된 메일** — 서버에 본문이 「인라인 첨부」로 그대로 남아 있음 → **보기 때 그것을 본문으로** 꺼내 보여 줌 · 숨어 있던 파일 첨부도 보임 · **운영 DB 는 바꾸지 않음**
- `app/main.py` — 메일 보기(`/mail/{id}` · 새 창)·읽기 칸(`/mail/{id}/pane`) 두 곳에서 위 함수 사용
