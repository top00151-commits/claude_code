## 0. 한 줄 요약

스크린샷의 달력 = **수주관리(`/sales/orders`) 페이지의 "납기 달력"**. 날짜별 **SO 납기 건수**를 **숫자(카운트)**로, **납기까지 남은 일수(D-day)**를 **배경색**으로, **공휴일**을 **K/V 배지**로 표시한다. 일요일 시작, 일·공휴일=빨강 / 토=파랑, 오늘=호박색 테두리.

## 2. 백엔드 — 달력 데이터 만드는 조건

### 2-1. 주(week) 구성
```python
import calendar as _cal
cal = _cal.Calendar(firstweekday=6)        # 6 = 일요일 시작 (KNK 표준)
for week in cal.monthdatescalendar(year, month):
    for dt in week: ...                     # 그 달을 채우는 모든 주(앞/뒤 달 칸 포함)
```
- **주 시작 = 일요일** (`firstweekday=6`). KNK 모든 달력 공통.
- 한 주는 일~토 7칸, 그 달 밖 날짜는 `in_month=False`(흐리게).

### 2-2. 날짜별 납기 집계 — `cal_buckets`
```python
b = cal_buckets[due_date] = {"count": 건수, "amount": 금액합, "overdue": 미납지연수}
# overdue 조건: 납기일 < 오늘  AND  상태 in ("CONFIRMED","DRAFT")  (출하 안 한 지난 건)
```
- `count` = 그 날 **납기인 SO 건수** → 셀의 **숫자**.
- `amount` = 그 날 납기 SO **금액 합** → 툴팁(title)에만 표시.
- `overdue` = 지났는데 아직 미출하(CONFIRMED/DRAFT)인 건수.

### 2-3. D-day 배경색 클래스 판정 — `cls` (핵심 조건)
```python
d_left = (셀날짜 - 오늘).days
if   count == 0:        cls = "empty"     # 납기 없음 → 색 없음
elif overdue > 0:       cls = "overdue"   # 미납 지연 (출하 안 함)
elif d_left < 0:        cls = "past"      # 지난 날 (이미 출하 완료)
elif d_left <= 3:       cls = "d3"        # D-3 이내 (임박)
elif d_left <= 7:       cls = "d7"        # D-7 이내
else:                   cls = "future"    # 8일 이상 여유
```
→ 셀에 `class="cal-day cls-{cls}"` 로 붙어 **배경색 결정**(§4-4).

### 2-4. 셀별 전달 값 (`_build_month` → 템플릿)
`date, day, in_month, count, amount, cls, is_today, is_selected, hol_kr, hol_vn, is_sun(=토 weekday 6), is_sat(=5)`

### 2-5. 월 이동(`cal_ym`)
- 파라미터 `?cal_ym=YYYY-MM` (없으면 오늘 달). `_nav = {prev, current, next}` 한 달씩.

## 3. 셀 표시 조건 (화면)

마크업 기준(`sales_orders.html` L258~273). **그 달 안 날짜만 클릭 가능한 `<a>`**, 그 달 밖은 `<div class="cal-day out">`(흐림).

| 요소 | 조건 / 내용 |
|---|---|
| **클릭(href)** | `?biz=&due_date={날짜}` → 그 **납기일의 SO 목록으로 필터** (달력 아래/옆 리스트). 선택된 날=`is_selected`→`.selected` |
| **날짜 숫자 색** | 일요일 **또는 공휴일** → 빨강 / 토요일 → 파랑 (그 외 먹색). `<span class="d {sun|sat}">` |

## 4. 색·값 표 (정확한 HEX) — 변경 금지 기준값

### 4-1. 요일/날짜 글자색 (KNK 공통)
| 항목 | 색 |
|---|---|
| 일요일 · 공휴일 | **빨강 `#dc2626`** |
| 토요일 | **파랑 `#2563eb`** |

### 4-2. 공휴일 배지
| 배지 | 의미 | 배경 / 스타일 |
|---|---|---|
| **K** | 한국 공휴일 | `#dc2626` 빨강, 흰 글씨 |
| **V** | 베트남 공휴일 | `#fb923c` 주황, 흰 글씨 |
| `.alt` | 대체공휴일 | 흰 바탕 + 해당색 **점선 테두리** |

### 4-3. 오늘/선택/다른달
| 상태 | 스타일 |
|---|---|
| 오늘 `.today` | 안쪽 테두리 2px **`#d4a574`**(호박) |
| 선택 `.selected` | 배경 `#fef3c7` + 안쪽 테두리 2px `#b91c1c` |
| 다른 달 `.out` | `opacity:.25`, 클릭 불가 |

### 4-4. D-day 납기 배경색 (이 달력의 핵심)
| 클래스 | 의미 | 배경 | 글자 |
|---|---|---|---|
| `cls-overdue` | 미납 지연(출하 안 함) | `#fee2e2` 연빨강 (앞에 ⚠) | `#991b1b` |
| `cls-past` | 지난 날(출하 완료) | `#f3f4f6` 회색 | `#6b7280` |
| `cls-d3` | D-3 이내(임박) | **`#fed7aa` 주황** | `#7c2d12` |
| `cls-d7` | D-7 이내 | **`#fef3c7` 노랑** | `#713f12` |
| `cls-future` | 8일+ 여유 | **`#d1fae5` 녹색** | `#065f46` |
| `cls-empty` | 납기 0건 | 기본 `#fafaf7` 베이지 | — |

> 스크린샷 검증(오늘=13): 15일=주황(D-3) / 19일=노랑(D-7) / 22·25일=녹색(여유) / 2·8·10·11·12일=지난(회색) — 규칙과 일치.

## 5. 공휴일 엔진 (KNK 전 달력 공통)

`_build_holidays_auto()` (`main.py:308~354`):
- **Python `holidays` 라이브러리**로 **한국(KR) + 베트남(VN)** 공휴일 자동 생성(음력·대체공휴일 포함).
- 범위 = **작년 ~ 5년 후 (7년치)**. 서버 기동 시 1회 로드 → 전역 `HOLIDAYS_KR`/`HOLIDAYS_VN` dict(`{ "YYYY-MM-DD": "공휴일명" }`).
- **예외**: "제헌절" 제외(2008~ 공휴일 아님). **"근로자의 날"(5/1)** 라이브러리에 없어 수동 추가(KR).
- 템플릿엔 context + `tpl.env.globals` 양쪽으로 주입(`KNK_HOLIDAYS_KR/VN`) → 서버·클라이언트(JS 데이트픽커) 공용.
- **"K"=한국 / "V"=베트남**. (※ 데이터 비면 = 서버 재시작 필요 신호.)

## 6. 네비게이션 (이 달력)

```
📅 2026.06        ← [오늘] → [2026년 06월 ▼]
```
- `←` = `?cal_ym={이전달}` / `→` = `?cal_ym={다음달}` / `오늘` = `?`(파라미터 제거, 오늘 달) / `<input type="month">` = 선택 시 `?cal_ym={선택월}` 이동.
- 사업부 탭(`biz`) 유지: 모든 링크에 `biz={biz}&` 포함.

## 7. KNK 공통 달력 표준 (다른 세션 — 새 달력/수정 시 반드시 준수)

새 달력을 만들거나 기존 달력을 고칠 때 **아래 표준을 그대로 따른다**(시각·동작 일관성):

1. **주 시작 = 일요일** (`calendar.Calendar(firstweekday=6)`).
2. **요일색**: 일요일·공휴일 **빨강 `#dc2626`**, 토요일 **파랑 `#2563eb`**.
3. **공휴일**: 전역 `HOLIDAYS_KR`/`HOLIDAYS_VN` 사용. 한국=**K**(빨강), 베트남=**V**(주황), 대체=점선(`.alt`). 절대 하드코딩하지 말 것(엔진에서 가져오기).
4. **오늘 강조** = 안쪽 테두리 `#d4a574`(호박). 다른 달 = `opacity:.25`.
5. **D-day 색이 필요한 달력(납기·일정 등)**은 §4-4 색 체계(overdue 연빨강 / past 회색 / d3 주황 / d7 노랑 / future 녹색) 재사용.
6. **건수/카운트**는 셀 안 작은 배지로, **금액 등 상세는 툴팁(title)**으로.
7. **셀 클릭**은 그 날짜의 상세/필터로 이동(예: `?due_date=`, `/daily/{date}`).
8. 색·HEX 변경 시 **이 문서를 먼저 갱신**하고 전 달력에 동일 적용.

- [ ] (납기형이면) D-day 색 체계 재사용

## 8. 핵심 생성 규칙 한눈에

- **데이터**: SO들의 **납기일(due_date)** 별로 건수·금액·미납지연 집계(`cal_buckets`).
- **색(배경)** = **납기까지 남은 일수(D-day)** → overdue/past/d3/d7/future.
- **숫자** = 그 날 **납기 건수**.
- **K/V** = 한국/베트남 공휴일(라이브러리 자동).
- **주 시작 일요일**, 일·공휴일 빨강 / 토 파랑, 오늘 호박 테두리.
- **이동**: `?cal_ym=YYYY-MM` (← 오늘 → · 월 선택기). **클릭**: `?due_date=YYYY-MM-DD`(그날 납기 SO 필터).
