# [전산팀 요청] NAS 역방향 프록시 `kmail` 대상 포트 변경 (5053 → 5051)

| | |
|---|---|
| **요청일** | 2026-11-16 (월) |
| **요청자** | 김정락 대표이사 |
| **작업 위치** | 시놀로지 NAS **DSM → 제어판 → 로그인 포털 → 고급 → 역방향 프록시** |
| **예상 소요** | **5분** (포트 숫자만 수정) |
| **되돌리기** | 즉시 가능 (숫자만 원복) |
| **서비스 영향** | **없음** — 업무시스템·메신저·포털 모두 무관 |

---

## 1. 요청 내용 — 한 줄

> **`Haist.KMail` 규칙 2건**의 **「대상」 포트**를
> **`5053` → `5051`** 로 변경 부탁드립니다.

---

## 2. 변경 대상 (현재 등록값 · 2026-11-16 확인)

| 설명 | 소스 | 대상 (현재) | 대상 (변경 후) |
|---|---|---|---|
| **Haist.KMail** | `http://kmail.knknara.co.kr:80` | `http://localhost:`**`5053`** | `http://localhost:`**`5051`** |
| **Haist.KMail** | `https://kmail.knknara.co.kr:443` | `http://localhost:`**`5053`** | `http://localhost:`**`5051`** |

**참고 — 변경하지 않는 규칙** (비교용)

| 설명 | 소스 | 대상 |
|---|---|---|
| Haist.Works | `http(s)://works.knknara.co.kr` | `http://localhost:5051` |
| Haist.Messenger | `http(s)://msg.knknara.co.kr` | `http://localhost:5052` |
| Haist.Portal | `http://portal.knknara.co.kr` | `http://localhost:5054` |

- `5051` = 업무시스템(HAIST WORKS)
- `5053` = 현재 연결된 **구 메일 시스템** (사용 중지 대상)

---

## 3. 요청 사유

### ① 업무시스템 창이 메일 창에 가려집니다 (사용 불편)

사내 메일이 `works.knknara.co.kr` **내부 경로**에 있어, 윈도우·크롬이 **업무시스템과 메일을 하나의 앱**으로 인식합니다.
→ 메일을 열어 둔 상태에서 업무시스템을 클릭하면 **메일 창이 앞으로 나옵니다.**
메일을 **별도 주소(`kmail`)** 로 열면 창이 분리됩니다.

### ② 사용하지 않는 구 메일 시스템이 외부에 공개돼 있습니다 (보안)

| 항목 | 현황 |
|---|---|
| 외부 노출 | `https://kmail.knknara.co.kr/login` — **로그인 화면이 인터넷에 열려 있음** |
| 보유 데이터 | 메일 **464건** · 첨부 **636건** · DB **223MB** |
| 최종 사용 | **2026-06-22** (약 5개월간 미사용) |
| 유지보수 | 중단 — 소스 저장소는 2026-11-09 삭제 |

**본 변경으로 이 로그인 화면이 외부에서 차단됩니다.**

> ①은 편의 개선이고, **②는 보안 사안**입니다. ② 만으로도 변경 사유가 됩니다.

---

## 4. 작업 절차

1. **역방향 프록시** 목록에서 `Haist.KMail` **(`https://kmail…:443`)** 행 선택 → **[편집]**
2. ⚠ **변경 전 화면 캡처** (원복용)
3. **「대상」** 영역의 **포트** 값 `5053` → **`5051`** 수정
   - **프로토콜(HTTP)·호스트 이름(localhost)** 은 **변경하지 않음**
   - **「소스」** 영역은 **일절 변경하지 않음**
4. **[저장]**
5. `Haist.KMail` **(`http://kmail…:80`)** 행에 대해 **1~4 반복**
6. 목록을 **아래로 스크롤**하여 `kmail` 관련 규칙이 더 있는지 확인
   (확인 시점에 12건 중 8건만 표시되어 있었습니다)

## 9. 변경 직후 예상 동작 (정상입니다)

`kmail.knknara.co.kr` 접속 시 **`works.knknara.co.kr` 로 이동**합니다.
창 분리 기능은 **후속 작업(10번)** 에서 적용됩니다. **장애가 아닙니다.**

---

## 10. 후속 작업 — **전산팀 작업 아님**

프록시 변경 완료 후, 아래는 **업무시스템(WORKS) 코드 측**에서 처리합니다.

1. `kmail` 로 들어온 요청은 **메일 화면만** 제공, 그 외는 `works` 로 전달
2. 로그인 왕복(SSO)이 **`kmail` 로 복귀**하도록 수정
   (허용 주소는 **`works` · `kmail` 2개만** 고정)
3. 메일 작성 화면 바로 열기 주소 + 앱 설치 설정

**전산팀에서 추가로 하실 작업은 없습니다.**

### 단, 한 가지만 확인 요청드릴 수 있습니다 — `Host` 헤더

위 1·2번은 업무시스템이 **「요청이 `kmail` 이라는 이름으로 들어왔다」**는 정보를 받아야 동작합니다.
DSM 역방향 프록시는 일반적으로 원래 호스트명을 그대로 전달하지만, 설정에 따라
`localhost` 로 치환해 전달하는 경우가 있습니다.

- **확인은 변경 완료 후 저희 쪽에서** 진행합니다. 지금은 조치 불필요합니다.
- 만약 전달되지 않는 것으로 확인되면, **`Haist.KMail` 규칙의 「사용자 지정 헤더」에서
  `Host` 전달 설정**을 한 번 더 요청드리겠습니다. 그 외 추가 작업은 없습니다.
