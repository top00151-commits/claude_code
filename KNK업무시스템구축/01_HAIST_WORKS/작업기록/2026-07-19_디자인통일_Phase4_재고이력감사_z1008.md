- **일자**: 2026-07-19
- **배경**: 대표 "다음 진행해"(compact 직후) — Phase 4 재고 분석 리포트(z1007) 이후 **재고 잔여 화면 7종**을 한 배포로 마무리.

- **대상**: `stock_turnover`(회전율)·`stock_issues`(출고이력)·`stock_audits`(실사 목록)·`stock_safety`(안전재고 설정)·`stock_adjustment`(조정 이력+첨부·양모드)·`stock_qc`(검수+부적합·양모드)·`stock_audit`(실사 상세).

## 1. 전환 원칙 — z1005~z1007 정착(셸만 knk, 업무 위젯 유지+브리지)

| 전환(knk) | 유지(업무 특화·색만 Sage 브리지) |
|---|---|
| 머리글 → knk-page-head(breadcrumb·title·meta) | **tbl-erp 표**·**KPI 스트립**(의미색 fast/slow·pending/issued·open/closed 등) |
| 단순 네비 버튼 → knk-btn(ghost/primary) | **액션 폼**: 승인/반려(act-btns)·첨부 업로드(upload-form)·실사 발의·라인 추가·마감·판정(status-pick)·처분(disp-pick)·인라인 저장(inline-input) |
| 빈상태 → knk-empty(refresh·file-export·clipboard-list·target·history·paperclip) | 상태 칩(chip-iss/st/au/band)·배너·토스트·필터바·사이드 카드(def·help-tip·warn-tip) |
| :root pq→knk Sage **풀 브리지** · 입력 포커스 → Sage focus(#3E6F89) | 조정 상태 필터(sa-actions 세그먼트)·마감 버튼(btn-ok 성공색·disabled 로직) |

- **JS 없음**(7종 모두 `<script>` 0 — POST 폼·inline onclick confirm만) → 스크립트 무관.
- **POST 동작 전수 보존**: `/stock/audits/new`·`/approve`·`/reject`·`/attach`·`/stock/adjust`·`/stock/qc/disposition`·`/stock/qc/{id}`·`/items`·`/close`·`/stock/safety/{id}` 그대로.
- 안전재고·QC·조정·audit은 지역 :root가 전역 pq 상속(부분 정의)이라 **풀 브리지**로 통일.

## 2. 세부 (파일별 처리)

- **turnover/issues/audits/safety**(Group A): 머리글·버튼·빈상태 knk. issues=네비 3버튼(재고현황·입고이력 ghost / 출고등록 primary)+빈상태 CTA. audits=실사 발의 폼 버튼 primary(폼 유지)+빈상태 발의 폼. safety=네비 2버튼 ghost+인라인 저장폼/필터/토스트 유지+포커스 Sage.
- **adjustment/qc/audit**(Group B·양모드/상세): 머리글만 knk, 업무 폼 전부 유지. adjustment=양모드 머리글 조건부(목록/첨부)·sa-actions(상태 필터+CTA) 유지·빈상태 2곳(목록·첨부). qc=2모드(검수/부적합) 머리글 2개·판정/처분/액션바 폼 유지·포커스 Sage. audit=상세 머리글(코드+상태칩 유지)·라인추가/마감 폼 유지·마감 btn-ok 재스코프(.knk-page-actions .btn-ok 성공색·disabled)·포커스 Sage.
- **제목 이모지 제거**(🔁📤📋🎯📎📜⚠️🔬📤 등) → 형제 화면 통일. **죽은 CSS 정리**(각 head 군·po-empty·미디어쿼리 `.xx-head` 잔재).
