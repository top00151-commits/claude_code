## 바꾼 것
- 펼침 상자(`mail_inbox.html`): 목록 = **내 종류 목록**(순서·보이기 그대로) · **맨 아래 「✏ 종류 고치기」**(점선으로 나눔) → `/mail/kinds`
  - 기본 셋(견적·발주·세금계산서) = 예전처럼 `cat=` · 내 종류 = `kd=u1` 처럼 · 하나를 고르면 다른 종류 조건은 빠짐 · 고른 것 다시 누르면 풂(✕)
  - 단추 이름 = 고른 종류 이름(「🏷 제작요청 ▾」)
- 새 화면 `/mail/kinds`(`mail_kinds.html`) — 「🏷 종류 목록 고치기」
  - ✔ 보이기·숨기기(지우지 않음) · ↑↓ 순서 · 🗑 내 종류 지우기 · 그림 고르기(메일 선 아이콘에 있는 18가지만)
  - **내 종류** = 이름 + 찾을 낱말(쉼표로 여러 개) → **제목이나 보낸 사람(이름·주소)** 에 낱말이 하나라도 들어간 받은 메일
  - 자주 쓸 만한 것 한 번에 더하기: 제작요청 · 구매 · 가공 · 납품·출하 · 성적서 · 샘플 · 도면(낱말은 고칠 수 있음)
  - **입력하는 순간 알림**(막지 않음): 「받은편지함에서 N통 걸림」 · 0통 = 낱말 확인 · 3,000통 넘음 = 좁히기 권함 · 한 글자 낱말 · 이름 빔·겹침
  - 저장 안 하고 나가면 묻기 · 「↺ 처음 목록으로」
  - 기본 셋 낱말은 보여 주기만(고치기는 「설정·정리 → 메일 종류 규칙」 그대로)
- ⚙ 설정·정리에도 「🏷 종류 목록 고치기(모아 보기)」 줄
- 서버: 내 계정에 기억(`mail_ui_prefs.prefs.kinds` · 글자 크기와 같은 칸 다른 열쇠) · `GET/POST /mail/kinds` · `POST /mail/kinds/count` · 받은편지함 `kd=` · `list_inbox(kind_words=)`
  - 거르기: 내 종류 15개까지 · 이름 20자 · 낱말 20개(각 40자 · `%` `_` 뺌) · 모르는 그림 = 🏷 · 빠진 기본은 숨김으로 끝에
- 선 아이콘 둘 더함: 🛠 wrench · 🚚 truck(`mail_design_icons.html` · MAP)
