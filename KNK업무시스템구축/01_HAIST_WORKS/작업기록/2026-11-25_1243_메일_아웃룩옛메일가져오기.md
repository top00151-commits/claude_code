## 설계

  - ① 고르기: 기간 5·3·2·1년(기본 2년 · 첨부도 같은 기간) · 폴더
    - **직원 = 3가지**: 아웃룩 폴더 그대로(받은 편지함 아래 경로를 메일 폴더로 · 없으면 만듦 · 3단계까지) / 이음웍스 자동 분류(고정 안 함) / 직접 정리(모두 「분류안됨」 = `fd_pin='gen'`)
    - **대표 계정(메일 기본 주인 `mail_folders._owner_id`) = 고르기 없음 · 「같은 이름 폴더만」 고정**(서버도 강제): 아웃룩 폴더 **마지막 이름**을 이음웍스 폴더 이름(메일 폴더 + 부서 폴더 `t<id>` · 바꾼 이름 포함)과 비교(빈칸·점·밑줄·괄호 무시 → 「1고객사」=「1.고객사」) → **하나만** 맞으면 그 폴더 · 둘 이상·없음 = 「분류안됨」(새 폴더 안 만듦)
    - 직원이 match 를 보내면 400
  - ② 「🔑 가져오기 번호 만들기」 → 번호 + **PowerShell 에 붙여 넣을 한 줄**(이 번호로 명령 파일을 서버에서 받아 바로 실행 · 다운로드 폴더 이름 문제 없음) · 📋 복사
  - ③ 진행 상황(가져옴·건너뜀·실패·첨부 MB·마지막 받은 때 · 15초마다) · 결과 머리말 ✅ 완료 / ⏳ 진행 중 / 👉 남은 일(knk-done-status) · ⏹ 멈추기 · 서버 남은 공간 · 「← 설정·정리」(knk-screen-exit · 공용 `mail_exit.html`)
- 번호 `mail_import_tokens`: **sha256 해시만 저장**(평문·로그 없음) · 만든 뒤 24시간(가져오는 중이면 마지막 받은 때부터 6시간 더 · 최대 72시간) · 새 번호를 만들면 앞 번호 끝 · 멈추기·끝 알림 = 끝 · 번호 주인 메일함에만 넣음
- 입구(번호로 · 로그인 없이): `GET /api/mail/import-outlook/script?code=`(명령 파일) · `POST …/check`(기간·방식·공간) · `POST …/mail`(한 통) · `POST …/done`(끝)
- 한 통 처리(`mail_import_outlook.take_mail`): 기간 밖 = outside · 같은 메일(Message-ID 해시 · 없으면 보낸이+제목+본문)이 내 메일함에 있으면(지운 것 포함) = skip(중복 수도 안 늘림) · `store_inbound(run_ai=False)` → **받은 시각 = 아웃룩 받은 시각 · 읽음** · 원래 보낸 시각(SentOn) · 원문 머리(transport headers)·받는 사람·참조 · 첨부(한 통 30MB 넘으면 첨부 빼고 본문만 + 「📎 첨부 N개는 너무 커서 … 아웃룩에 있습니다」) · 요청 45MB 넘으면 413(명령이 첨부 빼고 다시 보냄) · 폴더 고정 · `mail_import_items` 에 번호 기록 · 응답 = 결과 글자·숫자만
