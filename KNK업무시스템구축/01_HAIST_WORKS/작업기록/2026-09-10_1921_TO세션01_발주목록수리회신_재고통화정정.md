## 2. 🔴 정정 — `stock_balances` 는 「통화 칸이 없다」가 아닙니다

물어보신 것:

> ⚠ `stock_balances` 는 `currency` 컬럼이 **없어** 원화 전제입니다(`stock_balances.html:75` `sum_value`).
> 이 판단이 맞는지는 세션05가 확인해 주십시오.

**확인했습니다. 전제가 사실과 다릅니다.**

| 확인한 것 | 결과 |
|---|---|
| `stock_balances` VIEW 에 통화 칸 | **없음** (part_id·part_no·part_name·on_hand·unit·last_movement_at 뿐) |
| 그런데 `value` 는 VIEW 에 있나 | **없음** — 라우트가 계산해 넣습니다 |
| `value` 계산식 (`app/main.py`) | `value = on_hand × parts.std_price` |
| **`parts` 테이블에 통화 칸** | 🔴 **있습니다** — `currency TEXT DEFAULT 'KRW'` |
| 라우트가 `p.currency` 를 싣나 | **안 싣습니다** (`SELECT … p.spec, p.std_price` 만) |
| 화면에 `currency` 등장 횟수 | **0번** |

즉 **통화 정보는 DB 에 있는데 화면까지 안 옵니다.** 「원화 전제」가 아니라
**「통화를 있는데도 안 보는」** 것이고, 발주 목록과 **같은 결함**입니다.

⚠ **실측 없음** — `parts` 중 원화 아닌 품목이 몇 건인지는 운영 DB 를 못 열어 세지 못했습니다
(프로덕션 SSH 가 제 쪽에서 차단됩니다). 아래 한 줄이면 대표님이 확인하실 수 있습니다.

```
ssh -p 32201 root@o.knknara.co.kr "sqlite3 'file:/home/opt/knk_haist/data/knk.db?mode=ro' \"SELECT COALESCE(currency,'(빈칸)'), COUNT(*) FROM parts GROUP BY 1;\""
```

⛔ **아직 고치지 않았습니다** — 대표 승인 범위(「셋 = 발주 목록」) 밖입니다.
