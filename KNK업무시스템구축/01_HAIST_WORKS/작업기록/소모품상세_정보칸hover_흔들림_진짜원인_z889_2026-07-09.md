## 진짜 원인 (실브라우저 측정으로 확정)
흔들림의 주체는 **날짜칸이 아니라, 정보칸을 감싸는 `.card`** 다.

측정 환경: consumable_detail 의 실제 로드 스타일시트(v5_tokens.css·v5_main.css·design_quiet_v3·
_components·customer_picker·페이지 인라인)를 그대로 인라인/링크한 충실 재현 페이지를 `python -m http.server`
로 띄우고(`/static/css/...` 실제 해석), Chrome 실브라우저로 CSSOM 열거 + 실제 마우스 hover 측정. dpr=2.

1. **CSSOM 열거(전 시트)** — `.card:hover` 의 transform 선언은 **오직 1개**가 승자:
   - `v5_tokens.css` : `.card { transition: all var(--t-base); }` (= all 0.2s, 활성)
   - `v5_tokens.css` : `.card:hover { transform: translateY(-2px); box-shadow: var(--shadow-md); }`
   - v5_main.css `.card`(211행)에는 hover transform 없음, design_quiet_v3 는 `.kpi-card:hover` 만
     `transform:none`으로 무력화하고 **`.card:hover` 는 안 건드림**, 페이지 인라인 `.card` 도 transform 미지정.
     → `.card:hover { transform: translateY(-2px) }` 가 **덮이지 않고 그대로 적용**.
   - ※ 앞선 조사가 "코드 어디에도 없다"고 본 건 `v5_main.css` 만 확인했기 때문. 규칙은 **`v5_tokens.css`** 에 있다.

2. **실제 마우스 hover** — 커서를 정보칸(카드) 위에 올리면:
   - `card.matches(':hover') = true`, computed `transform = matrix(1,0,0,1,0,-2)` (= translateY(-2px))
   - 카드 top `174.29 → 172.29`(**-2px**), '발주일' 정보셀 top `266.16 → 264.16`(**-2px**),
     '합계'셀도 -2px — 카드+모든 정보셀이 정확히 2px 위로 이동(0.2s 애니메이션).

3. **경계 진동(= '계속 흔들린다'의 정체)** — 커서를 카드 하단 경계에 두고 rapid 샘플:
   `hov=false, tf=translateY(-2)` → `tf=translateY(-0.15)`(카드가 되돌아 내려오는 중) → `tf=none`.
   카드가 뜨면 경계가 커서 위로 올라가 hover 해제 → 카드 하강 → 다시 커서에 닿음 → hover …
   되먹임으로 카드가 물리적으로 진동. 커서를 정보칸에서 움직이면(대표 사용 패턴) 매 포인터 이동마다
   재계산돼 미세 진동이 계속 보인다.

## 수정
정보 카드는 클릭 대상이 아니므로 hover 시 어떤 이동/전환도 없앤다(레이아웃 불변 고정).
`consumable_detail.html` 페이지 인라인 `<style>`에서 z888 블록을 revert하고 아래로 교체:

```css
.card { transition: none; }
.card:hover { transform: none; box-shadow: 0 1px 2px rgba(15,23,42,.04); border-color: var(--qv-line); }
```

(페이지 인라인이라 가장 마지막에 로드 → 동일 명시도에서 `v5_tokens.css` 의 `.card:hover{transform}`를 이김.
box-shadow/border-color 는 어차피 `.main .card` 의 `!important` 로 평상 고정이라 hover 변화 없음 — 실효는 transform 제거.)

## 검증 (수정 후 재현페이지 실측)
- CSSOM: `.card:hover` transform 승자 = 페이지 인라인의 `none`(v5_tokens `translateY(-2px)` 뒤). `.card` transition = `none 0s`.
- 실제 hover(정보칸 중앙): `cardHovered=true` 인데 카드 top **174.29**(불변)·셀 top **266.16**(불변) = **이동 0px**, transform `none`.
- 카드 하단 경계 dwell: top 174.29 고정·`hov=true` 안정 = **진동 소멸**.
- z888 revert 회귀 확인: 날짜칸 input 박스 hover 전/후 rect 동일(top/left/width 불변) = 네이티브 날짜칸이 밀림 유발 안 함.
- Jinja 구문 파싱 OK(`jinja2.Environment().parse`), 편집/저장 등 기존 기능 무변경(CSS만 수정).
