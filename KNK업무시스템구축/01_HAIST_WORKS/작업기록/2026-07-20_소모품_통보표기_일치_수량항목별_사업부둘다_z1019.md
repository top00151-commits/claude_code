# z1019 — 소모품 통보 표기 일치 (수량 '항목별' + 사업부 '소모품·검사기')

- **일자**: 2026-07-20
- **신고(대표·사진 2장 제시)**:
  1. 소모품 **제작요청서** 화면은 수량란에 `항목별`이라 적혀 있는데, **이음(KNK Eum) 알림 카드**에는 항목 전체 **합산 수량(예: 14)**이 기재됨.
  2. 같은 소모품(관리번호 C)인데 어떤 건은 배지가 **`검사기`**, 어떤 건은 **`소모품`**으로 제각각 표시됨.

## 근본 원인 (실증 — 코드 확인)
두 문제 다 뿌리는 하나: **소모품 제작요청서 '화면'은 새 규칙으로 바꿨는데, '이음 알림 카드'와 '목록 배지'가 옛 규칙으로 남아 어긋남.**

### ① 수량
- 화면(목록·상세)은 z896(대표 지시)로 소모품 수량을 **'항목별'**로 표시 — "여러 품목 합산은 오히려 헷갈린다"고 하셔서 합산 숫자를 뺌.
  - 목록 카드: `prod_requests_list.html:155`
  - 상세 화면: `consumable_prod_request.html:82` ("항목별 · 아래 라인 참고")
- **이음 알림 카드**는 그보다 먼저 만든 z890 코드라 아직 **전 품목 수량 합**을 보냄.
  - `main.py _consumable_notify_send`: `qty_total = sum(품목 qty)` → `_card["qty"]`·본문 "품목: 라인 N건 · 수량 14".

### ② 사업부 배지
- 목록 카드 배지 규칙(`main.py:21509~`): 진행사업부(`consumable_orders.biz_div`)가 **T면 '검사기', M이면 '자동화'… 미지정이면 '소모품'** 폴백.
- z987(대표 지시)로 배지를 '소모품 고정'에서 '진행사업부'로 바꾼 것 → **소모품이라는 표기가 사라져** 소모품끼리도 검사기/소모품으로 갈림.
- 이음 카드는 반대로 **항상 '소모품' 고정**(`main.py:40181`)이라, 목록이 '검사기'로 뜬 건은 목록↔알림도 불일치.

### 공용 헬퍼 (표기 통일)
```python
# main.py (모듈 레벨)
_CONS_BIZ_SUB = {"T": "검사기", "M": "자동화", "L": "라이프밸류", "E": "기타"}
def _consumable_biz_label(biz_div):
    _sub = _CONS_BIZ_SUB.get(str(biz_div or "").strip().upper())
    return "소모품·" + _sub if _sub else "소모품"
```

### 적용 4곳
1. **목록 카드 배지**(`main.py` 제작요청서목록): `biz_label = _consumable_biz_label(biz_div)`, **색은 소모품(C)으로 통일**(진행사업부 색이던 z987 → 소모품 앰버). 
2. **소모품 상세 화면**(`consumable_prod_request.html`): `🧴 {{ biz_label or '소모품' }}` (라우트가 `biz_label` 전달).
3. **이음 카드 사업부**(`_consumable_notify_send` `_card["biz"]`): 헬퍼 적용·`biz_code="C"` 유지(소모품 색).
4. **이음 카드 수량**(`_card["qty"]`·본문): `qty_total`(합산) → **`"항목별"`**, 본문 "라인 N건 · 항목별".

### 배지 잘림 후속 (z1019b~d)
'소모품·검사기'가 목록 카드 **고정폭 칸(pc-r 64px)**에서 잘리는 문제 → 3회 조정 끝에 확정:
- z1019b: 배지 `white-space:normal`(잘림 방지) → 좁은 칸이라 '소모품/·/검사기' 3줄(· 홀로 = 투박).
- z1019c: 칸폭 64→84px → 배지 2줄 되나 **관리번호·수주번호가 줄바꿈**(`116C260/4`)되어 오히려 지저분 → 롤백.
- **z1019d(확정)**: 칸폭 64px 복귀(관리번호 한 줄 보존) + 배지를 `biz_label.split('·')`로 각 `display:block` = **'소모품'/'검사기' 딱 2줄**(· 제거·잘림0·관리번호 침범 없음).
