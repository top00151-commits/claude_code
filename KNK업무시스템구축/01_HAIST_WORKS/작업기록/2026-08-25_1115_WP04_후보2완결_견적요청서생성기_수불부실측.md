```

```

**칸 역할 = 허동준 매니저 설명 그대로 코드화**: 기존단가(K)=실적가(마스터 P) 당사 기입 / 변경단가(L)·소요일(R)·입고가능일(S)=매입처 몫이라 **비움** / 입고요청일(Q)=--due. **발주서와 반대로 `옛->새` 표기는 유지**(매입처가 변경을 봐야 함 — 실제 메일 실측). 관리번호는 3분할(001·M·2606) 자동, 금액수식(O=K×M·P=L×M)·SUBTOTAL 합계줄은 실물 양식 그대로(도출 양식 `양식_견적요청서.xlsx`).

**검증 — 직접 실행 2중**: 시험 17건/0 (+ 회귀: 발주서 23/0·①-a 19/0·①-b 21/0). 골든 = 실물 양식의 머리글·수식·견본 3줄 규칙(기존금액=기존단가×요청수량 정확 일치). 직접 실행 2건 대표 전달 — **파익스 4줄(어제 실제 메일과 같은 대상: 신규 2줄 단가 비움·`->` 4건 유지)** · 성화기전 75줄(신규 9줄 = 사전 실측과 동일·`->` 26건 유지).
