# z1011 — 매출 홈(sales_home) knk Sage 전환 · Phase 5 파일럿

- **일자**: 2026-07-19
- **지시**: 대표 "매출·영업부터" → "sales_home부터 진행"(파일럿 승인 — 전환 후 대표 LIVE 확인).
- **대상**: `app/templates/sales_home.html` — 매출영업센터 홈 대시보드(3지표 KPI·사업부별/년도별 표·TOP5 고객사·최근 프로젝트).
- **Phase 5 첫 화면**: 매출영업 영역(15화면) 전환의 파일럿.

## 원인 / 구조
- sales_home은 `--qv-*` 토큰을 **body에서 흰색/슬레이트로 로컬 재정의**(`#ffffff`·`#0f172a` 등) → 셸은 Sage인데 본문만 흰/슬레이트로 남아 있었음.
- 레이아웃 = **고정 뷰포트 flex**(z107 "진동 근본해결"): `.main{display:flex; height:calc(100vh-topbar); overflow:hidden}` + 자식별 flex-shrink. 머리글이 `.main`의 **직접 첫 자식**(`.{prefix}-page` 래퍼 없음).

## 전환 (z1005~1010 레시피: 셸/색 통일, 업무 위젯·레이아웃 유지)
| 전환(knk Sage) | 유지 |
|---|---|
| `body{}` `--qv` 6토큰 → **knk Sage 브리지**(surface·inset·경계·글자) + `--qv-surface-3`·`--qv-line-3` 신규 브리지 | **z107 고정뷰포트 flex 레이아웃 전체**(`.main` flex·자식 flex-shrink·마지막 grid 남은공간·list-card 독립 스크롤) |
| 머리글 `.page-head` div → `<header class="knk-page-head">`(breadcrumb·title·meta) | **3지표 색**(수주=`#2563eb` 파랑·진행=`#15803d` 초록·최종=`#b45309` 주황) — 데이터 의미색 |
| z107 flex 셀렉터 `.main > .page-head` → `.main > .knk-page-head`(flex-shrink 유지) | **사업부색**(`--biz-t/m/e/c`)·**환율 경고 바**(`#fffbeb`/`#b91c1c`) — 경고 의미색 |
| 머리글 Sage 배경밴드+경계+**content-pad 좌우 정렬**(KPI행과 맞춤) | 기간선택 `<select>`·GET 이동 JS·환율입력 링크·최근프로젝트 잉크알약(mgmt-pill) |
| 반응형(≤1100px) `.page-head/.page-title` → `.knk-page-head/.knk-page-title` 갱신 | 모든 표·수치·Jinja 데이터·POST/GET 동작 |

- **죽은 CSS 제거**: `.page-head`/`.page-meta`/`.page-title`(+em)/`.page-actions`/`.btn`/`.btn-primary`/`.btn-secondary` — 정의만 있고 미사용(본문·파샬 어디서도 안 씀).
- **JS 무변경**: 기간선택 IIFE(shMode/shYear/shQ/shM → `/sales?mode=...` GET 이동) 그대로.
- **컴포넌트 여백 정렬**: knk-page-head 기본 수평여백 sp-6(24px) ≠ `--content-pad`(32px) → 머리글 수평여백을 content-pad로 덮어 KPI/표와 좌우 정렬.
