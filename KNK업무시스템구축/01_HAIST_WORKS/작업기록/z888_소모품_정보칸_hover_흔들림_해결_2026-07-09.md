# z888 — 소모품 상세 정보칸 hover "화면 흔들림" 해결

- **일자**: 2026-07-09
- **지시(대표)**: "소모품 화면에서 마우스 커서를 입력된 정보 박스에 가져가면 화면이 조금씩 움직여서 흔들려… 어지러워. 확인해서 움직이지 않게 해줘."
- **커밋/미러**: (배포 확인란)

## 원인 (전수 확인 후 특정)
헤더 정보칸 중 **발주일·납기 = `<input type="date">`**(consumable_detail.html:230-231). 브라우저 네이티브 날짜칸이라 **마우스를 올리면(hover/focus) 숨어있던 스피너(`::-webkit-inner-spin-button`)·지우기 버튼이 나타나며 내부 내용(날짜·달력 아이콘)이 밀림** → 이것이 "조금씩 움직여 흔들리는" 정체.

**배제 검증(움직임의 다른 후보 전부 제거)**:
- 소모품 화면 로컬 CSS: 모든 `:hover`가 **색상(border-color·background·filter)만** 변경, 테두리는 `1px solid transparent`로 미리 선점 + `box-sizing:border-box` → **크기 변화(reflow) 없음**. `transition`·hover JS 핸들러 없음.
- 전역(`v5_main.css`·`design_quiet_v3`·`_components`·`customer_picker`·`chrome.html`): 입력칸 크기 바꾸는 hover 없음(transform은 버튼·카드뿐, kpi-card는 이미 `transform:none` 무력화). 고객사 콤보 드롭다운은 `position:absolute`(레이아웃 안 밀림).
- 페이지가 짧아 세로 스크롤바 토글도 아님.

## 수정 (CSS만)
`consumable_detail.html` `<style>`에 추가:
- `input[type="date"]::-webkit-inner-spin-button`, `::-webkit-clear-button` → `display:none`(hover 때 나타나 내용 미는 요소 제거).
- `::-webkit-calendar-picker-indicator { margin:0 }` — **달력 아이콘은 유지**(클릭해 날짜 선택 가능).
- `.header-grid .ef`, `table.items input[type=date]` → `transition:border-color/background .12s` — hover 테두리 하드 팝 → 부드러운 페이드(깜빡임 완화).

편집·저장 등 기존 기능 무변경. 날짜는 여전히 타이핑·달력 클릭으로 입력.

## 검증
- Jinja 파싱 OK · 추가 CSS 확인.
- 배포 후 `/api/version` 변경 + 엔드포인트 5xx 없음.
- ⚠ 브라우저 실제 hover 육안 확인은 대표님께 요청(원격 재현 불가) — type=date 스피너 hover 밀림은 크로미엄 알려진 동작이라 수정 근거 확실.

## 교훈(재사용)
`<input type=date/number>`를 좁은 flex/그리드 칸에 넣으면 **네이티브 스피너가 hover/focus 때 나타나며 내용이 밀려 "흔들림"**이 생김. 촘촘한 정보칸엔 스피너·지우기 버튼을 `display:none`으로 숨길 것(달력 인디케이터는 유지).
