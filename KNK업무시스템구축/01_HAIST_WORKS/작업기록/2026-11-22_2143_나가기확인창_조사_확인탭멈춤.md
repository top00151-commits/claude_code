# 「나가기 확인」 창 조사 — 실제로는 「확인용 탭이 열자마자 멈춤」

- **작성**: 2026-11-22 (일) 21:43 KST
- **세션**: 01 (빅터)
- **대표 지시(11-22)**: 앞 정리의 「나가기 확인 창이 어디서 뜨는지 아직 모름 · 다시 뜨면 창 글 받아 찾기」에 「진행해」.

## 1. 대화 기록에서 실제로 일어난 일(읽기만)
- 「나가기 확인」 창이 먼저 뜬 것이 아니라, **빅터가 대표님 Chrome에 연 확인용 탭이 열자마자 45초 동안 응답 없음(멈춤)** → 그 상태에서 탭 닫기가 안 됨 → 대표님이 직접 닫음.
- 같은 모양이 모두 4번 있었음(시각 = 한국 시간):

| 언제 | 연 화면 | 그 뒤 |
|---|---|---|
| 8월(작업 일정표) | `/sales/schedule` | 45초 멈춤 |
| 11-17 16:54 | 제작요청서 고치기 `/project/…/prod-request/edit` | 멈춤 → 닫힘 막힘 |
| 11-22 09:53 | 입금 확인 `/sales/receipts-check` | 멈춤 → 닫힘 막힘 |
| 11-22 15:40 | 견적 관리 `/sales/quotations` | 멈춤 → 닫힘 막힘 |

- 같은 날 같은 방식으로 연 다른 확인용 탭(z104·z106~z110 등 10번 넘게)은 모두 정상.

## 2. 앱 쪽 재현(운영 자료 사본 · 이 컴퓨터 시험 서버 · 107개 화면)
- ① 열고 아무것도 안 고친 채 떠나기 흉내: 떠나기 확인으로 막은 화면 **0**. 프로젝트 상세 → (본문만 바꾸는) 견적 관리로 옮긴 뒤에도 0.
- ② 배포 직후 상황 흉내(한 번 클릭 → 화면 숨김 → 새 판 번호): 저절로 새로고침 88개 · 확인 창 **0** · 나머지 19개는 「작업 중」으로 새로고침을 미룸(정상 동작).
- 모든 화면에 들어가는 공용 조각에서 묻는 창(alert·confirm)은 5곳뿐이고 모두 사람이 누를 때만 뜸(책갈피 고정 한도 · 숫자 칸 고침 확인 · 앱 설치). 화면이 열릴 때 저절로 뜨는 묻는 창은 없음.
- `beforeunload`(떠날 때 묻기)를 쓰는 화면 12곳은 모두 「고친 칸이 있을 때만」 막음.

## 3. 결론
- 앱(WORKS) 화면이 스스로 「나가기 확인」 창을 띄운 흔적은 찾지 못함. 화면도 매번 달라 특정 화면 문제로 보이지 않음.
- 빅터가 Chrome 확장으로 연 **뒤쪽(숨은) 탭이 열리는 도중 멈추는 일**로 보임. 대표님이 직접 쓰시는 화면에서 같은 일이 생긴 보고는 없음.
- 빅터 쪽 대책(바로 적용): 확인용 탭은 연 뒤 화면을 읽기 전에 잠깐 기다리고, 응답이 없으면 닫기를 거듭 시도하지 않고 대표님께 바로 알림(탭은 그대로 둠).
- 대표님이 쓰시다가 실제로 「나가기 확인」 창을 보시면, 그 화면 주소와 창 글을 알려 주시면 그 화면을 다시 봄.
