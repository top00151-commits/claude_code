## 1. 적용 내용

### po_list.html (발주 관리 목록)
- 머리글 → `knk-page-head`: 엑셀 내보내기 `ti-download`·새로고침 `ti-refresh`(ghost)·
  **신규 발주 `ti-plus`(브랜드 primary — 잉크 검정 폐지)**. 메타=전체/진행/완료/취소(knk-num)
- **KPI 8칸 → `knk-kpi-strip`**: 전체·작성중·발주완료·부분입고·입고완료·취소(**클릭=상태 필터 유지**,
  현재 상태=`is-active` 밑줄)+총 발주액·평균(권한 🔒 마스킹 그대로)
- 필터바: 상태 칩(fb-chip) 유지 · 검색 버튼 → **'조회'**(§25)
- 표 → `knk-table knk-table--dense`: 고정 머리글·줄무늬·hover=공통 컴포넌트.
  페이지 보정=행 클릭 커서·`td.code`(모노)·`.mgmt-no` 관리번호 칩(`#27302B`)·
  **바닥 합계줄(tfoot sticky) — 공통엔 없는 ERP 특화라 페이지 규칙으로 이식**·min-width 1100/720
- 빈상태 → `knk-empty`(`ti-clipboard-list`)
- KPI 셀의 `<div class="l/v/sub">`→`<span class="knk-kpi__*">` 전환은 **닫힘 태그(</div>→</span>)까지
  줄 단위 후처리**로 정합 — div/span 여닫 균형 검사로 증명

### po_detail.html (발주 상세)
- 머리글 → `knk-page-head`: 발주번호(knk-num)+상태 칩 · 수정 `ti-edit`·QR `ti-qrcode`(ghost)·
  **입고 처리 `ti-package`(primary·발주완료/부분입고 시만)**
- 정합성 자가치유 경고 → `knk-alert--warning`
- 라인 표 → `knk-table--dense`(+페이지 보정: code·합계줄)
- **유지(업무 특화)**: 요약 카드 4장(sm-card)·발주 정보 def 목록(VAT 모드·공급가액/부가세)·
  입고 진행바(qty-bar)·메모(note-box)·chip-po 상태 칩 — 색만 Sage 브리지
