> 성격: **우리 회사 모든 일정이 모이는 포괄적 일정 협의 보드** (장비·소모품·전 부서)
> 목적: "데이터 정리 시스템" → "매일 돌리는 전사 업무 도구"

---

## 1. 한 문장 정의
**영업이 전사 전체 일정을 한 화면에 올리고, 각 부서가 자기 진행사항을 그 일정에 적어 넣으며, 매일 그 화면으로 미팅하는 실시간 운영 보드.**

---

## 2. 왜 (AS-IS → TO-BE)
- **지금:** 영업 1인이 매일 엑셀 일정표 갱신 → 배포 → 미팅. (스냅샷·시차·수기)
- **앞으로:** 시스템이 **실시간 보드** 제공 → 모두 같은 화면 → 그 화면으로 미팅. 엑셀 수기 배포 불필요.

---

## 3. 화면 구성 (확정)

```
[월: 26년 6월 ▼]  [오늘 출하 3 · 납품 1 · 지연 2]  [거래처/담당자/사업부 필터]
┌───────────────────────────┬──────────────────────────────────┐
│ 좌측 고정 (관리코드 = 1줄)   │ 우측: 1일 ─────────────── 31일 (달력) │
│ 거래처·부서·담당자·관리코드  │  ▓▓▓▓▓▓▓▓▓▓▓▓▓●           ← 일정 막대 │
│ ·모델명·품명·진행사항·수량    │  (전체 한 색) + 납품일(●)만 다른 색   │
└───────────────────────────┴──────────────────────────────────┘
```

- **행 단위 = 관리코드 1줄** (출하일이 여러 개여도 한 줄. 달력 위에 날짜별로 표현)  ← 결정 2
- **좌측 고정 컬럼**: 거래처 · 부서 · 담당자 · 관리코드 · 모델명 · 품명 · **진행사항** · 수량 · 유형
  - ~~분류(기/제/연/구)~~ **삭제**  ← 결정 5
- **날짜 칸 표시**: **일정 전체를 한 색 막대로 칠하고, 납품일만 다른 색**으로 표시  ← 결정 3
- 헤더행 + 좌측 컬럼 **고정**(스크롤해도 기준 유지), 오늘 열 강조
- 상단 요약: 오늘 출하/납품/지연 건수

---

## 4. 진행 단계 (확정)

**메인 단계 (일정 막대 + 단계 표시):**
```
제작  →  검사  →  출하  →  납품(●)
```

**명판/라벨:** 메인 파이프라인 아님. **영업담당자가 별도 관리**하는 항목 → **간단한 체크 또는 메모** 형태로 **누락만 방지**.  ← 결정 1
- 예: 행에 「명판 ☐ / 라벨 ☐」 체크 또는 작은 메모칸

---

## 5. 입력 주체 (확정 + 1개 설계 필요)  ← 결정 4

| 역할 | 입력 |
|---|---|
| **영업 1인** | **전체 스케줄**(행 추가·날짜·납품일·일정 막대) 관리 — 지금처럼 앞으로도 동일 |
| **타부서(생산·구매·기술 등)** | 자기 건의 **진행사항을 해당 일정에 작성** ← **방식 설계 필요** |

**타부서 진행사항 작성 = (다) 혼합 [확정]:**  ← 결정
- **단계 버튼**: 제작/검사/출하/납품 단계를 해당 부서가 **클릭으로 갱신**(누가·언제 자동 기록)
- **+ 메모**: 추가 설명은 **한 줄 메모**로 (작성자·시간·부서색 자동)
- 미팅에서 한 줄에 **"진행 단계 + 이유"** 가 함께 보임

---

## 6. 범위 (확정)
**전사 모든 일정 포함** — 장비(검사기/자동화), 소모품, 기타까지 **여기 한 곳**에 모임. 포괄적 일정 협의용.  ← 결정 6

---

## 7. 기존 데이터와 연결 (재료는 이미 있음)
| 보드 항목 | 출처 |
|---|---|
| 거래처·관리코드·모델·품명·수량·유형 | 프로젝트/수주 (있음) |
| 납품일(●)·일정 | 호기/수주 납기 (있음) + 영업이 일정 막대 지정 |
| 진행 단계(제작/검사/출하) | **신규: 단계 + 타부서 진행 메모** |
| 명판/라벨 | **신규: 영업 체크/메모** |
| 소모품 일정 | 소모품 수주 (있음) |

→ **대표님이 정리한 데이터가 보드의 뼈대.** 위에 "일정 막대 + 단계 + 부서 메모"만 얹으면 됨.

## 8. 미팅 시나리오
```
아침 9:00 — 보드 띄움(오늘 열 강조)
 · 지연 빨강 2건 → 해당 부서 진행 메모 확인
 · 오늘 출하 3건 → 부서별 가능 여부
 · 납품(●) 1건 → 명판/라벨 체크됐는지 확인
→ 화면이 곧 안건. 끝나면 각자 진행 메모 입력.
```

## 9. 단계별 구현 (작게 시작)
| 단계 | 내용 |
|---|---|
| **1단계** | **읽기전용 보드** — 기존 수주/프로젝트 데이터로 월 달력 + 일정 막대(납기 기반) 자동 생성. 영업이 일정/납품일 지정 |
| **2단계** | **타부서 진행 입력** — 단계/메모를 해당 일정에 작성(결정된 방식) + 명판/라벨 체크 |
| **3단계** | **미팅 모드 + 요약 + 알림 + 엑셀 출력**(기존 배포본 호환) |
