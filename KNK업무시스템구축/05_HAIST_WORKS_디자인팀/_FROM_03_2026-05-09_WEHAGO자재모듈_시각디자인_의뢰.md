## 1. 의뢰 배경

대표 직접 지시로 03이 WEHAGO 물류관리(자재등록·발주·입고·자재출고 BOM전개·생산지시/입고)를 정확 분석하고 KNK 적용 운영·디자인 초안을 작성. 03은 **정보 아키텍처(IA) + 텍스트 와이어 + 데이터 모델 SQL**까지만 진행. **시각 디자인은 05 영역**으로 위임.

## 2. 03이 전달하는 인풋 (원본 §C)

### 2.1 IA — 자재모듈 8 대분류

```
HAIST_WORKS > 자재 (신규 모듈)
├── 대시보드 (홈)
├── 기준정보 (품목·거래처·창고·분류·단위·BOM)
├── 구매 (발주서·입고)
├── 생산 (생산지시·자재출고·생산입고)
├── 외주 (외주자재출고·외주제품입고)  ※ 09 결재 우선순위 결정 후
├── 재고 (현재고·입출고현황·재고이동·재고조정)
├── 영업 (baby V2 마이그레이션 시점)
└── 보고 (채권채무·자재 회전율·납기 준수율·호기별 원가)
```

### 2.2 5개 핵심 화면 텍스트 와이어 (원본 §C.2)

1. **품목등록** — 좌 목록 / 우 상세 (탭: 기본·원가·BOM·거래·첨부)
2. **발주서** — 상단 거래처/납기/연결 호기 / 하단 라인 그리드 / 하이웍스 결재 상신
3. **입고처리** — 발주서 적용 → 라인 자동 / LOT·검수 / 회계 전표 자동 옵션
4. **자재출고처리(BOM전개)** — 작업지시 적용 → BOM전개 버튼 → 자재 라인 자동 / 안전재고 인라인 경고
5. **생산지시 + 생산입고** — 1 화면 2 단계 (지시 → 진행 → 완료)
