## 3. 절대 원칙 (이전 시안 실패 학습)

이전 자체 시안은 다음 3가지로 실패했습니다. **반드시 회피**:

### 실패 1: 눈 피로
- 색·그림자·테두리 과다
- → **회피**: 한 화면 시각 자극 최소. 흑백 베이스 + 액센트 1색만.

### 실패 2: 구분 약함
- 카드끼리 비슷해서 어디가 어디인지 모름
- → **회피**: 카드 종류 ≤ 3가지 패턴. 각 패턴 명확한 위계 차이.

### 실패 3: 정보 과밀
- 한 페이지에 모든 걸 다 올려서 스크롤이 끝없음
- → **회피**: **정책 §6 정보 분산** 4 패턴 강제 적용

## 4. 정책 §6 정보 분산 (4 패턴 — 모든 페이지에 적용)

### 패턴 ①: 탭 분산
- 대시보드: [오늘 / 이번주 / 이번달 / 전체]
- 결재함: [대기 / 처리 / 위임]
- 검색결과: [전체 / 발주 / 견적 / 자재 / 거래처]

### 패턴 ②: 접기 (Collapse)
- 폼: 1 단계만 펼치고 나머지 접기
- 상세: 첨부·이력은 접어둠
- 리스트 더 보기: "+5 더 보기" 버튼

### 패턴 ③: 드로어
- 빅터 AI: 우측 드로어 (메인 영역 침범 X)
- 필터: 좌측 또는 상단 토글
- 빠른 보기: 상세 드로어

### 패턴 ④: 페이지네이션
- **무한 스크롤 절대 금지**
- 1 페이지 ≤ 20 행
- 1·2·3·...·N + 이전·다음
