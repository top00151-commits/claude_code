## 1. 에러 페이지 (4종)

### 1-1. `error_404.html` — Not Found
- 페이지 중앙: 큰 "404" (선정 컨셉 폰트로)
- 1줄 메시지: "찾으시는 페이지가 없습니다"
- 2줄 가이드: "주소를 다시 확인해주세요" / "또는 빅터 AI에게 물어보세요"
- 버튼: [홈으로] [빅터 AI 호출]
- ⚠ 이미지·일러스트 없이 타이포만으로 단정하게

### 1-2. `error_403.html` — Forbidden
- "접근 권한이 없습니다"
- "이 기능은 [관리자 / 결재권자] 권한이 필요합니다"
- 버튼: [관리자에게 요청] [홈으로]

### 1-3. `error_500.html` — Server Error
- "잠시 문제가 발생했습니다"
- "잠시 후 다시 시도해주세요" + 시간 표시
- 버튼: [새로고침] [빅터에게 알리기]
- 하단 회색 텍스트: 오류 코드 (개발자용)

### 1-4. `error_offline.html` — 네트워크 끊김
- "인터넷 연결을 확인해주세요"
- 자동 재시도 카운트다운 (5초)
- 버튼: [지금 다시 시도]

## 2. 로딩 상태 (3종 — 컴포넌트 형식)

### 2-1. `loading_full_page.html` — 전체 로딩
- 화면 중앙: 단정한 spinner (선정 컨셉 액센트 색)
- 텍스트: "불러오는 중..."
- ⚠ 깜빡임 강한 애니메이션 금지 (50대 눈 피로)

### 2-2. `loading_skeleton.html` — 스켈레톤 (리스트·카드)
- 회색 박스 placeholders (펄스 약하게)
- 카드 5개 / 표 행 7개 형식
- 콘텐츠 비율 실제와 동일

### 2-3. `loading_button.html` — 버튼 내 로딩
- "처리 중..." + 작은 spinner
- 버튼 비활성화 상태

## 3. 빈 상태 (Empty States) — 6종

### 3-1. `empty_dashboard.html`
- "오늘 등록된 항목이 없습니다"
- 가이드: "새 발주서를 작성해보세요"
- 버튼: [새 발주서] [빅터에게 묻기]

### 3-2. `empty_search.html`
- "[검색어] 에 대한 결과가 없습니다"
- 추천: "비슷한 결과 / 검색 팁 3가지"
- 버튼: [전체에서 다시 검색]

### 3-3. `empty_inbox.html` (결재함 비어있음)
- "처리할 결재가 없습니다"
- 가이드: "수고하셨습니다" / "처리한 결재 보기"

### 3-4. `empty_list.html` (리스트 비어있음 — 발주·견적·자재 공통)
- "[항목]이 없습니다"
- 버튼: [새 [항목] 만들기]
- 빅터 AI: "첫 [항목]은 어떻게 만드나요?" 안내 1줄

### 3-5. `empty_filter.html` (필터로 결과 0)
- "필터 조건에 맞는 결과가 없습니다"
- 버튼: [필터 초기화]

### 3-6. `empty_first_time.html` (최초 진입 — 데이터 0)
- "환영합니다, 김 부장님"
- 3 단계 안내: "1. 거래처 등록 → 2. 자재 등록 → 3. 첫 발주서"
- 빅터 AI: "함께 시작할까요?" 버튼

## 4. 모바일 사양 (전 페이지 반응형)

### 브레이크포인트
- Desktop: ≥ 1024px
- Tablet: 768-1023px
- Mobile: < 768px

### 모바일 변환 규칙

| 데스크탑 | 모바일 |
|---|---|
| 사이드바 (상시) | 햄버거 메뉴 (드로어) |
| 좌우 분할 | 단일 컬럼 (수직 적층) |
| 표 (가로 스크롤) | 카드 형식 (세로 적층) |
| 헤더 검색바 | 검색 아이콘 (탭 시 풀스크린) |
| 빅터 AI 사이드 | 하단 플로팅 버튼 |

### 모바일 전용 화면
- `mobile_drawer.html` — 햄버거 메뉴 펼침 (사이드바 내용)
- `mobile_search.html` — 풀스크린 검색
- `mobile_victor.html` — 풀스크린 빅터 AI

### 터치 타겟
- 최소 44x44px (iOS 가이드)
- 인접 요소 간격 ≥ 8px
- 스와이프 제스처 사용시 가이드 표시 (점선 화살표)

## 5. 인쇄 스타일 (Print CSS)

다음 페이지에 `@media print` 규칙 추가:

- 발주서 (`master_B_po_print.html` — 이미 BRIEF #02에 있음)
- 견적서 (`master_C_quote_detail.html`)
- 세금계산서 (`master_G_invoice_detail.html`)
- 보고서 (`master_L_report_view.html`)

규칙:
- 사이드바·헤더·푸터 숨김
- 흰 배경, 검정 잉크
- 페이지 분리 (`page-break-before`)
- A4 크기 가정 (210x297mm)

## 6. 다크 모드 (옵션 — 단일 페이지)

⚠ 메인 시스템은 라이트 모드 단독. 다크 모드는 **선호 옵션만 제공**.

- `dark_mode_sample.html` — 대시보드 다크 버전 1장만
- 라이트 토큰 → 다크 토큰 매핑 표 제공
- 자동 전환 미디어쿼리 (`prefers-color-scheme: dark`)
