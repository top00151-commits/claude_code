- 하단에 "이 화면에서 할 일" 1줄 가이드 (페르소나 시점)

## 1. Walkthrough 시리즈 (5종)

### W1. 김 부장 (52, 영업) — 견적 → 발주 전환
**시나리오**: 삼성중공업에서 부품 견적 요청 받음. 견적서 작성 → 고객 승인 → 발주서 자동 변환 → 결재 상신.

**8 화면**:
1. W1-1 로그인 후 대시보드 (오늘 할 일에 "삼성중공업 견적 요청" 표시)
2. W1-2 견적 작성 폼 (자재 마스터에서 부품 검색·추가)
3. W1-3 빅터 AI 추천 ("이 거래처 평균 견적가 검색·반영")
4. W1-4 견적서 미리보기 + PDF 발송
5. W1-5 (다음 날) 고객 승인 알림 → 견적 → 발주 전환 한 클릭
6. W1-6 발주서 확인·보완
7. W1-7 결재 상신 (이 차장 → 대표 라인)
8. W1-8 결재함에서 진행 상황 확인

### W2. 이 차장 (48, 자재) — 재고 알림 → 발주 처리
**시나리오**: 안전재고 미달 알림 → 자동 발주서 초안 → 거래처 견적 비교 → 발주 확정.

**6 화면**:
1. W2-1 대시보드 재고 알림 위젯 (3건)
2. W2-2 재고 알림 상세 (어떤 자재가 며칠치 남았는지)
3. W2-3 자동 발주서 초안 (빅터 AI 추천)
4. W2-4 거래처 3사 견적 비교 표
5. W2-5 발주 확정 + 결재 상신
6. W2-6 결재 진행 상황 + 입고 예정일

### W3. 박 과장 (45, 생산) — 작업 지시 → 진행 → 완료
**시나리오**: 발주 완료된 부품 입고 → 작업 지시 → 칸반 진행 → 납기 체크.

**5 화면**:
1. W3-1 생산 보드 (대기 5건 / 진행 3건 / 완료 12건)
2. W3-2 작업 카드 상세 (도면·자재·인원·납기)
3. W3-3 진행 상태 변경 (대기 → 진행)
4. W3-4 완료 처리 + 검수
5. W3-5 일일 생산 보고서

### W4. 최 대리 (35, 회계) — 세금계산서 발행 → 수금
**시나리오**: 발주 완료분에 대한 세금계산서 발행 → 수금 관리.

**5 화면**:
1. W4-1 회계 대시보드 (이번달 매출·미수금·미지급금)
2. W4-2 세금계산서 발행 대기 목록
3. W4-3 세금계산서 작성 (홈택스 연동 안내)
4. W4-4 발행 완료 + 수금 예정일 등록
5. W4-5 수금 대기 리스트 + 빅터 AI 알림

### W5. 김 대표 (60, 의사결정) — 결재 → 보고서 → 의사결정
**시나리오**: 아침 출근 후 결재 처리 → 주간 보고서 검토 → 의사결정.

**6 화면**:
1. W5-1 대표용 대시보드 (KPI 4개·결재 대기 5건·핵심 지표)
2. W5-2 결재함 (대기 5건)
3. W5-3 결재 상세 (빅터 AI 요약 1줄: "이 발주는 평소 대비 20% 증가")
4. W5-4 일괄 결재 (빅터 추천 5건 검토)
5. W5-5 주간 보고서 (매출·발주·재고·생산)
6. W5-6 빅터 AI 인사이트 ("이번 주 주목할 3가지")

## 2. 일관성 규칙 (5 walkthrough 공통)

- **시각 톤**: 선정 컨셉 그대로 (BRIEF #01에서 선정한 컨셉)
- **단계 표시**: 좌상단 흐릿한 회색 (`#999`) `W1-3 / 8`
- **다음 버튼**: 우상단 `다음 →` (KNK 레드 텍스트만, 버튼 아님)
- **가이드 박스**: 하단 슬레이트/회색 박스 1줄 ("👁 이 화면에서 할 일")
  - ⚠ 이모지 절대 금지면 텍스트만 (예: "[가이드]")
- **페르소나 컨텍스트**: 우상단 아바타 (김 부장님 / 이 차장님 ...)
