## 2. 사용성 절대 원칙 (이전 시안 실패 원인)

이전 자체 시안은 다음 3가지로 실패했습니다. **반드시 회피**:

1. **눈 피로** — 색·그림자·테두리 과다. 한 화면에 시각 자극이 너무 많음.
2. **구분 약함** — 카드끼리 비슷해서 어디가 어디인지 모르겠음.
3. **정보 과밀** — 한 페이지에 모든 걸 다 올려서 스크롤이 끝없음.

→ **해결 원칙 (정책 §6 정보 분산)**:
- 한 화면 핵심 카드 **≤ 5개**
- **탭 분산** (예: 오늘/이번주/이번달/전체)
- **접기 Collapse** (긴 리스트는 첫 N개만 펼침, 나머지 접기)
- **무한 스크롤 절대 금지** — 페이지네이션
- **콘트라스트 ≥ 7:1** (글씨 가독성)
- **색 사용 ≤ 5%** (메인은 흑백, 액센트만 컬러)

## 4. 3 컨셉 (각 다른 디자인 방향)

### 컨셉 A — "순백 미니멀"
- 베이스: 순수 흰색 / 잉크: 순흑
- 액센트: KNK 레드 단독 (다른 색 추가 금지)
- 그림자: **없음** (호버시 1px 검정 테두리만)
- 모서리: 8px (둥글지도 sharp 하지도 않음)
- 톤: **단정·미니멀·일본 무인양품 느낌** (브랜드명 직접 언급 금지)

### 컨셉 B — "차분한 슬레이트"
- 베이스: 따뜻한 흰 `#FCFCFC` / 잉크: 소프트 검정 `#1A1A1A`
- 액센트: 회청색 슬레이트 `#5C7A8A` + KNK 레드
- 그림자: 미세 (`0 1px 3px rgba(0,0,0,.04)`)
- 모서리: 6-10px 부드러운 곡선
- 톤: **차분·신뢰감·문서형 협업툴 느낌**
- **빅터(코디네이터) 권장**: 50대 친숙도 + 위계 명확

### 컨셉 C — "전문 사무용"
- 베이스: 흰색 + 좌측 진한 네이비 사이드바 `#1E2A3A` (검정은 너무 무거움)
- 잉크: `#000000`
- 액센트: 인디고 `#3B5BDB` + KNK 레드
- 그림자: 없음, 포커스링만
- 모서리: 6px
- 톤: **전문성·관리자급** ("개발자 도구" 느낌은 금지. 사무직 관리자 느낌으로)

⚠ **3 컨셉 모두 다음 금지사항 동일**:
- 영문 코멘트 (`// VICTOR.AI` 같은 코드 주석 스타일) **금지** — 50대가 거부감
- 모노스페이스 폰트로 한국어 표시 **금지**
- 그라데이션 화려한 배경 **금지**
- 이모지 남발 **금지**

## 5. 5 페이지 (각 컨셉마다 동일)

### 01_home.html — 대시보드
- 상단: 헤더 (로고 + KNK 로고 + 검색 + 알림 + 김 부장님 아바타)
- 좌측: 사이드바 (대시보드·발주·견적·자재·고객·승인·설정)
- 메인:
  - 히어로 1개 (오늘의 핵심 한 줄 + 빅터 AI 추천 1개)
  - KPI 3개 (진행 중·결재 대기·재고 알림)
  - **탭 분산**: [오늘 | 이번주 | 이번달 | 전체]
  - 최근 활동 5개 (접기로 더 보기)

### 02_po_list.html — 발주서 리스트
- 상단 필터 (상태·기간·담당자) + 검색
- 테이블: PO번호·거래처·금액·상태·담당·날짜·액션
- **페이지네이션** (1~10 페이지, 무한 스크롤 절대 금지)
- 행 호버: 미세 강조만 (색 채움 X)

### 03_po_form.html — 발주서 작성
- 진행 단계 표시 (1.기본정보 → 2.품목 → 3.납기·결제 → 4.확인)
- **첫 단계만 펼치고 나머지 접기**
- 품목 테이블: 품번·품명·수량·단가·금액·삭제 (행 추가 버튼)
- 우측: 빅터 AI 추천 ("이 거래처는 평균 5일 납기" 같은 1줄 인사이트)
- 하단: 임시저장 / 다음

### 04_po_detail.html — 발주서 상세
- 상단: PO 번호·상태 뱃지·작성자
- **워크플로우 5단계 시각화** (작성 → 검토 → 승인 → 발주 → 입고)
- 본문 탭: [기본정보 | 품목 | 첨부 | 이력]
- 우측: 빅터 AI 카드 (현재 상태 요약 + 다음 액션 1개)
- 하단: 결재 버튼

### 05_login.html — 로그인
- **단일 컬럼** (좌우 분할 X — 50대 산만함 회피)
- KNK 로고 + "HAIST WORKS"
- 사번 / 비밀번호 / 로그인 유지 / 비밀번호 찾기
- 메인 버튼: KNK 레드
- 하단 푸터: ㈜케이엔케이 · 02-3142-XXXX

## 6. 산출물 형식

각 컨셉마다 다음 5개 파일:
```
컨셉A_순백/01_home.html
컨셉A_순백/02_po_list.html
컨셉A_순백/03_po_form.html
컨셉A_순백/04_po_detail.html
컨셉A_순백/05_login.html
컨셉B_슬레이트/... (동일 5개)
컨셉C_사무용/... (동일 5개)
```

각 파일은:
- **단일 HTML** (외부 의존 = Pretendard CDN만)
- inline `<style>` (외부 CSS 금지)
- 더미 데이터 한국어 (예: 거래처 "삼성중공업·현대제철·LS전선")
- 반응형 기본 (`@media (max-width:768px)` 처리)
