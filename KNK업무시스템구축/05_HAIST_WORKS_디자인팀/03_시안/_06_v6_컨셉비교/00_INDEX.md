## 🎨 3 컨셉 비교

### v6-A · 순백미니멀
**철학**: *"색에서 도망치는 디자인"*

- 베이스: `#FFFFFF` 순수 흰색
- 잉크: `#111111` 순흑 (콘트라스트 19:1)
- 액센트: KNK 레드 단독 (5%)
- 그림자: 거의 없음 (호버 1px 검정 outline)
- 모서리: **8px** (둥글지도 sharp 하지도 않음)
- 폰트: Pretendard 일관
- **톤 묘사**: 절제된 순백 미니멀

→ 가독성 ★★★★★ / 차별성 ★★★ / 친화감 ★★★★

### v6-B · 차분슬레이트
**철학**: *"위계는 색·여백·미세 그림자로"*

- 베이스: `#FCFCFC` 따뜻한 흰
- 잉크: `#1A1A1A` 소프트 검정
- 액센트: **회청색 슬레이트** `#5C7A8A` + KNK 레드
- 그림자: 미세 (`0 1px 3px rgba(0,0,0,.04)`) — 카드 부유감
- 모서리: **6-10px** 부드러운 곡선
- 폰트: Pretendard
- **톤 묘사**: 차분한 문서형 협업 대시보드

→ 가독성 ★★★★ / 차별성 ★★★★ / 친화감 ★★★★★

### v6-C · 전문사무
**철학**: *"전문가용 도구 — 정보 밀도"*

- 베이스: `#FFFFFF` 메인 + `#0A0A0A` 진한 사이드바
- 잉크: `#000000` 순흑
- 액센트: **보라 인디고** `#5E6AD2` + KNK 레드
- 그림자: 거의 없음 + `box-shadow:0 0 0 3px rgba(94,106,210,.12)` 포커스링
- 모서리: **6px** (sharp)
- 폰트: Pretendard (고정폭 글꼴은 메타·타임스탬프 한정, 한글 본문 제외)
- **톤 묘사**: 전문 관리자용 대시보드

→ 가독성 ★★★★ / 차별성 ★★★★★ / 친화감 ★★★

## 📋 대표 비교 방법

### 1차 — 한 페이지 3 컨셉 동시 비교
```
탭 1: v6-A_순백미니멀/01_home.html
탭 2: v6-B_차분슬레이트/01_home.html
탭 3: v6-C_전문사무/01_home.html
```

→ 같은 화면을 3 컨셉으로 번갈아 보면서 **눈 피로·구분 명확·정보 위계** 비교.

### 2차 — 한 컨셉 5 페이지 흐름 비교
```
탭 1-5: v6-A의 home → po_list → po_form → po_detail → login
```

→ 한 컨셉으로 사용자 흐름 따라가며 **일관성·작업 흐름** 검증.

### 3차 — 페르소나 시나리오
- **김 부장 (영업)**: home → 견적 작성 (po_form 변형)
- **이 차장 (자재)**: home → po_list → po_form → po_detail
- **대표**: home → dashboard → 빅터 AI 카드
