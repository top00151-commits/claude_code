```
[기존 §5-2]

   ↓
   Claude Design HTML/CSS/React 라이브 생성
   ↓
   빅터(05) 검증 (액면 수용 금지 — §4-A 7차)
```

### 4-3. 빅터(05) 검증 의무 (정책 §4-A 7차 + §5-7 신설)

Claude Design 산출물 도착 시 빅터(05) 즉시:
1. **시각 검증**: KNK 톤 준수 (색·타이포·모서리·그림자)
2. **표준 토큰 grep**: `--paper`·`--amber`·`--knk-red` 사용 확인
3. **구조 검증**: 시안 폴더 카테고리 패턴 정합
4. **외부 자산 grep**: 외부 CDN·이미지·폰트 0건
5. **접근성 grep**: aria-*·focus-visible·44×44 터치

→ FAIL 시 즉시 대표·디자이너에게 회신 + Claude Design 재변형.
