## 2. 결재 요청 5건

### DEC-1 [필수] 민감 데이터 자동 마스킹
- AI 호출 직전 정규식 차단: 비밀번호 / 주민번호 / 계좌번호 / 카드번호 / 사번 일부
- 마스킹 후 호출 → OpenAI 서버에 평문 전송 0건
- 적용 위치: `ai_client.py` ai_chat() 호출 직전 + 10 `app.py` 번역 호출 직전
- 추정 작업: 2시간 (정규식 모듈 1개 추가)

### DEC-2 [필수] AI 호출 로그 사내 DB 기록
- 모든 AI 호출 → `ai_call_log` 테이블 INSERT
  - 컬럼: user_id / role / purpose / input_chars / output_chars / cost_estimate / created_at
  - **본문 저장 X** (감사·청구만)
- 적용 위치: ai_chat() 래퍼 + 10 번역 호출 후
- 추정 작업: 3시간 (테이블 추가 + 호출 후크)

### DEC-3 [권고] OpenAI 학습 옵트아웃 설정
- OpenAI Dashboard → API → Data Usage → "Models trained from my data" OFF
- 또는 API 호출 헤더에 `{"openai-data-opt-out": "true"}` 명시
- 작업 위치: 빅터(01·10) HTTP 호출 헤더
- 추정 작업: 30분
- **단** Anthropic Claude는 API 데이터 학습 미사용 (기본 정책 — 추가 설정 불필요)

### DEC-4 [필수] 외부자산 결정서 갱신
- `/admin/external-assets` 결정 항목 추가:
  - ChatGPT API (OpenAI) — 유지+제약 (마스킹/로그/옵트아웃 3종 적용)
  - Claude API (Anthropic) — 유지+제약 (마스킹/로그)
- 99_DISPATCH 결정 문서: `99_DISPATCH/외부자산_결정_2026-05-01_AI공급사.md`
- 추정 작업: 1시간

### DEC-5 [권고] 고객사 모드 AI 차단
- 외부 사용자(고객사 진입) 식별 시 빅터·AI 호출 일체 차단
- 또는 매우 제한된 모드 (FAQ 같은 정형 응답만)
- 적용 위치: `victor.py` 진입 가드 + 10 메신저 외부 사용자 분기
- 추정 작업: 2시간
