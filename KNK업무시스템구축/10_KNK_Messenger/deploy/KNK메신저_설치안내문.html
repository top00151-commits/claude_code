💻 PC (윈도우) Edge · Chrome

① 앱으로 설치
1
엣지/크롬으로 위 접속 주소에 들어가 로그인
2
화면 아래 [설치] 버튼 클릭 (또는 주소창 오른쪽 설치 아이콘)
haist.knknara.co.kr/msg   ⊕ 앱 설치   또는   설치
3
팝업에서 "설치" → 독립 창 + 시작 메뉴에 KNK 아이콘 생성
② 알림 켜기 (윈도우 하단 알림)
1
처음 뜨는 알림 권한을 "허용"
2
→ 창을 닫아도 메시지가 오면 우측 하단 알림 + 소리
💬 김정락 (관리팀) · 새 메시지
③ 켤 때 자동 실행 (선택)
1
주소창에 edge://apps 입력 (크롬은 chrome://apps)
2
KNK → "로그인 시 자동 시작" 켜기

📱 휴대폰

🤖 안드로이드 (갤럭시 등)
1
크롬으로 접속 주소 들어가 로그인
2
아래 [설치] 버튼 → (또는 메뉴 ⋮ → 홈 화면에 추가)
3
홈 화면 KNK 아이콘으로 실행 → 알림 "허용"
⚡ 알림이 늦게 와요? — 설정 → 배터리 → KNK 메신저(또는 Chrome) → "제한 없음"
갤럭시는 추가로: 설정 → 배터리 → "배터리 보호 모드 해제". 1회 설정만으로 알림 도착률 크게 개선.
🍎 아이폰 (iPhone)
⚠️ 아이폰은 iOS 16.4 이상 + 반드시 홈 화면 아이콘으로 실행해야 알림이 옵니다. (사파리 탭에서는 알림 ❌)
1
사파리(Safari)로 접속 주소 들어가 로그인
2
하단 공유 버튼(⬆️) → "홈 화면에 추가"
3
홈 화면 KNK 아이콘으로 실행
4
화면 아래 🔔 "알림 켜기" 한 번 탭 → "허용"
🔔 알림을 켜시겠어요?  알림 켜기
✅ 설치하면 — 같은 방 알림은 1개로 합쳐지고, 앱 아이콘에 새 알림 표시가 보입니다. 같은 방 안에 있으면 알림 안 옴 (의도된 동작).
📌 로그인 — 휴대폰 1대 + PC 1대까지 동시 사용. 휴대폰에서 로그아웃하면 PC도 함께 로그아웃됩니다.
