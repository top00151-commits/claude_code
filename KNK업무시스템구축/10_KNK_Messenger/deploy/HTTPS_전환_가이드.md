# KNK 메신저 HTTPS 전환 가이드

**작성일**: 2026-05-12  
**소요시간**: 약 30분 (라우터 5분 + DSM 10분 + 빅터 5분 + 검증 10분)  
**목표**: `https://o.knknara.co.kr/` 안정 서비스 (Let's Encrypt 인증서 자동 갱신)

---

## 사전 확인

- ✅ DNS A 레코드 등록: `o.knknara.co.kr` → 회사 외부 고정 IP (가비아에서 확인)
- ✅ Synology NAS 운영 중 (`o.knknara.co.kr` = 같은 NAS 다른 도메인)
- ✅ NAS 내 Docker 컨테이너에서 `gunicorn :5050` 실행 중

---

## 1단계 — 공유기/라우터 포트 개방 (5분)

**누가**: 대표님 또는 IT 담당자  
**왜**: Let's Encrypt 인증 발급(80 포트 필요) + HTTPS 서비스(443 포트 필요)

| 외부 포트 | 내부 NAS 포트 | 용도 |
|---|---|---|
| **80** | 80 | Let's Encrypt 인증서 발급 (HTTP-01 challenge) |
| **443** | 443 | HTTPS 서비스 |

회사 공유기 관리자 페이지 (보통 `192.168.x.1`) → 포트 포워딩 / NAT → 위 2개 추가

이미 외부 3310 → NAS 매핑은 그대로 유지 (HTTP 베타 유지 중).

---

## 2단계 — DSM 인증서 발급 (5분)

**누가**: 대표님 (Synology DSM 웹 접속)

1. 브라우저로 Synology DSM 로그인 (보통 `http://NAS_IP:5000`)
2. **제어판** → **보안** → **인증서**
3. **추가** → **새 인증서 추가** → **다음**
4. **Let's Encrypt 인증서 받기** 선택 → **다음**
5. 폼 입력:
   - **도메인 이름**: `o.knknara.co.kr`
   - **이메일**: `admin@knknara.co.kr` (또는 대표님 이메일)
   - **주제 대체 이름**: (비워둠)
6. **적용** → 약 30초 내 발급 완료
7. 발급 안 되면 → 1단계 포트 80 개방 다시 확인

---

## 3단계 — DSM Reverse Proxy 설정 (3분)

**누가**: 대표님

1. DSM **제어판** → **로그인 포털** (또는 **응용 프로그램 포털**) → **고급** 탭 → **역방향 프록시**
2. **생성** 클릭
3. **일반** 탭:
   - 역방향 프록시 이름: `KNK 메신저`
   - 소스:
     - 프로토콜: **HTTPS**
     - 호스트 이름: `o.knknara.co.kr`
     - 포트: `443`
     - ☑ HSTS 활성화
   - 목적지:
     - 프로토콜: **HTTP**
     - 호스트 이름: `localhost`
     - 포트: `5050`
4. **사용자 정의 헤더** 탭 → **만들기** → **WebSocket** 선택 (Socket.IO 위해 필수)
   - 자동으로 추가됨:
     ```
     Upgrade  $http_upgrade
     Connection  $connection_upgrade
     ```
5. **고급 설정**:
   - 최대 업로드 크기: `600M` (기본은 작음 — 사진/도면 업로드 위해 필요)
6. **저장**
7. **인증서** 탭으로 가서 `o.knknara.co.kr` 인증서가 이 리버스 프록시에 매핑됐는지 확인 (자동)

---

## 4단계 — 메신저 production 모드 전환 (빅터 자동)

대표님이 1~3단계 완료 후 빅터가 자동 수행:
- `.env` 의 `KNK_MSG_ENV=production` 으로 변경
- 세션 쿠키 SECURE 플래그 활성 (HTTPS 강제)
- HSTS 헤더 활성
- supervisord 재시작

---

## 5단계 — 검증 (10분)

대표님이 진행, 모든 항목 ✓ 시 완료:

- [ ] `https://o.knknara.co.kr/` 직접 접속 → 자물쇠 아이콘 + 정상 로딩
- [ ] iPhone Chrome 에서 위 URL → 정상 작동 (기존 흰 화면 문제 해결)
- [ ] iPhone Safari 에서 정상 작동
- [ ] PWA 재설치 (기존 PWA 삭제 후 새 HTTPS URL 로 다시 추가)
- [ ] 로그인 → 메시지 송수신
- [ ] 파일/사진 업로드 정상 (600MB 이내)
- [ ] Socket.IO 실시간 메시지 (다른 기기에서 메시지 보냈을 때 즉시 표시)
- [ ] 새 메시지 알림 토스트 (창 비활성 시)

검증 실패 시 → 빅터에게 알려주세요. 즉시 디버그.

---

## 롤백 (만약 문제 발생)

- DSM Reverse Proxy 비활성화 → 기존 `http://o.knknara.co.kr:3310/` 그대로 작동
- 빅터가 `.env` 의 `KNK_MSG_ENV=development` 으로 되돌리고 재시작
- 추가 30초 내 원상 복구

---

## 향후 자동 갱신

- Let's Encrypt 인증서는 90일 유효
- DSM이 만료 30일 전 자동 갱신 (수동 작업 X)
- 갱신 실패 시 DSM이 이메일 알림 (제어판 → 알림 설정에서 이메일 등록)
