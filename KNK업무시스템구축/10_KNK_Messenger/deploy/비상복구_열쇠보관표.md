## 복구 빠른 순서 (이 종이를 든 사람에게)

1. 새 PC에 **Claude Code(클로드) + Git** 설치
2. 코드 받기: `git clone git@github.com:top00151-commits/knk-messenger.git`
3. 받은 폴더에서 **클로드 실행** → 클로드가 `CLAUDE.md` 를 자동으로 읽고 상황 파악
4. 점검 실행: `& "deploy\recover_setup.ps1"` → 무엇이 빠졌는지 안내됨
5. 위 1~5번 비밀값을 PC 환경변수로 입력 → `& "deploy\recover_setup.ps1" -RunDiag` 로 서버 연결 확인 → 정상 배포

> 메신저 자체는 회사 서버에서 24시간 스스로 돌아갑니다. 이 복구는 **"고치고 바꾸는 능력"** 을 되찾는 절차입니다.
