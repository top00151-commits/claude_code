# 새 PC 준비 — 프로그램 설치 안내

> 새 컴퓨터에서 KNK 메신저를 **고치고 배포**하려면, 아래 프로그램만 설치하면 됩니다.
> Windows 기준 · 인터넷 연결 필요 · 약 15분이면 끝납니다.
> (메신저 자체는 회사 서버에서 계속 돌아갑니다. 이건 "고치는 도구"를 새 PC에 갖추는 과정입니다.)

---

## 한눈에

| 프로그램 | 꼭 필요? | 용도 |
|---|---|---|
| **① 클로드 (Claude)** | ✅ 필수 | 코드를 고치고 배포해주는 AI 도구 (지금 쓰시는 그 프로그램) |
| **② Git (깃)** | ✅ 필수 | 코드를 인터넷에서 받고(다운) 다시 올리는(백업) 도구 |
| **③ Python (파이썬)** | ▢ 선택 | 문서 생성·로컬 점검용 (없어도 고치고 배포는 됩니다) |

---

## ① 클로드 (Claude) 설치  — 필수

**지금 대표님이 쓰고 계신 바로 그 프로그램입니다.** 새 PC에 똑같이 깔면 됩니다.

1. 인터넷 주소창에 입력해서 다운로드 페이지 열기:
   `https://code.claude.com/docs/en/desktop-quickstart`
   (또는 Windows 설치파일 바로 받기: `https://claude.ai/api/desktop/win32/x64/setup/latest/redirect`)
2. 설치파일 실행 → 안내대로 설치
3. 실행 후 **지금 쓰시는 그 계정으로 로그인** (유료 플랜 계정)
4. 상단 **"Code(코드)"** 탭 클릭 → **"Local(로컬)"** 선택
5. **"폴더 선택"** 으로 메신저 코드 폴더를 열면 → 폴더 안 `CLAUDE.md` 를 **자동으로 읽고** 무엇을 해야 하는지 바로 파악합니다

## ② Git (깃) 설치  — 필수

코드를 인터넷(GitHub)에서 받고, 고친 것을 다시 올리는 데 필요합니다.

1. 다운로드: `https://git-scm.com/download/win`
2. 받아진 파일 실행 → **"Next(다음)"** 만 계속 눌러 설치 (기본값 그대로 두면 됩니다)
3. 마지막에 **"Install(설치)"** → 끝

## ③ Python (파이썬) 설치  — 선택 (있으면 좋음)

메신저는 파이썬으로 만들어졌습니다. 서버에서 돌아가므로 PC엔 꼭 필요하진 않지만, 문서를 만들거나 PC에서 시험해 볼 때 쓰입니다.

1. 다운로드: `https://www.python.org/downloads/`
2. 받아진 파일 실행 → ⚠️ **첫 화면 맨 아래 "Add Python to PATH(파이썬을 PATH에 추가)" 체크박스를 꼭 체크!**
3. **"Install Now(지금 설치)"** → 끝

> ③의 체크박스를 빠뜨리면 나중에 오류가 납니다. 이것만 주의하세요.

---

## 설치가 끝나면

1. 클로드를 열고 **메신저 코드 폴더**를 엽니다 (위 ①-4,5 단계)
2. 클로드에게 이렇게 말하세요: **"재해복구 점검 도와줘"** (또는 `recover_setup.ps1` 실행)
3. 클로드가 무엇이 빠졌는지 알려주면, **금고의 "열쇠보관표"** 종이를 보고 비밀번호를 입력
4. 연결 확인되면 → 평소처럼 코드 수정·배포 가능 ✅

## 코드는 어디서 받나요?

클로드에게 "코드 받아줘"라고 하거나, 아래를 실행하면 됩니다 (GitHub 로그인 필요):

```
git clone git@github.com:top00151-commits/knk-messenger.git
```

> 막히는 부분이 있으면, 그 화면을 **클로드에게 그대로 보여주고 물어보면** 단계별로 도와줍니다.
