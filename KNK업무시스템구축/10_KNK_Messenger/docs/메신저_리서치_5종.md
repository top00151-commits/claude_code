## 1. KakaoTalk (카카오톡)

### 개요
- **회사/출시**: ㈜카카오 / 2010년 출시
- **MAU**: 글로벌 약 5,350만 (2025년 기준), 그중 **48.2백만이 한국**
- **주 사용 국가**: 대한민국 (스마트폰 보급률 96.3%, 시장 점유율 약 97%)
- **메시지량**: 일 약 10억 건 송수신

### 핵심 강점
1. **한국 사회 인프라화**: 본인 인증·송금·결제·예약 등 일상 서비스가 한 앱에 묶임
2. **카카오페이/선물하기 등 강력한 부가 생태계** — 단순 채팅을 넘어선 lock-in
3. **친구 자동 추가(주소록 기반)** — 가입 직후 즉시 네트워크 형성
4. **이모티콘 시장** — 작가 생태계 + 유료 상품화 성공
5. **오픈채팅** — 익명·관심사 기반 공개 커뮤니티 (한국에서 강세)
6. **PC/모바일/태블릿 멀티 디바이스 동기화** + #검색 한글 자모 매칭 우수

### 약점
1. **광고 과잉**: 채팅방 목록 상단 + 채팅방 사이 끼워넣은 광고로 오클릭 유도 비판 (2025년 개편 이후 가속)
2. **15년 만의 인스타그램풍 UI 개편 역풍** — "혼란스럽다·정신없다" 라는 사용자 반발 폭증
3. **개인정보·타깃 광고 투명성 최하위권** (Ranking Digital Rights 2025)
4. **글로벌 확장 실패** — 96.72% 사용자가 한국에 집중, 해외 협업·해외 거주자 소통에 부적합
5. **메시지 전체 검색 약함** — 채팅방별 검색은 되지만 전체 통합 검색 부재
6. **E2EE 미적용(비밀채팅 제외)** — 일반 톡은 서버 평문 저장 후 일정 기간 후 삭제 방식
7. **사칭/스팸 비중 높음** — 서비스 제한 사유의 66.8%가 사칭, 17.5%가 불법 스팸

### 차별화 기능
- **선물하기/송금**: 채팅 흐름 안에서 즉시 금전·상품 이동
- **오픈채팅(90일 보관) + 톡채널** — 브랜드 운영 채널과 익명 커뮤니티 양립
- **나에게 보내기(메모용 1인방)** — 메모 앱 대체 용도로 사실상 표준화

### 알림 처리
- PC 클라이언트 백그라운드 동작 시 모바일도 동시 푸시 (이중 알림 우려)
- 채팅방별 알림 켜기/끄기·키워드 알림 가능
- 화면 잠금 알림 시 발신자명/내용 분리 노출 가능

### 첨부파일 처리
- **무료 톡드라이브**: 최근 100MB 1년 (이상은 자동 삭제 → 사용자 항의 핵심 포인트)
- **톡 클라우드(유료)**: 2025-08 가격 인상으로 비판
- 사진은 원본/일반 화질 옵션, 동영상은 압축 권장
- 미리보기는 이미지/문서 모두 채팅창 내 인라인 지원

### 검색
- 채팅방 단위 키워드 검색 + 친구·채널·이모티콘 통합 검색
- **방 간 통합 메시지 검색은 약함**

### 그룹/방 관리
- 일반 그룹 정원 미공개 (실무상 수백 명 운용), 오픈채팅 1,500명
- 방장/부방장 권한, 강퇴, 알림 차단 가능

### 보안/암호화
- **기본 채팅은 서버 저장 (E2EE 아님)** — 영장 기반 통신 자료 제공 이력
- **비밀채팅**만 E2EE 적용 (사용성 낮아 사실상 미활용)
- 2014년 "사이버 검열" 사태 이후 망명 사태 경험

### KNK Messenger 적용 아이디어
- **"나에게 보내기" 1인 메모방을 기본 제공** — 직원들이 업무 메모·임시 파일 옮길 때 즉시 사용 (학습비용 0)
- **광고는 절대 넣지 않는다** — 카카오톡 광고 역풍이 사내 메신저에서 가장 큰 차별 포인트

## 2. Telegram

### 개요
- **회사/창립자**: Telegram FZ LLC / Pavel Durov / 2013년 출시
- **MAU**: **10억 명 돌파(2025-03)**, DAU 4.5억
- **주 사용 국가**: 러시아·우크라이나·인도·동남아시아·중동·이란
- **유료**: Telegram Premium 약 1,500만 구독자(2025-05)

### 핵심 강점
1. **속도/안정성**: 분산 서버 인프라로 모바일·PC·웹 모두 거의 동일한 응답성
2. **무제한 클라우드** — 모든 채팅·미디어가 서버에 저장돼 기기 변경 시 동기화 즉시
3. **대용량 파일 전송**: 2GB(무료) / 4GB(Premium) — 메신저 중 최상위
4. **봇 생태계**: API 공개로 결제·뉴스·자동화 봇 폭발적 확산
5. **채널(Channel)**: 구독자 수 무제한, 방송형 일방 통신에 최적화
6. **다중 계정/세션 관리** + Premium 시 4개 동시 사용
7. **클라이언트 오픈소스** + 다양한 데스크톱 네이티브 앱

### 약점
1. **기본 E2EE 아님**: 일반 채팅은 서버 평문에 가까운 형태(서버측 복호 가능), Secret Chat만 E2EE
2. **MTProto 자체 암호화** — 동료 검증 부족, 보안 학계 비판 지속
3. **Secret Chat UX 불편** — 사용자가 일부러 켜야 하고, 1대1·디바이스 한정 → 거의 안 씀
4. **검색 약함** — 키워드 정확도 떨어지고 한국어 형태소 처리 부실
5. **인프라 지정학 리스크** — 2025 조사에서 일부 네트워크 인프라가 러시아 FSB 연계 업체 운영으로 밝혀짐
6. **계정이 사전 통보 없이 차단**되는 사례 보고
7. **마약·스팸 등 불법 사용 온상**이라는 사회적 평판

### 차별화 기능
- **채널/봇/슈퍼그룹(20만 명)** 3축 — 다른 메신저 압도
- **메시지 예약 발송, 자기 소멸 메시지(타이머)**, **익명 전달, 텍스트 포맷팅(코드블록/스포일러)**

### 알림 처리
- 채널·그룹별 알림 세분화, 키워드 멘션 알림 가능
- 데스크톱 클라이언트가 활성 상태면 모바일 푸시 자동 억제 (KNK가 벤치마크할 핵심 동작)
- 야간 자동 무음(Schedule)

### 첨부파일 처리
- 무제한 클라우드 저장 + **만료 없음**
- 2GB / 4GB 대용량, 인라인 미리보기·스트리밍 재생
- 압축 없는 원본 전송 가능

### 검색
- 글로벌 검색(전체 채팅 한 번에) 지원, 단 한국어 정확도 부족
- 채팅 내 발신자별·날짜별 필터

### 그룹/방 관리
- 슈퍼그룹 **20만 명**, 채널 무제한 구독
- **관리자 50명, 봇 20개**, 권한 세분화(메시지 삭제·차단·고정·통계)
- 스레드형 댓글, 메시지 반응(이모지)

### 보안/암호화
- 기본 채팅 E2EE 아님 (서버측 키 보관)
- Secret Chat만 E2EE — 1대1, 디바이스 종속
- 2단계 인증, 자동 종료 세션

### KNK Messenger 적용 아이디어
- **"데스크톱 활성 시 모바일 푸시 자동 억제"** — 직원이 PC에서 일하는 동안 휴대폰 알림이 안 울려서 집중에 큰 도움
- **메시지 예약 발송** — 야간 작성한 공지를 다음 날 업무 시작 시간에 자동 발송 (관리자 만족도 높음)

## 3. WhatsApp

### 개요
- **회사/출시**: Meta Platforms / 2009년 출시(2014 Meta 인수)
- **MAU**: **30억 명 돌파(2025-05)** — 메신저 부동의 1위
- **주 사용 국가**: 인도(전 국민), 브라질, 인도네시아, 멕시코, 유럽 대부분, 중동
- **메시지량**: 일 1,000억 건

### 핵심 강점
1. **기본 E2EE(Signal Protocol)** — 메시지·통화·미디어·백업 모두 자동 암호화
2. **2025년 패스키 기반 백업 암호화** — iCloud/Google Drive 백업도 Meta조차 못 봄
3. **압도적 보급률** — 해외 협력사·물류 파트너와 즉시 연결 가능
4. **WhatsApp Business API** — 고객 응대·결제 자동화 표준
5. **전화번호 기반 즉시 가입** + 친구 자동 매칭
6. **고품질 음성/영상 통화** — 저대역 환경에서도 안정

### 약점
1. **전화번호에 묶인 계정** — 번호 변경 시 이전 부담, 다중 계정 어려움
2. **스레드 기능 없음** — 대화 분기 추적 어려움 (Slack/Discord 대비)
3. **고급 모더레이션·역할 권한 미흡** — 업무용으로는 한계
4. **광범위한 메타데이터 수집** — Meta 광고 생태계 연결 의혹
5. **그룹 검색·기록 검색** 약함 (대화량 많을 때 사실상 못 찾음)
6. **제3자 통합/봇 생태계 빈약**
7. **데스크톱 클라이언트가 모바일에 종속**되는 경향(개선 중이나 여전)

### 차별화 기능
- **Communities** — 여러 그룹을 묶어 공지 채널 + 하위 그룹 구조로 운영
- **상태(Status)** — 24시간 만료 스토리
- **메시지 자동 삭제 타이머**(24시간/7일/90일)
- **2025 AI 그룹 요약** — 안 본 메시지 자동 요약(영문 시장 우선)

### 알림 처리
- 채팅·그룹 단위 무음 설정(8h/1주/항상)
- "@멘션만 알림" 옵션 — 대형 그룹에 필수
- iOS 집중모드 연동 자연스러움

### 첨부파일 처리
- **2GB 단일 파일** 전송 (모바일 4G 환경 고려한 가장 큰 장점)
- 사진/영상 자동 압축 옵션 + "문서로 보내기" 시 원본
- 미디어 만료 없음 (단, 백업 안 하면 폰 분실 시 손실)

### 검색
- 전체 대화 글로벌 검색 + 사진/링크/문서 타입 필터
- 단, **한국어 형태소 부정확** + 대량 채팅에서 결과 누락 잦음

### 그룹/방 관리
- 그룹 정원 **1,024명**(기존 256명에서 상향)
- Community 산하 그룹 무제한, 5,000명 공지 채널
- 관리자 권한·승인 후 가입·메시지 사전 승인 가능

### 보안/암호화
- **Signal Protocol 기반 E2EE 전면 적용**
- 2025-10 패스키 기반 백업 암호화 출시 — 비밀번호 분실 위험 해소
- 메타데이터(연락처·접속 IP·기기)는 Meta가 수집

### KNK Messenger 적용 아이디어
- **메시지 자동 삭제 타이머(24h/7d/90d)** — 보안 정책상 민감 정보가 영구 보관되지 않도록 기본 옵션 제공
- **"@멘션만 알림" 그룹 옵션** — 사내 전체 공지방의 알림 피로 즉시 해소

## 4. Discord

### 개요
- **회사/출시**: Discord Inc. / 2015년 출시
- **MAU**: **약 2.59억(2025)**, YoY +13.8%
- **주 사용 국가**: 미국·유럽·일본·한국(게이밍·개발자 커뮤니티 강세)
- **사용 시간**: 활성 사용자 일평균 94분 (메신저 중 최장 수준)

### 핵심 강점
1. **상시 접속형 음성 채널** — "들어가 있기만 해도 대기 상태", 원격 협업 가상 사무실 효과
2. **서버 구조** — 하나의 워크스페이스에 채널 수십 개를 카테고리로 묶기
3. **음성 평균 53분 세션** — 텍스트(24분)의 2배 — 실시간 협업에 최적
4. **봇/통합 풍부** — 자동 환영, 역할 부여, 음악, 투표 등
5. **스레드 메시지 1만 개까지 확장(2025)** + AI 자동 요약
6. **무료 화면 공유·게임 스트리밍** — Slack보다 가벼움
7. **권한 세분화(역할 색상·채널별 권한)**

### 약점
1. **대형 서버 알림 폭주** — 무음/멘션 설정을 직접 세팅해야 함
2. **2025-03 새 UI 개편 후 "너무 넓고 산만하다" 반발**
3. **HD 화면공유·대용량 업로드는 Nitro 유료**
4. **업무 표준 워크플로(승인·결재·문서 연계) 부재**
5. **모더레이션 부담** — 사용자 자율, 사내용으로는 부담
6. **보안 사고 이력** — 봇 토큰 유출, 피싱 봇 다수
7. **검색 기능 약함** — 서버 단위만, 키워드 정확도 낮음

### 차별화 기능
- **항상 켜진 음성 채널 + Stage(연단)** — 실시간 회의·발표 인프라
- **포럼 채널** — Slack 스레드보다 시각적으로 구조화된 토론 게시판
- **역할 기반 권한** + **이모지 반응 자동 역할 부여**
- **소셜 게임/Activities(Watch Together)** — 회식·아이스브레이킹

### 알림 처리
- 서버 단위/카테고리 단위/채널 단위 3계층 알림 설정
- @everyone, @here, @멘션, 키워드 알림 가능
- 모바일/PC 푸시 분리 설정

### 첨부파일 처리
- 무료 **10MB / Nitro Basic 50MB / Nitro 500MB**
- 영상은 인라인 재생, 이미지/PDF 미리보기 우수
- 만료 없음 (단, 서버 삭제 시 함께 삭제)

### 검색
- 글로벌 검색 + `from:`, `mentions:`, `has:link/file/embed`, `before:`, `after:` 필터 — 메신저 중 가장 풍부
- 한국어 토큰화는 보통 수준

### 그룹/방 관리
- 서버 **회원 50만(검증 서버 100만)**, 채널 500개
- 역할 250개, 권한 30+종
- 환영 화면·온보딩 설문·규칙 동의 흐름 표준화

### 보안/암호화

- 2FA, SSO(Enterprise) 지원

### KNK Messenger 적용 아이디어

## 5. Slack

### 개요
- **회사/출시**: Slack Technologies (Salesforce 자회사) / 2013년 출시
- **DAU/MAU**: DAU **약 4,720만 / MAU 약 7,900만(2025)**
- **주 사용 국가**: 북미·유럽 IT 기업 표준, 일본 IT 업계 점유율 높음
- **수익**: ARPU 연 425달러, Enterprise Grid 좌석당 1,100달러 이상

### 핵심 강점
1. **스레드(Threaded Reply)** — 채널을 어지럽히지 않고 토픽별 깊은 대화 (KNK가 가장 부족한 기능)
2. **2,600개 이상 앱 통합** + Workflow Builder(코드 없는 자동화)
3. **Slack Connect** — 외부 회사와 채팅방 직접 공유 (이메일 대체)
4. **검색 강력** — 글로벌 + 모든 메타데이터 필터, Salesforce 연동
5. **엔터프라이즈 컴플라이언스** — HIPAA, FINRA, GDPR, EKM 등 100+ 통제
6. **Huddle(허들)** — 클릭 한 번 음성 회의(녹화·자막 자동)
7. **Canvas** — 채널 내 위키/문서 작성

### 약점
1. **알림 피로 1위 불만** — 기본값이 "모든 메시지 알림"
2. **스레드를 안 보면 놓침** — 팔로워가 아니면 본 채널에 안 뜸
3. **유료 의존도 높음**: 무료는 **90일 메시지 보존 / 통합 앱 10개 한도**
4. **사용자당 요금제** — 인원이 늘수록 비용 폭증
5. **신규 사용자 학습 곡선** — 채널/스레드/허들 개념이 처음엔 혼란
6. **한국어 검색 형태소 한계** — 조사·어미 분리 부정확
7. **API Rate Limit** — 봇 대량 운용 시 제약

### 차별화 기능
- **Slack Connect**: 외부 회사·고객사와 채널 단위 공유 — 이메일 0으로 만들 수 있음
- **Workflow Builder** — 결재·휴가신청·온보딩 등 폼 기반 자동화 (KNK 결재함과 직결)
- **Canvas**: 채널 안에 협업 문서, **메시지를 캔버스로 끌어다 정리**
- **Huddle 자동 녹화·자막·요약(AI)**

### 알림 처리
- 채널/DM/스레드/키워드별 정밀 알림
- **방해금지 시간(DND) 자동 설정** + 시차 자동 인지
- 모바일/PC 알림 분리 + 비활성 시 모바일로 자동 전환

### 첨부파일 처리
- 무료 5GB(워크스페이스 합산), Pro 10GB/사용자, Business+ 20GB/사용자
- 단일 파일 1GB 제한
- 미리보기 풍부(이미지·PDF·코드 스니펫·동영상 인라인)
- 만료 없음, 단 무료는 90일 후 메시지와 함께 숨김

### 검색
- 글로벌 검색 + `in:`, `from:`, `to:`, `before:`, `after:`, `has:link/pin/star` 필터
- 파일·메시지·캔버스·채널 통합 검색

### 그룹/방 관리
- 채널 무제한, 1채널 최대 1,000명 권장(기술적 더 큼)
- 사용자 그룹(@team-eng) 멘션 — 부서별 일괄 호출
- 역할·권한(Workspace Owner/Admin/Member/Guest)

### 보안/암호화
- **E2EE 없음** — 서버 측 암호화(at-rest, in-transit)만
- Enterprise Grid: EKM(자체 키), DLP, eDiscovery, SCIM
- SOC 2 Type II, ISO 27001/27017/27018, HIPAA

### KNK Messenger 적용 아이디어
- **스레드(Threaded Reply)** — KNK 사내 공지방의 댓글이 본문을 묻어버리는 문제 해결 (1순위 권고)
- **Workflow Builder형 사내 결재/휴가 폼** — 별도 결재 시스템 대신 메신저 안에서 처리 → HAIST WORKS 결재함과 직접 연동 가능

## KNK Messenger 우선 적용 권고 Top 5

### 1순위. 스레드(Threaded Reply) — Slack형
- **근거**: 사내 공지방 댓글이 본문 메시지를 묻어버리는 가장 흔한 사내 메신저 문제 해결
- **구현 효과**: 한 채널 안에서 토픽별 깊은 토론 가능 → 채널 수 폭발 억제
- **참고 모델**: Slack(원조) / Discord(1만 메시지 확장)

### 2순위. 데스크톱 활성 시 모바일 푸시 자동 억제 — Telegram형
- **근거**: 직원이 PC에서 일하는 동안 휴대폰까지 동시 진동 → 가장 큰 불만 포인트
- **구현 효과**: 카톡 대비 즉각 체감되는 차별화. 설정 없이 기본 동작
- **참고 모델**: Telegram (PC 클라이언트 active 감지)

### 3순위. 고급 검색 필터 — Slack/Discord형
- **근거**: KNK처럼 PO·SO·프로젝트 호기 등 키워드 많은 환경에서 "찾기"가 핵심
- **구현 효과**: `from:김정락`, `has:file`, `before:2026-05-01`, `in:#영업` 등 — 업무 추적 폭발적 개선
- **참고 모델**: Slack(필터 가장 풍부), Discord(시각적 UX)

### 4순위. 메시지 자동 삭제 타이머 + "나에게 보내기" 1인 메모방 — WhatsApp + KakaoTalk 하이브리드
- **근거**: 민감 업무 정보(가격·계약) 영구 보관 위험 해소 + 직원 메모 앱 대체
- **구현 효과**: 보안 정책 자동화 + 카톡 사용자 학습비용 0
- **참고 모델**: WhatsApp(24h/7d/90d 타이머), KakaoTalk(나와의 채팅)

### 5순위. Workflow Builder형 사내 폼·승인 통합 — Slack형
- **근거**: HAIST WORKS의 결재함·휴가·구매요청을 메신저에서 직접 시작/승인
- **구현 효과**: 별도 사이트 이동 없이 채팅창에서 결재 완결 → 모바일 결재율 급상승
- **참고 모델**: Slack Workflow Builder + Canvas
