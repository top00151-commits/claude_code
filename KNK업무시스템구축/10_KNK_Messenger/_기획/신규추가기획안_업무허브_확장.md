## 1. 배경 / 목적

메신저 프로젝트 정의서의 정체성은 **"업무 관리 허브 = 회사 일의 관문"** 이다. 4원칙은:

1. **쉬움 1순위** — "카톡만큼 쉬운가?" 통과 못 하면 아무리 좋아도 보류·숨김
2. 업무는 추적되게 (업무 누락 0)
3. 언어장벽 0 (본사–베트남)
4. 고객사는 가볍게

이 기획안은 대표 제안 3가지(부서별 업무 박스 · 사내 전용 메일 · AI 보고서 번역)를 정의서 4원칙으로 비추어, **이미 만들어진 것과 새로 만들 것을 구분**하고 우선순위를 제안한다.

**핵심 발견:** 3가지 중 2가지(부서 업무 박스 · AI 번역)는 **재료가 이미 절반 이상 구현**되어 있다. 새로 짓는 게 아니라 "있는 걸 묶고 확장"이라 빠르게 가능하다.

## 2. 현재 메신저 기능 현황 (인벤토리)

| 기능 | 상태 | 내용 |
|---|---|---|
| **AI 번역** | ✅ 완성 | 메시지 단위 한↔베↔영↔중, 메시지마다 번역 버튼, AI 엔진, 비용·사용량 관리자 집계까지 |
| **부서방 / 그룹방** | 🟡 ~85% | 부서별 자동 채팅방, 고정 공지(핀), 24개 부서 구분, 고객사(게스트) 방 |
| **할 일 (업무)** | ✅ ~90% | 담당자·기한·상태(진행/보류/완료/반려), **메시지 길게 눌러 "할 일로" 전환** 이미 됨, 내 업무 목록 |
| **확인 추적** | ✅ ~95% | "확인 도장"(알겠음/처리중/완료/반려 + 한마디), 멘션 읽음, 반응 이모지 |
| **WORKS·결재·메일 연동** | 🔴 ~30% | SSO 입장 + 활동 히스토리 동기화만 있음. **결재·메일 알림 브리지는 없음** |
| **봇 / 시스템 발신자** | 🔴 ~20% | 시스템 메시지·공지는 있으나 **봇 계정·외부 알림 수신구(웹훅)는 없음** |

> 강점: 번역·할 일·확인 추적은 이미 강하다. 약점: **외부 시스템 연동·봇(관문 알림)** 이 가장 비어 있다.

## 3. 신규 추가 3안

### 안 ① 부서 업무 박스

**개요:** 부서방에 들어가면 지금은 그냥 채팅이다. 여기에 **상단 얇은 띠 한 줄**을 더해, 그 부서의 할 일·공지·파일을 한 화면에 모아 본다.

**화면 스케치**
```
┌───────────────────────────────────────┐
│ 영업부 ▾      📌 공지   ✅ 할 일 3   📁 파일 │ ← 새로 추가 (얇은 띠)
├───────────────────────────────────────┤
│  김빅터: 견적서 오늘까지 부탁해요          │
│     └ 길게 누르면 → [✅ 할 일로 만들기]     │ ← 이미 됨
└───────────────────────────────────────┘

[✅ 할 일 3] 누르면 ↓
  ☐ 견적서 작성   — 박OO · 오늘까지 · 진행중
  ☐ 거래처 방문   — 이OO · 6/5    · 대기
  ☑ 계약서 검토   — 김OO · 완료
```

| 구분 | 내용 |
|---|---|
| 이미 있는 것 | 할 일(requests)·공지(room_notices)·확인 도장(acks)·파일 첨부 — **전부** |
| 새로 만들 것 | 부서방 상단 "업무 박스 띠" + 그 방 기준으로 모아보기 (백엔드는 거의 그대로, 화면 조립 위주) |
| 카톡만큼 쉬움? | ✅ 평소엔 채팅만, 안 누르면 안 보임 (단톡방 + 상단 고정 공지 수준) |
| 규모 / 위험 | **1~2일 시안** · 외부 연동 없음 · 위험 낮음 |
| 정할 점 | 띠를 **부서방·그룹방만** 붙일지(추천), 1:1 대화는 제외 |

---

### 안 ② 문서·보고서 AI 번역

**개요:** 메시지 번역은 이미 완성. 빠진 것은 **문서(장문) 번역**이다. 출장보고서·업무보고서 파일을 올려 한↔베 번역. 정의서 ①(언어장벽 0) 가장 직결, 차별화 큼.

**화면 스케치**
```
📎 출장보고서_베트남.docx
   [📥 받기]   [🌐 한국어로 번역]   ← 버튼 추가
        ↓ 누르면
🤖 🌐 번역(한국어): "이번 출장은 …"   + 번역본 파일

또는: 입력창 위 [🌐 번역] → 긴 글 붙여넣기 → 언어 골라 번역
```

| 구분 | 내용 |
|---|---|
| 이미 있는 것 | 번역 AI 엔진·비용 집계 (메시지 번역에 쓰는 것 그대로 재사용) |
| 새로 만들 것 | 파일 → 글자 뽑기 → 번역 → 결과. **docx·txt·붙여넣기는 쉬움 / 한글(hwp)·pdf는 까다로움** |
| 카톡만큼 쉬움? | ✅ 버튼 하나. 단 긴 글은 "번역 중…" 표시 필요 |
| 규모 / 위험 | docx·txt·붙여넣기 먼저 **2~3일**, hwp·pdf는 2차 |
| 정할 점 | 번역본을 **올린 사람만 먼저 보고 → "공유" 누르면 방에**(추천), 어떤 파일형식부터 |

---

### 안 ③ 업무 봇 (관문 알림)

**개요:** 정의서 ②(업무 누락 0)·③(관문)에 가장 직결되나 **지금 가장 약한 부분**(연동 30%·봇 20%). "업무 알림" 봇방 하나가 흩어진 알림을 모아준다.

**화면 스케치**
```
🤖 업무 알림                ─ 오늘 9:00 ─
  📋 결재 대기 1건: 「출장비 정산」      → [열기]
  ✉️ 새 메일 2통 (외부 그룹웨어)        → [열기]
  ✅ WORKS 새 일 1건: 「견적 검토」      → [열기]
        (탭하면 해당 화면으로 바로 — SSO)
```

| 구분 | 내용 |
|---|---|
| 이미 있는 것 | 시스템 메시지·SSO·푸시 알림 |
| 새로 만들 것 | ⓐ 봇 계정(시스템 발신자) ⓑ **외부에서 "생겼다"를 받아오는 연결**(웹훅 또는 주기 확인) |
| 카톡만큼 쉬움? | ✅ 채팅처럼 옴. 단 **하루 1~2회 묶음**(알림 과다 금지) |
| 규모 / 위험 | **가장 큼.** 외부 연동·전산담당자·사전 승인 필요 |
| ⚠️ 선결 확인 | **외부 그룹웨어가 메일·결재 알림을 API/웹훅으로 내주는지** — 안 주면 메일 알림은 어려움. (우리 WORKS 결재는 우리 시스템이라 상대적으로 쉬움) |

## 4. 우선순위 / 로드맵 (제안)

**① → ② → ③** (쉽고 재료 있는 것부터, ③은 외부 확인이 깔려야 함)

| 순위 | 안 | 이유 | 예상 |
|---|---|---|---|
| 1 | **부서 업무 박스** | 재료 다 있음, 가장 빠른 체감, 외부 의존 없음 | 1~2일 |
| 2 | **문서·보고서 AI 번역** | 번역 엔진 재사용, 언어장벽 0 직결, 차별화 | 2~3일(1차) |
| 3 | **업무 봇 (관문 알림)** | 효과 크나 외부 연동·승인 필요 (기반 작업) | 외부 확인 후 산정 |

**연결 관계:** 안 ②와 ③은 이어진다 — 출장보고서를 번역(②)하면 → 그대로 결재로 넘기는 흐름(③)으로 연결.

## 5. 지킬 선 (정책 제약)

- **외부 그룹웨어 메일·결재는 계속 사용** — 메신저가 "대체"하는 것이 아니라 **관문(알림)** 역할. 사내 공지·요청·보고는 메신저로, 공식·외부·법적 문서는 외부 그룹웨어 유지.
- **외부 연동(웹훅·SSO·메일 브리지)은 사전 승인 후 진행** — 전산담당자 확인 필요.
- **"카톡만큼 쉬운가?" 1순위 통과** — 각 기능 출시 전 관문 점검. 통과 못 하면 보류·숨김.
