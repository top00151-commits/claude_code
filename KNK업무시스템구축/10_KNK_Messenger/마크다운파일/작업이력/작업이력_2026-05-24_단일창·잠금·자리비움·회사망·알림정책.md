## 1. PC 앱 중복 창 방지 (단일 실행)

- **증상**: 아이콘을 누를 때마다 창이 계속 새로 열림.
- **진짜 원인**: 실제 실행은 `.bat`이 아니라 **설치된 크롬 PWA**였고, PWA는 기본값이 "누를 때마다 새 창". (`launch_handler` 미설정)
- **해결**: 매니페스트에 **`launch_handler: focus-existing`** + 앱 고유 **`id`** 추가 → 아이콘 재클릭 시 새 창 대신 **기존 창 포커스**.
- **중요**: 매니페스트는 정적 파일이 아니라 **`serve_manifest()`가 동적 생성**(BASE_PATH `/msg` 반영)이라 거기에 반영. (`82677d6`)
- 적용엔 **PWA 재설치** 필요(설치 시점 설정 고정).
- 부수: `메신저START.bat` 단일 실행 + `single_window.ps1`(기존 창 포커스, 로컬 테스트 서버용). (`27b05c4`, `4212781`)

## 2. 로그인 화면 회사 슬로건

- 회사 로고 아래 **"Human & AI create the Best"** 텍스트로 추가(이미지 아님). 흰 카드에 맞춰 KNK 빨강·가운데. (`47be420`)

## 3. 멘션함 개선

- **항목 레이아웃**: 삭제(🗑) 버튼이 내용 길이에 따라 들쭉날쭉하던 것 → 카드를 좌(본문)/우(🗑) 2칸으로 분리해 **🗑 항상 오른쪽 끝 고정**. (`53a4231`)
- **필터바 멘션 배지 잘림**: 내 요청·멘션 배지 추가로 한 줄 폭 초과 → 칩 간격·여백·배지 축소로 한 줄에 들어오게. (`6c2afd3`)

## 4. 📌 내 요청 배지

- `📌 내 요청` 칩에 **받은 미완료(진행 전·진행중) 요청 수** 빨강 배지. (`fcc13c4`)
- **실시간성 수정**: requests_updated가 방 단위라 메인창만 보면 늦게 떴음 → 요청 생성·변경 시 **담당자·요청자 본인 SID로 직접 전송**(멘션 방식)해 즉시 갱신. (`d700cfc`)

## 5. 화면 잠금 (자리 비움 보안)

- 자리 비우면 **화면을 가림**(로그인 유지). 해제 = **비밀번호(서버 확인) 또는 지문·얼굴(WebAuthn 기기보안)**. (`57595d6`)
- 설정(🔔)에서 **미적용(기본)/3분/5분/10분** 선택 + 지문·얼굴 등록. 기기별 저장.
- 미사용 시간·백그라운드 복귀·새로고침(세션 잠금유지) 처리. 잠금화면에 로그아웃 비상구.

## 6. 모바일 길게누름 2단계

- 말풍선 기본 텍스트 선택 차단(브라우저 복사·번역 메뉴가 앱 메뉴보다 먼저 뜨는 충돌 방지).
- **0.6초 = 앱 메뉴 / 계속 1.3초 = 브라우저 기본 텍스트 선택(부분 복사·번역)**. (`f31e54e`)
- 부가: 길게누름 메뉴가 방 나가기/전환 후에도 남던 버그 수정. (`c7442b2`)

## 7. 번역 줄 오른쪽 "← 뒤로"

- 입력하다 상단 ←까지 손 뻗기 불편 → 입력창 위 번역 줄 오른쪽 끝에 **"← 뒤로"** 추가. 상단 ←는 안전용 유지. (`e53762b`)

## 8. 다이제스트 "오늘 더 이상 열지 않기"

- 자동 노출이 앱 재실행마다 또 뜨던 문제 → **localStorage 날짜 기준 하루 1회**. "🚫 오늘 더 이상 열지 않기" 버튼 추가. 날짜 바뀌면 다시. (`e691c7b`)

## 9. 자동 자리비움 + 아이콘 변경

- 앱을 켜둔 채(포커스) **10분간 무조작이면 자동 🪑 자리비움**. 조작 시 즉시 복귀. 수동 상태가 우선. (`63914b4`)
- 자리비움 아이콘 **🌙 → 🪑(빈 의자)** 변경. (`1293fbd`)
- 판정: presence에 idle 플래그 추가(클라이언트) → 서버가 활성 기기 idle이면 'away' 계산·broadcast. 푸시 동작은 미변경.

## 10. 회사망 접속 시 "🏢 회사" 표시

- 회사 인터넷(WiFi·유선)에 접속 중이면 사용자 상태 옆 **"🏢 회사"** 표시. **위치추적 아님 — 등록된 회사 공인 IP와 접속 IP 대조만**. (`760c9a6`)
- 관리자(🔔 설정)에서 **"현재 네트워크를 회사망으로 등록"**(현재 IP 캡처) + 목록·삭제. 등록 즉시 재broadcast.
- 개인 IP는 메모리에서 판별만(영구 저장 X), DB엔 회사 IP 목록만.
- 한계: 회사 안이라도 모바일데이터(LTE)면 통신사 IP라 미표시(회사 WiFi/유선만). 유동 IP면 재등록.

## 11. 알림 필수 정책 지원

- 회사 "알림 필수" 정책을 앱이 뒷받침. (`25742fe`)
  - **강한 첫 로그인 모달**: 새 기기 첫 로그인(알림 OFF) 시 "회사 정책: 알림 필수" + [알림 켜기].
  - **상시 배너**: 알림 OFF면 상단 중앙 알약 "🔔 알림 필수 — 꺼져 있어요 [켜기]". 켜면 사라짐.
  - **관리자용 "알림 미설정 직원" 목록**: 푸시 안 켠 활성 직원 + 인원수 (모든 관리자 열람).
- **한계**: 브라우저·OS 정책상 강제 자동 켜기는 불가(사용자 "허용" 필수, 아이폰은 홈화면 설치 후). → 강한 유도 + 관리자 추적으로 대응.

## 개념 정리 (코드 변경 없이 합의)

- **자동 로그아웃**: 도입 안 함 (화면 잠금으로 보안 커버, 사내 메신저는 잦은 재로그인 불편).
- **오프라인 vs 로그아웃**: 실질적으로 동일(둘 다 메시지는 저장→재접속 시 확인). 따로 구분 안 함. 의미 있는 차이는 "실시간 알림(푸시) 도달 여부"뿐 → 📱 휴대폰(감) vs 오프라인(안 감).
- **위치 정보**: GPS 추적은 법적 부담(위치정보보호법·개인정보보호법)으로 미사용. 근무지 확인은 회사망(IP) 감지로 갈음.
