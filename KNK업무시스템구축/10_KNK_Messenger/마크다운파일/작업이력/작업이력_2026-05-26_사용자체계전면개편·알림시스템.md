## 1. 사용자 등록 체계 전면 개편 ⭐⭐

### 1-1. 베트남 직원 자동 ID — 변천사
한 세션 안에서 정책이 3단계로 진화:

| 단계 | 정책 | 결과 |
|---|---|---|
| 1단계 | 영문이름 + `@knkvn.local` 자동 부착 | `nguyenvana@knkvn.local` |
| 2단계 | 도메인 제거 — 영문이름 슬러그만 | `nguyenvana` |
| **최종** | **사번 = 로그인 ID 전면 통일** | **본사 = 사번 그대로, 베트남 = `VN` + 사번** |

### 1-2. 베트남 직원 이름 3종 + 한국어 병기
- `display_name` — 한국식 발음 한글 (예: "응우옌 반 아")
- `display_name_vn` — 베트남어 원어 (예: "Nguyễn Văn A") — **신규 컬럼**
- `display_name_en` — 영문 (예: "Nguyen Van A")

**한국어 모드 표시**: `Nguyễn Văn A (응우옌 반 아)` 병기 — 한국 직원이 발음·기억 쉽게.

### 1-3. 영문 직급·부서 자동 매핑 (서버 측)
`TITLE_TO_EN` (16종) + `DEPT_TO_EN` (24종) 매핑 테이블 신설 — 사용자가 영문 칸 입력 불필요, 서버가 자동 채움.

### 1-4. ID와 이메일 분리 (베트남)
- 베트남 직원 username = 사번 (자동), email = 사용자 입력값 또는 NULL (메일 미사용 직원)
- 본사 username = email (그대로 동일)

### 1-5. KNK 표준 직급 (드롭다운 15종)
**본사 (9)**: 대표이사 / 전무이사 / **상무이사** / 이사 / 이사(팀장) / 매니저 / 매니저(팀장) / 프로 / 프로(팀장)
**베트남 (6)**: 법인장 / 부장 / 차장 / 과장 / 대리 / 주임
**공통 (1)**: 사원

> "팀장"은 별도 직급 아닌 부가 역할 — 이사·매니저·프로 어디든 붙음.

## 2. 일괄 등록 양식 — 시트 분리·슬림화 ⭐⭐

### 2-1. 시트 구조 (5개)
| # | 시트 | 색 | 역할 |
|---|---|---|---|
| 1 | **본사(KOR)** | 🔴 빨강 | 본사 직원 입력 (7컬럼) |
| 2 | **베트남법인(VN)** | 🟢 초록 | 베트남 직원 입력 (8컬럼) |
| 3 | 안내 | — | 정책·매핑 표 |
| 4 | 예시 | — | 본사 3 + 베트남 1 견본 |
| 5~8 | `_부서_KOR`·`_부서_VN`·`_직급_KOR`·`_직급_VN` | hidden | 드롭다운 참조 |

### 2-2. 시트별 분리된 드롭다운
- 본사 시트 → 본사 부서 14개 + 본사 직급 9개만
- 베트남 시트 → 베트남 부서 10개 + 베트남 직급 6개만

### 2-3. 슬림화 — 제거된 컬럼
- ~~권한~~ — 관리자가 등록 후 메신저에서 별도 부여
- ~~사진~~ — 메신저에서 카드 → "사진 등록"으로 1명씩
- ~~영문 직급·부서~~ — 서버 자동 매핑

### 2-4. api_users_bulk — 모든 시트 자동 순회
시트 이름에 "본사" / "베트남" / "KOR" / "VN" 포함 → 데이터 시트로 인식 → 동일 파싱. 옛 단일 "직원등록" 시트도 호환 유지.

### 2-5. upsert 정책 강화
- 같은 사번(또는 영문이름 슬러그) → 정보만 갱신, 사용자 중복 등록 X
- 옛 동명이인 자동 숫자 부여 폐기 — 사용자가 영문이름에 직접 숫자 추가

### 2-6. KNK 톤 스타일 통일
- 본사: KNK 빨강 헤더(`#A5282C`)
- 베트남: 초록 헤더(`#0F766E`)
- 행 줄무늬 + 점선 테두리

## 3. 사번 = 로그인 ID 전면 변경 + 데이터 초기화 ⭐⭐

### 3-1. 정책 (대표 결정)
| 구분 | username | 비고 |
|---|---|---|
| 본사 | 사번 그대로 (예: `5`) | OWNER_USERNAME 기본값 `5`로 변경 |
| 베트남 | `VN` + 사번 (예: `VN1`) | 자동 부착 |

### 3-2. 데이터 초기화 (1회용)
대표 명시 승인 후 임시 admin endpoint로 진행:
- `factory_reset` (1차) — 김정락·안지연만 보존, 다른 사용자·방·메시지 삭제
- `cleanup_v2` (2차) — 잔존 데이터 + 빅터(추가 등록)까지 3명 보존
- `cleanup_seed` (3차) — 부팅 시드 잔존(프로젝트 4개) + 고아 멤버 정리

**최종 상태**: 김정락(5)·안지연(67)·빅터(999) 3명 + 자동 채널 3개

### 3-3. 시드 코드 영구 제거 ★
`init_db()` 안의 옛 시드 데이터(users 3종 + 전체공지 + 프로젝트 4종)가 매 부팅 시 items 비어 있으면 재주입 → 잔존 발생.
→ 시드 코드 영구 삭제. 신규 직원은 양식 또는 단건 등록으로만 추가.

### 3-4. 임시 endpoint 일괄 제거
작업 완료 후 모두 코드에서 영구 삭제 (보안):
- `/api/admin/factory_reset` ❌
- `/api/admin/cleanup_v2` ❌
- `/api/admin/cleanup_seed` ❌
- `/admin/factory_reset_ui` ❌
- `/admin/cleanup_seed_ui` ❌

## 5. 아바타 시스템 ⭐⭐

### 5-1. 비로그인 외부 접근 차단
`@login_required` 추가 — 잠금 후 외부인은 URL을 알아도 사진 접근 불가 (HTTP 302 → /login).

### 5-2. 크롭 다이얼로그 신설 (사용자가 영역 직접 선택)
- **Canvas 기반 정사각형 stage + 원형 마스크**
- 마우스 드래그 / 터치 드래그 / 휠 줌 / 핀치 줌 / 슬라이더
- 512×512 JPEG q=0.85로 저장
- 슬라이더 최솟값 `1.0` → **`0.4`** (사진 60% 더 축소 가능)
- i18n 3언어 (9키)

### 5-3. 일괄 등록 사진 (시도 후 폐기)
- 1차: 엑셀 셀에 사진 직접 삽입 → 자동 추출·등록 (`_extract_images_by_row`, `_save_avatar_for_user`)
- 2차: 512×512 견본 사진 양식에 동적 삽입 (Pillow + 한글 폰트 자동 탐색)
- 최종: 대표 지시로 **일괄 등록 사진 폐기** — 사진은 메신저에서 1명씩 등록

### 5-4. 사진 표시 정책 (확정)
| 동작 | 권한 |
|---|---|
| 등록·변경·삭제 | 관리자(CEO)만 |
| 보기 | **로그인된 사내 직원 전체** (외부 비로그인 차단) |
| 사이드바 큰 아바타 | 상태 표시(휴대폰/컴퓨터) 우선 — 사진은 카드 펼침 시 별도 섹션 |

## 7. 알림 시스템 ⭐⭐

### 7-1. 알림 내용 숨기기 옵션
- 설정 → 🔔 알림 → 🖥 화면 알림 끝 **"🔒 알림 내용 숨기기"** 체크박스
- 체크 시: 시스템 알림·화면 토스트 모두 **`KNK message`** 로만 표시
- 잠금화면(서버 측 push payload)도 가림 — `users.push_hide_preview` 컬럼 + `/api/me/push_hide_preview` GET/PUT
- i18n 3언어

### 7-2. 빈 괄호 제거
`💬 김정락 ()` 같은 빈 괄호 — 1:1 방 room.name 빈 경우 괄호 자체 생략.

### 7-3. 푸시 실시간 도착 — `_user_has_active_session` 정책 변경
- 휴대폰(`device='mobile'`)은 **active 판정 제외** → 항상 푸시 발송
- 휴대폰은 인앱 + OS 푸시 동시 OK
- PC만 active 판정 — `_PC_ACTIVE_STALE_SEC` 60s → **30s**

### 7-4. 푸시 진단 (1회용)
대표 보고 "알림 늦음·배지 1 고정·사운드 1번만 옴" → 진단 endpoint·로그 추가:
- `/api/admin/push_log` — 메모리 ring buffer (서버 push 발송 + sw.js 수신 통합)
- `/api/push/sw_debug` — sw.js → 서버로 수신 통계
- supervisor stdout `[push]` `[sw_debug]` print

**진단 결과**: 우리 코드는 모두 정상. OS·브라우저 차원 한계 (Samsung Browser 30 / Android 10):
- setAppBadge `setBadgeOk=true`인데 시각적으로 갱신 안 됨
- 같은 tag 알림 사운드 throttle (OS 정책)

작업 완료 후 **진단 코드 일괄 제거** (보안).

### 7-5. 푸시 알림 카드 정책 (확정)
- **같은 방 1장 카드 통합** (대표 결정 — 시각 정리 우선)
- tag = `room_{room_id}` (이전 unique 정책 롤백)
- sw.js 카운트 누적: `(2)`, `(3)`, `(5)` 표시
- **진동 패턴 강화**: `[300, 80, 300, 80, 300, 80, 500]` (사운드 throttle 보완)
- 사운드 1번만 오는 건 PWA 한계 인정
