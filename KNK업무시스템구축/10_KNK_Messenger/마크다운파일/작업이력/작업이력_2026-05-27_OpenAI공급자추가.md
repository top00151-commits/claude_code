### 4) `app.py` — 라우터 함수 3개

```python
def _ai_translate(text, target_lang_code):
    if TRANSLATE_MOCK:
        return _claude_translate(text, target_lang_code)  # mock 분기 재사용
    if TRANSLATE_PROVIDER == "openai":
        return _openai_translate(text, target_lang_code)
    return _claude_translate(text, target_lang_code)

def _ai_summarize_messages(messages_payload, mode="channel"):
    if TRANSLATE_PROVIDER == "openai":
        return _openai_summarize_messages(messages_payload, mode=mode)
    return _claude_summarize_messages(messages_payload, mode=mode)

def _ai_summarize_for_history(messages_payload, item_meta=None):
    if TRANSLATE_PROVIDER == "openai":
        return _openai_summarize_for_history(messages_payload, item_meta=item_meta)
    return _claude_summarize_for_history(messages_payload, item_meta=item_meta)
```

## 키 등록 — 운영 NAS 적용 방법

운영 환경에서 키 활성화는 **SSH 접근 필요**. 빅터는 명시적 승인 없이 SSH 직접 접속 불가.

대표가 직접 또는 승인 후 다음 절차:

```bash
# 1) NAS SSH 접속 (root@o.knknara.co.kr:31201)
# 2) /opt/knk_messenger/.env 편집
nano /opt/knk_messenger/.env
# 또는
nano /opt/knk_messenger/.env.production   # systemd 환경

# 3) 다음 두 줄 추가/수정
KNK_MSG_TRANSLATE_PROVIDER=openai
OPENAI_API_KEY=sk-proj-XXXXXXXXXX

# 4) 서비스 재시작
supervisorctl restart knk-messenger
# 또는
systemctl restart knk-messenger
```

로컬 PC 테스트는 `OpenAI키설정.bat` 더블클릭으로 동일 효과.
