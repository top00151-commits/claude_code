## 3️⃣ 파일 업로드 정책 — HTML 허용 + 에러 메시지 개선

### HTML 첨부 허용 (대표 지시 옵션 A)
- `DANGEROUS_EXT` 에서 html/htm 제거
- `ALLOWED_FILE_EXT` 에 추가
- `UNSAFE_INLINE_EXT` 신설 — html/htm/xhtml/shtml/svg/xml/mhtml/mht
- `serve_upload`: UNSAFE_INLINE 파일은 **Content-Disposition: attachment + octet-stream** 강제
  - 메신저 화면에서 자동 실행 X, 다운로드 후 본인 PC 에서만

### 클라이언트 업로드 에러 개선
이전: 어떤 에러든 "HTTP 502 / 파일이 너무 크거나..." 일률 표시
이후: 서버 에러 메시지 우선 + status 별 친절 메시지
- 413 → "파일이 너무 큽니다"
- 502/503/504 → "서버 일시 오류"
- 400~499 → "요청 거부"

## 5️⃣ BAT 인코딩 안정화 (수차례 시행착오)

### 발생 문제
- 한글 + em dash(—)/middle dot(·)/→ 화살표 → cmd 파싱 깨짐
- LF only 줄바꿈 → cmd 가 명령들을 한 줄로 합쳐 파싱 실패
- single_window.ps1 needle "메신저" → 다른 창과 오탐
- `start "" /B powershell` → 같은 console 점유 → BAT hang
- `if not "%%a:~0,1%"=="#"` 잘못된 substring → syntax error

### 최종 해결
- `.gitattributes` 추가 — `*.bat/*.ps1=CRLF`, `*.sh=LF`, `*.py/*.js/*.css=LF`
- 모든 BAT/PS1 ASCII 위주 재작성
- `OpenAI키설정.bat` → `OpenAI_setup.ps1` 로 분리 (PowerShell UTF-8 BOM 안정)
- `메신저START.bat`:
  - 특수문자 모두 제거
  - `else if` → `goto` 패턴
  - `for /f "eol=#"` 옵션 사용
  - `start /MIN powershell -WindowStyle Hidden` (별도 console)
  - single_window.ps1 호출 부분 비활성 (5050 포트 검사로 중복 방지 충분)
