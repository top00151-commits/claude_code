## 1) DB 마이그레이션

`message_translations` 테이블에 신규 컬럼:
```sql
ALTER TABLE message_translations ADD COLUMN requested_by_user_id INTEGER
CREATE INDEX idx_translations_requested_by ON message_translations(requested_by_user_id)
```

기존 데이터는 NULL — 백엔드 쿼리에서 `COALESCE(t.requested_by_user_id, m.user_id)` 로 fallback.

## 2) 백엔드 INSERT 시 user_id 기록

**`api_message_translate`** (사후 번역 — 메시지 우클릭):
```python
INSERT INTO message_translations
  (message_id, target_lang, ..., requested_by_user_id)
  VALUES (?, ?, ..., me["id"])
```

**`api_messages_send`** (자동 번역 첨부 — translate_to):
```python
# 메시지 작성자 = 요청자
INSERT ... requested_by_user_id) VALUES (..., me["id"])
```

## 3) 백엔드 신규 endpoint

### `GET /api/admin/translate_usage`

Query params:
- `period`: `this_month` (기본) / `last_month` / `last_7days` / `all`
- `dept`: `all` (기본) / 부서명 (LIKE)

응답 예시:
```json
{
  "period": "this_month",
  "period_label": "이번 달",
  "total_cost_usd": 0.1234,
  "total_calls": 156,
  "total_in_tokens": 45234,
  "total_out_tokens": 8901,
  "monthly_limit_usd": 20.0,
  "monthly_cost_usd": 0.1234,
  "provider": "openai",
  "departments": ["관리팀", "기술영업팀", ...],
  "users": [
    {
      "user_id": 5,
      "display_name": "김정락",
      "department": "01_KOR/00_총괄",
      "title": "대표이사",
      "username": "5",
      "calls": 88,
      "in_tokens": 25104,
      "out_tokens": 4567,
      "cost_usd": 0.0823
    },
    ...
  ]
}
```

권한: `_is_admin_user(me)` — role=ceo 또는 OWNER 본인. 아니면 403.

### `GET /api/admin/translate_usage/export`

같은 쿼리 파라미터. openpyxl 로 .xlsx 생성:
- 상단 제목 + 메타 (기간·부서·공급자)
- 컬럼: 순위, 이름, 직급, 부서, 로그인ID, 호출수, 토큰(in/out), 비용
- 합계 행 (노란 강조)
- 파일명: `AI번역사용량_{period}_{YYYYMMDD}.xlsx`

## 4) 프론트엔드

### HTML — `templates/chat.html` (🛠 관리자 탭 안)
- 기간·부서 드롭다운
- 새로고침 + 엑셀 버튼

- `_refreshAiUsageUI()` — fetch + 부서 드롭다운 동기화 + 표/합계 렌더
- 한도 진행률 색상: <50% 초록, 50~80% 주황, >80% 빨강
- 엑셀: `window.open(url)` — 새 탭에서 다운로드 트리거
