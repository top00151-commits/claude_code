## 1. 로그인 입력칸 폭 넘침 수정 (모바일)

- 아이디·비밀번호 입력칸이 휴대폰에서 카드 밖으로 삐져나가던 문제. (`77748d6`)
- **원인**: 입력칸이 그리드 항목이라 `min-width:auto`(입력칸 기본 ~20글자 폭) 때문에 좁은 폭보다 작게 안 줄어듦.
- **해결**: `.login-form input`·`label`·`.pw-wrap` 에 `min-width:0` + `width:100%`.

## 2. 얼굴 사진 권한 — 관리자(CEO) 전용

- 사용자 카드의 얼굴 사진 **등록·변경·삭제는 관리자만**, **보기는 전체 사용자**. (`ea981a5`)
- 프론트(컨텍스트 카드) + 서버(`/api/users/<id>/avatar` POST·DELETE) 양쪽 권한 강화 — UI 우회 직접 호출도 403 차단.
- 아바타(상태표시 원)는 그대로, 얼굴 사진은 별도 공간.

## 3. 멘션함(@) 신규 — "내게 온 멘션 모아보기"

- **DB**: `mentions` 테이블(메시지·방·멘션대상·보낸이·읽은시각) + 인덱스. (`2944385`)
- **전송 시**: `@이름` 파싱 → 같은 방 멤버와 매칭해 멘션 기록 + 멘션된 사람에게 실시간 알림. 귓속말·스티커 제외, 본인 멘션 제외. **이름(display_name)·아이디(username) 모두 인식**(옛 `@아이디` 형식도 잡힘).
- **과거 소급(v7 마이그레이션)**: 기존 메시지의 멘션을 스캔해 목록에 채움(전부 안 읽음).
- **API**: `GET /api/mentions`, `/unread_count`, `POST /<id>/read`, `/read_all`, `DELETE /<id>`, `/delete_all`.
- **UI**: 안 읽음 배지 + 목록 팝업 → 항목 클릭 시 **읽음 처리 + 해당 방 열고 그 메시지로 스크롤·강조**.
- **항목 삭제**: 개별 🗑 + "모두 삭제" — **목록에서만 삭제, 대화방 메시지는 그대로 유지**(안내 confirm). (`39f7085`)
- **버튼 위치 이동**: 상단 알림(🔔) 옆 → **하단 필터바의 📌 내 요청 옆 "@ 멘션" 칩**으로. (`d31b51b`)

## 4. 사이드바 레이아웃 · 좌우 분리선

- **헤더 아이콘 잘림 수정**: @ 버튼 추가로 알림(🔔)이 잘리던 것 → 사이드바 폭 320→360 + 아이콘묶음 `flex-shrink:0`(절대 안 잘림)·"대화방만들기"는 양보(글자 …). (`5b33934`, `3c58089`)
- **좌우 분리선 드래그**: 분리선을 마우스로 끌어 사이드바 넓히기(대화방 제목 잘릴 때 펼쳐 확인). **오른쪽으로만 최대 +100px**(360~460), 더블클릭=원래대로, 폭은 자동 저장. (`319d99a`, `a25cb0b`)
- 폭(가로)만 변경 → 좌/우 헤더 105px 높이 정렬 등 기존 라인 유지. 모바일·단독창은 핸들 숨김.

## 5. 상태표시 — 컴퓨터/휴대폰 '쓰는 기기' 자동 전환

- **수동 7종**(자리비움·바쁨·회의중·외근·해외출장·국내출장·휴가)은 **사용자 선택 = 우선순위**(그대로 표시).
- **컴퓨터/휴대폰**은 **지금 쓰는(활성) 기기** 기준으로 자동 표기. PC·휴대폰 동시 로그인이어도 휴대폰 보면 📱, PC 보면 💻 로 **자동 전환**. (`abe6f9c`)
- 새 `_active_device()`(포커스·화면ON + 최근 heartbeat 연결 중 가장 최근 기기). 표시 경로 2곳(실시간 broadcast + 일괄 목록) 모두 반영.
- 상태 메뉴: 💻·📱 제거, **"🔄 자동(컴퓨터·휴대폰)"** 추가 — 수동상태 풀고 자동 복귀용.

## 6. 전송 속도 · 실시간 안정성 (불안정망 대비)

베타 중 "가끔 메시지가 늦게 옴 / 메신저를 봐야 옴" 피드백 → 서버/보안 관점 전체 점검 후 조치.

- **전송 지연 개선**: 멘션 처리를 메시지 전달 **이후** 백그라운드로 분리 → 전송 즉시 전달. (`32a1f08`)
- **A. 재연결 메시지 재동기화**: 소켓 재연결·네트워크 복귀·화면 복귀 시 '보고 있는 방'의 끊긴 동안 놓친 메시지를 재조회+읽음. 휴대폰 기지국 전환·**로밍·해외 와이파이·LTE↔WiFi 전환** 대응(증상 핵심 원인). (`d07e227`)
- **B. 전송 확인(ack)**: 8초 내 서버 확인 없으면 경고 + 입력창 비어있으면 텍스트 복원(유실·착각 방지). (`d07e227`)
- **C. 업로드 멈춤 감지**: 업로드 중 60초간 정지 시 중단·안내(로밍·느린 회선). 느린 업로드는 진행이 있어 오중단 없음. (`13fe475`)
- **D. 바이러스 검사(ClamAV) 연동**: 코드 탑재, **기본 비활성(dormant)**. 서버에 clamd 설치 + `KNK_MSG_CLAMAV=1` 설정 시 자동 활성 → 업로드 직후 검사·감염 차단. (`41227dc`)
- 점검 확인(견고): 첨부 보안(위험확장자·magic·이중확장자·HTML/SVG 차단·다운로드 강제), SQL 바인딩, 출력 escape, 세션 쿠키 보안, 단일 워커(소켓 유실 없음).

## 7. 회사 로고 · 실행 아이콘 적용

- **로고 교체**: 실제 KNK 로고(빨강 워드마크)로 앱 아이콘·로그인·개요팝업·favicon 교체. 이름 "KNK 메신저" 유지. (`e1ca595`)
- **실행 아이콘 = 빨강 배경 + 흰색 로고**: 흰 배경은 홈화면에서 가독성 낮아, 로고를 흰색 변환 후 빨강 그라데이션 배경 위 배치(꽉 찬 maskable). 로그인은 흰 카드라 빨강 로고 그대로. (`651f7c1`)
- **PWA 새 로고 강제**: 매니페스트 아이콘 URL에 `?v` 버전 + 테마색 KNK 빨강 통일. (`6cbdcd0`)
- **PC 바탕화면 실행 아이콘**: `KNK.ico` + `바탕화면_아이콘_만들기.bat`(더블클릭 시 바로가기 생성). (`af466f2`)
- **아이콘 캐시 새로고침 도구**: 바탕화면/작업표시줄에 옛 아이콘이 캐시로 남을 때 `아이콘_캐시_새로고침.bat`. (`13f9464`)
- ※ PWA 아이콘은 설치 시점 고정 → **제거 후 재설치(휴대폰: 홈화면에 다시 추가)** 해야 새 로고 반영.
