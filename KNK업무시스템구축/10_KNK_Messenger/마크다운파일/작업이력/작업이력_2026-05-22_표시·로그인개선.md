## 1. "이름 직급 부서" 표기 전면 통일

사람 이름이 표시되는 모든 곳을 **이름 + 직급 + 부서** 형식으로 통일.

- **대화창 메시지 작성자** — 이름 옆에 직급·부서를 작고 연한 회색으로. (`18a98a2`)
- **스레드 답글 작성자**, **요청 목록(받은/보낸)** 의 요청자·담당자, **@멘션**, **시스템 메시지**(초대/나감 등) 까지 동일 적용. (`4c2a183`, `2d6495b`, `5abbb4e`)
- **부서 표기 규칙(`deptShortLabel`)**: 본사는 **숫자코드 없이**(예: `구매팀`), 베트남법인은 `VN…`(예: `VN관리팀`), 임원 `총괄`은 **대화/요청에선 숨김**.
- 시스템 메시지는 `[이름]`·`by 이름` 위치의 **사용자명만** 보강 → 프로젝트명·요청명 등 비-이름은 그대로(안전).

## 2. 임원 '총괄' 부서 처리

- 김정락·김동후·최홍광 임원의 `총괄` 부서가 대화창에 그대로 노출되던 것 조정.
- **사용자 목록**: `00 총괄` 그룹으로 **그대로 표시**(정렬·그룹핑 유지).
- **대화창·요청 등**: `deptShortLabel`이 `총괄`을 **숨김**(직급만 표시).
- 마이그레이션 v5(제거)→v6(복원) 으로 운영 DB 정합성 유지. (`b525761`, `6e59a7a`)

## 3. @멘션 개선

- 멘션 삽입이 **이메일(username)** 로 들어가던 버그 수정 → **이름(display_name)** 으로 삽입. (`00bb266`)
- 멘션 표시·자동완성을 **'이름 직급 부서'** 로 보강(저장은 `@이름`, 표시 때 보강 → 항상 최신 직급·부서). (`2d6495b`)

## 4. 요청(요청목록) 패널 개선

- **내 요청 패널**: 요청자·담당자를 이름 직급 부서로 표기. (`4c2a183`)
- **행 클릭** 시 → 해당 방을 열고 **요청 목록을 그 요청 상태 탭으로** 열어 해당 요청을 **스크롤·강조(req-flash)** → 요청 내용 즉시 확인. (`4c2a183`)
- **범위 분리**: 내 요청에서 진입 = **본인것만**(요청자/담당자=나), 대화방 헤더 압정·요약줄 `📌 N 열림` 배지 = **방 전체**. (`11fa313`)
- **태블릿 가독성**: 내 요청 카드에서 방 이름과 요청자·담당자를 **별도 줄로 분리**. (`75d9f91`)

## 5. 아바타 = 상태색 원 + 상태 이모지

- 아바타 원형을 **상태 색상 배경 + 상태 이모지**(💻📱🌙🔴🤝🚗✈️🚆🌴⚫)로 표시. (`90366db` → `019f005`)
- **모든 아바타**에 적용: 대화창 메시지·스레드·사용자 목록·사용자 메뉴·1:1 방 목록·멤버 피커·읽음 명단·헤더 본인.
- 절대위치 오버레이(`avatar-status-fill`)로 위치별 배경색 위에 일관 적용. 중복 코너 색점 제거.
- 상태 변경(소켓)·1분 주기 갱신 시 실시간 반영.
- **아바타 원 크기 전체 10% 축소**(내용 크기는 유지). (`dbd258b`)

## 6. 사용자 카드에 '얼굴 사진' 공간

- 아바타(상태표시)는 그대로 두고, 사용자 카드(우클릭/롱프레스)에 **별도 얼굴 사진 공간** 추가. (`560c3ce`)
- 본인 또는 최고관리자만 등록/변경/제거. 업로드 시 **자동 512px·JPEG 리사이즈**(용량 자동 조정).
- 사진은 `avatar_url`에 저장, 카드에서 96px로 표시.

## 7. 로그인 화면 개선

### 7-1. 모바일 흔들림 수정
- **원인**: 모바일 주소창(툴바)이 스크롤 중 나타났다 사라지며 `100vh`/`100dvh` 가 계속 바뀌어 레이아웃이 출렁임(상하). + 미세 가로 흔들림.
- **해결**: `min-height: 100svh`(주소창 보이는 **고정 높이**) + `overflow-x: hidden` + 여백 축소. (`384c6f5`~`cad42f0`)
- **보안·이용 정책 박스 접기(`<details>`)** — 기본 접힘으로 **로그인 폼이 한 화면에** 들어와 스크롤 자체 제거 → 흔들림 원천 차단. 헤더와 '동의 간주' 문구는 항상 표시. (`c540402`)
- 참고: 서비스워커(`sw.js`)가 CSS/JS를 강제로 새로 받음(no-store) → 변경이 휴대폰에 즉시 반영됨(캐시 문제 아님).
