----------------------------------------------------------------
 폴더 안 파일 설명
----------------------------------------------------------------

1) 비상복구_열쇠보관표.pdf   ★ 가장 중요 — 인쇄하세요
   - GitHub·서버·도메인·관리자 "로그인/비밀번호"를 펜으로 적는 양식
   - 인쇄 → 펜으로 작성 → 회사 금고에 보관
   - (비밀번호는 비어 있음. 대표님이 직접 채우세요)

2) 새PC_프로그램설치_안내.pdf   ★ 새 컴퓨터에서 시작할 때 먼저
   - 새 PC에 클로드 + Git + (선택)Python 설치하는 단계별 안내
   - 인쇄해 두면 복구 첫 단계에 그대로 따라 하기 좋음

3) 비상복구_열쇠보관표.md / 새PC_프로그램설치_안내.md
   - 위 PDF들의 원본(텍스트). 내용 고칠 때만 사용.

3) CLAUDE.md
   - 새 컴퓨터에서 클로드가 자동으로 읽는 "안내서"
   - 클로드가 이 메신저를 어떻게 고치고 배포하는지 적혀 있음

4) recover_setup.ps1
   - 복구 점검 자동 도구 (새 PC에서 무엇이 빠졌는지 알려줌)

5) 프로젝트_히스토리.md
   - 이 메신저를 왜·어떻게 만들었는지 배경 설명 (인계용)

----------------------------------------------------------------
 PC가 고장났을 때 복구 순서 (요약)
----------------------------------------------------------------
1. 새 PC에 클로드 + Git 설치  ("새PC_프로그램설치_안내.pdf" 참고)
2. 인터넷(GitHub)에서 코드 받기:
   git clone git@github.com:top00151-commits/knk-messenger.git
3. 받은 폴더에서 클로드 실행 → CLAUDE.md 자동 인식
4. recover_setup.ps1 실행 → 빠진 것 확인
5. 금고의 "열쇠보관표" 종이를 보고 비밀번호 입력 → 복구 완료

----------------------------------------------------------------
 잊지 마세요
----------------------------------------------------------------
- 메신저 자체는 회사 서버에서 24시간 스스로 돌아갑니다.
  PC가 고장나도 직원들은 메신저를 그대로 씁니다.
- 단 하나, "열쇠(비밀번호)" 종이만 금고에 잘 보관하시면
  어떤 상황에서도 100% 되살릴 수 있습니다.
