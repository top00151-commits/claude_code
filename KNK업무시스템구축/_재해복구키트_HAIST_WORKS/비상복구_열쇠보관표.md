## 복구 빠른 순서 (이 종이를 든 사람에게)

1. 새 PC에 **Claude Code(클로드) + Git** 설치
2. 코드 받기: `git clone git@github.com:top00151-commits/knk-haist-works.git`
3. 받은 폴더에서 **클로드 실행** → 클로드가 `CLAUDE.md` 를 자동으로 읽고 상황 파악
4. **시스템이 살아있으면** (https://works.knknara.co.kr/ 정상) → 이 양식 비밀번호로 관리만 하시면 됨
5. **시스템 죽었으면** → `재현가이드_NAS배포.md` 의 8단계 따라하기 + 위 비밀번호 입력

> HAIST WORKS 자체는 회사 서버(NAS)에서 24시간 스스로 돌아갑니다. 이 복구는 **"고치고 바꾸는 능력"** 을 되찾는 절차입니다.
