================================================================
  HAIST WORKS — 재해 복구 키트 (모아 보기용 복사본)
================================================================

이 폴더는 "HAIST WORKS가 망가지거나 PC가 고장났을 때 되살리는
데 필요한 자료"를 한곳에 모아둔 것입니다.

※ 여기 파일들은 "복사본"입니다. 실제로 작동하는 원본은
   프로젝트 폴더(01_HAIST_WORKS) 안에 그대로 있습니다.
   이 폴더는 대표님이 한눈에 보고 보관하시기 편하라고 모은 것입니다.

※ 메신저 비상복구는 별도 폴더(_재해복구키트_KNK메신저)에 있습니다.
   두 시스템은 서로 분리되어 있어 따로 복구합니다.

----------------------------------------------------------------
 폴더 안 파일 설명
----------------------------------------------------------------

1) 비상복구_열쇠보관표.md   ★ 가장 중요 — 인쇄하세요
   - GitHub·NAS·도메인·관리자 "로그인/비밀번호"를 펜으로 적는 양식
   - 인쇄 → 펜으로 작성 → 회사 금고에 보관
   - (비밀번호는 비어 있음. 대표님이 직접 채우세요)

2) 재현가이드_NAS배포.md   ★ 처음부터 다시 만들 때
   - 컨테이너 새로 만들고 코드 받고 서비스 띄우기까지 8단계
   - 비상 복구 시나리오 5종 (코드 손상 · 컨테이너 삭제 · NAS 교체 등)
   - 자산 인벤토리 (도메인 · 포트 · DSM · SSL · DNS 전체)

3) CLAUDE.md   ★ 새 컴퓨터에서 클로드가 자동으로 읽음
   - 새 클로드가 이 폴더 열면 자동으로 HAIST WORKS 이해
   - "이 프로젝트가 무엇이고 어떻게 고치고 어떻게 배포하는지" 안내

4) 프로젝트_히스토리.md
   - HAIST WORKS를 왜·어떻게 만들었는지 배경 설명 (인계용)
   - 시안1 사이클 + NAS 배포 + 사번 SSO 등 주요 결정 이력

----------------------------------------------------------------
 시스템이 망가졌을 때 복구 순서 (요약)
----------------------------------------------------------------
1. 새 PC에 클로드 + Git 설치  (메신저 키트의 "새PC_프로그램설치_안내" 참고)
2. 인터넷(GitHub)에서 코드 받기:
   git clone git@github.com:top00151-commits/knk-haist-works.git
3. 받은 폴더에서 클로드 실행 → CLAUDE.md 자동 인식
4. "재현가이드_NAS배포.md"의 8단계 따라하기
5. 금고의 "열쇠보관표" 종이를 보고 비밀번호 입력 → 복구 완료

----------------------------------------------------------------
 잊지 마세요
----------------------------------------------------------------
- HAIST WORKS 자체는 회사 서버(NAS)에서 24시간 스스로 돌아갑니다.
  PC가 고장나도 직원들은 그대로 씁니다.
- 단 하나, "열쇠(비밀번호)" 종이만 금고에 잘 보관하시면
  어떤 상황에서도 100% 되살릴 수 있습니다.
- 컨테이너 삭제는 KNKHAIST 컨테이너의 `/opt/`와 `/root/` 볼륨이
  영구 마운트라 코드·DB·SSH 키 모두 살아있습니다.
