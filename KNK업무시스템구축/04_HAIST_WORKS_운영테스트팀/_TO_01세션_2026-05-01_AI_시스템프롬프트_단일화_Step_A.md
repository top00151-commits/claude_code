6. 결론 먼저, 표·불릿, 간결

## 4. 01 적용 지시

### 4.1 모듈 이동
- 04 시제품 `_DRAFT_company_prompt_v1.py` → **검토 후** 01 `app/company_prompt.py` 로 복사
- 또는 별도 공통 폴더 (`KNK업무시스템구축/_common/company_prompt.py`) 추출 후 01·10 양쪽 import

### 4.2 01 적용 (ai_client.py)
**현재 (line 294-299)**:
```python
def ai_translate(text: str, target: str = "vi") -> tuple[bool, str]:
    ...
    system = (
        "당신은 KNK(검사기·자동화 설비 제조) 사내 메신저의 전문 번역기입니다. "
        f"입력 텍스트를 자연스러운 {lang_name}로 번역하세요. "
        ...
    )
    return ai_chat(text, system=system, max_tokens=1500, temperature=0.2)
```

**수정**:
```python
from app.company_prompt import build_system_prompt

def ai_translate(text: str, target: str = "vi", *, user: Optional[dict] = None) -> tuple[bool, str]:
    ...
    system = build_system_prompt(
        user_role=(user or {}).get("role", "member"),
        user_team_code=(user or {}).get("team_code"),
        user_name=(user or {}).get("name"),
        lang=(user or {}).get("lang", "ko"),
        purpose="translate",
        target_lang=target,
    )
    return ai_chat(text, system=system, max_tokens=1500, temperature=0.2)
```

→ `ai_summarize()`, `ai_vision()`, `ai_chat()` 도 동일 패턴 적용.
