## 0. 한 줄

외부 ERP 물류관리는 **5 대분류(영업·구매·재고·생산·외주) + 기준정보**로 구성, 핵심 흐름은 **「견적→수주→출고지시→출고처리」 / 「발주서→입고처리」 / 「생산지시→자재출고처리(BOM전개)→생산입고처리」 / 「외주자재출고등록→외주제품입고처리」**. 03이 메뉴 트리 + 5 핵심 화면(품목등록·발주서·입고·자재출고+BOM전개·생산지시/입고) 분석 후 **KNK 운영 모델(RACI·일·주·월 캐던스·데이터 흐름) + 디자인 IA + 5개 텍스트 와이어 + 데이터 모델 SQL 초안**을 작성. 시각 디자인은 05·코드 구현은 01·페르소나 검증은 04로 위임 명시.

## 1. 검증된 메뉴 트리 (요약)

```
물류관리
├── 기준정보: 품목등록·거래처등록·분류등록·단위등록·창고등록·일괄매매군등록·수집정보등록
├── 영업관리: 견적서·수주서·출고지시서·출고처리·전자세금계산서·전자계산서
├── 구매관리: 발주서·입고처리
├── 재고관리: 기간별입출고현황·재고이동·재고조정
├── 생산관리: 생산(작업)지시서·자재출고처리(BOM전개)·생산입고처리·생산입고현황·생산지시현황
├── 외주관리: 외주자재출고등록·외주제품입고처리·외주매입마감및회계처리·외주출고/입고현황·외주매입마감현황
└── 채권채무현황·BI현황·전기이월
```

## 2. KNK 적용 초안 핵심 (원본 §B·C 요약)

- **RACI 매트릭스**: 영업·구매·자재창고·생산·품질·외주·회계·시스템 8축으로 14 액션 분담
- **일·주·월 캐던스**: 일간 6시점, 주간 금요일 마감, 월간 월말 마감
- **데이터 흐름**: baby V2 + HAIST_WORKS v5H136 + 신규 자재모듈 + 10_KNK_Messenger 알림 통합
- **디자인 IA**: 자재모듈 8 대분류 (대시보드·기준정보·구매·생산·외주·재고·영업·보고)
- **5개 화면 텍스트 와이어**: 품목등록·발주서·입고처리·자재출고처리 BOM전개·생산지시/입고
- **데이터 모델 SQL 초안**: 8개 핵심 테이블 (items·boms·purchase_orders·receipts·work_orders·material_issues·production_receipts·stock_movements)
- **KNK 특화**: 모든 트랜잭션에 `project_id`(호기 003M2501·WP-LOA·HM-001·M2504 연결), `stock_movements` 단일 원장

## 4. 09 결재 5대 질문 (단답 가능)

1. **본 초안 적용 범위?** (a) HAIST_WORKS 자체 자재모듈 신규 설계 참조용 / (b) 외부 ERP 도입 검토용(정책 변경) / (c) baby V2 → HAIST_WORKS 마이그레이션 시 / (d) 학습 자료 보관
