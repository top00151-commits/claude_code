## 🔑 절대 규칙

1. **메신저 영역 손대지 말 것** — `10_KNK_Messenger/` · `_재해복구키트_KNK메신저/` 별도 세션 담당
2. **빅터 권한** — `KNK업무시스템구축/` 폴더 안쪽만. 외부 경로 금지.
3. **DB 스키마 변경** — 마이그레이션 SQL 별도 작성 + 적용 위임 (`01_HAIST_WORKS/migrations/`)
4. **NAS 운영 영역** — DSM·라우팅·DNS·SSL은 전산담당자(최보현 상무) 영역. 빅터 직접 금지.
5. **외부 상표권 비침해** — 위하고·하이웍스·카톡·삼성 등 실명 직접 거론 금지 (`_STANDARDS/외부브랜드_익명화_매핑.md`)
6. **사람 친화 용어** — 워크플로우→일순서, 노드→일, 마법사→만들기 (메모리 룰)
7. **`git add -A` 금지** — 비밀파일 실수 commit 방지 (메모리 룰)
8. **지시 받으면 이해 정리 보고 후 진행** (메모리 룰 절대준수)

## 🚀 로컬 개발 (운영은 NAS, 로컬은 개발·테스트용)

```cmd
KNK_시작.bat     ← 로컬 PC에서 개발용 서버 시작
KNK_중지.bat     ← 로컬 서버 중지
KNK_AI키등록.bat ← AI 키 환경변수 등록
```

로컬 URL: `http://localhost:8081`
디버그 모드: `?debug=1` 또는 `Ctrl+Shift+D`

**※ 운영 배포는 git push → NAS 자동 pull** — `KNK_운영시작.bat`는 NAS 배포 전 사용. 현재 NAS는 supervisor가 자동 관리.
