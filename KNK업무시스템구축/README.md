## 🎯 분업 구조 (2026-05-10 신설)

대표 직접 지시로 **3개 실무팀 병렬 작업** 체제 도입:

```
[실무팀0] 빅터 (현재 세션)
  └─ 통합·조율·표준 관리·합치는 작업
     │
     ├─ [실무팀1] 통합플랫폼 (업무현황, 일일/주간, 알림, 캘린더, 티켓 등)
```

## 🔑 절대 규칙 (전 팀 공통)

1. **권한 폴더만 작업** — 다른 세션 폴더 침범 금지
2. **빅터(01)에게 보고** 후 통합 — 직접 main 머지 금지
3. **`_STANDARDS/` 표준 절대 준수** — 임의 디자인/색상/폰트 추가 금지
4. **DB 스키마 변경 금지** — `01_HAIST_WORKS/data/knk.db` 직접 수정 금지
5. **롤백 명명 규칙** — `rollback-YYYYMMDD-HHMM` (메모리 룰)
6. **외부 상표권 비침해** — 타사 브랜드/UI 자산 사용 금지
