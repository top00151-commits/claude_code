## 2️⃣ 일괄 재분류 도구 (정제) — `/parts/reclassify` ⭐ 핵심

### 동작 원리
```
stock_movements (kind='OUT', 최근 N일)
   ↓ JOIN projects.biz_div
자재별 M 사용량 / T 사용량 집계
   ↓
정규화 → M_pct / T_pct (known 분포)
   ↓
추천 사업부 결정:
   M ≥ 90%             → M
   T ≥ 90%             → T
   M ≥ 30% AND T ≥ 30% → 공통
   evidence < 3        → review (수동)
```

### confidence 등급
| 등급 | 조건 | 시각화 |
|---|---|---|
| **HIGH** | 90:10+ 분포 + evidence ≥ 5 | 초록 배지 |
| **MID** | 70:30+ 분포 + evidence ≥ 3 | 황색 배지 |
| **LOW** | 그 외 / 데이터 부족 | 회색 배지 |

### UI (parts_reclassify.html)
- **KPI 5종**: 분석대상 / M추천 / T추천 / 공통유지 / 검토필요
- **표 9컬럼**: 체크박스·#·자재코드·자재명·현재·추천·M/T 분포 막대·출고이력·총 출고량
- **분포 막대**: 한 막대 안에 M(파랑) + T(보라) 비율 시각화
- **액션바**: [전체 선택] [전체 해제] [📌 추천만 선택 (M+T HIGH·MID)] [✓ 일괄 재분류 적용]
- **필터**: 공통/1년 · 공통/90일 · 전체/1년

### POST /parts/reclassify/apply
- Form: `apply_{part_id}=on` 체크박스 + `new_{part_id}=M|T|공통` hidden
- 일괄 UPDATE 트랜잭션 → 결과 카운트 배너로 표시
