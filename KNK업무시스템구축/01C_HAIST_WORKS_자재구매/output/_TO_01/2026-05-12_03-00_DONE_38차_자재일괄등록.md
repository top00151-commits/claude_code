## 신규 구현 (3-Step 워크플로우)

```
[1] 업로드        [2] 검증 미리보기    [3] 등록 완료
   ↓                ↓                   ↓
파일 선택       헤더 자동 매핑        DB INSERT
template 다운   행별 검증             결과 표시
                중복·유사 검사        오류 행 별도 표시
                DB INSERT 0건         자재 상세 링크
```

## 핵심 알고리즘

### 1) 헤더 자동 매핑
```python
_PARTS_IMPORT_HEADER_MAP = {
    "자재코드": "part_no", "partno": "part_no", "code": "part_no", "품번": "part_no",
    "자재명": "part_name", "partname": "part_name", "name": "part_name", "품명": "part_name",
    "사업부": "biz_div", "bizdiv": "biz_div",
    "단가": "std_price", "stdprice": "std_price", "price": "std_price",
    ... 총 50+ 매핑 (한글/영문 모두)
}
```
- 정규화 키 (`_norm_header_key`) — 공백·특수문자·대소문자 무시
- 미매핑 헤더는 사용자에게 노란 배너로 안내 + 자동 스킵

### 2) 행별 검증 (4단계)
```
status 'ok'       — 정상, 등록 가능
status 'error'    — 필수 누락 (part_no, part_name) 또는 사업부 값 오류
status 'dup'      — 자재코드 UNIQUE 중복 (기존 DB와)
status 'similar'  — 유사 자재 ≥85점 발견 (등록 가능, 선택)
```

### 3) 유사 자재 통합 검사 (37차 A안 연동)
- 행마다 `parts_find_similar()` 호출 (≥85점 임계)
- 발견 시 사이드에 기존 자재 링크 표시 → 클릭으로 비교 가능
- 사용자가 "유사 자재 경고 무시" 체크박스 선택 시 `force_similar=True` 로 강제 등록

### 4) Dry-run 보안
- 첫 POST는 항상 `dry_run=True` — DB INSERT 0건
- 사용자가 미리보기 확인 후 [등록 확정] 버튼 클릭 시에만 실제 INSERT
- 파일은 base64로 hidden field에 임시 보관 → 두 번째 POST 시 재파싱
