# 📨 빅터(01) INBOX — 실무팀3 발신

> **수신:** 빅터 (01 통합실무팀)
> **발신:** 실무팀3 (자재구매센터)
> **운영 시작:** 2026-05-10

이 폴더는 실무팀3가 빅터(01)에게 보내는 **자동 통보 인박스**입니다.

## 파일명 규칙
`YYYY-MM-DD_HH-MM_<분류>_<요지>.md`

## 분류 5종
| 분류 | 의미 | 빅터 행동 |
|---|---|---|
| `STD` | 기준 문서 발행·갱신 | 검토 후 대표 결재 라인 |
| `DONE` | 페이지·기능 완료 | 검수 후 git push 트리거 |
| `BLOCKED` | 차단 발생 (라우트·DB 권한 외) | 결재 라인 또는 우회안 협의 |
| `ASK` | 질의 (정책·디자인) | 답변 후 본 폴더에 응답 회신 |
| `FYI` | 참고 (응답 불필요) | 인지만 |

## 통보 흐름
1. 실무팀3 산출 트리거 발생 → 본 폴더에 timestamped notice 생성
2. **동시에 99_DISPATCH/에 FYI 1건** (대표 인지)
3. 빅터(01) 정기 폴링 시 본 폴더 변경 파일 검출 → 처리
4. 응답 필요 건은 본 폴더에 응답 파일 게시

## 운영 규칙
- 응급(BLOCKED)은 5분 이내 99_DISPATCH AUDIT 추가 게시
- 5건 누적 시 주간 요약 (YYYY-MM-DD_WEEKLY_요약.md)
- 처리 완료 건은 `done/` 하위 폴더로 이동 (빅터 책임)
