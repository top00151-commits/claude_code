## 1) 자재 중복 방지 (A안 3층 방어)

### 핵심 알고리즘
| 단계 | 구현 | 비고 |
|---|---|---|
| **정규화** | `_normalize_part_key()` — 공백·하이픈·언더스코어·대소문자 제거, 영숫자·한글만 잔존 | "모터 A1" / "MOTOR-A1" / "모터_a1" 모두 동일 키 |
| **거리** | `_levenshtein()` 편집거리 자체 구현 (라이브러리 0건) | 단문자열 빠름 |
| **점수** | `_similarity_score()` 0~100 — 정규화 일치 100, 부분 포함 60~90, 거리 기반 점수 | spec/maker 일치 시 +5씩 보너스 |
| **검색** | `parts_find_similar()` LIKE 200건 1차 후보 → 점수 ≥ 60 정렬 상위 5 | id, part_no, score 포함 반환 |

### 단위 검증 결과 ✓
```
"모터 A1" vs "모터-A1"     → 100점  (차단)
"Motor A1" vs "MOTOR_A1"  → 100점  (차단)
"AC서보모터" vs "서보모터" → 80점   (정보 노출, 통과 허용)
"베어링" vs "나사"         → 0점    (무관)
```

### 3층 방어 흐름
1. **층 1 (정규화)**: 자재명·spec·maker 비교 시 표기 변형 차단
2. **층 2 (실시간 API)**: `GET /parts/check?name=&spec=&maker=` JSON — 입력 중 debounce 400ms로 자동 검색
   - 결과 사이드 카드에 5건 표시 + ≥85점 빨강 강조 + ≥70점 노랑
3. **층 3 (등록 시 confirm)**: `parts_create(force=False)` — ≥85점 발견 시 ValueError + 후보 목록
   - 사용자가 정말 신규면 confirm("정말 신규입니까?") OK → `force=1` hidden + 재제출
   - 등록 버튼 자체가 "⚠ 그래도 등록 (강제)" 빨강 변경

## 2) QR 코드 발행 + 스캔 통합

### QR 페이로드 표준
```
자재: KNK-PART:{part_no}|{id}    예) KNK-PART:P-M-MTR-0001|42
발주: KNK-PO:{po_number}|{id}    예) KNK-PO:PO-2026-0517|99
```

### 라우터 (신규 5개)
| 라우터 | 역할 |
|---|---|
| `GET /parts/{pid}/qr.svg?scale=` | 자재 QR (SVG, 인라인) |
| `GET /po/{po_id}/qr.svg?scale=` | 발주 QR (SVG, 인라인) |
| `GET /parts/{pid}/qr/print?count=` | 자재 QR 라벨 인쇄 (A4 격자) |
| `GET /po/{po_id}/qr/print` | 발주 QR 단독 (A4) |
| `GET /qr/scan?payload=` | 스캔 페이로드 해석 + JSON 응답 (PART/PO 자동 라우팅) |

### 신규 인쇄 페이지 2종
- **part_qr_print.html** — A4 3×4 격자 (12장 기본, 6/12/24/48 선택) + 자재 코드·자재명·규격·KNK 브랜드
- **po_qr_print.html** — 단독 큰 QR (80mm) + 발주 메타 6행 + 입고 처리 가이드

### 발주 → 입고 QR 통합 흐름
```
[발주 상세] /po/{id}
  → 헤더 [📱 QR] 버튼 → QR SVG 즉시 다운
  → 또는 [🖨 라벨 인쇄] → A4 단독 인쇄 → 출력물에 부착

[입고 처리] /po/{id}/receive
  → 페이지 진입 시 상단 QR 스캐너 자동 focus
  → 1단계: 발주 QR 스캔 (KNK-PO:...)
            → 현재 PO와 일치 검증 (다르면 ⚠ 빨강 경고)
  → 2단계: 자재 QR 스캔 (KNK-PART:...)
            → 해당 라인 자동 찾기 → receive_qty +1 증분
            → 라인 강조 (1.5초 초록 배경)
            → 잔량 초과 시 차단 + 경고
  → 3단계: 일반 클릭으로 LOT·유효기한·비고 입력
  → [📦 입고 등록] 제출
```

### 자재 → 창고 라벨 흐름
```
[자재 상세] /parts/{id}
  → 사이드 QR 카드 → [🖨 라벨 인쇄] (3×4 격자)
  → 12장씩 출력 → 창고 자재함·박스에 부착
  → 모든 입출고·실사 시 QR 스캔으로 식별
```
