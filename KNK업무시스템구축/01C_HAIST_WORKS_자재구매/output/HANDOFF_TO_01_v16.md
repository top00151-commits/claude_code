## 2. 산출물 (1 파일)

### `stock_adjust.html` — 재고 조정 폼

#### 🎯 핵심 UX — 부호 토글

```
[＋ 입고조정 (증가)] [－ 출고조정 (감소)]   ← 버튼 토글
조정 수량 (절대값): [        0]              ← 사용자 절대값만 입력
```

- 사용자는 **절대값**만 입력 → 헷갈림 제거
- 부호는 **토글 버튼**으로 명확히 선택 (＋ 초록 / － 빨강)
- 라우터 제출 시 **hidden input**으로 부호 적용한 quantity 전송
- 입력 input 색상도 부호에 따라 변경 (＋ 초록 텍스트 / － 빨강 텍스트)

#### 사유 11종 grouped select
```
입고조정 (+)
├─ 실사 차이 (실제 더 발견)
├─ 이전 누락 보정
└─ 환입 (반품 회수)

출고조정 (-)
├─ 실사 차이 (실제 부족)
├─ 손망실 (파손·분실)
├─ 폐기 (불량·기간만료)
├─ 시제품 (샘플 소모)
└─ 외주 무상 지급

기타
└─ 기타 (비고 필수 입력)
```

#### 조정 후 재고 미리보기
수량 입력 → JS로 즉시:
- 현재 재고 + 부호×절대값 = 예상 재고
- **음수 결과 시 빨강 + "재고 음수 — 조정 불가"** + 사이드 상태 ⚠
- 정상 시 사이드 상태 "정상" 초록

#### 사이드 3 카드
- 조정 요약 (자재·부호·수량·상태)
- 💡 입력 가이드 (+/- 사용 케이스)
- ⚠️ **회계 감사 주의** 황색 박스 (사유·비고 명확 기록 / 음수 불가 / 큰 금액 별도 보고)
