## 1. 시스템 구성 — 2개의 핵심 산출물

### A. HAIST WORKS — 통합 업무 플랫폼 (`01_HAIST_WORKS/`)
KNK 사내 모든 업무가 모이는 웹 시스템. FastAPI + SQLite + Jinja2 단일 서버.

| 영역 | 핵심 페이지·기능 |
|---|---|
| **통합 Hub** | 통합 홈 / 일일업무 / 주간보고 / 실시간 진행 / 팀 대시보드 / 캘린더 / 알림함 |
| **매출·영업 Hub** | 매출홈 / 프로젝트(고객사×모델) / 견적 / 수주 / 출하·수금 / 매출예측 / 매출분석 |
| **자재·구매 Hub** | 자재홈 / 부품마스터 / 단가이력(FIFO) / 공급사 / 발주 / 입고 / 재고(ABC·안전재고) / QC |
| **워크플로우(일순서)** | 4가지 시나리오(T1~T4) / 8문항 마법사 / 일순서 만들기 / 체크포인트(추가·수정·삭제) / IC 페어 모니터 |
| **티켓·이슈·게시판** | 요청 티켓 / 이슈/AS / 부서·전사 게시판 / 변경 공지 |
| **인사·관리** | 외부 그룹웨어 연동(전자결재·메일·근태) / 권한·팀 관리 / 외부자산 점검 |
| **AI(예정)** | Victor 컨시어지 / 한↔베 번역 / 문서 요약·작성 — 공급사 무관(Claude/OpenAI) |

**수치(2026-05-21):**
| 항목 | 수치 |
|---|---|
| 라우트 | **441개** (`@app.get/post`) |
| main.py 라인 | 20,280 |
| HTML 템플릿 | **165개** + 워크플로우 8개 |

### B. KNK Messenger — 사내 업무 전용 메신저 (`10_KNK_Messenger/`)
"일반 메신저로 안 풀리는 **대화→자동 정리된 아이템별 이력**" 해결. Flask + Socket.IO.

| 영역 | 기능 |
|---|---|
| **아이템 카드** | 방 = 고객사×모델, 메타데이터(상태/납기/담당) 방 속성으로 |
| **요청 승격** | 메시지 옆 📌 → 담당·마감 추적 가능한 티켓으로 |
| **일간 다이제스트** | 로그인 시 지연/오늘마감/이번주/내 요청 자동 표시 |
| **아이템 대시보드** | 전체 카드 그리드, 검색·필터·정렬 |
| **갤러리·타임라인** | 사진·파일 시간순, 모든 이벤트 날짜별 그룹 |
| **FTS5 검색** | 한글 토크나이저 + 전문검색 |
| **PWA + Web Push** | 휴대폰 알림, 앱 설치, 백그라운드 알림 |
| **AI 보조** | 일간 요약 / 작성 톤 조정 (한국어 1순위) |
| **번역** | 한↔베 양국어 동시 발송 (받는 사람만 번역되는 한계 극복) |
| **상태/Presence** | 자리비움·회의중·외근·방해금지 + PC 활성 시 모바일 푸시 억제 |

**수치:** app.py 9,331 라인 / 템플릿 3 / 인터넷 배포 가이드(AWS Lightsail) 완비 / 부하테스트(140명) 통과.
