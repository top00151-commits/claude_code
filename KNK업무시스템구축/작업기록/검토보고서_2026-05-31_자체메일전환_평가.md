# 검토 보고서 — 자체 메일 서버 전환 평가 (D안)

- **작성:** 빅터(Victor)
- **일자:** 2026-05-31
- **요청:** 대표 — "하이웍스 메일을 직접 운영(자체 전환) 가능성 검토"
- **성격:** 의사결정 지원용 평가. **착수 아님.** 실행하려면 별도 결재(기존 정책 변경) 필요.
- **관련 정책:** [system_scope_policy] "하이웍스 전자결재·메일 계속 사용"(절대준수 확정) — D안은 이 정책의 **변경**을 전제로 함.

---

## 1. 결론 요약 (먼저)

> **권고: 자체 메일 서버 전면 전환은 현 시점 비권장.** 대신 **하이웍스 유지 + 플랫폼 연동(A안)** 또는 **하이브리드(자체발송 릴레이만)**가 비용·리스크 대비 유리.
>
> 자체 메일의 가장 큰 벽은 비용이 아니라 **"상대방에게 안 막히고 도착하는가(전달성)"** 와 **상시 운영 인력**입니다. 중소기업이 가장 자주 실패하는 지점입니다.

---

## 2. 선택지 3가지

| 안 | 내용 | 메일주소 | 운영 주체 |
|----|------|----------|-----------|
| **① 하이웍스 유지(현행)** | 그대로 사용 + 플랫폼은 SMTP/IMAP로 연동(A안) | 하이웍스 | 가비아(외주) |
| **② 하이브리드** | 수신/보관은 하이웍스, **발송 일부만** 자체 또는 외부 발송전용 서비스 경유 | 하이웍스 | 일부 자체 |
| **③ 완전 자체 전환(D)** | 메일 서버 직접 구축·운영(NAS 또는 클라우드 VM) | 자체 도메인 | **사내 상시 운영** |

## 3. 평가 기준별 비교

### 3-1. 전달성(Deliverability) — ★가장 중요
- 자체 메일은 **SPF·DKIM·DMARC** 정확 설정 + **고정 IP 평판** 관리가 안 되면, 보낸 메일이 거래처 **스팸함行 또는 차단**됩니다.
- 신규 IP는 "평판 0"에서 시작 → 워밍업 수개월 필요. 한 번 블랙리스트 등재되면 해제가 까다로움.
- 하이웍스(가비아)는 이미 검증된 IP·인증 체계를 보유 → **현행이 압도적으로 안전.**
- **판정:** 자체 전환 시 가장 큰 리스크. 영업·견적 메일이 안 닿으면 직접적 사업 손실.

### 3-2. 운영·보안 부담
- 자체: 24/7 가동, 스팸·바이러스 필터, 백업, 장애 대응, 보안 패치, 침해 대응 → 사실상 **메일 담당자 상시 필요**
- 보안 사고(계정 탈취·스팸 발신원 악용) 시 회사 도메인 평판 전체가 타격
- **판정:** 전담 인력/전문성 없으면 위험. 하이웍스는 이 부담을 외주화한 것.

### 3-3. 비용
- 하이웍스: 계정당 월 구독료(예측 가능, 운영비 포함)
- 자체: 서버/VM·고정IP·스토리지·백업 + **숨은 비용 = 운영 인건비·장애 리스크**. 표면 비용은 낮아 보여도 총소유비용(TCO)은 인건비에서 역전되기 쉬움
- **판정:** 계정 수가 많지 않으면 자체가 더 비쌀 수 있음. (정확한 비교는 현재 하이웍스 월 비용·계정수 확인 필요)

### 3-4. 법·보존·연속성
- 메일 보존·감사 추적·퇴사자 계정 인계 등 요건을 자체로 갖춰야 함
- 단일 장애점(NAS 1대) 위험 — 메신저·WORKS와 같은 NAS면 동반 장애 위험

---

## 4. 하이브리드(②) — 절충안

- **수신·보관·계정관리 = 하이웍스 유지**(전달성·보안 부담 회피)
- **발송만** 플랫폼에서: ⓐ 하이웍스 SMTP 경유(A안, 추가비용 0) 또는 ⓑ 외부 발송전용 서비스(대량 발송 시) 경유
- 사실상 **A안이 곧 하이브리드의 실속 버전**. 자체 인프라 부담 없이 "플랫폼에서 메일 발송" 효과를 얻음.

---

## 5. 권고 & 의사결정 체크리스트

**권고:** ① 하이웍스 유지 + A안 연동 (필요 시 발송만 ②로 확장). ③ 완전 자체 전환은 아래가 모두 충족될 때만 재검토.

자체 전환(③)을 진지하게 고려하려면 다음을 먼저 확보해야 함:
- [ ] 메일 서버 상시 운영 가능한 **전담 인력/전문성**
- [ ] **고정 IP + 역방향 DNS(PTR) + SPF/DKIM/DMARC** 운영 역량
- [ ] 스팸필터·백업·이중화(단일 장애점 제거) 설계
- [ ] 현 하이웍스 비용 대비 **TCO(인건비 포함) 실제 비교 우위**
- [ ] 전달성 사고 시 영업 손실 감수 가능 여부 판단
- [ ] 기존 정책("하이웍스 메일 계속 사용") **변경 결재**

## 6. 다음 단계 제안

1. **즉시 가치:** A1(하이웍스 SMTP 발송 연동) 먼저 구현 → "연락처/문서에서 바로 메일 발송" 효과
2. **데이터 보완:** 자체 전환을 계속 검토하실 경우, 현재 ① 하이웍스 월 비용 ② 계정 수 ③ 전담 인력 가용성 — 이 3가지를 주시면 **TCO 정량 비교표**로 보강하겠습니다.
