## 0. 한 줄

외부 ERP(더존비즈온의 클라우드 SaaS ERP, ≠ iCUBE 온프레미스)의 자재는 **Smart A 10 물류관리** 모듈에서 6 메뉴(발주서 → 입고처리 → **자재출고처리 BOM전개** → 생산지시 → 생산입고현황 → 재고/매출마감/전자세금계산서)로 흐르며, 외부 연결은 **developer.외부 ERP.com/api 개발자 포털 + 파트너 어댑터(신한 뱅크인 등) + 외부 메일/2단계 인증 + CSV/엑셀 백업** 4채널로 제공. KNK는 외부 그룹웨어 사용 중·외부 ERP 사용 중 아님(system_scope_policy 인용).

## 1. 자재 정리·취합 핵심 (사실 인용)

### 1.1 자재 흐름 6 메뉴 (외부 ERP 고객센터 확인)

```
발주서 → 입고처리 → [BOM전개] 자재출고처리 → 생산지시 → 생산입고현황 → 재고/매출마감/전자세금계산서
```

**검증 출처**:
- 2024-09-12 물류관리 업데이트: **"자재출고처리 BOM전개 기능 개선"** 명시
- 생산지시현황: 지시번호별·일자별·품목별 3 탭
- 생산입고현황: 입고번호별·일자별·품목별 3 탭

### 1.2 BOM 3종 + MRP·MPS 자동 (공식 솔루션 페이지)

- **Engineering BOM·공정경로 BOM·프로젝트 BOM** (3종)
- "MPS를 자동으로 불러와 자재소요계획을 효율적으로 산출"
- "재고 현황을 실시간으로 확인하여 주문, 출고, 수금까지 전체 진행 현황을 한눈에 파악"
- "실제원가를 자동으로 산정"

### 1.3 가격 (korea-erp.com)

- Club ₩20,000/월 + ₩3,000/유저
- Pro ₩30,000/월 + ₩6,000/유저

## 2. 외부 연결 4 채널

| # | 채널 | URL | 용도 |
|---|---|---|---|
| 1 | **REST API 개발자 포털** | developer.외부 ERP.com/api | 외부 앱 read/write |
| 2 | **외부 ERP H 자체 클라우드** | douzone.com/product/외부 ERPh.jsp | 대규모 통합 |
| 3 | **외부 메일 계정 연동** | 네이버·다음 2단계 인증 | 메일 통합 |
| 4 | **파트너 어댑터** | 신한 뱅크인(급여이체)·세무사 T edge | 모듈 단위 통합 |

**연동 패턴 3종**:
- P1. 외부 ERP API → KNK Pull (협력사 데이터 가져오기)
- P2. KNK → 외부 ERP API Push (KNK가 회계·세무 백엔드로 사용)
- P3. CSV/엑셀 백업 (Smart A 백업·복구 메뉴)

**⚠️ 검증 한계**:
- developer.외부 ERP.com/api 직접 fetch 시 **ECONNREFUSED** — 일시 점검 가능성, 공식 엔드포인트 목록 미수집
- 외부 ERP 고객센터 일부 페이지 **403** — 검색 미리보기로만 메뉴명 확인

## 3. KNK 컨텍스트 정합성 (정책 인용)

- KNK = **외부 그룹웨어(가비아)** 사용 중. 외부 ERP(더존) **사용 중이 아님**.
- 03 §13.8 기존 노트: "외부 그룹웨어 ≠ 외부 ERP 주의"
- system_scope_policy: "외부 그룹웨어 전자결제·메일 계속 사용"
- 외부 ERP 자재 연결 시 4가지 의도 시나리오 가능 (A 협력사 / B 회계·세무 백엔드 / C 도입 검토 / D 자체 설계 참고)
