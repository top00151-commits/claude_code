## 1. 검증된 KNK 실 사실 (실 양식 직접 분석)

### 1.1 회사 메타
- 등록사명: **(주)케이엔케이** | 결산기수: **17기** | 회기: 2026.01.01~2026.12.31 | 매니저: **허동준**

### 1.2 자재 마스터 규모
- **품목등록 6,042 품목 × 33 컬럼** (조달구분·품목계정·코드·품명·분류 3단·단위 4종 12컬럼·창고·표준원가·실제원가·적정재고·세금계산서명·거래명세서명·사용여부)
- 보유 자재 **1,985** (현재고총괄)
- prefix: KNKD(시트류)·KNKK(부품)·KNKJ(부품)·KNK-P(PCB)·외부코드(SB684ZZ 등)

### 1.3 트랜잭션 채번 (검증)
- 발주서: **POZ + YYYYMMDD + 5자리** (예: POZ2026010100031) — 1월 526건
- 자재출고: **IWK + YYYYMMDD + 5자리** (예: IWK2026020200001)
- 마스터·라인 **2 파일 분리** (1-1 헤더 / 1-2 라인)

### 1.4 현재고 = 7가지 입출고 분류
- 입고: 구매·생산·외주제품·**합계**
- 출고: 판매·생산·외주자재·**합계**
- 기초 + 입고합계 − 출고합계 = 기말

### 1.5 KNK 실 인력
- 구매팀 0050: 오용균(0298)·박성준(0295) 2 입력자
- 매니저: 허동준 (WEHAGO 메인 계정)

### 1.6 KNK 호기·프로젝트 코드 (실 양식 비고)
- 000T2026 = 검사기 공용 (연단위)
- 001T2602 = Bach RCV SPK-MIC 검사기**(LEFT)**
- 002T2602 = Bach RCV SPK-MIC 검사기**(RIGHT)**
- 003T2602 = Sig29 ASSY 검사기
- 008T2601 = Q8 FRC SUB PBA VK 성능검사기
- 패턴: **3자리 + T + YYMM**

→ **메신저 시드 호기(003M2501·WP-LOA·HM-001·M2504)와 별개 체계** — 매핑 필요!

### 1.7 단가 매트릭스 (image2·3·6 직접 검증)
- 매입 7단가 (코드 11~17: 상한·정상·하한·설정1~4)
- 매출 7단가 (코드 21~27 동일)
- + **거래처별 예외등록** (광원전기 003654 / 우리산전 004124 등)

### 1.8 WEHAGO 실 화면 UI 패턴 (image3·6)
- 노란색 헤더 (WEHAGO 로고 + ONE AI)
- 좌·우 분할 + 우측 다중 그리드 (3분할)
