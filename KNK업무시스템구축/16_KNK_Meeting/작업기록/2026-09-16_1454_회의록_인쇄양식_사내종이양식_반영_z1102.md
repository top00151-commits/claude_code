## 1. 무엇을 고쳤나

회의록 상세 화면의 **「📄 회의록 양식」**(`/meetings/{id}/doc`) 인쇄·PDF 화면을,
대표가 사진으로 주신 **사내 종이 회의록 양식** 모양 그대로 다시 짰다.

### 사진(종이 양식) ↔ 새 화면

| 사진 | 새 화면 |
|---|---|
| 좌상단 가로 로고 (KNK / Human & Ai create the Best / HAIST Innovation) | `/static/logo.png` 원래 가로 비율로 (예전엔 52×52 네모 안에 찌그러져 있었음) |
| 「회 의 록」 큰 글씨, 글자 간격 넓게 | `.doc-title span` — 글자 간격 .62em, 꼬리 여백은 음수 여백으로 상쇄해 정확히 가운데 |
| 결재란: 결/재 \| 담당 \| 검토 \| 승인 + 도장칸 + 날짜 `/` 줄 | `table.appr` 그대로 (담당칸에 작성자 이름을 흐리게 표시) |
| 회의명 / 일시 / 회의장소 / 부서·작성자 | `table.form` 4줄 |
| 「참 석 자」 띠 + 부서 \| 성명(서명) 3쌍 × 3줄 | `.band` + `table.att` (사람이 많으면 줄이 늘어남·최소 3줄) |
| 「안&nbsp;&nbsp;&nbsp;건」 띠 + 큰 빈 칸 | `.band.wide` + `.body` — **AI 정리 본문 + 결정사항 표 + 할 일 표**가 여기에 들어감 |

- A4 세로 1장 기준(`@page { size: A4 portrait; margin: 12mm }`), 「🖨 인쇄 / PDF 저장」 그대로.
- 휴대폰(≤840px)에서는 로고·결재란이 겹치지 않게만 줄인다(양식 구조는 동일).

### 사진에 없지만 남긴 것 (대표께 보고·승인)
1. 맨 아래 작은 회색 줄 — 문서번호 · 공개범위 · 연결 프로젝트/영업기회
2. 결재 「담당」 칸의 작성자 이름 (종이는 빈칸)

## 2. 자동으로 채워지는 값

| 양식 칸 | 값 | 비고 |
|---|---|---|
| 회의명 | `meetings.title` | |
| 일시 | `meeting_date` + 요일 + **시작 시각** | 시각은 `msg_started_at`(회의 알림 「회의 시작」으로 만든 회의록)이 **같은 날짜일 때만**. 모르면 날짜만 — 추측하지 않는다 |
| 회의장소 | `meetings.location` | 없으면 빈칸(`—` 아님 — 종이 양식이니까) |
| 부서/작성자 | `팀이름 / 이름 직책` | 부서가 없으면 빗금 없이 이름만 [[knk_name_display_rule]] |
| 참석자 부서·성명 | `meeting_attendees` → `users`·`teams` 조인 | **사번으로 연결된 사람만** 부서·직책이 붙는다. 외부 참석자(계정 없음)는 이름만, 부서 칸은 빈칸 |
| 안 건 | `meetings.summary` (AI 정리 본문) | `핵심:` 줄과 `[안건명]` 줄은 굵게, 빈 줄은 그대로 살림 |
| 결정사항 / 할 일 | `meeting_decisions` / `meeting_actions` | 없으면 표 자체를 만들지 않음(종이처럼 빈 칸으로) |

베트남 직원 이름은 기존 규칙대로 `Nguyen Van A (응우옌반아) 프로` 로 나온다.

### main.py 에 추가한 도우미
- `_mtg_doc_att_rows(atts, per_row=3, min_rows=3)` — 참석자를 3쌍씩 줄로 묶고 빈칸을 채운다(최소 3줄)
