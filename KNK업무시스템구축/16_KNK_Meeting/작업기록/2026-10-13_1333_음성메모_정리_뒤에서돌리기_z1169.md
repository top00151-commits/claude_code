### 서버 (`main.py`)

| | |
| --- | --- |
| `_VN_SUM_JOBS` | 🔴 받아쓰기와 **따로** 적는다 — 한 칸을 같이 쓰면 「올리기 → 받아쓰기 → 곧바로 정리」 흐름에서 서로의 상태를 덮어쓴다 |

| `POST …/extract` | **시작만 알린다** → `{"ok":true,"started":true}` · 이미 하고 있으면 `{"already":true}` |
| `GET …/extract-status` | `idle` / `running` / `done` / `error` |
| 지울 때 | `_VN_SUM_JOBS` 도 같이 치운다 |

🔵 **사람이 바로 알아야 할 것은 그대로 즉시 답한다** — 로그인 · AI 꺼짐 · 남의 메모 · 내용 없음.

### ⓑ 🔴 **한도는 사슬이다 — 이번엔 「답 길이 → 걸리는 시간 → 앞단 기다림」**

메모리에 이미 **「한도는 하나가 아니라 사슬이다」**(파일 한 개 · 요청 봉투 · 앞단 웹서버)가 적혀 있었다.
**같은 모양의 함정에 다시 빠졌다** — 이번 사슬은 길이가 아니라 **시간**이었다.
⏭ 사슬을 셀 때 **용량만이 아니라 시간도** 셀 것.

### ⓒ **「서버는 성공했는데 화면은 실패」가 가장 헷갈린다**

대표에겐 **실패로 보였지만** 정리는 멀쩡히 저장돼 있었다. 신고를 받고 **먼저 DB 를 본 것**이

⏭ **「안 된다」 신고는 화면 글만 믿지 말고 저장된 값부터 볼 것.**
