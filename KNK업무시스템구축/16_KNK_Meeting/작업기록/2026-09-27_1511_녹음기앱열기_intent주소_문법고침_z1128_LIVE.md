| 근거 | 내용 |
| --- | --- |
| `Intent.parseUri` (AOSP) | `if (data.startsWith("intent:")) { data = data.substring(7); }` → **「//」가 남고**, `if (data.length() > 0) intent.mData = Uri.parse(data);` 로 **그 「//」가 요청의 데이터가 된다** |
| `IntentFilter.matchData` (AOSP) | 걸개에 data 칸이 없으면 `return ((type == null && data == null) ? MATCH… : NO_MATCH_DATA);` → **MAIN·LAUNCHER 걸개는 data 가 없으니 「//」 붙은 요청은 아무 앱에도 안 걸린다** |
| 그래서 | 크롬이 열 앱을 못 찾아 **어느 기종에서도 곧바로 fallback**(안내 화면)으로 떨어졌다 — 단추를 눌러도 녹음기가 열릴 수 없었다 |
| 크롬 문서 | "Only activities with the category filter, android.intent.category.BROWSABLE can be invoked using this method." → **BROWSABLE 을 적어 둔 앱만** 열 수 있다(삼성 녹음기가 그 표시를 가졌는지는 **대표 휴대폰에서만 판정**) |
