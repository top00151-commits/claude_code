## 2. 🔴 먼저 고칠 것 — 「⏳ 정리 중」이 **아무것도 안 돌 때도** 뜬다

`_meeting_msg_stage`(이음웍스 · 이음 카드와 모아보기 탭이 둘 다 이것을 쓴다):

```
정리 글 있음                         → done
받아쓰기(STT) 작업이 도는 중          → processing
받아쓰기 작업이 실패                  → failed
녹음 중                              → started
녹음 파일 또는 받아쓴 글이 있음        → recorded   ← 🔴 여기
그 밖                                → started
```

- `recorded` 는 「녹음은 있는데 정리 글이 없다」일 뿐, **지금 무언가 돌고 있다는 뜻이 아니다.**
  그런데 이음 카드·모아보기 탭 모두 `recorded` 를 「⏳ 정리 중」으로 보여 준다.
- 🔴 **AI 정리 작업**(z1170 부터 뒤에서 돈다)은 단계 판단에 **들어 있지 않다** → AI 정리가 실패해도 「⚠ 정리 실패」가 안 뜬다.
- 🔴 서버가 다시 켜지면 작업 기록이 사라져 「실패」도 사라지고 `recorded` 로 돌아간다.

### 고칠 방향 (이음웍스 · 단계 값 5개는 그대로 — **뜻만 정확하게**)

| 단계 | 바뀐 뜻 |
| --- | --- |
| `processing` | 받아쓰기 **또는 AI 정리**가 **지금 도는 중**일 때만 |
| `failed` | 받아쓰기 **또는 AI 정리**가 실패 · 또는 녹음은 있는데 **몇 분째 아무것도 안 돌고** 정리도 없음(= 사람 손이 필요) |
| `recorded` | 녹음이 막 들어와 다음 단계가 곧 시작될 짧은 사이(몇 분)만 |
| `done` · `started` | 그대로 — **「📋 회의록 등록」 알림 기준(`done`)은 안 바뀐다** |

→ 이음 v854 화면은 그대로 둬도 멈춘 회의가 「⚠ 정리 실패 + 🔄 다시 정리」로 보인다(막다른 곳 없음).
→ 이음 v853 이하에서도 해가 없다(실패 = 「다시 시도 + 회의록 열기」).
