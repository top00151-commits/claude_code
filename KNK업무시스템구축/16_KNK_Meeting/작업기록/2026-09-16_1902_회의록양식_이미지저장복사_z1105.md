## 1. 무엇을 만들었나

회의록 양식 화면(`/meetings/{id}/doc`) 위 도구줄에 빨간 **「🖼 이미지 저장·복사」** 버튼.

```
누름 → (1~2초) 이미지 만들기 → 미리보기 창
         ├ 양식 한 장 전체가 한눈에 (휴대폰에서 안 보이던 문제 해결)
         ├ 💾 이미지 저장
         ├ 📋 이미지 복사
         └ 닫기   + "이미지를 길게 눌러도 저장·복사" 안내
```

| 항목 | 내용 |
|---|---|
| 이미지 모양 | **휴대폰에서 눌러도 A4(794px) 양식 모양 그대로** — 사진의 종이 양식과 같은 모습 |
| 선명도 | 기기 배율(최소 2·최대 3배). 삼성 폰 2382×3018 약 0.5MB / PC 1588×2012 약 0.3MB |
| 파일 이름 | `회의록_제목_날짜.png` (파일 이름에 못 쓰는 `\ / : * ? " < > \|`·제어문자 제거, 제목 40자) |
| 💾 저장 | 아이폰 = 공유 창 → 「이미지 저장」 / 안드로이드·PC = 내려받기 (휴대폰은 갤러리 「Download」 앨범) |
| 📋 복사 | 클립보드에 PNG 한 장 → 카카오톡·이음·메일에 붙여넣기. 안 되는 기기는 "이미지를 길게 눌러 복사" 안내 |
| 두 번 누르는 이유 | 휴대폰은 저장(공유)·복사를 **누른 그 순간**에만 허락. 이미지를 만드는 1~2초 사이에 그 순간이 지나감 → 미리보기에서 한 번 더 (이음 「📸 대화 캡처」 v574 와 같은 이유·같은 흐름) |
| 인쇄 | 미리보기 창·버튼은 인쇄에 안 나옴 (종이 양식 그대로) |

### 방식
- **html2canvas 1.4.1** — 이음이 7월(v573 「📸 대화 캡처」)부터 운영에서 쓰는 **바이트 동일 파일**을
  `01_HAIST_WORKS/static/vendor/html2canvas/html2canvas.min.js` 에 두었다(MIT 표기 유지, sha256 `e87e5507…eab8cb`).
  인터넷(외부 CDN)에서 받지 않는다. 버튼을 누를 때만 불러온다(평소 화면 속도 영향 없음).
- 화면에 보이는 양식을 **복사해 화면 밖에 둔 사본**(`.sheet.cap`)을 그린다 — 휴대폰 화면이 깜빡이지 않는다.

### ⚠ 앞으로 이 파일을 고칠 때
- 휴대폰 전용 줄임 규칙은 **반드시 `.sheet:not(.cap)` 아래**에 둘 것. 아니면 이미지가 휴대폰 모양으로 찌그러진다.
- 이미지 사본만 `border-collapse: separate` + 칸마다 오른쪽·아래 한 줄. html2canvas 가 붙은 테두리(collapse)를
  **칸마다 따로 그려 가로줄이 두 겹**(2~5px 들쭉날쭉)이 되던 것을 실측해 고침(고친 뒤 1줄로 고름). 화면·인쇄 모양은 그대로.
