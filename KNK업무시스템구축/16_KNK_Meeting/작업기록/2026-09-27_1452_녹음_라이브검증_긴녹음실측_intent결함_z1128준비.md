## 2. 🔴 찾은 결함 — 「📱 녹음기 앱 열기」가 어느 기종에서도 안 열린다

운영에 올라간 주소(삼성폰):

```
intent://#Intent;action=android.intent.action.MAIN;category=android.intent.category.LAUNCHER;
package=com.sec.android.app.voicenote;S.browser_fallback_url=…;end
```

안드로이드·크롬 **공개 소스와 문서를 직접 받아** 확인했습니다(짐작 아님).

| 근거 | 내용 |
| --- | --- |
| `Intent.parseUri` (AOSP) | `if (data.startsWith("intent:")) { data = data.substring(7); }` → `intent://` 는 **「//」가 남고**, `if (data.length() > 0) intent.mData = Uri.parse(data);` 로 **그 「//」가 intent 의 데이터가 된다** |
| `IntentFilter.matchData` (AOSP) | 걸개에 data 칸이 없으면 `return ((type == null && data == null) ? MATCH… : NO_MATCH_DATA);` → **MAIN·LAUNCHER 걸개는 data 가 없으니 「//」 붙은 요청은 아무 앱에도 안 걸린다** |
| 결과 | 크롬이 열 앱을 못 찾아 **곧바로 fallback**(=「자동으로 열지 못했습니다」 안내)으로 떨어진다 |

➡ **고침(z1128)**: 데이터 부분 없이 `intent:#Intent;action=…` 로 적는다(크롬 문서의 문법: 호스트/경로는 **선택**).

## 3. 🔴 그래도 남는 제약 — 크롬은 「BROWSABLE」을 적어 둔 앱만 연다

크롬 공식 문서:

> "Only activities with the category filter, android.intent.category.BROWSABLE can be invoked using this method, as it indicates that the application is safe to open from the Browser."

- 삼성 「음성 녹음」의 시작 화면이 그 표시를 적어 두었는지는 **앱 속을 볼 수 없어 이 PC 에서 확인 불가** → **대표님 휴대폰에서만** 판정됩니다.
- 안 열리면 화면은 **바로 「홈 화면에서 「음성 녹음」을 직접 열어 주세요」** 안내로 돌아옵니다(그 길도 **똑같이 계속 녹음**되고, 끝나면 「공유 → KNK WORKS」로 붙습니다 — 이 길은 위 1절대로 이미 검증됐습니다).
- 그래서 z1128 에서는 **화면 글도 사실대로** 고쳤습니다: 단추 부제 「녹음기 앱에서 녹음하면 다른 앱을 봐도 안 끊겨요」 · 안내 「크롬이 막아 안 열리는 기종도 있습니다 — 그때는 홈 화면에서 「음성 녹음」을 직접 열어 주세요(효과는 같습니다)」.
