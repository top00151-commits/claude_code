## 3. 🔴 할 때 조심할 것 (이미 걸려 본 것)

1. **한글을 다 바꾸면 안 된다** — 뽑아 보면 **주석·CSS 주석·코드 조각**이 섞여 나온다
   (예: `;   // 칸이 없는 옛 응답`, `120000) { loadFirst(); return; }   // 2분마다…`).
   → **사람이 보는 글만** 고른다. 주석은 한국어로 그대로 둔다(다음 사람이 읽어야 한다).

   → **화면 단위로 완성**해서 올린다. `meetings.html` → `meeting_form.html` 순서.
3. **JS 안에서 만드는 글**이 많다(카드·경고·상태줄). 템플릿 `{{ i.키 }}` 로는 안 된다.
   → 화면 맨 위에 `var I = { … }` 로 **필요한 말만** 내려 주고 JS 가 그걸 쓰게 한다.
4. **이음과 말을 맞춘다** — 내가 새로 지어내지 않고 **용어집(1,909 짝)** 에 같은 글이 있으면 그 말을 쓴다.
