2. 기준값 `curl https://works.knknara.co.kr/api/version` → `{"v":"…"}` 200(000 이면 다시).
3. 운영 바쁜가(4절 busy) · 08:50~09:30 금지.
4. 되돌림 표시 `git tag rollback-YYYYMMDD-HHMM <origin/main>` → 푸시 · 원격 확인.
5. 따로 쓰는 `GIT_INDEX_FILE` 로 `read-tree origin/main` → 내 파일만 `hash-object -w --no-filters` + `update-index --cacheinfo` → `write-tree` → 바뀐 파일 수 확인 → `commit-tree -p origin/main` → `git push origin <sha>:main`.
6. 확인: 버전 200·형식·기준값과 다름 · NAS 커밋 `mirror: … @ <모노7>` · md5 · 기동 뒤 오류 0 · 배포 직전 DB 사본.
