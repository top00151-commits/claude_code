## 1. 고친 곳 — WORKS 한 줄, 메신저는 무접촉

이음 카드의 「📋 회의록 보기」 버튼은 **WORKS 가 알려준 주소를 그대로** 엽니다.

```
WORKS  POST /api/meeting/msg/status  →  items[msg_id].url
  ↓
이음   _minlink_land(url)   # '/meetings/…' 로 시작하는 내부 경로만 통과
  ↓    WORKS_LANDING_URL + "?next=" + quote(url)
이음   /sso/login?redirect_uri=<land>  → WORKS /sso/land → next 경로 착지
```

그래서 **WORKS 가 주는 `url` 만 바꾸면** 이음 코드는 한 줄도 건드릴 필요가 없다.

| 단계 | 카드에 보이는 것 | 착지 |
|---|---|---|
| `done` (정리 끝) | 「📋 회의록 보기」 | **`/meetings/{id}/doc` = 회의록 양식** ← 이번에 바뀜 |
| `failed` (정리 실패) | 「⚠ 정리 실패 — 회의록에서 다시 시도」 + 「📋 회의록 보기」 | `/meetings/{id}` 회의록 화면 (그대로) |
| `started` / `recorded` / `processing` | 안내 문구만(버튼 없음) | `/meetings/{id}` (그대로) |

> **왜 실패 단계는 양식으로 안 보내나**: 양식은 읽기 전용이라 거기서는 「🔄 다시 시도」를 누를 수 없다.
> 카드 안내문이 "**회의록에서** 다시 시도"라고 말하는 바로 그 화면으로 보내야 말이 맞는다.

「▶ 회의 시작」(`msg/start`) 쪽 `?autorec=1` 녹음 화면은 **그대로 두었다**(양식으로 가면 녹음이 안 된다).
볼 수 없는 사람에게 주소 자체를 주지 않는 규칙도 그대로.

### 바뀐 코드 (`app/main.py` · `api_meeting_msg_status`)
```python
if can_view:                  # 볼 수 없는 사람에겐 회의록 주소 자체를 주지 않는다
    it["meeting_id"] = m["id"]
    # 「📋 회의록 보기」 착지 (대표 지시 2026-09-16): 정리가 끝났으면 **회의록 양식**으로 바로.
    #   양식은 읽기 전용이라, 아직 손봐야 하는 단계(정리 실패 등)는 고칠 수 있는 회의록 화면으로 보낸다
    #   — 카드 안내문이 "회의록에서 다시 시도"라고 말하는 그 화면.
    it["url"] = (f"/meetings/{m['id']}/doc" if it["stage"] == "done"
                 else f"/meetings/{m['id']}")
```
