## 📐 발주서 표준 양식

각 발주서는 다음 8섹션을 포함:

1. **세션 정체성** — "당신은 실무팀N..."
2. **권한 폴더** — 작업 가능 경로 명시
3. **작업 범위** — 페이지 목록 (URL + 파일 + 기능)
4. **표준 (절대 준수)** — `_STANDARDS/` 참조
5. **참고 자료** — 디자인 핸드오프, 의뢰서 등
6. **현재 상태** — 적용 완료 시점 + 미완 항목
7. **금지 사항** — DB / chrome / 다른 팀 영역
8. **완료 기준 + 빅터 보고 양식**

## 🔄 통합 흐름

```
[대표] ──────► 발주서 작성 (이 폴더)
                    │
[각 실무팀] ────► 작업 진행 (자신의 권한 폴더)
                    │
[빅터(01)] ──────► 변경 파일 + diff 검수
                    │
                    ├─ 충돌 ─► 해당 팀 재작업 지시
                    │
                    └─ 안전 ─► main 적용 + 롤백 태그
```

## ⚠️ 주의

- 발주서는 **대표 또는 빅터만** 신규 작성
- 각 팀이 자체 발주서 변경 금지
- 변경 필요 시 빅터에게 요청 → 빅터가 새 버전(.v2.md) 발행
