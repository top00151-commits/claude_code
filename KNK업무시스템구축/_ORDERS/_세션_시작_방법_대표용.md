## 🔄 통합 흐름

```
[대표] ─► 위 메시지로 3개 세션 시작
   │
[실무팀1/2/3] ─► 각자 작업 진행 (병렬)
   │
[빅터(01) — 현재 세션] ─► 각 팀 output/HANDOFF_TO_01.md 받아 통합
   │
   ├─ 충돌 없음 ─► main 적용 + 롤백 태그
   └─ 충돌 발생 ─► 해당 팀에 재작업 지시 (직접 수정 안 함)
```

## 🔔 빅터(01)에 작업 보고하는 방법

각 팀이 작업 끝나면:
1. `output/HANDOFF_TO_01.md` 작성 (양식은 INSTRUCTIONS.md 9번 참조)
2. 변경 파일 목록 + diff 요약 포함
3. 대표님께 "팀N 작업 완료, 빅터에 통합 요청" 통보
4. 대표님이 빅터(01) 세션에 "팀N 산출물 통합해" 지시
5. 빅터가 검수 → 충돌 없으면 main 적용 → 롤백 태그 생성

## ⚠️ 주의사항

- 각 세션은 **자기 팀 폴더에서 시작** (cwd가 해당 팀 폴더)
- 다른 팀 폴더 / 다른 세션 폴더 절대 침범 금지
- DB / chrome / 라우트 / Jinja 변수 변경 금지
- 외부 라이브러리 추가 금지
