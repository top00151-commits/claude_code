## 5. 🟡 Medium

### LAW-007 [Medium] 디자인/트레이드드레스 모방 의도가 소스에 명시

**실측 근거** (대표 예시):
```
static/css/style.css:674  "화면 안 토스트 — 카카오톡PC 스타일"
static/css/style.css:762  "메시지 컨텍스트 메뉴 — 카카오톡PC 스타일"
static/css/style.css:1530 "컴포저 — 슬랙 스타일(대표 지시 2026-05-19)"
static/js/app.js:883      "더블클릭 → 그 방만 새 창 — 카카오톡PC 와 같은 멀티윈도우"
templates/chat.html:585   "Slack AI / Teams Copilot 식"
```

**위협**: UI를 특정 타사 제품과 동일하게 만들었다는 **모방 의도가 코드에 기록**됨. 트레이드드레스(상품外观) 분쟁 시 고의성 입증의 불리한 증거. (기능적 UI는 보호 약하나, 기록된 의도는 별개 리스크.)

**시정 지시 (10 메신저 세션)**:
- 주석을 기능 중립어로 변경 ("토스트 알림 우하단 슬라이드", "컴포저 상단 툴바형").
- 특정 타사 화면을 픽셀 단위로 복제하지 않았음을 자체 점검.

### LAW-008 [Medium] 코드·문서 내 타사 브랜드명 약 200건

**실측 근거**: 한글 86건/18파일 + 영문 114건/6파일.
- 다수는 리서치 문서(`docs/메신저_리서치_*.md` — 비교분석 성격)·기술 주석.
- 리서치 목적의 언급은 불가피하나, 내부 정책(`외부 제품 익명화 규칙`)은 **내부 문서에서도 익명 라벨 사용**을 권고.

**시정 지시 (10 메신저 세션)**:
- 리서치 문서는 익명 라벨(메신저 A/B/C)로 치환 또는 "대외비·내부 한정" 표기.
- 코드 주석의 브랜드명은 점진적으로 중립어 치환 (LAW-007과 병행).

### LAW-009 [Medium] 오픈소스 통합 라이선스 고지 파일 부재

**실측 근거**: requirements.txt 라이브러리(Flask/Flask-SocketIO/gunicorn/eventlet/pywebpush/cryptography/openpyxl/Pillow/anthropic)는 모두 permissive이나, 통합 `THIRD_PARTY_NOTICES` / `LICENSES` 파일 없음.

**위협**: 사용 자체는 합법이나, BSD/Apache 등은 **고지 의무**가 있어 배포 형태에 따라 미이행 소지.

**시정 지시 (10 메신저 세션)**:
- `THIRD_PARTY_LICENSES.md` 생성 — 라이브러리별 라이선스·저작권 고지 일괄 수록.
- 폰트 2종(이미 LICENSE 동봉)도 이 문서에 인덱싱.

## 6. 🟢 자문 필요 (감사팀 판단 영역 밖)

### LAW-010 [자문필요] 특허·실용신안 충돌 가능 영역

**식별된 기능** (침해 여부 아님 — 변리사 선행기술조사 필요):
- 메시지 → "요청" 승격 + 마감/담당 추적
- 전달확인(ack) 4종 상태(ok/doing/done/reject)
- 전송 시점 양국어 동시 자동번역
- 이모지 리액션 → 워크플로/결재 트리거 (로드맵)
- FTS5 한글 전문검색

**감사팀 의견**: 위 기능들은 상용 협업툴에 보편적으로 존재하여 **신규 특허 침해 가능성은 일반적으로 낮으나**, 특정 등록특허(국내 KIPO·해외)와의 청구항 대비는 **변리사 선행기술조사**로만 확정 가능. 외부 상용화·SaaS 전환 시 FTO(Freedom To Operate) 검토 권고.

**시정 지시**: 사내 한정 사용 단계에서는 즉시 조치 불요. **외부 판매·타사 제공 전환 시 변리사 FTO 의뢰**.

## 9. 00 감사팀 총평

- **즉시 위험 1건(LAW-001)**: 직원 평문 비밀번호 엑셀이 git에 올라가 있음. 보안감사_02 SEC-001/002와 동일 패턴 — **형상관리에 개인정보·비밀번호를 올리는 습관**이 반복됨. 근본 대책(.gitignore 강화 + pre-commit 차단) 필요.
- **상표권**: 내부 정책(규칙 3)이 명문화되어 있음에도 코드·UI·DB·문서 전반에 타사 브랜드명 약 200건 잔존. 특히 **사용자 대면 배포물·DB 시드 메시지**는 우선 정리 대상.
- **저작권(스티커)**: 외부 IP 직접 복제 증거는 없으나 **출처 입증 자체가 불가** — "권리 있음"을 증명 못 하면 분쟁 시 불리. 문서화 또는 재제작 필요.
- **개인정보·국외이전**: 운영 중인 시스템인데 처리방침·동의·국외이전 고지가 모두 부재 — 직원 대상이라도 최소 사내 고지문 필요.
- **특허**: 사내 한정 사용 동안은 리스크 낮음. 외부 판매 전환 시 변리사 FTO 필수.

**감사팀 권고**: LAW-001은 오늘 내 처리. 나머지는 "외부 인터넷 운영 중"임을 감안해 1~2주 내 정리. 외부 상용화 검토 시점에 변리사·변호사 정식 자문 1회 필수.
