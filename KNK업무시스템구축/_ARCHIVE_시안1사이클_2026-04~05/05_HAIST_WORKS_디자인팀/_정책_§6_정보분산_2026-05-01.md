## 2. 4 분산 패턴 (페이지 종류별)

### 패턴 1. 탭 분산 (Tab Split) — 대시보드·매트릭스
**적용**: home / dashboard / sales_dashboard / weekly

```
┌─────────────────────────────────────┐
│  [오늘] [이번주] [이번달] [전체]     │  ← 탭
├─────────────────────────────────────┤
│  ┌─────────┐                        │
│  │ 핵심 KPI │  ← 한 탭 = 핵심 1-2개  │
│  └─────────┘                        │
│  보조 카드 2-3개 (한 row)             │
└─────────────────────────────────────┘
```

- 한 탭당 카드 5개 이하
- 첫 탭 = 가장 자주 보는 것 (오늘)
- 탭 전환 = 페이지 로드 X (JS·SPA)

### 패턴 2. 접기 (Collapse) — 폼·상세
**적용**: po_form / quotation_form / po_detail / customer_detail

```
┌─────────────────────────────────────┐
│  ▼ 기본 정보 (펼침)                  │
│    [입력 필드]                       │
│  ▶ 결제·배송 (접힘)                  │  ← 클릭 시 펼침
│  ▶ 첨부 파일 (접힘)                  │
│  ▶ 메모·이력 (접힘)                  │
└─────────────────────────────────────┘
```

- 첫 섹션만 펼침 (필수 입력)
- 나머지는 접기 (사용자 선택 시 펼침)
- 진행률 인디케이터 상단 (어디까지 작성했는지)

### 패턴 3. 드로어 (Drawer) — 리스트·검색
**적용**: po_list / customers_list / search

```
┌─────────────────────────────────────┐
│  [필터 ☰] 검색           내보내기    │  ← 도구바
├─────────────────────────────────────┤
│  [표·카드 리스트 — 한 화면 전체]      │
└─────────────────────────────────────┘

[필터 ☰] 클릭 →
┌──────────────┐┌──────────────────┐
│              ││ 표·카드           │
│ 필터 패널     ││                  │
│ - 기간        ││                  │
│ - 등급        ││                  │
│ - 담당        ││                  │
└──────────────┘└──────────────────┘
```

- 필터·인사이트 = 드로어 (기본 숨김)
- 메인 영역 = 데이터 우선
- 일괄 액션 바 = sticky bottom

### 패턴 4. 페이지네이션 강화 — 무한 스크롤 X
**적용**: 모든 리스트 페이지

```
이전 v5: 무한 스크롤 (스크롤 과대)
신 v6:   페이지네이션 + 페이지당 25 행 표준
         (10·25·50·100 선택 가능)
```

- 페이지당 25 행 (현 시스템 표준화)
- 정렬·필터 후 자동 1 페이지로
- 카드뷰 ↔ 표뷰 토글 (모바일 최적화)

## 4. 정보 위계 시각 표준

### 4-1. 한 화면 우선순위 (시선 흐름)
```
1순위 (좌상단·중앙): 핵심 KPI 1-2개 (font-3xl)
2순위 (가운데):     보조 카드 2-3개 (font-xl)
3순위 (하단):       데이터 표·리스트
4순위 (드로어):     필터·인사이트·이력 (숨김)
```

### 4-2. 폰트 크기 위계 (사용성)
- h1: 32px (페이지 타이틀)
- h2: 26px (섹션)
- h3: 22px (카드 제목)
- 본문: 15px (이전 14 → 가독성 ↑)
- 라벨: 12px (이전 11 → 가독성 ↑)

### 4-3. 색 위계 (절제)
- 1순위 KNK 레드: VIP·CTA·필수·경고 (5% 미만)
- 2순위 검정 ink: 강조 (헤드라인·중요 데이터)
- 3순위 회색 mute: 메타·부수
- **그 외 색 사용 금지** (앰버·녹·청·보라 등)

## 5. 빅터(05) 검증 의무 — 사용성 5종 grep

| # | 검증 | 기준 |
|---|---|---|
| **U-1** | 한 화면 카드 수 | ≤ 5 (탭·접기·드로어 사용) |

| **U-3** | 무한 스크롤 잔존 | = 0 (페이지네이션 강제) |
