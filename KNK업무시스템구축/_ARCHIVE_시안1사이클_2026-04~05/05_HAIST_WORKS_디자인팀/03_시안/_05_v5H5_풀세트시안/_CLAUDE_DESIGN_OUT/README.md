| **C-1** | 시각 일관성 (KNK 톤) | 색·타이포·모서리·그림자 시안 표준 정합 |

```
5. 빅터(05) 검증 (5종 grep) — 즉시 가동 (정책 §5-6 5분 SLA)

   - 카테고리 폴더로 이동
   - 빅터(05) Jinja2 inject 통합본 작성
   - _TO_01 반영 발주서 발행

   - 폴더 보존 + 회신
   - 재변형 요청
```
