## 1. 자동 검증 7종 grep (Claude Design 자가검증과 교차 확인)

### U-1. 한 화면 카드 ≤ 5
```
grep -c '<div class="card"' [파일]
grep -c 'class="kpi"' [파일]
```
→ 각 페이지에서 시각적 카드 5개 초과시 ⚠

### U-2. 콘트라스트 ≥ 7:1
- 본문 색·배경 색 추출 → WCAG AAA 계산기 통과 확인
- 일반적 통과: `#111` on `#FFF` = 19:1 ✅
- 일반적 실패: `#999` on `#FFF` = 2.85:1 ❌
- 액센트 텍스트도 확인

### U-3. 무한 스크롤 = 0
```
grep -E 'IntersectionObserver|infinite|loadMore' [파일]
grep -E 'onscroll' [파일]
```
→ 결과 0건이어야 합격. 페이지네이션 사용 확인:
```
grep -E 'pagination|페이지|next|prev' [파일]
```

### U-4. 액센트 색 ≤ 5%
- KNK 레드 `#A5282C` 또는 선정 컨셉 액센트 사용 비율
- HTML 캔버스 렌더 → 픽셀 카운트 (가능시)
- 또는 CSS 검사: 액센트 색이 `background:` 채움 ≤ 3 곳

### U-5. 모서리 일관성
```
grep -oE 'border-radius:[^;]+' [파일] | sort -u
```
→ 한 컨셉 내 종류 ≤ 2가지 (예: 8px, 9999px=원형 만 허용)

### U-6. 외국 상용 제품명 노출 0건
```
grep -iEf [비공개_금지어_사전.txt] [파일]
```
→ 결과 0건. 검출 대상은 **비공개 금지어 사전**(05 디자인팀 내부 1부, 공유 문서 미기재)으로 관리. 산출물에 작업 도구 자체 브랜드도 노출 0건(화이트라벨).

### U-7. 영문 코멘트 라벨 0건
```
grep -E '//[^>]*[A-Z_][A-Z_0-9]+' [파일]
grep -iE 'monospace' [파일]
```
→ 고정폭(monospace) 글꼴을 한국어 본문에 적용시 ❌

## 2. 정성 검증 5종 (페르소나 시뮬레이션)

빅터(05)가 각 페르소나 시점에서 화면을 보며 평가:

### P-1. 김 부장 (52, 영업)
- [ ] 첫 화면 진입시 "오늘 할 일"이 한눈에 보임
- [ ] 견적 작성 폼이 단계별로 명확함
- [ ] 글씨 크기 ≥ 14px (본문)
- [ ] 컬러 의존 정보 없음 (색맹 시뮬레이션)

### P-2. 이 차장 (48, 자재)
- [ ] 표 정보가 압축적·식별 가능
- [ ] 정렬·필터·검색이 직관적
- [ ] 행 높이 ≥ 36px (마우스 클릭 여유)
- [ ] 페이지네이션 명확

### P-3. 박 과장 (45, 생산)
- [ ] 모바일 (768px 이하) 진입시 메뉴 접근 쉬움
- [ ] 칸반 보드가 모바일에서도 작동
- [ ] 터치 타겟 ≥ 44px

### P-4. 최 대리 (35, 회계)
- [ ] 표·차트의 숫자 가독성 (숫자 우측 정렬·천단위 콤마)
- [ ] 인쇄시 양식 정렬 정상

### P-5. 김 대표 (60, 의사결정)
- [ ] 대시보드에서 KPI 4개 즉시 인지 (3초 룰)
- [ ] 결재 화면에서 빅터 AI 요약 1줄로 결정 가능
- [ ] 색 화려하지 않음 ("차분"한 느낌)
