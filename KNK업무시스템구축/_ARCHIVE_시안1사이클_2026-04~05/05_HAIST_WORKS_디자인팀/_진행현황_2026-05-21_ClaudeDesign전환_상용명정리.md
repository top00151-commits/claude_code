## 1. Claude Design 전환 — 빅터(05) 역할 변경

### 1-1. 역할 (확정)

| 빅터(05)가 하는 일 ✅ | 안 하는 일 ❌ |
|---|---|
| 요구사항·페르소나·정책 정리 | HTML/CSS 직접 작성 |
| Claude Design 의뢰 **브리프 작성** | 색·레이아웃 자율 결정 |
| 결과물 **검증**(grep + 페르소나) | 컨셉 자율 발의 |
| 대표 보고·다음 단계 발주 | 시안 직접 디자인 |

> ⚠ 빅터는 Claude Design을 **직접 호출하는 API 도구가 없음**. Claude Design은 web.claude.ai에서 사람이 사용하는 별개 제품 → 빅터 역할 = **브리프 작성 + 결과 검증** (대표가 붙여넣기).

### 1-2. 구축한 의뢰 인프라

```
05_HAIST_WORKS_디자인팀/03_시안/_07_ClaudeDesign_의뢰/
├── 00_README_사용법.md
├── 01_브리프/
│   ├── BRIEF_00_마스터_오리엔테이션.md   ← 새 채팅마다 첫 메시지
│   ├── BRIEF_01_v6_3컨셉_5페이지.md       ← 컨셉 비교(15장)
│   ├── BRIEF_02_풀세트_13마스터.md         ← 풀세트(30+장)
│   ├── BRIEF_03_페르소나_walkthrough.md   ← 업무 흐름(30장)
│   └── BRIEF_04_보조페이지_에러로딩빈상태모바일.md
├── 02_결과물/   ← Claude Design 산출물 저장 위치

```

### 1-3. 모든 브리프 공통 강제 사항
- 페르소나: 50~60대 한국 직원 (김 부장 52·이 차장 48·박 과장 45·최 대리 35·대표 60)
- 이전 실패 3원인 회피: **눈 피로 · 구분 약함 · 정보 과밀**
- 정책 §6 정보 분산 4패턴: 탭 분산 · 접기 · 드로어 · 페이지네이션(무한 스크롤 금지)
- 자가검증 7종: 카드 ≤5 · 콘트라스트 ≥7:1 · 무한스크롤 0 · 색 ≤5% · 모서리 일관 · 외국 상용명 0 · 영문 코멘트 라벨 0
- KNK Red `#A5282C` 액센트 5% 이내, Pretendard 글꼴

### 1-4. 대표 다음 액션 (3단계)
1. claude.ai/design 접속(Pro 구독) → 새 채팅에 `BRIEF_00` 붙여넣기 + KNK 로고 첨부
2. "이해했습니다" 응답 → `BRIEF_01` 붙여넣기
3. 결과물 → `_07_ClaudeDesign_의뢰/02_결과물/`에 저장 → 빅터에게 알림 → 빅터 검증

## 2. 상용 제품명 전수 정리 (법적 리스크 제로화)

### 2-1. 원칙
- 모든 산출물에서 외국·국내 상용 제품명 **직접 거론 금지**
- 스타일은 **"특징 묘사"**로만 (예: "특정 외국 협업툴" / "결제 대시보드 스타일")
- 중립 명칭 통일: **외부 그룹웨어 / 외부 ERP / 외부 메신저 / 문서형 협업툴 / 고정폭 글꼴** 등

### 2-2. 처리 결과

**✅ 정리 완료 (05 디자인팀 전 영역 · 약 60+ 파일)**
- 활성 시안(v6 컨셉비교·풀세트), 브리프, 디스패치
- 정책·원칙 문서, 개선제안, 핸드오프(_세션01_전달), Phase 문서
- 레퍼런스 카탈로그, 옛 시안(v2~v5H5), 아카이브, 백업(.bak)
- 폴더·파일명 익명화: **MujiWhite→순백미니멀 · NotionCalm→차분슬레이트 · LinearMono→전문사무**
- 최종 검증 grep = **0건** (예외 항목 제외)

**🛡 일부러 남긴 항목 (지우면 오히려 위험/무의미)**
| 항목 | 이유 |
|---|---|
| **Pretendard · Lucide** 고지 | 실제 사용 오픈소스 — **라이선스가 이름 표기(attribution) 요구**. 지우면 라이선스 위반(새 법적 리스크) |
| 시스템 글꼴 폴백(Consolas 등) | OS 내장 폰트 기술 선언, 상표 문제 없음 |
| `_비공개_금지어사전.txt` | 검출 전용 단어목록 1부 (공유 금지) — 정리 도구 자체 |
| 영어 코드 식별자(`hiworks_*`)·외부 API 엔드포인트 URL | 실제 코드/연동 식별자 → **01팀 코드 단계에서 별도 처리(staged)** |

**📤 01팀 발주 (직원 배포 화면 — 법적 우선순위 높음)**
- `_세션01_전달/_TO_01_2026-05-21_상용제품명_배포템플릿_정리지시.md`
- 순서: (a) 화면 텍스트 → (b) CSS 폰트 → (c) 코드 주석 → (d) 라우트·변수(단계적)

**🟡 대표 별도 판단 영역 (빅터 권한 밖)**
- **03 리서치 / 10 메신저** 의 경쟁 분석 문서 — 분석 대상이라 실명 필요. 발주 여부 대표 지시 대기.
