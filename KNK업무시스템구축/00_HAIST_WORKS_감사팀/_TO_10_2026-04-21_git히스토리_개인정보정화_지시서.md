## 2. 실행 (filter-repo)

> 🚨 히스토리 재작성 = force push 필요. **백업 후, 대표 승인하에, 01 지시서와 동시에** 실행 권장 (같은 저장소이므로 한 번의 filter-repo 패스로 01의 파일들과 함께 처리하는 게 효율적).

### 권장: 01 지시서와 통합 실행
01 세션의 `_TO_01` 지시서 3순위 (c) 단계에 **경로 한 줄만 추가**하면 한 번에 처리됨:
```bash
cd "C:/Users/top00/JR/Claude 코드"
# 백업 (01 지시서와 공유 — 한 번만)
# git clone --mirror "Claude 코드/.git" "...BACKUP....git"

pip install git-filter-repo

git filter-repo --invert-paths \
  --path "KNK업무시스템구축/01_HAIST_WORKS/data/_credentials_2026-04-28.csv" \
  --path-glob "KNK업무시스템구축/01_HAIST_WORKS/data/knk.db.*" \
  --path "KNK업무시스템구축/10_KNK_Messenger/등록자정보.xlsx" \
  --force

git remote add origin git@github.com:top00151-commits/claude_code.git
git push origin --force --all
git push origin --force --tags
```

### 단독 실행 시
```bash
git filter-repo --invert-paths --path "KNK업무시스템구축/10_KNK_Messenger/등록자정보.xlsx" --force
```
